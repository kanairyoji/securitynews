GhostEmperor

公開されている脅威インテリジェンスと一次資料から整理したもの。 事実と評価を分けて書いています。

一言でいうと

GhostEmperor は、中国語話者による長期のサイバースパイ活動として複数のベンダーが別々の名前で追ってきたグループである。Trend Micro は自社の呼称 Earth Estries について「Salt Typhoon、FamousSparrow、GhostEmperor、UNC2286 の別名でも知られる」と整理し、2023年以降、米国・アジア太平洋・中東・南アフリカの通信事業者と政府機関という重要産業を中心に狙う、中国系 APT のなかでも最も攻撃的なグループの一つになったと述べている [7]。標的の規模は、Trend Micro が JSAC2025 で示した被害者像で標的国10か国以上・標的組織20以上（8業種以上）、活動期間は「少なくとも2019年から現在まで」とされる [1]。MISP galaxy は、東南アジアの政府機関と通信事業者を標的とし、Demodex という Windows のカーネルモードルートキットで標的サーバを遠隔操作する、アンチフォレンジック・アンチ解析に長けた集団だと記述している（骨格）。

素性

国と言語。 MISP galaxy は GhostEmperor を「中国語話者の脅威アクター（Chinese-speaking threat actor）」とする（骨格）。Trend Micro は Earth Estries を「中国の APT グループ（a Chinese APT group）」と呼ぶ [7]。Cisco Talos は、この一連の道具を共有する別クラスタ UAT-8302 について「中国系（China-nexus）の APT」と高い確度で評価しているが、GhostEmperor そのものの帰属主体には踏み込んでいない [4]。どの資料も、中国語話者・中国系という水準で止まっており、背後の政府機関を名指ししたものは読んだ範囲には無い。

名前が一つに収束していない。 これはこのアクターを読むうえで最も重要な前提である。Trend Micro は JSAC2025 の発表で、UNC2286 と Salt Typhoon は他組織が GhostEmperor や FamousSparrow として追っているキャンペーンと活動が重なる脅威グループ／クラスタを指し、Trend Micro の呼称である Earth Estries もまた GhostEmperor と FamousSparrow に帰属された活動と重なる、と説明している [1]。同社は2024年11月の記事で、Microsoft が FamousSparrow と GhostEmperor を Salt Typhoon の名前で追跡していることに触れつつ、「Earth Estries が最近報じられた Salt Typhoon のサイバー攻撃と関係するという十分な証拠は無い。Salt Typhoon についてのより詳細なレポートを見ていないため、現時点で確認できるのは Earth Estries の TTP の一部が重なるということだけである」と明記した [7]。台帳が持つ別名は Salt Typhoon、GhostEmperor、FamousSparrow、UNC2286、RedMike、OPERATOR PANDA の6つだが（骨格）、このうちどこまでが同一実体かは、資料の中でも決着していない。

FamousSparrow としての出自。 ESET は2021年に、ホテル・政府・民間企業を世界規模で狙う新しいサイバースパイ集団を FamousSparrow と名付けた。同社は、このグループを独自バックドア SparrowDoor の唯一の利用者とみなし、独立した実体と考える一方で、他の既知 APT との接点も見つけている——ある事例では SparklingGoblin が使うローダー Motnug の亜種が展開され、別の事例では侵害端末上で DRBControl に関連するドメイン cdn.kkxx888666[.]com を C2 とする Metasploit が動いていた [5]。

道具の系譜。 Trend Micro が JSAC2025 で挙げた道具一覧は DEMODEX、TrillClient、ZINGDOOR、GHOSTSPIDER、SparrowDoor、MASOL（別名 Backdr-NQ）、CrowDoor、SNAPPYBEE（別名 Deed RAT）、POPPINGBEE（別名 SHADOWPAD）、HEMIGATE である [1]。Malpedia が本グループ固有と帰属しているのは MASOL（elf.masol）、DracuLoader（win.dracu_loader）、HemiGate（win.hemigate）、SNAPPYBEE（win.snappybee、別名 Deed RAT / POISONPLUG.DEED）、SparrowDoor（win.sparrow_door）の5系統（骨格）。なお Google Threat Intelligence Group は、POISONPLUG を「PRC を拠点とする複数の、しかしおそらく関連した脅威グループが使う高度なモジュール型バックドア」と評価し、POISONPLUG / POISONPLUG.DEED / POISONPLUG.SHADOW の3つの亜種を追跡していると述べている。ただし同資料が使用を APT41 関連クラスタに限定しているのは POISONPLUG.SHADOW のほうであり、資料本文に GhostEmperor や Earth Estries の名前は出てこない [9]。

日本のセキュリティコミュニティとの関わりは、被害側ではなく解析側である。 JSAC2024 では Cyber Defense Institute と Trend Micro の研究者が Earth Estries の HemiGate を他の RAT と突き合わせて解析し [2]、伊藤忠サイバー＆インテリジェンスは Tropic Trooper の調査の過程で、既存の SparrowDoor Loader から読み込まれる新種マルウェア CrowDoor を発見して FamousSparrow との関係を論じている [3]。いずれも日本の組織が被害に遭ったという記述ではない。

これまでの活動

  1. 2019年8月
    ESET は FamousSparrow が少なくともこの時期から活動していたとし、主に世界各地のホテルを標的にしていたと述べている。ほかに政府、国際機関、エンジニアリング企業、法律事務所を、ブラジル・ブルキナファソ・南アフリカ・カナダ・イスラエル・フランス・グアテマラ・リトアニア・サウジアラビア・台湾・タイ・英国で少数観測している [5]。
  2. 2020年
    Trend Micro は Earth Estries が少なくとも2020年から活動していたとする [6]。同社は2020年に東南アジアの政府機関の事案を調査する中で、後に MASOL RAT と名付けるクロスプラットフォームのバックドアを発見したが、当時は情報が限られ既知のグループに結びつけられなかった [7]。
  3. 2021年3月3日
    Microsoft Exchange の ProxyLogon 脆弱性の悪用を開始する。パッチ公開の翌日である。ESET はこれを、2021年3月に ProxyLogon の遠隔コード実行を手にしていた10以上の APT グループの一つとして記録している [5]。
  4. 2023年
    Trend Micro が Earth Estries の新しいサイバースパイキャンペーンを発見する。標的はフィリピン・台湾・マレーシア・南アフリカ・ドイツ・米国の政府機関と技術産業で、TTP に FamousSparrow との重なりが認められた [6]。
  5. 2023年10月12日〜2024年4月2日
    C2 サーバ 23.81.41[.]166:80 が稼働していたとみられる期間。Trend Micro は2023年10月にこの C2 上で検体を観測し、SNAPPYBEE の2組の検体（C2 は api.solveblemten[.]com と esh.hoovernamosong[.]com）、frp の設定ファイル sql.toml（C2 は 165.154.227[.]192）、PowerShell スクリプトを含む onedrived.zip、および frpc・NeoReGeorg トンネル・fscan といった公開ツールを見つけている [1]。
  6. 2024年
    Trend Micro が、Earth Estries が Linux 機器上に MASOL RAT を展開して東南アジアの政府ネットワークを狙っていることを観測する。同じ年、東南アジアの通信事業者への攻撃の中で新しいバックドア GHOSTSPIDER を発見。被害は20を超える組織に及び、通信・技術・コンサルティング・化学・運輸の各産業と、多数の国の政府機関・NGO が含まれる [7]。
  7. 2025年
    Trend Micro が「Premier Pass」と名付けた事例を公表する。Earth Estries が侵害済みの資産を、別の中国系グループ Earth Naga（別名 Flax Typhoon / RedJuliett / Ethereal Panda）にアクセスブローカーとして引き渡し、後者が継続的に侵害を進めるというもので、両者の直近の焦点は APAC の小売と政府関連組織だとしている [8]。

手口

入口は公開サーバの脆弱性である（T1190）。 ESET は FamousSparrow の初期侵入を、インターネットに面した脆弱な Web アプリケーションと特定した事例があるとし、Microsoft Exchange（2021年3月の ProxyLogon を含む）、Microsoft SharePoint、そしてホテル管理業務ソフトウェアである Oracle Opera の既知の遠隔コード実行脆弱性を悪用したとみている [5]。Trend Micro も Earth Estries について「公開サーバの脆弱性を悪用して初期アクセスを確立し、ネットワーク内の横展開には living-off-the-land バイナリを使う」と要約する [7]。なお JSAC2025 の発表は、frp の C2 として使われた 165.154.227.192 がいくつかの Ivanti 脆弱性の悪用レポートでも言及されている、という接点を指摘しているが、Earth Estries が Ivanti を悪用したとは述べていない [1]。

DLL サイドローディングが一貫した実行手段である。 SparrowDoor は3つの要素——正規の K7 Computing 製実行ファイル Indexer.exe（サイドローディングの宿主）、悪性 DLL K7UI.dll、暗号化シェルコード MpSvc.dll——を %PROGRAMDATA%\Software\ に置いて起動する。K7UI.dll は Indexer.exe のコードにパッチを当て（call WinMain を jmp K7UI.0x100010D0 に書き換える）、WinMain の代わりに自分の中のルーチンへ制御を移し、そのルーチンが同じディレクトリの MpSvc.dll を読み込んで復号・実行する。永続化の設定後は -i 引数付きで起動される（ほかに -k、-d の引数がある）。ESET が回収できたのはローダー部分のみで（SHA-1: E2B0851E2E281CC7BCA3D6D9B2FA0C4B7AC5A02B）、VirusTotal 上の類似ローダー（SHA-1: BB2F5B573AC7A761015DAAD0B7FF03B294DC60F6）から欠けていた構成要素、すなわち SparrowDoor 本体を見つけている [5]。

HemiGate も同じ形をとる。JSAC2024 の解析によれば、ProgramData\WinDrive\ に、サイドローディングの宿主となる正規実行ファイル taskhask.exe、それが読み込む悪性 DLL K7AVWScn.dll、暗号化された Dracu Loader を含む taskhask.doc、HemiGate の設定を持つ taskhask.dat が置かれる。復号は、暗号化ペイロード内に埋め込まれた鍵を使う RC4 である [2]。同発表は HemiGate と、日本の組織を狙う別系統 RatelS を突き合わせ、第1段階はコードの類似は無いが手法が似ており、第2段階はインメモリ PE ローダーが異なり（Dracu Loader と Mofu Loader）、ペイロードにはコードや設定など実装レベルの類似が認められる、と結論している [2]。

ルートキット DEMODEX の投入は多段である。 JSAC2025 の解析によれば、感染連鎖は PSEXEC → cmd.exe → powershell.exe -ex bypass c:\windows\assembly\onedrived.ps1 password@123 という形をとる。解析には2つの条件が要る——第1段階の PowerShell スクリプトは復号鍵を引数として要求し、第2段階のサービスローダーはコンピュータ名を AES 鍵として使う。加えて制御フロー平坦化（Control Flow Flattening）による難読化がかかっている [1]。Trend Micro はこの DEMODEX と GhostEmperor との結びつきについて、文字列が base64 で符号化されている点が違いだと述べている [1]。

侵害後は living-off-the-land と公開ツールで進む（T1588.002）。 JSAC2025 が挙げる Campaign Alpha の侵害後コマンドは、WMIC.exe /node: /user: /password: process call create によるリモートでのプロセス生成、expand c:/windows/debug/1.zip c:/windows/debug/notepadup.exe（win32up.exe の場合もある）による frp クライアントの展開、-c c:/windows/debug/sql.toml での frp 起動、ping 165.154.227.192 -n 1 > c:\Windows\debug\info.log による C2 到達性の確認、tasklist /v によるホスト情報の収集、そして wevtutil qe security /format:text /q:"Event[System[(EventID=4624)]" によるログオンユーザ（ユーザ名とログオン元 IP）の抽出である。PsExec は ps.exe にリネームして C:\Windows\assembly\ から /accepteula 付きで動かす [1]。Trend Micro は2023年の記事でも、内部サーバを侵害したあと管理者権限を持つ既存アカウントを乗っ取り、Cobalt Strike を導入し、SMB と WMIC で他の端末へバックドアとハッキングツールを広げる、という流れを記述している [6]。

ESET が FamousSparrow の侵害サーバ上で観測した道具立ては、Mimikatz の亜種（2つの独自版があり、事案の紐づけに使える）、ProcDump をディスクに落として lsass プロセスをダンプする小さなユーティリティ、NetBIOS スキャナ Nbtscan、そして SparrowDoor のローダーである [5]。

痕跡を減らす運用が徹底している。 Trend Micro は2023年の記事で、AMSI（Windows Antimalware Scan Interface）のログ機構による検知を避けるために PowerShell のダウングレード攻撃を使うこと、そして各作戦ラウンドの終了ごとに既存のバックドアを定期的に掃除し、次のラウンドを始めるときに新しいマルウェアを置き直すことを報告している。露見と検知のリスクを下げるためだとみている [6]。MISP galaxy も、多様なアンチフォレンジック・アンチ解析技術で検知を回避すると記述している（骨格）。

持ち出しは正規サービスに紛れ込ませる。 Earth Estries は GitHub、Gmail、AnonFiles、File.io といった公開サービスをコマンドの受け渡しや盗んだデータの転送に悪用する。各ラウンドの終わりに指定フォルダから収集したデータを書庫にまとめ、標的としていた PDF ファイルと DDF ファイルを curl.exe で AnonFiles や File.io にアップロードしていた [6]。

トンネリングで C2 を隠す（T1572）。 frp（frpc／notepadup.exe／win32up.exe）、NeoReGeorg トンネル、そして Campaign Beta では SoftEther VPN が使われている [1]。

独自マルウェアを自前で作る（T1587.001）。 DEMODEX、GHOSTSPIDER、SparrowDoor、CrowDoor、MASOL、HemiGate、ZINGDOOR、TrillClient がその系統である [1]。伊藤忠サイバー＆インテリジェンスは、既存の SparrowDoor Loader から CrowDoor という別種のマルウェアが読み込まれる第2段階を確認しており、これが FamousSparrow との関係を論じる出発点になっている [3]。Cisco Talos は2026年に、SNAPPYBEE/DeedRAT と ZingDoor を組み合わせて展開する手口が Trend Micro によって2024年に指摘されたものと同じであること、および汎用シェルコードローダー Draculoader が Earth Estries と Earth Naga の両グループでも使われていることを記録している [4]。

動機は情報収集であり、標的の選び方に一貫性がある。 JSAC2025 の整理では、複数の政府機関を狙い、通信事業者を継続的に攻撃し、加えて政府や通信事業者と取引関係のある組織（技術企業、NGO など）を狙う、という三層になっている。米国の NGO が狙われた理由として同発表が挙げるのは、その NGO が議会・連邦機関・ホワイトハウス・評議員・高等教育コミュニティと連絡を取り合っていること、顧客に軍部隊向けの訓練サービスを提供していること、そして組織のリーダー・政策立案者・実務者にデータと分析を提供していることである [1]。

ATT&CK との対応について。 骨格が挙げる14技術のうち、読んだ9本の資料で裏づけられるのは T1190（公開アプリケーションの悪用）、T1587.001（マルウェアの開発）、T1588.002（ツールの入手）、T1572（プロトコルトンネリング）の4つである。残る10技術——T1590.004（ネットワーク構成の偵察）、T1098.004（SSH 認可鍵）、T1136（アカウント作成）、T1040（ネットワーク盗聴）、T1110.002（パスワードクラッキング）、T1021.004（SSH）、T1602.002（ネットワーク機器の設定ダンプ）、T1048.003（非 C2 の平文プロトコルによる持ち出し）、T1685.006（Linux/Mac のシステムログ消去）、T1686（ファイアウォールの無効化・改変）——は、いずれも本記録が読んだ資料には対応する記述が無い。

最近の動き

本グループ自身の活動として公開資料で確認できる最新は、2025年10月に Trend Micro が公表した「Premier Pass」の事例である。Earth Estries がアクセスブローカーとして振る舞い、侵害済みの資産を Earth Naga（Flax Typhoon / RedJuliett / Ethereal Panda）へ引き渡して継続的な侵害を任せた、という中国系 APT 間の協働で、直近の焦点は APAC の小売と政府関連組織だとされる [8]。

2026年5月の Cisco Talos の資料はこれより新しいが、扱っているのは UAT-8302 という別の中国系グループであり、Earth Estries は Draculoader の共同利用者、および SNAPPYBEE/DeedRAT と ZingDoor を組み合わせる手口の先行例として言及されるにとどまる [4]。

したがって、2025年10月以降の本グループ自身の動きは、本記録が読んだ資料からは確認できない。

何が変わったか

ここからは本記録の評価です。

第一に、名前が一つに収束していない状態が続いている。 Microsoft は FamousSparrow と GhostEmperor を Salt Typhoon の傘に入れたが、Trend Micro は2024年11月の時点で、自社が追う Earth Estries と報道された Salt Typhoon 攻撃との関係について「十分な証拠が無い」と明言し、確認できるのは TTP の一部の重なりだけだとした [7]。台帳が持つ6つの別名は、同一実体の別称というより、活動が重なる複数のクラスタの集合と考えたほうが実態に近い。読み手にとっての含意は実務的である——ベンダーの脅威情報を「Salt Typhoon」という一語でフィルタすると、Earth Estries / FamousSparrow / GhostEmperor / UNC2286 の名前で出た情報を取りこぼす。逆に Salt Typhoon の名前で語られる通信事業者侵害の知見を、そのまま GhostEmperor の手口として自組織に当てはめるのも早い。

第二に、標的が「ホテル」から「政府と通信の基幹」へ移った。 2019年から2021年にかけての FamousSparrow は主に世界各地のホテルを狙う集団として記述されていた [5]。2023年以降の Earth Estries は、政府機関と通信事業者、そしてそれらと取引関係のある技術企業・NGO を狙う集団として記述される [1][6][7]。標的の格が上がったというより、収集したい情報の性質が変わったと読める。米国 NGO を狙った理由の説明——議会・連邦機関・ホワイトハウスとの連絡、軍部隊向け訓練サービス、政策立案者への分析提供 [1]——は、最終的に欲しいのは政策と軍事に関わる情報であり、そこへ届く経路として周辺組織が選ばれていることを示している。

第三に、単独の作戦から役割分担へ移りつつある。 Premier Pass の事例は、一つのグループが侵入から収集まで通してやるのではなく、初期アクセスを取ったグループが別のグループに引き渡す形を示した [8]。これは防御側にとって二重に厄介である。マルウェアや TTP の重なりから帰属を組み立てる従来の方法が、複数の侵入セットが同じ被害環境に重なることで通りにくくなる——Trend Micro 自身が、プロセスチェーンの重なりだけを見るのを超える必要があると述べている [8]。加えて、侵害の「終わり」を宣言しにくくなる。最初の侵入者を追い出しても、アクセスが既に別の主体に渡っていれば、対応は終わっていない。

第四に、道具では帰属できなくなっている。 Draculoader は Earth Estries と Earth Naga と UAT-8302 が使う [4]。SNAPPYBEE は Deed RAT の名でも呼ばれ、Trend Micro は「中国系 APT 間で共有される道具」と明記する [7]。POISONPLUG は PRC を拠点とする複数の関連グループが使うモジュール型バックドアだと Google は評価している [9]。Trend Micro は2024年の時点で、TTP が他の中国系 APT と重なることについて、マルウェア・アズ・ア・サービス提供者からの共有ツールの利用の可能性を挙げている [7]。本プロジェクトが「共有ツールを追いかけない」という方針を持っているのは、まさにこの状況に対応するためである。

日本の組織にとっての含意

ここからも評価です。

日本の名指しが無いことを「関係が無い」と読まないほうがよい。ただし、あると読むのも同じくらい根拠が無い。 本記録が読んだ9本の資料に、日本の被害の記述は一つも無い。これは、被害が無かったのか、公表されていないのか、観測されていないのかを区別できない状態である。したがって、日本の CISO にとって GhostEmperor は「差し迫った既知の脅威」ではなく、「標的の型が自組織と重なるかどうかで判断する対象」である。

判断材料になるのは標的の型のほうだ。政府機関、通信事業者、技術企業、NGO、物流、航空、化学、不動産、運輸 [1]。地域は東南アジア、台湾、そして米国 [1][7]。この二つを掛け合わせると、日本企業のアジア拠点、とりわけ台湾・タイ・インドネシア・ベトナム・フィリピンに現地法人を持つ通信・技術・化学・物流の企業は、標的の型に入る。加えて、政府や通信事業者と取引関係のある組織を経由して狙うという明示的な動機 [1] は、自社が直接の標的でなくとも、取引先の名簿に載っていることが理由になりうることを意味する。

初期の標的がホテルだった点は、日本のホスピタリティ産業にとって具体的な示唆になる。 ESET は初期侵入の経路として Oracle Opera を名指ししている [5]。これはホテル管理業務の基幹ソフトウェアであり、宿泊者情報という、政府・軍・企業幹部の移動を追うのに使える情報を持つ。ホテルを狙う動機が窃盗ではなく人の移動の把握にあるなら、日本のホテルチェーンと、その予約・PMS 系のインターネット公開面は、同じ論理の対象になる。

ProxyLogon の翌日悪用は、パッチ適用の目標値を突きつけている。 ESET は、パッチ公開の翌日である2021年3月3日から悪用が始まったと記録している [5]。月次のパッチサイクルは、この相手には間に合わない。公開面の緊急脆弱性については、適用または緩和までの目標を「日」の単位で持つ必要がある。

痕跡が残らない前提で設計する必要がある。 各作戦ラウンドの終わりにバックドアを掃除して置き直すという運用 [6] は、点の検知——ある日ある端末で悪性ファイルが見つかる——に頼る体制では追いつかないことを意味する。侵害が発覚した時点で、直近のマルウェアしか残っていない可能性が高い。長期のログ保全と、過去に遡って探せる状態が、この相手には効く。

取るべき防御

ここからも評価です。資料に出てきた具体的な挙動から、優先度の高いものを並べる。

1. インターネット公開面の棚卸しと、緊急パッチの日単位の目標。 Exchange、SharePoint、ホテル管理システム（Oracle Opera）、VPN・リモートアクセス機器 [5][7]。何が外から見えているかの一覧が無い組織は、まずそこから。ProxyLogon が翌日に悪用された事実 [5] を、パッチ SLA を決める根拠として使ってよい。

2. DLL サイドローディングの検知。 正規実行ファイルが標準でない場所から起動し、同じディレクトリの DLL を読み込む——これがこのアクターの一貫した実行手段である [2][5]。資料に出た具体的な置き場所は %PROGRAMDATA%\Software\、ProgramData\WinDrive\、C:\Windows\assembly\、C:\Windows\debug\ [1][2][5]。この4か所からの実行ファイル起動を検知ルールにするのは、費用対効果が高い。

3. PowerShell のダウングレード実行の検知とログ。 AMSI を迂回するために古いバージョンの PowerShell を呼ぶ手口が明示されている [6]。スクリプトブロックログとモジュールログを有効化し、-version 2 系の呼び出しを検知対象にする。あわせて -ExecutionPolicy Bypass を伴う起動の可視化。

4. WMIC と PsExec によるリモートプロセス生成の監視。 WMIC.exe /node: /user: /password: process call create という形が繰り返し出てくる [1]。PsExec は ps.exe のようにリネームされて使われるため [1]、ファイル名ではなくサービス作成や名前付きパイプの挙動で見る。

5. 偵察コマンドの束での検知。 tasklist /v、wevtutil qe security による EventID 4624 の抽出、ping の結果を info.log に書き出す一連の動き [1]。単体では良性でも、短時間に束で出れば意味を持つ。fscan・Nbtscan といったスキャナの実行も同様 [1][5]。

6. 認証情報の保護。 ProcDump による lsass ダンプと Mimikatz 亜種が定番である [5]。LSA Protection と Credential Guard の有効化、ProcDump の実行そのものの検知。

7. 外向き通信の監視——トンネルと正規クラウド。 frp、NeoReGeorg、SoftEther VPN の通信 [1]。および GitHub・Gmail・AnonFiles・File.io への、curl.exe によるアップロード [6]。特に AnonFiles / File.io のような匿名ファイル共有への通信は、業務上の正当な用途が乏しいので遮断候補にしやすい。

8. Linux 側とネットワーク機器を視界に入れる。 MASOL RAT は Linux 機器上に展開されている [7]。Windows の EDR だけで見ている組織には、この経路が見えない。

9. ログの長期保全。 バックドアを定期的に消して置き直す運用 [6] への対処は、後から遡れることに尽きる。認証ログ・プロセス実行ログ・プロキシログを、少なくとも1年は探せる状態に置く。

10. 名前ではなく振る舞いで追う。 別名が6つあり、道具が複数グループで共有され [4][7][9]、アクセスが別グループに引き渡される [8] 以上、「Salt Typhoon の IoC」を配ってもらって照合する運用では追えない。上の1〜9はいずれも、どのグループ名が付くかに依存しない。

分からないこと

1. 6つの別名がどこまで同一実体か。 Trend Micro は Earth Estries と報道上の Salt Typhoon の関係について、十分な証拠が無いと明言している [7]。骨格が持つ RedMike と OPERATOR PANDA については、読んだ9本の資料に一度も出てこない。どのクラスタがどこまで重なるのかは、資料からは決められない。

2. 日本での被害の有無。 資料に日本の被害の記述は無い。無いのか、公表されていないのか、そもそも観測されていないのかを区別する材料が無い。台帳が本アクターを追跡対象に置いているのは、通信基盤という標的の性質からの判断であって、日本での観測に基づくものではない。

3. 初期侵入で使われた具体的な脆弱性。 ESET が2021年について Exchange・SharePoint・Oracle Opera を挙げている [5] のを除くと、Trend Micro は「公開サーバの脆弱性」という水準でしか述べていない [7]。Campaign Alpha と Campaign Beta で実際にどの CVE が使われたかは資料に無い。frp の C2 165.154.227.192 が Ivanti の悪用レポートにも出るという指摘 [1] は接点の示唆であって、Earth Estries が Ivanti を悪用したという記述ではない。

4. ルートキット DEMODEX の現在の位置づけ。 MISP の説明は Demodex を中核に据えるが（骨格）、2023年以降の資料で主役になっているのは GHOSTSPIDER と SNAPPYBEE である [7]。DEMODEX が今も使われているのか、置き換えられたのかは資料からは分からない。

5. 背後の組織。 中国語話者（骨格）、中国の APT [7]、中国系 [4] という水準で止まっており、どの政府機関のどの部門かを述べた資料は無い。台帳が記録する2025年1月の米財務省による制裁は、本記録の資料の外にある。

6. Premier Pass の性質。 Earth Estries から Earth Naga へのアクセスの引き渡しが、商業的な取引なのか、上位の指揮系統による割り当てなのか、単発の協力なのかは、資料からは判断できない [8]。Trend Micro 自身が四層の枠組みを提示しているのは、この性質が一様でないことの裏返しでもある。

7. ATT&CK 技術のうちネットワーク機器側の10件の根拠。 骨格が挙げる T1602.002（ネットワーク機器の設定ダンプ）、T1098.004（SSH 認可鍵）、T1040（ネットワーク盗聴）、T1685.006（Linux/Mac のログ消去）、T1686（ファイアウォールの改変）などは、通信事業者のルータ侵害を思わせる一群だが、本記録が読んだ9本にはこれらを裏づける記述が無い。Salt Typhoon としての別系統の知見に由来する可能性はあるが、確認できていない。

8. 資料そのものの制約。 本記録が読んだ9本は、いずれも本文の先頭約6,000字までしか材料に入っていない。SparrowDoor 本体のコマンド仕様、GHOSTSPIDER の技術詳細、伊藤忠サイバー＆インテリジェンスによる CrowDoor と FamousSparrow の関係の結論部分、JSAC2025 の帰属（Attribution）の章は、いずれも切れた先にある。ここに書けていないことがある。
