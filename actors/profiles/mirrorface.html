MirrorFace

公開されている脅威インテリジェンスと一次資料から整理したもの。 事実と評価を分けて書いています。

一言でいうと

MirrorFace（別名 Earth Kasha）は、2019年12月から日本の組織を狙い続けている中国系のサイバースパイ集団である [3][5][8]。専用バックドア LODEINFO と NOOPDOOR を使い、標的型メールで政治・外交・メディア・シンクタンクに入り込んできたが、2023年以降は外部公開資産の脆弱性を突く経路に移り、標的も製造業と研究機関へ広がった [1][13]。目的は情報とファイルの窃取であり、破壊や金銭要求ではない [11][13]。

素性

MITRE ATT&CK は MirrorFace（G1054）を中華人民共和国に連なるサイバースパイ実体とし、標的・ツール・インフラの重なりから menuPass（APT10）傘下のサブグループとみている〔ATT&CK G1054〕。ただし帰属の見立ては調査機関で割れている。

機関 見立て 根拠
Kaspersky [9] APT10 に高い確度で帰属（HITCON 2021） 2019〜2020年の LODEINFO 活動の追跡
NFLaboratories [3] 中国の国家を背景とする APT（APT10 か） BISONAL とのコード類似、スピアフィッシングと DLL サイドローディングの類似
ESET [11] 中国語話者のアクター。既知グループには帰属せず MirrorFace として追跡 LODEINFO は MirrorFace 専用のマルウェア
Trend Micro [13] Earth Kasha として追跡。APT10 とは別実体（「APT10 アンブレラ」内） 同一とする証拠が足りない

固有マルウェアは2つ。LODEINFO はメールで配られるファイルレスのバックドアで、検体内にバージョン文字列を持つ [3][5]。NOOPDOOR（別名 HiddenFace）は2022年以降に観測された、侵入後のネットワーク内に居座るためのバックドアである [1]。

これまでの活動

  1. 2019年12月
    JPCERT/CC が日本国内の組織を狙う標的型攻撃メールを確認。添付の不正な Word 文書から、当時未知の LODEINFO に感染させるものだった [5][6]。
  2. 2020年
    JPCERT/CC が LODEINFO（v0.1.2）を公表（2月）[5][6]。新型コロナ、日露・日韓外交、履歴書を装った誘導メールを確認。標的業種はメディア系と公共系で、送信には Gmail 等のフリーメールが使われた。起動方法は rundll32.exe から DLL サイドローディングへ変わった [7]。
  3. 2021年2月
    JPCERT/CC が v0.4.8 を報告。文書へのパスワード付与、白く小さいフォントで隠した文字列といった回避が加わり、ファイル暗号化の ransom とキーロガー keylog が実装された [4]。
  4. 2022年3月〜6月
    感染経路が広がる。3月は Word 文書、6月は SFX ファイル。SFX を使った攻撃は日本政府またはその関連組織を狙い、日本語の囮文書と著名な日本の政治家の名前をファイル名に使っていた。新しいダウンローダー DOWNIISSA も確認された [9]。
  5. 2022年6月29日〜7月
    Operation LiberalFace。参議院選挙（投開票 7月10日）の直前、特定政党の広報部を装い著名政治家名義で「SNS 用動画の拡散のお願い」を送るなどして日本の政治組織を狙った。LODEINFO から追加マルウェア・認証情報・文書とメールが盗まれ、未報告の認証情報窃取ツール MirrorStealer が使われた。侵入後の操作は手動または半手動とみられる [11]。
  6. 2023年
    手口と標的が変わる。標的はメディア・政治団体・シンクタンク・大学から製造業と研究機関へ移った [1]。初期侵入に外部公開資産の脆弱性悪用が加わり、Array AG（CVE-2023-28461）・Proself（CVE-2023-45727）・FortiOS/FortiProxy（CVE-2023-27997）の悪用が確認された。悪用する脆弱性は時期によって入れ替わっていた [13]。JPCERT/CC は同年11月に注意喚起を出し、Array AG と FortiGate の悪用を確認、Proself も可能性があるとした [1]。侵入後は Cobalt Strike・LODEINFO・NOOPDOOR を置いて居座る。標的の地理も日本を主としつつ台湾とインドの一部組織へ広がり、業種は先端技術関連と政府機関だった [13]。
  7. 2024年
    伊藤忠サイバー＆インテリジェンスが v0.6.6〜v0.7.3 を分析し、v0.6.9 でリモートテンプレートインジェクションが使われたことを報告（1月24日）[8]。JPCERT/CC が NOOPDOOR と侵入後 TTP を公表（7月16日）[1]。Trend Micro が Earth Kasha の新キャンペーンを公表（11月19日）[13]。

手口

入り口（T1566.001 / T1566.002 / T1190 / T1221）。2022年までは一貫して Word・Excel のマクロを開かせる標的型メールで [7]、パスワード保護・白文字の隠し文字列・SFX と回避を重ねてきた [4][9]。2023年にはリモートテンプレートインジェクションが加わった。添付の Word 自体は外部のテンプレート（.dotm）を読みに行くだけなので、それ単体では不正と判定しにくい [8]。同時に SSL-VPN やファイル保管サービスの脆弱性という別経路が使われるようになった [13]。

実行と隠蔽（T1204.002 / T1059.005 / T1047 / T1574.001 / T1027.013）。初期は VBA から WMI と rundll32.exe [5][6]、のちに正規実行ファイルを同梱する DLL サイドローディング [7]。NOOPDOOR はシェルコードで正規アプリに自身を注入する。起動経路は XML 内の難読化 C# を MSBuild でビルドする型と、Windows タスクから正規アプリを起動して DLL サイドローディングでローダーを読ませる型の2つ。復号したコードはレジストリへ暗号化して残され、鍵は端末固有の MachineId と ComputerName から作るため他所では復号できない。ローダーは制御フロー平坦化で解析を妨げる [1]。

認証情報（T1003.001 / .002 / .003）。lsass のメモリダンプ、NTDS.dit（vssadmin 等）、SYSTEM・SAM のレジストリハイブ、と3系統から取る [1]。JSAC2024 では copy \\<ホスト>\c$\windows\temp\ntds.dit . のように共有経由で運ぶコマンドが示されている [2]。

探索・横展開・持ち出し（T1087.002 / T1482 / T1033 / T1083 / T1021.001 / T1021.002 / T1560.001）。正規ツールで AD を調べる。実際のコマンドは csvde.exe -f all.csv -u、nltest.exe /domain_trusts、quser.exe。その後ファイルサーバーで dir を再帰的に打ち、操作者は見つけた文書の中身を手で確認していた形跡がある [13]。ネットワーク図・PC 一覧・IP 一覧が RDP のクライアントドライブ（\tsclient\）経由で持ち出され、makecab で圧縮されている [2]。

C2（T1090 / T1071.002）。LODEINFO は HTTP POST で通信し、版が上がるたび暗号と難読化が増えた [3][5][10]。NOOPDOOR は能動・受動の両方を持ち、システム時刻から DGA で生成した宛先へ TCP/443 で出る一方、TCP/47000 で命令を待ち受ける。ファイルのタイムスタンプを書き換える命令もある [1][2]。C2 は日本国内の VPS やホスティング（Vultr・CHOOPA・LINODE 等）に置かれることが多い [3]。

日本語環境の判定（T1614.001）。keylog はレジストリの OverrideKeyboardIdentifier が PCAT_106KEY か、GetKeyboardLayout が 1041 を返すかを見て、日本語キーボードなら打鍵をそれに合わせて変換する。JPCERT/CC はこれを攻撃者が日本語利用者を標的にしている表れだとしている [4]。逆に v0.6.2 では en_US 環境を避ける実装が入った [10]。

日本との関係

層を分けて書く。混ぜると帰属の確度が語れなくなる。

公開情報（本記録が読んだ一次資料13本） — Kaspersky は「日本が LODEINFO の主要な標的とみられる」と明言している [9]。標的業種は資料ごとに、メディア・外交・政府および公共部門・シンクタンク [9]、防衛関連企業・学術機関 [11]、公共機関と学術 [13]、メディア系と公共系 [7] と挙がる。2023年以降は製造業と研究機関 [1]、先端技術関連と政府機関 [13]。台湾とインドにも広がったが、件数の偏りから日本が主標的である点は変わらない [13]。

公開情報（基礎層・MITRE ATT&CK） — 「少なくとも2019年から活動しており、当初はメディア・防衛・外交・金融・製造・学術の各分野で日本の組織のみを標的としていた。その後の作戦には中欧の標的も含まれる」〔ATT&CK G1054〕。

人手（台帳 config/japan_watchlist.yaml） — 2025年1月、警察庁と内閣サイバーセキュリティセンターが、日本を標的とした一連の攻撃を中国系の MirrorFace に帰属すると公表。安全保障・先端技術に関わる組織と個人が対象とされた。台帳の記載であり、本記録が読んだ13本には含まれない。

自前の観測 — 骨格に観測層の記載は無い。本記録は自前の観測を根拠にしていない。

実被害（リークサイト掲載） — 該当なし。

最近の動き

読んだ13本のうち最も新しい一次資料は2024年11月19日の Trend Micro 分析である [13]。公開されている資料は2024年11月までで、それ以降の動きは確認できていない。 骨格が持つ作戦名 Operation AkaiRyū も、13本には記述が無く時期を特定できない。

したがって現時点で確認できる最後の姿は、2023年初頭から2024年初頭にかけての変化——初期侵入が脆弱性悪用へ移り、標的が製造業・研究機関・先端技術へ移り、侵入後は NOOPDOOR で長く居座る形になった——までである [1][13]。

ここから先は本記録の評価です。上の各節は公開資料に基づく事実で、以下は解釈と推論を含みます。

何が変わったか

ここからは本記録の評価です。

入り口が人からモノに移った。 2022年までは時事を材料に受信者へ添付を開かせる集団だった。2023年からは SSL-VPN とファイル保管製品の既知脆弱性を突く。メール訓練で減らせる部分が減り、資産管理とパッチ適用の速度で決まる部分が増えたということになる。

居座る道具が別立てになった。 LODEINFO は入るための道具、NOOPDOOR は残るための道具である。端末固有鍵でレジストリに自分を仕舞い、DGA で宛先を変え、TCP/47000 で受け身にも待ち、タイムスタンプまで書き換える設計は、年単位の滞在を前提にしているように見える。

日本専用から日本中心へ。 台湾・インド、ATT&CK が言う中欧。日本専用という前提は2023年で崩れているが、件数の偏りからは主標的は日本のままである。

日本の組織にとっての含意

対象かどうかは業種では決められない。 2019年はメディアと政治、2023年は製造業と研究機関。移り方を見るかぎり業種ではなく「日本の安全保障・外交・先端技術に関わる情報を持っているか」で選ばれている。系列会社・共同研究先・受託先としてそうした情報に触れる立場なら対象になりうる。

気づけない期間が長い前提で考える。 NOOPDOOR の設計、侵入後の操作が手動だった形跡 [11]、2023年の活動が2024年に公表された事実は、いずれも滞在の長さを示唆する。侵害の有無を「アラートが出ていないこと」で判断すると外す。

効くのは境界製品の棚卸しである。 悪用対象は時期で入れ替わっており [13]、特定 CVE を潰す話ではなく、境界に置いた製品を漏れなく把握して早くパッチを回せるかという体力の話になる。

取るべき防御

骨格の ATT&CK 技術と資料の挙動から、優先順に挙げる（本記録の評価）。

  1. 境界製品の棚卸しとパッチ（T1190）。SSL-VPN・ファイル保管・リモートアクセス製品を資産台帳で押さえる。悪用対象は入れ替わるので個別 CVE ではなく製品群として見る。
  2. lsass と NTDS.dit へのアクセス監視（T1003.001/.003）。JPCERT/CC は Windows Defender/Operational のイベント ID 1011（Trojan:Win32/LsassDump）で lsass ダンプへのアクセスを検知できるとしており、NTDS.dit へのアクセスもイベントログに残る [1]。まずこの2つが取れているか確認する。
  3. 正規ツールの異常な実行（T1087.002 / T1482 / T1033）。csvde -f・nltest /domain_trusts・quser が管理業務以外の端末や時間帯で走ったら疑う [13]。単発では判断できないので短時間に連続する並びを見る。
  4. マクロとリモートテンプレート（T1204.002 / T1221）。マクロの既定無効化に加え、Word が外部からテンプレート（.dotm）を取りに行く通信を検知・遮断する。添付自体が無害に見えるので添付検査だけでは足りない [8]。
  5. 侵入後の足跡を記録する（T1574.001 / T1021.002 / T1560.001 / T1685.005）。正規実行ファイルが %ProgramData%・%TEMP% 等から起動していないか、\\ホスト\c$ への書き込み、\tsclient\ 経由のファイル移動、makecab の実行を見る [1][2]。NOOPDOOR にはファイルのタイムスタンプを書き換える命令があり [1]、骨格の技術一覧にはイベントログの消去（T1685.005）も入っている。ログは端末外へ転送しておく。

骨格に付く IoC（検体ハッシュ140件・ドメイン38件・IP81件）は機械抽出で悪性を検証しておらず、照合先のテレメトリも無い。そのまま検知に使わない。

分からないこと

  1. APT10 との関係が決着していない。 Kaspersky は高確度で APT10 [9]、ATT&CK は menuPass 傘下のサブグループ〔ATT&CK G1054〕、ESET は既知グループへ帰属せず [11]、Trend Micro は別実体 [13]。公開情報だけでは決められない。防御の打ち手は変わらないが、他の APT10 系レポートを流用してよいかは変わる。
  2. 背後の国家機関が特定できない。 読んだ13本に、中国のどの機関が運用しているかを示す記述は無い。
  3. 2024年11月以降の動きが分からない。 公開資料がそこで止まっており、手口が現在も同じかは確認できていない。
  4. Operation AkaiRyū の実体が分からない。 骨格は作戦名を持つが13本に記述が無く、骨格が示す年（2004年）も壊れている。時期も内容も特定できないため年表に入れていない。
  5. 日本国内の被害規模が分からない。 何組織が侵害され何が持ち出されたかを示す数字は、どの資料にも無い。
  6. 中欧での活動と、初期侵入の内訳が分からない。 ATT&CK は中欧の標的に言及するが〔ATT&CK G1054〕13本に記述は無く、2023年以降のメール経由と脆弱性経由の割合も示されていない。

攻撃者Adversary／何者か

MITRE ATT&CKMirrorFace は中華人民共和国（PRC）と連携するサイバースパイ主体で、標的・ツール・インフラの重複から menuPass の傘下のサブグループとみられている。MirrorFace は遅くとも 2019 年から活動しており、当初はメディア、防衛、外交、金融、製造、学術の各分野の日本の組織のみを標的としていた。その後の MirrorFace の作戦には中欧の標的も含まれるようになり、LODEINFO、HiddenFace、UPPERCUT といったマルウェアが用いられた。
MISP galaxyMirrorFace は中国語話者による APT（持続的標的型攻撃）グループで、メディア・政府・外交・政治といった日本の重要組織を標的としてきた。スピアフィッシングによるキャンペーンを展開し、LODEINFO や MirrorStealer などのマルウェアを用いて認証情報を窃取し、機微なデータを外部へ送信している。APT10 とのつながりが取り沙汰されてはいるが、ESET は現時点で別個の実体として追跡している。
