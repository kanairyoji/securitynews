INC-2026-0110「ファンくる」に506万回のリスト型攻撃

覆面調査サービス「ファンくる」に3日15時間で506万270回のログイン試行が入り、59,389名がログインを許した——成功率は約1.17%で、攻撃が止まったのは検知ではなくサービス停止と同時刻。パスワードはハッシュ保存で「社内から流出した事跡は無い」とされ、2アカウントでポイントが不正交換された。認証情報の入手元・攻撃元・多要素認証の有無は公表されていない

不正アクセス・侵害システム障害続報が続いている日本の組織が当事者認証情報の悪用（使い回し・推測可能・窃取）設計・実装上の不備
初報: 2026年8月24日 最終更新: 2026年9月9日

消費者参加型の覆面調査（ミステリーショッパー）サービス「ファンくる」を運営する株式会社ファンくるは2026年8月24日に第一報、翌8月25日に第二報を公表し、2026年8月20日（木）22:00 から8月24日（月）13:00 にかけて利用者本人になりすましてログインを試みるリスト型攻撃（パスワードリスト攻撃）を受けたと説明しました。

第二報が示した調査結果は、不正ログイン試行回数 5,060,270 回・不正ログイン成功会員数 59,389 名です。ログインを許したアカウントではマイページ（会員情報等）が閲覧された可能性があり、項目は「氏名、生年月日、郵便番号、電話番号、メールアドレス」。2アカウントで第三者による不正なポイント交換が確認されています。同社は「モニター会員様のパスワードを復号できない形式（ハッシュ）で保存しており、当社内から ID やパスワードが流出した事跡は確認されておりません」と述べ、使われた認証情報が自社由来ではないという立場を取っています。

対応は、8月24日13:00 にサイトの閲覧と全機能を停止し、不正通信の遮断・ログイン画面への不正アクセス対策機能の導入・監視体制の強化を行ったうえで、8月25日12:00 にサービスを再開しました（停止は約23時間）。個人情報保護委員会と警察へ報告し、対象となった可能性のある会員へは順次個別にメール等で連絡してパスワードの再設定を案内しています。

本記録の評価として、この事案の読みどころは「3日15時間・506万回の試行が完走した」という一点にあります。同社の公表には検知の日時が無く、攻撃期間の終了時刻（8月24日13:00）はサービス停止の時刻と一致します。つまり公表された範囲では、攻撃を止めたのはレート制限や異常検知ではなくサービスの全面停止でした。試行に対する成功率は約1.17%（本記録の算出）で、リスト型攻撃としてはむしろ高い部類に入り、使い回されたパスワードが大量に生きていることを示します。ポイントは換金性があるため、国内の会員制サービス全般が同じ標的層にあります。

認証情報の入手元、攻撃元の IP・国、多要素認証の提供の有無、レート制限の設定、会員数の母数、不正交換されたポイントの額、通知の完了時期は公表されていません。本記録は、ファンくるの第一報・第二報と報道から確認できた範囲を整理します。

ハッシュ保存であること自体は適切な実装だが、リスト型攻撃はハッシュ保存では防げない。攻撃者は他所で漏れた平文の組み合わせを持って正面から入ってくるため、保存形式ではなく「正しいパスワードを持つ相手をどう止めるか」が争点になる（本記録の評価）。

59,389 ÷ 5,060,270 は約1.17%である（本記録の算出）。分子は「会員数」、分母は「試行回数」で母数の性質が違うため厳密な成功率ではないが、規模感を測る指標にはなる。

リスト型攻撃の成功率は一般に1%未満とされることが多い。本件はその水準を上回っており、「ファンくるの会員は、他所で漏れたのと同じパスワードを使っている人が相対的に多かった」と読める（本記録の評価）。ポイントサイト・懸賞サイト・覆面調査サービスのような「登録の心理的な負担が軽く、無料で始められる」サービスでは、利用者が使い捨てのつもりで同じパスワードを使い回しやすい。攻撃者から見れば、投入した認証情報リストの歩留まりが高い標的である。

閲覧された可能性がある情報は、第二報によれば氏名、生年月日、郵便番号、電話番号、メールアドレスの5項目である。金融情報やカード情報は挙げられていない。ただし、氏名・生年月日・住所の一部・電話番号の組み合わせは本人確認の材料になりうるため、他サービスでのなりすましやフィッシングの精度を上げる方向に働く（本記録の評価）。

実害として公表されたのは2アカウントのポイント不正交換だけである。59,389 名がログインを許したことを考えると極端に少ない。攻撃者の目的が即時の換金ではなく、「この ID とパスワードの組み合わせは生きている」という検証や、会員情報の収集にあった可能性が残る（本記録の推定であり、同社はこの点に触れていない）。生きている組み合わせのリストは他サービスへの攻撃に転用できるため、被害はファンくるの外へ出ていく。

会員数の母数は公表されていない。そのため 59,389 名が全体の何%かは計算できず、「使い回しがどれだけ残っているか」という本来いちばん知りたい数字は読めないままである。

一方で、対応の中身には評価しにくい点が残る。第一報が挙げた再発防止策は「不正通信の遮断」「ログイン画面への不正アクセス対策機能の導入」「監視体制の強化」の3点で、多要素認証には一言も触れていない。リスト型攻撃で正しい ID とパスワードを持つ相手を止められる手段は実質的に MFA しかないため、ここが空白のまま再開したことになる（本記録の評価）。同社が MFA を提供していたか、提供する予定があるかも公表されていない。

停止の判断そのものは合理的である。攻撃が継続している最中にサービスを開けたままにすれば、被害アカウントは増え続ける。23時間という長さは、EC やポイントサービスの停止としては短い部類で、会員への影響を抑えつつ対策を入れる時間を確保した形になっている。ただし、公表された範囲では停止以外に攻撃を止める手段が働いていないため、同じ攻撃が再開後に来たときに何が止めるのかは示されていない。

  1. 調査で範囲が確定し、表現を整理した。 第一報は「閲覧できてしまっている状況です」という現在進行形の記述で、マイページに表示されうる項目を広めに挙げた可能性がある。第二報は調査結果として、実際にマイページに表示される項目に絞った、という読み方である。

リスト型攻撃の防御を整理すると、効く場所は3つしかない。

  1. 入る前に減らす（レート制限・IP 評価・CAPTCHA・デバイス評価）。 506万回の試行が87時間続いたという事実は、ここが機能していなかったことを強く示唆する。同一 IP からの試行なら遮断は容易だが、住宅用プロキシで分散されると IP 単位では効かない。その場合は「ログイン試行の総量」と「失敗率」をサービス全体で見る必要がある。毎秒16回の失敗が3日半続いたなら、総量の監視で気づける（本記録の評価）。
  2. 正しいパスワードでも通さない（MFA・リスクベース認証）。攻撃者は正しい組み合わせを持っているので、パスワードの強度も保存形式も関係しない。本件で同社が挙げた再発防止策に MFA が無いことは、この層が空白のままであることを意味する。
  3. 入られた後の被害を止める（重要操作の再認証・ポイント交換の閾値と保留）。本件で実害はポイント交換2アカウントに留まった。ポイントの交換・出金・登録情報の変更といった「換金と乗っ取りに直結する操作」に再認証や保留を挟めば、ログインを許しても損失は出にくい。

日本の CISO にとっての読みどころは、この事案がファンくる固有の失敗ではないことである。使われた認証情報は他所で漏れたものであり、同社のパスワード保存は適切だった。それでも59,389名が入られた。つまり、自社に落ち度が無くても、利用者の使い回しを通じて自社が被害の現場になる。ポイント・マイル・電子マネーの残高を持つサービスは、その残高が攻撃者にとっての換金経路になるため、他業種より狙われる理由がある。

同じ構図の先例が本 DB にある。ペット用品通販チャーム（INC-2026-0082）では正しい ID とパスワードによる不正ログインが6週間続き、対象件数が約23万件から約43万件へ増えた。韓国の GS リテール（INC-2026-0070）では、個人情報保護委員会が「同一 IP からの大量ログイン試行を識別・遮断する仕組みが無かった」ことを理由の一つとして過去最大級の課徴金を科している。規制当局は「入られたこと」ではなく「大量試行を止める仕組みが無かったこと」を問題にしているという点は、日本の事業者にとっても示唆的である（本記録の評価。国内の法制度で同じ判断が下る保証はない）。
