INC-2026-0138SCAT の有償クラウドが不正利用され被害届

美容サロン向け顧客・売上管理システムの SCAT株式会社で、契約する有償クラウドサービスが2026年8月24日〜25日に第三者に不正利用され、発生した利用料金の扱いをクラウド事業者と協議中——データ漏えいの形跡は「現時点で確認されていない」一方、9月2日に三田警察署へ被害届を出した。クラウドサービスの名前・不正利用された資源・金額・侵入の経路は公表されていない

不正アクセス・侵害初報のみ日本の組織が当事者公表されていない／不明
初報: 2026年9月4日 最終更新: 2026年9月15日

美容サロン向けの顧客・売上管理システムなどを開発・販売するSCAT株式会社は2026年9月4日、「当社利用の有償クラウドサービスの第三者による不正利用に関するお知らせ（第一報）」を公表しました。

公表によれば、2026年8月25日、同社が利用するクラウドサービスで、同社が契約する有償サービスを第三者が不正利用している形跡を確認しました。クラウド事業者と連携して調査した結果、不正利用と判明し、不正利用の可能性がある期間は8月24日から25日までです。同社は警視庁に事前相談したうえで、9月2日付で三田警察署に被害届を提出しました。

同社のサービスで扱う個人情報・機密情報その他のデータが外部へ漏えいした形跡は、現時点で確認されていないとし、不正利用で発生した利用料金はクラウド事業者と協議中です。

本DBのジーニー（INC-2026-0083）と同じく、奪われたのはデータではなくクラウドの計算資源・課金枠とみられる型の事案です。一方で公表文は、クラウドサービスの名前・不正利用された資源の種類・金額・侵入の経路を示していません。評価・示唆は本記録の判断として分けて書きます。

クラウドの課金枠は「漏えいしなくても損失になる資産」——検知の速さが請求額を決める（本記録の評価）評価・解釈出典 [1]

ここからは本記録の作成者の評価である。

第一に、本件は発覚が早かった部類に入る。 不正利用の期間は8月24日〜25日で、25日に形跡を確認している。本DBのジーニー（INC-2026-0083）は計算資源の不正利用で1億8,100万円を損失計上したが、暗号資産の採掘や生成AI の API の転売に使われる場合、請求額は検知までの時間にほぼ比例して積み上がる。課金アラートや利用量の急増検知がどれだけ早く鳴るかが、そのまま損失の大きさになる。

第二に、料金の負担はクラウド事業者の裁量に委ねられている。 同社は協議中としており、被害届の提出は協議の材料にもなる。事前に「不正利用時の料金減免の条件」を確認している組織は少ない。

第三に、「データの漏えいの形跡は確認されていない」は、データへのアクセスが無かったことと同じではない。同じクラウドのアカウントに顧客データのストレージがあったなら、課金枠を使える権限でデータにも届いた可能性がある。同社の説明が「現時点において」と留保しているのはそのためとみられる。

    取るべき行動 クラウドの不正利用・不正アクセスの初動手順に、ログの保全、所轄警察署への相談窓口、被害届に添える資料の一覧を入れる
セキュリティ技術者への示唆
  • 課金アラートを検知の第一線にする
    請求額は検知までの時間に比例して積み上がる（本記録の評価）。本件は1日程度で形跡を確認した
    取るべき行動 予算アラートを実額と予測額の両方で設定し、時間単位の異常検知（コスト異常検知機能）を有効にする。 通知先を個人のメールではなく当番のチャットと電話にする
  • 高額資源を使えないようにしておく
    有償サービスが第三者に不正利用された
    取るべき行動 組織のポリシーで使わないリージョン、GPU・大型インスタンス、生成AI の API 利用枠を既定で禁止し、 必要な場合だけ期限付きで許可する
  • 認証情報とアクセスキーの管理を見直す
    初動にパスワード変更、恒久策にアクセス権限の見直しと認証設定の強化が挙がっている
    取るべき行動 管理コンソールの多要素認証を全ユーザーに必須化し、長期アクセスキーを棚卸しして一時認証情報に置き換える。 リポジトリと CI の設定に鍵が埋め込まれていないかをシークレットスキャンで検査する
  • 課金枠と顧客データを同じアカウントに置かない
    課金される資源を使える権限で顧客データにも届く構成なら、不正利用がデータ漏えいに発展しうる
    取るべき行動 検証用・本番用・顧客データ保管用のクラウドアカウントを分離し、アカウント間のアクセスを最小権限のロールに限定する

自組織に当てはまるか

該当する項目があれば、この事案と同じ構図が自組織でも成立しうることを意味します。
観点自社に当てはまるか該当する場合に何が起きうるか
運用・監視□ クラウドの課金額・利用量の急増を時間単位で検知・通知する仕組みが無い本件は有償サービスの不正利用で利用料金が発生し、損失は検知までの時間に左右される
認証・認可□ クラウドの管理コンソールに多要素認証が必須でない、または長期のアクセスキーを使っている同社の初動はパスワード変更で、恒久策は認証設定の強化だった
システム構成□ 顧客データの保管と、高額な計算資源の利用が同じクラウドアカウントで行われている課金枠を使える権限がデータにも届く構成では、不正利用が漏えいに発展しうる
体制・契約□ 第三者による不正利用時の料金の扱いを、クラウド事業者の規約で確認していない同社は発生した利用料金をクラウド事業者と協議中である
体制・契約□ クラウドの不正利用時に警察へ届け出る手順とログ保全の方法が決まっていない同社は警視庁に相談し、被害届とアクセスデータを提出した
