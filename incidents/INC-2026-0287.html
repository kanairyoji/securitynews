INC-2026-0287新韓銀行で2.5万名の与信情報流出

韓国の新韓銀行（신한은행）が2026年10月1日、外部の非認可者が「非正常な方法」で一部サービスに接近し、顧客約2万5,000名の貸付申込関連の個人・信用情報が流出したと公表した。流出項目は顧客名・電話番号・CI（連携情報）・年間所得・算出限度などで、住民登録番号66件と CI 97件が含まれる。銀行は認知直後に非常対応体制を敷いて外部 IP を遮断し関連サービスを停止、鄭相赫（정상혁）行長名の謝罪文で「損害は責任を持って全額補償する」と表明した。金融監督院は前日（9月30日）から緊急の現場調査に入っている。流出の経路・手口と侵害の時期は公表されておらず、一部報道はクレデンシャルスタッフィングの可能性を挙げるにとどまる【続報・2026年10月2日】보안뉴스がセキュリティ業界の見立てとして手口を具体的に報じた——**初期侵入は貸付募集人が申込状況を照会するモバイル照会サービス「M 신한」と推定**され、攻撃者はダークウェブ等で事前に窃取した他プラットフォームの認証情報を無作為に大量投入して本人認証を突破した（速度制限・アカウントロックが無かったとみられる）。**侵入後は取得した顧客番号を改変して一般顧客向けの照会 API へ反復要求し、データを掻き集めた**——認証（Authentication）は通ったが、要求されたデータの閲覧権限をサーバ側で交差検証する認可（Authorization）が欠けていた典型的な Broken Access Control である。**確認された10余りの IoC の IP はすべて海外**で、自動化されたボット／AI エージェントによる攻撃の可能性が指摘されている。**いずれも銀行が認めた説明ではない**【続報2・2026年10月2日〜3日】**攻撃に使われたとされる道具の名前が初めて挙がり、当局の対応が業界横断に広がった**—— 보안뉴스は手口を**オープンソースで公開された AI ベースの自律型ペネトレーションテストツール**の悪用と推定し、 金融各社が当局の関連機関から「**AI エージェントを悪用した自動化攻撃が金融業界で発生したと推定され、さまざまな国の海外 IP を通じて攻撃が行われた**」との通知を受けたと報じた。 뉴시스（10月3日）はより具体的に、**ジニアンズ（Genians）セキュリティセンター長が、国内複数箇所への攻撃に使われたウェブサーバの一部から中国語ベースの AI 自律型侵入テストツール「ARTEX AI」に関連する文字列を確認した**と述べたと伝えたが、 **同記事は「実際の新韓銀行への攻撃過程で ARTEX AI が活用されたかは確認されていない」と明記している。** **金融保安院は2026年9月に金融業界を狙った AI Agent ベースの攻撃の試みを実際に探知したと表明**し、新韓銀行の事故の届出を受けた直後に**攻撃者の IP 等の脅威情報を銀行業界へ共有**した。 金融委員会は**10月2日に金融監督院・金融保安院・主要銀行・カード会社と「金融圏緊急状況対応会議」を開催**、金融業界全体へ**緊急セキュリティ点検**（外部に露出した電算システム・サービス、認証・アクセス統制の脆弱性）を指示した。 **ウリ銀行と NH農協銀行も攻撃を受けたが、情報流出の被害は確認されていない。** **ARTEX AI が本件に使われたことは誰も確認していない** 【続報3・2026年10月4日】**当局の対応が金融業界の全業権へ広がり、 KISA が民間企業向けの勧告を出した**——金融委員会は10月4日、 **全金融業権の協会長と侵害事故が起きた金融会社の CEO を招集して緊急点検会議を開き**、 科学技術情報通信部も内部検討会議を開いて対策を準備していると報じられた。 KISA は10月3日に「最近のサイバー攻撃に備えた企業セキュリティ強化勧告」を公表し、 **ウェブ・API の権限検証（ログインの有無にかかわらず要求ごとにサーバ側で データと機能の実行権限を独立に検証する／文書番号や識別子の改変で他人の情報が 引けないか確認する）を5つの柱の2番目に置いた**—— **本件で報じられた手口に一対一で対応する内容である。** 流出が確認された金融会社は新韓・KB国民（119名）・ハナ（89名）・ BNK釜山（外注職員11名）に加え、**예가람貯蓄銀行（約4万名と推定）と 現代キャピタル（住宅ローン募集人146名のうち一部）**へ広がり、 ウリ銀行と NH農協銀行でも攻撃の試みが確認されている。 **ただし金融委員会の10月4日の会議そのものは、本記録の確認時点で 同委員会のサイトに公表文が無い**

  • 規模 — 約2万5,000名。うち住民登録番号が66件、CI（連携情報）が97件
  • 項目 — 顧客名・電話番号・CI・年間所得・算出限度など、貸付（ローン）申込に関わる個人信用情報
  • 対応 — 認知直後に非常対応体制を敷き、外部 IP の遮断・関連サービスの停止・セキュリティの新規適用を実施
  • 経営の表明 — 鄭相赫（정상혁）行長名の謝罪文。「損害を受けた場合は責任を果たし全額補償する」
  • 当局 — 金融監督院（금융감독원）が前日（9月30日）から緊急の現場調査に入っている

日本の読者にとって重いのは、流出した項目の性質です。

漏れたのは住所や生年月日といった属性情報ではなく、年間所得と「算出限度」——つまり審査の結果そのものです。これは「この人はいくらまで借りられるか」という情報であり、貸付を装った詐欺の精度を直接上げます。本記録の評価として、名簿としての価値が属性情報とは別の次元にあります。

もう1つは CI（連携情報）です。韓国の本人確認制度で使われる、サービスをまたいで同一人物を結びつけるための識別子で、利用者側で変更できません（本記録の補足）。件数は97件と小さいものの、住民登録番号66件と合わせて「取り替えられない識別子」が外に出ています。

手口は公表されていません。報道には「認証を迂回する非正常な方法」「貸付募集人向けの『早見照会』の仕組みの弱点」「クレデンシャルスタッフィングの可能性」という記述が並びますが、いずれも銀行が認めた説明ではありません。銀行が述べたのは「非正常な方法で一部サービスに接近された」という事象の側だけです。

韓国の銀行では2026年7月のウリ銀行（우리은행）でも顧客情報の流出が起きており、報道はこれを「銀行業界のセキュリティが問われる」文脈で並べています。

公表されていない・確定していないこと14
  • 流出の経路・手口を**銀行自身が説明していない**（報道の見立ては具体化した）公表されていない
    銀行の説明は「非正常な方法で一部サービスに接近された」までで、 **2026年10月2日時点でも変わっていない。** **一方、보안뉴스はセキュリティ業界の見立てとして経路を具体化した**—— 初期侵入は貸付募集人向けのモバイル照会サービス「M 신한」と**推定**され、 ダークウェブ等で窃取した他プラットフォームの認証情報の大量投入で本人認証を突破、 その後は取得した顧客番号を改変して一般顧客向けの照会 API へ反復要求した、という筋である。 **これは「業界によれば」という伝聞であり、銀行・当局のいずれも確認していない。** **銀行が認めていない以上、同種の照会系を持つ金融機関にとっては 「報道の筋を仮に正しいとして点検する」以外の手が無い**（本記録の評価）。 **確定を要する点は3つ**——①初期侵入が本当に「M 신한」だったのか、 ②認証の突破が総当たり（クレデンシャルスタッフィング）だったのか、 ③認可の欠落がどの層（API ゲートウェイか業務ロジックか）にあったのか。
  • 「AI エージェントによる攻撃」という評価の根拠公表されていない
    보안뉴스は「10余りの IoC の IP がすべて海外だった」「特定対象を精密に狙うのではなく 無差別に自動投入するボット攻撃の形」という2点から、 **自動化された AI エージェント攻撃の可能性に重みが置かれる**と書いた。 **しかしこの2点は、従来型のボットネットやスクリプトによる攻撃でも同じように現れる。** **「AI エージェントである」ことを示す固有の証跡（挙動の適応・道具の組み替え等）は 示されていない**（本記録の評価）。銀行も当局も AI への言及をしていない。 本記録はこれを**報道の評価として記録するにとどめ、事実として扱わない。**
  • 侵害の開始時期・期間と滞留時間公表されていない
    銀行は「最近」とだけ述べている。**認知の日時も公表されていない。** したがって「2万5,000名分がどれだけの時間をかけて取られたのか」が分からず、 封じ込めの速さも評価できない。
  • 接近された「一部サービス」の具体名と、停止したサービスの範囲・期間公表されていない
    銀行は「一部サービス」と述べ、報道は「スーパーSOL」「タンギョヨ」は無関係だとしている。 **何が止まり、いつ戻ったのかは示されていない。**
  • 流出した情報の悪用の有無、ダークウェブ等への掲載の有無調査中
    銀行は「損害が確認されれば全額補償する」と述べており、 **悪用の確認状況そのものには触れていない。** 本記録の作成者も掲載・売買の独自確認を行っていない。
  • 対象者への個別通知の方法と時期公表されていない
    銀行はホームページとアプリに**自己照会のメニュー**を設け、専任の相談センターを置いた。 **一方で「対象者へ個別に通知するか」「いつまでに通知するか」は示されていない。** 自己照会は、顧客が自分で調べに来ることを前提にした通知の形である（本記録の評価）。
  • 金融監督院の調査結果、行政処分・制裁の有無調査中
    現場調査は2026年9月30日に始まったばかりである。 **調査結果、検査の結論、制裁金や是正命令の有無はいずれも公表されていない。**
  • 攻撃者の帰属、恐喝・身代金要求の有無公表されていない
    銀行は「外部の非認可者」としか述べていない。**要求の有無にも触れていない。**
  • 「ARTEX AI」が本事案の攻撃に使われたか検証できない
    **ジニアンズのセキュリティセンター長が述べたのは 「最近の国内複数箇所に対する攻撃に使われたウェブサーバの一部から ARTEX AI に関連する文字列を確認した」までである。** **뉴시스の記事自身が「実際の新韓銀行への攻撃過程で ARTEX AI が活用されたかは 確認されていない」と明記している。** 本記録は**道具の名前が挙がったことと、本件でそれが使われたことを区別する。** 確認には**銀行側のログと、当該ウェブサーバの検体の突合**が必要だが、 どちらも公表される見込みは示されていない（本記録の評価）。
  • 金融保安院が2026年9月に探知した「AI Agent ベースの攻撃の試み」と本事案の関係公表されていない
    金融保安院は**2026年9月に金融業界を狙った AI Agent ベースの攻撃の試みを 実際に探知した**と表明している。 **しかしそれが本事案と同一の攻撃者・同一の道具であるかは示されていない。** 探知の内容（対象・件数・判定の根拠）も公表されていない。 **「9月に AI Agent の攻撃を探知した」と「本件が AI Agent の攻撃だった」は別の主張である** （本記録の評価）。
  • 当局が指示した緊急セキュリティ点検の結果と、追加の侵害の有無調査中
    金融当局は金融各社に**外部に露出した電算システム・サービスと 認証・アクセス統制の脆弱性**の点検を求め、結果を近日中に報告させるとした。 **報告の期限・公表の有無・ウリ銀行と NH農協銀行が受けた攻撃の詳細は いずれも示されていない。**
  • 金融委員会の10月4日の緊急点検会議で何が指示されたか公表されていない
    **全金融業権の協会長と侵害が起きた金融会社の CEO が集められたことは 報じられているが、会議で示された指示・期限・報告の形式は公表されていない。** **本記録の確認時点（2026年10月4日）で、金融委員会のサイトに この会議の報道資料は無い**——10月2日付の公表が最新である。 10月2日の会議で求められた各社の自己点検の結果が この会議に上がったのかも分からない
  • 科学技術情報通信部が準備している対策の中身公表されていない
    보안뉴스は「同省が内部検討会議を開き関連対策を準備していると知られている」と 記すにとどまる。**同省の公表文は本記録では確認していない。** 金融業界の監督は金融委員会・金融監督院が担うため、 **情報通信の所管官庁が何を担うのか（KISA を通じた技術支援か、 制度の改正か）は示されていない**
  • 連鎖した各社の流出が同一の攻撃者・同一の手口によるものか調査中
    **当局も各社も、6社の事案を結ぶ説明をしていない。** 金融保安院が新韓銀行の届出直後に攻撃者の IP 等の脅威情報を銀行業界へ共有した ことから、**同じ指標で他社が点検できる状態にはある**が、 **指標が一致したという発表は無い。** **本記録は「連鎖」を時期と業種の集中として記録し、 同一の攻撃者による一連の作戦とは扱わない**（本記録の判断）

  • 確認された10余りの侵害指標（IoC）の IP がすべて海外のものであったこと

本記録は、この2点が AI エージェントを示す証跡にはならないと考えます。無差別な自動投入と海外からの多数の接続元は、従来型のボットネットや既製のスクリプトによる攻撃でも同じように現れます。「AI エージェントである」ことを区別するには、たとえば阻まれた後に手口を組み替える適応の跡や、道具を目的に合わせて継ぎ足す跡が要ります。そうした証跡は示されていません。銀行も金融監督院も AI に言及していません。

記事自身も、匿名の専門家の評としてこう締めています（原文韓国語）。

仮に AI エージェントに基づく攻撃に当たったとしても、基本的な管理およびシステム運用の疎かさの責任は免れがたい

実務上の読み方はここにあります。 攻撃側が AI であったかどうかは、防御側の打ち手を変えません。本件で欠けていたと指摘されているのは、速度制限・アカウントロック・サーバ側の認可検証・照会量の監視という、いずれも AI 以前からある統制です。

なお、記事は新韓銀行が金融業界の網分離規制の緩和（AI 活用促進のための第1次実証）の対象企業に選定され、AI 技術導入の先頭に立っていることに触れ、「外部通信の安全網の役割を果たすべき DMZ の統制や API のアクセス制御に現れた基礎的な問題は痛い部分だ」と書いています。AI を使う側の体制の話と、AI に攻められた可能性の話は別です（本記録の注記）。

読者が使える形に整理すると、確かめられていることは ①AI を用いた自律型の侵入テストツールがオープンソースで入手でき、 実際に国内への攻撃で痕跡が見つかっている、 ②当局は金融業界を狙った同種の攻撃の試みを9月に探知しているの2つです。 確かめられていないのは③本件がその道具によるものだったかです。 ①②から③を導かないこと——これが本記録の立場です。
