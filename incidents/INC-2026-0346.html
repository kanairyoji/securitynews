INC-2026-0346米財務省が A7 を犯罪組織に指定

米財務省が2026年10月1日、対イラン経済作戦「Operation Economic Outcast」の一環として、**ロシアに結びつく影の銀行網「A7 Network」を重大な国際犯罪組織（significant transnational criminal organization）として指定**し、同時に FinCEN が**米国外で A7 が支配する企業が関与する取引を「主要な資金洗浄の懸念」のクラスと認定する規則案（NPRM）**と**金融機関向けの警告（FIN-2026-Alert007）**を出した——A7 は逃亡中のモルドバのオリガルヒ **Ilan Mironovich Shor** が率い、**第三国に作り込んだ「Sub-Agent」会社群**に請求書・契約・支払指示上の当事者を演じさせ、偽造した貿易書類とともに**制裁対象の支払いを通常の商取引に見せかける**。A7 自身の主張では2026年1月時点で**1日2,000件超・7.5兆ルーブル超（約915億ドル・ロシアの2025年の対外貿易の約13%相当）**を処理し、FinCEN の調査では **Sub-Agent が2025年1月〜2026年6月に170億ドル超**を、**ルーブル裏付けのステーブルコイン A7A5 では180超の主体が2025年2月〜2026年6月に計1,791億ドル以上**を動かしていた。利用者としてイラン中央銀行・革命防衛隊（IRGC）・ハマス等に加え、**ランサムウェアを含むサイバー犯罪者と、北朝鮮による暗号資産取引所のハッキングに関わる取引**が名指しされた。SDN リストの記載は「A7 NETWORK, Russia; Kyrgyzstan; Nigeria; Zimbabwe; 設立2024年; 対象種別 Criminal Organization [TCO]」で、**Sub-Agent の社名一覧は公表されていない**

詐欺の手口初報のみ有名事象として記録（日本と直接の関係は薄い）公表されていない／不明
初報: 2026年10月1日 最終更新: 2026年10月5日

米財務省は 2026年10月1日、対イランの経済作戦 「Operation Economic Outcast」 の一環として、A7 Network に対する3段構えの措置を公表しました。

  • OFAC が A7 Network を 重大な国際犯罪組織（significant transnational criminal organization）として指定した。SDN リストの記載は「A7 NETWORK, Russia; Kyrgyzstan; Nigeria; Zimbabwe; 設立2024年; 対象種別 Criminal Organization [TCO]」
  • FinCEN が、米国外で A7 が支配する企業が関与する取引を「主要な資金洗浄の懸念（primary money laundering concern）」のクラスと認定し、対象の資金移転を禁じる規則案（NPRM）を出した（ロシア資金洗浄対策法 第9714条(a)。意見募集は官報掲載から30日）
  • FinCEN が金融機関向けの警告 FIN-2026-Alert007 を出し、赤旗指標を示した（疑わしい取引の届出には「FIN-2026-A7NETWORK」の語を記載するよう要請）

A7 は何をする網か。 逃亡中のモルドバのオリガルヒ Ilan Mironovich Shor が率い、ロシア国防銀行である Promsvyazbank（PSB） と共同で2024年に作られました。中核は第三国に作り込んだ「Sub-Agent」という会社群です。顧客の支払い義務は網の内部で veksel（約束手形・為替手形） により帳簿上処理され、請求書・契約・支払指示には Sub-Agent が当事者として現れます。支払いは非ロシアの銀行口座からコルレス銀行と SWIFT を通って実行され、偽造した貿易書類・輸出入記録・誤導的な商品説明によって、受け取る金融機関には通常の商取引に見えます。並行して、ルーブル裏付けのステーブルコイン A7A5（Tron と Ethereum 上。発行は制裁済みの Old Vector LLC）が、ロシア国内の送金を国外の支払いに鏡のように対応づける内部帳簿として使われます。

攻撃の経過

公表された範囲の事実のみ。公表されていない段階は補完せず明示しています。

制裁対象の顧客の支払いを、第三国の Sub-Agent を当事者に見せた偽の商取引として 国際金融システムに通す。網の内部では veksel と A7A5 で帳尻を合わせ、 相手方どうしを遮断する。ランサムウェアの身代金や北朝鮮の窃取資金も同じ器を通る

  1. 1. 偵察disclosed[2]
    支払いを通す業種に合わせて Sub-Agent を仕立てる。 FinCEN の脚注は「**Sub-Agent は資金を動かす業種に可能な限り合わせて作られるが、 顧客の業態と合わせきれていない兆候もある**」と記す
    根拠: FinCEN の警告（脚注の記述）
  2. 2. 初期侵入disclosed[2]
    顧客が A7 に供給者情報と貿易書類を渡し、A7 が内部の決済手段（veksel）で 支払い義務を満たしたうえで、**Sub-Agent を契約・支払の当事者として割り当てる**
    根拠: FinCEN の警告
  3. 3. 検知回避disclosed[1]
    **Sub-Agent のウェブサイトと銀行口座は A7 の職員が管理し、 独自に作った VPN で真の所在を隠して金融口座にアクセスし、支払いを高速に実行する**
    根拠: 財務省の公表文
  4. 4. 持ち出しdisclosed[1] [2]
    支払いが**非ロシアの銀行口座**からコルレス銀行と SWIFT を通って実行される。 受け取る金融機関には通常の商取引に見える。 並行して A7A5 が内部帳簿として動き、**USDT 等に替えられて最終的な法定通貨になる**
    根拠: FinCEN の警告・財務省の公表文
  5. 5. 影響（暗号化・破壊・改ざん）disclosed[1] [2]
    制裁対象（イラン中央銀行・IRGC・イラン支援のテロ組織）の資金移動、 イラン原油の販売と兵器調達、**ランサムウェアを含むサイバー犯罪者の資金移動**、 **北朝鮮による暗号資産取引所のハッキングに関する取引**が成立した
    根拠: 財務省の公表文・FinCEN の警告

制裁の対象が「会社」から「網そのもの」に変わった概観出典 [1] [4] [5]

2025年8月14日、OFAC はすでに A7 LLC・A71 LLC・A7 Agent LLC・Old Vector LLC を個別に指定していた（サイバー関連の E.O. 13694）。それでも網は動き続けた。第三国の Sub-Agent が、指定された社名を支払いの表に出さないからである。

2026年10月1日の措置は、そこを変えに来た。財務省の表現では「今回の措置は2025年8月14日の指定の上に立ち、より広い網そのものを米国の制裁にさらす（exposing the broader network itself）」。結果として、

  • A7 Network の財産・権益はブロックされ、OFAC への報告義務が生じる
  • A7 のために行動する Sub-Agent が関与する取引も、その対象に含まれる
  • A7A5 トークン自体がブロック財産として扱われる（発行者 Old Vector LLC の権益による）

SDN リストの記載は次のとおりである（本記録が OFAC の Recent Actions で確認した）。

A7 NETWORK, Russia; Kyrgyzstan; Nigeria; Zimbabwe; Organization Established Date 2024; Target Type Criminal Organization [TCO]

所在に Nigeria と Zimbabwe が並ぶことは、The Insider が伝えた「2026年4月に Financial Times が A7 のアフリカでの基盤構築とナイジェリア事務所開設を報じた」という話と符合する（本記録の照合）。

手口は「Sub-Agent に当事者を演じさせ、A7A5 で帳尻を合わせる」二層構造である原因・手口出典 [1] [2]

FinCEN の警告が示す仕組みは、法定通貨の層と暗号資産の層の二層である。

法定通貨の層。

  1. 顧客（ロシアやイランなど厳しく制裁された法域の主体）が、A7 に取引の情報（供給者情報・貿易書類など）を渡す
  2. A7 が、網の内部で価値を記録する決済手段——為替手形・約束手形（ロシア語で veksel）——を使って顧客の支払い義務を満たす
  3. A7 が Sub-Agent を割り当て、請求書・売買契約・支払指示の上で「契約当事者」「支払当事者」として現れさせる
  4. 支払いは非ロシアの銀行口座から、コルレス銀行と SWIFT を通って実行される

ここで使われるのが、偽造した貿易書類・偽造した輸出入記録・誤導的な商品説明である。受け取る側の金融機関には、制裁対象との取引が通常の商取引に見える。

暗号資産の層。 A7 は A7A5（ルーブル裏付け・Tron と Ethereum 上・発行は Old Vector LLC・PSB のルーブル預金で裏付けると宣伝）を、銀行経路が使えないときの価値移転と、網の内部帳簿として使う。FinCEN はこれを「ミラー（鏡）」と呼ぶ。

ロシア国内で A7A5 を使って行われる取引が、Sub-Agent を通じた法定通貨の移動を「鏡のように」写し、取引の両側の相手方を完全に遮断したまま帳尻を合わせる（FinCEN・原文英語）

米国の金融機関が A7A5 を直接見ることはまずないとも書かれている。A7A5 は主に制裁済みの主体の間を動き、凍結されないブリッジ資産としてUSDT（Tether） などに替えられ、そこから顧客の望む法定通貨に換えられる。流動性の供給には、ロシア国外の OTC ブローカー——とくに新設の会社や、ステーブルコインの取扱を急拡大している会社——が使われうる。さらに A7A5 に値を連動させた「wrapped」トークンが、本来のブロックチェーン以外の場で現れることも警告されている。

運用面で押さえておくべき記述が1つある。 財務省は「Sub-Agent のウェブサイトと銀行口座は A7 の職員が管理し、独自に作った VPN で真の所在を隠して金融口座にアクセスし、支払いを高速に実行する」と述べている。Sub-Agent は実体のある取引先ではなく、操作される器である。

金融機関が持てる手がかりは社名ではなく赤旗指標である対策・注意喚起出典 [1] [2]

Sub-Agent の社名一覧は公表されていない。 だから FinCEN は赤旗指標を出した。本記録が警告の本文で確認できた指標は次のものである（警告の全ページを転記したわけではない。完全な一覧は原文を見る必要がある）。

Sub-Agent の利用に関するもの

  • 疑われる、または既に特定された A7 の Sub-Agent と取引している
  • キルギス共和国その他 A7 の活動で懸念される法域の、シェル会社と疑われる相手と取引している
  • 経済的な目的がはっきりしないまま、複数の法域の複数のシェル会社を経由して資金が最終的な宛先に届く
  • 設立して間もない会社が、不自然に高額・大量の取引を始める

貿易書類に関するもの

  • 会社の設立時期と取引の規模が釣り合わない
  • 商品の説明と供給者の事業内容が食い違う
  • シェル会社と見られる相手を経由する不自然な送金経路
  • 偽造された、または AI で改変された請求書

FinCEN は「単独で決定的な赤旗は無い」と明記し、顧客の過去の取引・業界慣行との整合・複数の赤旗の重なりを総体として見るよう求めている。

届出にあたっては、SAR の第2欄（Filing Institution Note to FinCEN）と記述欄に「FIN-2026-A7NETWORK」の語を入れるよう要請されている。

NPRM の意味も実務では大きい。これは制裁リストへの掲載とは別の仕組みで、ロシア資金洗浄対策法 第9714条(a)に基づき「米国外で A7 が支配するあらゆる企業が関与する取引」をクラスとして主要な資金洗浄の懸念と認定し、対象の資金移転を禁じる。名前が分からなくても禁止が及ぶ作りである。意見募集は官報掲載から30日で、最終規則の時期・内容はまだ決まっていない。

ランサムウェアの身代金と北朝鮮の窃取資金が、同じ器を使っていた帰属出典 [1] [2]

この事案をサイバーの記録として残す理由はここにある。財務省の記述はこうである。

国家主体にとどまらず、A7 Network の Sub-Agent は、ランサムウェアを含むサイバー犯罪者と、規制品を得ようとする調達アクターにも応え、国際金融システムを通じて資金を動かした（原文英語）

A7 Network は、OFAC が2026年6月2日に指定したイラン最大の暗号資産取引所 Nobitex とも結びついており、北朝鮮による暗号資産取引所のハッキングに関する取引その他の不正な主体の取引も仲介した（原文英語）

FinCEN の警告も、利用者として 北朝鮮（DPRK）・イラン支援のテロ組織・サイバー犯罪者とランサムウェア実行者・IRGC を並べ、「A7 の十分に確立され広く行き渡った暗号資産の経路は、幅広い脅威アクターにとって魅力的な道具である」と述べている。

ただし、個別名は何も出ていない。 どのランサムウェア群か、どの事案の資金か、いくらだったかは公表されていない（未確定事項に記録した）。本記録はここを推測で埋めない。

なお Garantex と後継の Grinex の経緯は、この器がサイバー犯罪の資金ともともと地続きであることを示す。FinCEN の脚注によれば、ロシアのサイバー犯罪者のための大規模な資金洗浄者として制裁されていた Garantex は、2025年3月の米法執行の措置の後に資金を Grinex（キルギス拠点）へ移し、資金を失った顧客には A7A5 トークンで残高を回復させた。

日本の実務にとっては「身代金の出口」と「貿易金融の入口」の両方の話である評価・解釈出典 [1] [2]

以下は本記録の評価である（公表資料に日本への言及は無い）。

第一に、ランサムウェア対応の判断材料が1つ増えた。身代金を払うか否かの議論は、日本では「払っても復号できるか」「資金提供になるか」の2点で語られがちだが、今回名指しされたのは「払った金が通る器」が制裁対象の国際犯罪組織だという構図である。器が指定されれば、支払いの経路そのものが制裁違反のリスクを帯びる。支払いの是非を決める手順に、資金の通り先の確認を入れておく必要がある。

第二に、貿易金融・コルレス業務の側では「社名の照合」が効かない。 Sub-Agent の社名は公表されていない。NPRM はクラスとしての禁止という形を採った。これは裏を返せば、各機関が自力で「A7 が支配する企業かどうか」を判断しなければならないことを意味する。赤旗指標（新設会社の大量取引・商品説明と供給者の業態の不一致・経済合理性の無い多段のシェル会社・AI で改変された請求書）は、日本の貿易金融の現場でもそのまま点検項目になる。

第三に、「AI で改変された請求書」が赤旗に入ったことは記録に値する。 FinCEN は偽造請求書の文脈でディープフェイクに関する過去の警告を引いている。書類の目視確認を前提にした統制は、もう前提が崩れているという評価になる。

第四に、数値の扱いには注意が要る。 本件に並ぶ「915億ドル」「170億ドル」「1,791億ドル」はいずれも取引高であり、被害額ではない。 しかも出どころがA7 の自称・FinCEN の調査・FinCEN の分析と異なり、期間も違う。足し合わせたり、被害額として引用すれば誤りになる。

  • 制裁は「社名の照合」から「クラスとしての禁止」へ広がっている
    Sub-Agent の社名は公表されていない。FinCEN の NPRM は **「米国外で A7 が支配するあらゆる企業が関与する取引」をクラスとして** 主要な資金洗浄の懸念と認定した。**名簿に無いから安全という判断は成り立たない**
    取るべき行動 取引先審査を、制裁リストの照合だけで完了とせず、 **赤旗指標による判断の記録**を残す作りに変える。 米国向けの決済・コルレスを使う取引については、外部の法的助言の経路を確保する
  • 取引高の数値を被害額として社内に流通させない
    本件の「915億ドル」「170億ドル」「1,791億ドル」は**取引高**で、 出どころ（A7 の自称／FinCEN の調査／FinCEN の分析）と期間がすべて違う。 **足したり被害額として引用すれば、経営の判断を誤らせる**
    取るべき行動 報告資料では数値に**値・単位・確度・出所・時点**を必ず添える。 「自称」と「当局の調査」を区別して書く
  • 書類の目視確認を前提とした統制は見直しの対象になった
    FinCEN は赤旗指標に**「偽造された、または AI で改変された請求書」**を入れ、 ディープフェイクに関する過去の警告を参照している
    取るべき行動 請求書・契約書の確認を目視と押印の有無に依存している業務を洗い出し、 **支払元・設立年・実体との突き合わせ**という別軸の確認を足す
セキュリティ技術者への示唆
  • 法人口座の操作について、接続元の所在と登記上の所在の不一致を見る
    財務省は**「Sub-Agent の口座は A7 の職員が、独自に作った VPN で真の所在を隠して 操作し、支払いを高速に実行する」**と明記した。 **器としての Sub-Agent は、操作の痕跡に特徴が出る**
    取るべき行動 法人向けオンラインバンキングの認証・操作ログについて、 接続元の地理情報・自律システム番号（AS）と登記所在地の不一致、 および**同一接続元から複数法人の口座が操作される**事象を検知対象に加える
  • ステーブルコインの監視対象を「本来のチェーン」だけに限定しない
    FinCEN は **A7A5 に値を連動させた wrapped トークン**が、 本来の Tron / Ethereum 以外の場で現れうると警告している。 **分散型金融の経路を通ると、名前も変わる**
    取るべき行動 取り扱う資産の監視リストに、連動トークン・派生トークンの検出手段を含める。 契約アドレス単位の監視だけでは足りないことを前提に設計する
  • ランサムウェア事案の記録に「資金の経路」の欄を作る
    交渉・支払いが行われた場合、**どの取引所・どのウォレット・どの仲介者を通ったか**が 後から制裁該否の判断材料になる。本件のように器が後から指定されることがある
    取るべき行動 インシデント記録の様式に、交渉窓口・支払いの経路・相手方のアドレスを残す欄を設け、 **事後に照合できる形**で保全する
  • 貿易書類と支払いのデータを突き合わせられる状態にしておく
    赤旗指標の多くは、**書類（商品説明・供給者）と支払い（支払元・経路・法人の設立年）を 並べないと判定できない**。片方だけ見ている限り、何も引っかからない
    取るべき行動 貿易書類の情報と送金データを同じ検索基盤に載せ、 「新設法人・多段経路・業態の不一致」を機械的に拾う照会を用意する
