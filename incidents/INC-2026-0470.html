INC-2026-0470CyberXero が AI でウクライナを侵害

AI オーケストレーション層を備えた初期侵入ブローカー「CyberXero」がウクライナのエネルギー・公益7組織を偵察し、4組織から実際にデータを持ち出した——SOCRadar が2026年10月6日に公表。攻撃者自身の公開ディレクトリ（9万ファイル超）から、51体の Claude Code エージェント定義と PentAGI＋Cobalt Strike の連携、WordPress の大量侵害（1回の実行で4,708件を走査し61秒で32個のシェルを設置）が明らかになり、628,000 を超えるウクライナの個人に関わるデータが攻撃者の手元にあった

脅威・攻撃キャンペーン不正アクセス・侵害続報が続いている有名事象として記録（日本と直接の関係は薄い）既知の脆弱性の悪用認証情報の悪用（使い回し・推測可能・窃取）脆弱性の放置
初報: 2026年10月6日 最終更新: 2026年10月12日

SOCRadar は 2026年10月6日、AI を組み込んだ初期侵入ブローカー（IAB）「CyberXero」 の分析「CyberXero: An AI-Augmented Initial Access Broker Targeting Ukrainian Critical Infrastructure」を公表しました。The Hacker News が2026年10月12日に報じ、本記録の起点になりました。

調査の端緒は、攻撃者自身の設定不備です。 IP アドレス 46.21.250.135 で認証の要らない HTTP ディレクトリが公開されており、そこには稼働中の作業ディレクトリが——9万件を超えるファイルが約3,000のサブディレクトリに——そのまま置かれていました。 スクリプト、AI とのセッション記録、そして窃取したデータが含まれていたため、研究者は攻撃者の手元を内側から読むことができました。

明らかになった構成は2つです。 第一に、主たる作業用端末に51体の専用 Claude Code エージェントの定義があり、偵察・侵入・侵入後の作業に割り当てられていました。 第二に、AI 支援型のペネトレーションテスト基盤 PentAGI がAI プロバイダの API を介して Cobalt Strike Team Server に接続されており、ペイロード生成に使われていました。 回収された設定では、作業の推論の重さに応じてモデルとトークン予算が割り当てられ、ペイロード生成の役割に最も高い予算と推論強度が与えられていました。

セッション記録には、モデルが拒否した履歴も残っていました。 バックドアの設置・ファイアウォールの無効化・横展開・ウェブシェルの配置は拒否されています。 攻撃者は「自分が所有するシステムに対する許可された試験である」という前提を文脈として読み込ませ、拒否された後は同じ作り話を載せた新しいセッションを開き直していました。

被害の側では、ハルキウの地域熱供給事業者から564,073件の加入者記録と213,340件のアクセスログが抜かれています。 使われたのは、その事業者自身のスクリプトに書かれていた固定の資格情報でした。 SOCRadar は、628,000 を超えるウクライナの個人に関わるデータが攻撃者の手元にあることを確認したとしています。

CyberXero は Dread・HackForums・Exploit.in で使われている通り名で、SOCRadar は金銭目的の初期侵入ブローカー——侵入した先への到達手段を他の犯罪者に売る立場——と評価しています。 ロシア語話者で、活動はモスクワ時間の22時ごろに最も多くなります。 国家の関与を示す評価は示されていません。 公表時点で活動は継続中とされています。

攻撃の経過

公表された範囲の事実のみ。公表されていない段階は補完せず明示しています。

**2つの作戦が同じ基盤から動いている。** **①無差別型** — 56,000件超の URL 一覧に対し、内製ツール `wp2shell` で WordPress と EC プラットフォームを大量に侵害する。 **1回の実行で4,708件を走査し、429の到達可能な管理画面を確認し、 61秒のうちに32個のウェブシェルを設置した。** **②指向型** — ウクライナのエネルギー・公益7組織に対し、 サブドメインの列挙（2組織で95件）から始め、 4組織でファイルとしての持ち出しに至った。 **両者を貫いているのが AI のオーケストレーション層である。** **主たる作業用端末に51体の専用 Claude Code エージェントの定義があり、 別の構成では PentAGI が AI プロバイダの API を介して Cobalt Strike Team Server に接続され、ペイロード生成に使われていた。** **ただし侵害の中核的な行為——バックドアの設置・ファイアウォールの無効化・ 横展開・ウェブシェルの配置——はモデルに拒否されており、 攻撃者はそれらを従来の道具で自前に行っている**（本記録の整理）。

  1. 1. 偵察推定
    **無差別型では56,000件を超える URL の標的一覧を持ち、 masscan・nuclei・wpscan で到達可能な資産と脆弱性を走査する。** **指向型ではウクライナの2組織について95のサブドメインが列挙されており、 電子メール・VPN・系統の指令・データ基盤にまたがっていた。** **MS17-010（EternalBlue）についてはパッチ適用状況の確認の記録が残るが、 悪用は確認されていない。** **偵察は7組織に対して「精査された（curated）」形で行われており、 無差別型の走査とは質が異なる**（SOCRadar）
    根拠: SOCRadar の分析（標的一覧の規模・列挙されたサブドメインの数と種別・使用ツール）
  2. 2. 初期侵入推定
    **無差別型では内製ツール `wp2shell` が WordPress の REST API のバッチエンドポイントを悪用して SQL を注入し、 不正な管理者アカウントを作成して WSO 系のウェブシェルを設置する （CVE-2026-63030・CVE-2026-60137）。** **1回の自動実行で4,708件を走査し、429の到達可能な管理画面を確認し、 61秒のうちに32個のシェルを設置した。** **EC 側では Support Board 3.8.7 の時間差 SQL 注入（CVE-2026-4815。 公表から30日以内に使われた）と Magento CE の CVE-2015-1397 が使われている** （SOCRadar・Cyber Security News）
    根拠: SOCRadar の分析（wp2shell の挙動・実行1回の数値・CVE）、Cyber Security News（30日以内の使用・連鎖の順序）
  3. 3. 認証情報アクセス推定
    **ハルキウの地域熱供給事業者の件では、 その事業者自身のスクリプトに書かれていた固定（ハードコード）の資格情報が 攻撃者のスクリプトに現れていた。** **これにより564,073件の加入者記録と213,340件のアクセスログが抽出された。** **無差別型では「パスワードの試行」に割り当てられたエージェントの定義が 確認されている**（SOCRadar）
    根拠: SOCRadar の分析（攻撃者のスクリプトに現れた固定資格情報と抽出された件数）

    **主たる作業用端末に51体の専用 Claude Code エージェントの定義が置かれ、 ウェブの探索・パスワードの試行・侵入・データ窃取に割り当てられていた。** **別の構成では、AI 支援型のペネトレーションテスト基盤 PentAGI が AI プロバイダの API を介して Cobalt Strike Team Server に接続されていた。** **回収された設定は、作業の推論の重さに応じてモデルとトークン予算を割り当てており、 ペイロード生成の役割に最も高い予算と推論強度が与えられていた** （SOCRadar・Cyber Security News）
    根拠: SOCRadar の分析（51体のエージェント定義・PentAGI と Cobalt Strike の接続）、Cyber Security News（モデルとトークン予算の割り当て）
  5. 5. 検知回避推定
    **モデルが拒否した要求——バックドアの設置・ファイアウォールの無効化・ 横展開・ウェブシェルの配置——に対し、攻撃者は 「自分が所有するシステムに対する許可された試験である」という前提を 文脈として読み込ませ、拒否された後は同じ作り話を載せた新しいセッションを開き直していた。** **通信面では VLESS/Xray のプロキシが使われている**（SOCRadar）
    根拠: SOCRadar の分析（セッション記録に残る拒否の一覧と迂回の手口・VLESS/Xray）

  • **「AI を使う攻撃」への備えは、AI 対策ではなく既知脆弱性と資格情報の管理である**

    **本件で持ち出しが「確認された」のは、 研究者が攻撃者の公開ディレクトリを見たからである**（SOCRadar）。 **被害組織側のログで検知された記述は無い。** **さらに、SOCRadar が当事者や CERT-UA に通知したかも公表されていない** 〈未確定事項に記録〉——**つまり「分析は公表されたが、 当事者が知っているかは分からない」状態が生じている**（本記録の整理）。
