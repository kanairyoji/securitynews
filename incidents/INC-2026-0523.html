INC-2026-0523Kimsuky がウクライナ専門家を標的

北朝鮮系の脅威アクター Kimsuky が、ウクライナの外交・安全保障・国際政策の 専門家を標的にした。韓国の Genians が2026年10月12日に公表したもので、 2026年8月6日にソウルのサイバーセキュリティ会議（KCSCON 2026）の 登壇依頼を装った電子メールから始まる。初回のメールには悪性のリンクも 添付も無く、返信を引き出してから資料を送る「返信誘い」の手口を取る。 続いて Codeberg に置いた書庫のリンク、PDF を装った LNK ファイル、 正規の Zoom インストーラを偽装した実行ファイルが使われた。 C2 には GitHub・GitLab・Codeberg が使われ、作戦名は Operation GitPower。 同じ基盤の上に日本語の文書2点（ICC の分析と日経のコラム頁）が置かれており、 Genians は日本語話者を標的とする準備の可能性を指摘している。 観測された攻撃の大半は不成功

脅威・攻撃キャンペーン初報のみ日本に波及した海外事案人を介した誘導（ビッシング・BEC）
初報: 2026年10月12日（Genians Security Center の公表） 最終更新: 2026年10月15日

北朝鮮系の脅威アクター Kimsuky が、ウクライナの外交・安全保障・国際政策の専門家を標的にしていました（出典1・2）。韓国のセキュリティ企業 Genians（Genians Security Center）が2026年10月12日に公表したもので、執筆は Mun Chong Hyun 氏です（出典1）。作戦名は Operation GitPower です（出典1・2）。

標的の選び方について、Genians はこう述べています（出典2。本記録の訳）。「Kimsuky のウクライナに対する攻撃は、戦争に関する情報、北朝鮮軍の損失の規模、捕虜の尋問と処遇をめぐる動き、および韓国とウクライナの協議の内容を集めることを狙ったものである可能性がある。」

背景には、北朝鮮とロシアの軍事協力があります（出典2）。北朝鮮は2024年以降、ウクライナでの戦争に兵員を送り、ロシアへの軍事支援を行っています（出典2）。Genians は、2026年9月にウクライナ軍が捕らえた北朝鮮兵2名が韓国へ移送されたことも、平壌にとって情報上の関心事になりうると指摘しています（出典2）——捕虜が北朝鮮軍の作戦や損失について何を明かすかという点です。

手口の中心は「返信誘い」です（出典1・2）。2026年8月6日、攻撃者はソウルで開かれるサイバーセキュリティ会議（第14回 KCSCON 2026）の主催者を装い、ウクライナの安全保障専門家に登壇を依頼する電子メールをProton Mail のアカウントから送りました（出典1）。メールには会議の実在する情報が書かれ、旅費と宿泊費の負担も申し出ていました（出典2）。悪性のリンクも添付も、この時点では入っていません（出典1・2）。代わりに、受信者に返信を促し、返信があってから追加の資料を送る形を取っています（出典2）。

別の例では、欧州の政策研究者を装い、ロシアと北朝鮮の軍事協力に関する報告書への意見を求めました（出典2）。受信者が応じたのち、研究資料を装った悪性の書庫のリンクが送られました（出典2）。

続く段階では、PDF を装った LNK ファイル（.pdf.lnk のような二重拡張子）と、正規の Zoom インストーラを偽装した実行ファイルが使われています（出典1・2）。マルウェアは、感染した端末から情報を集め、侵害した系へのアクセスを保ち、盗んだ情報を攻撃者が管理する基盤へ送る設計です（出典2）。

C2 には、正規のソフトウェア開発プラットフォームが使われています（出典1・2）——GitHub（Contents API への投入・生データ用リポジトリ・ハードコードされたトークン）、GitLab（複数のリポジトリ）、Codeberg（悪性の書庫の配布）です（出典1）。作戦名の GitPower はここに由来します（出典1・2。整理は本記録）。

日本に関わる点が1つあります（出典1・2）。Genians は、同じ基盤の上に日本語の文書2点（国際刑事裁判所（ICC）に関する分析と、日本経済新聞のコラム頁）を見つけており、攻撃者が日本語話者を標的とする準備をしていた可能性を指摘しています（出典1・2）。本記録はこれを「準備の可能性」として記録します（本記録の留保）——日本国内で実際に標的とされた組織・個人は公表されていません。

観測された攻撃の大半は不成功だったと Genians は述べています（出典1・2）。
