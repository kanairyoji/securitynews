INC-2026-0553Candiru が広告経由でアルジャジーラ狙う

広告が画面に表示された瞬間に感染する——Candiru が広告配信事業者 Discover-Tech を経由して アルジャジーラの端末45台を狙い、NATO・国連・20数カ国の政府網にも広告が届いていた

脅威・攻撃キャンペーン不正アクセス・侵害初報のみ有名事象として記録（日本と直接の関係は薄い）設計・実装上の不備ガバナンス・組織文化（ガイドライン理解不足・丸投げ等）未知の脆弱性の悪用
初報: 2026年10月15日（Citizen Lab と Confiant の報告公開） 最終更新: 2026年10月16日（本記録の確認時点）

これまで「広告の仕組みはスパイ活動に使えるのではないか」という推測はありました。今回はじめて、技術的な証拠が揃いました。

カナダ・トロント大学 Munk School の Citizen Lab は2026年10月15日、イスラエルの広告配信事業者 Discover-Tech が、傭兵スパイウェア業者の標的追跡と端末侵害の経路になっていたとする報告を公表しました（出典1）。広告セキュリティ企業 Confiant との並行調査です（出典1・2）。

本記録が要点と見たのは、次の4点です。

  • 利用者は何も押していない。広告が画面に表示された瞬間に攻撃が始まる。 Discover-Tech の Controlium というプラットフォームは、顧客に対し「広告が描画された瞬間に、端末の匿名性を解除し、指紋を取り、自動的に感染させる——ゼロクリック攻撃の一形態」を可能にすると説明されています（原文英語。出典1・2）。広告が画面外（背景）で読み込まれた場合も含まれます（出典5）。
  • 広告そのものには攻撃コードが入っていない。だから広告審査に引っかからない。 広告が表示されると、中の小さなコードが端末の広告ID と IP アドレスをDiscover-Tech のサーバへ送ります。サーバは標的かどうかを判定し、標的であればブラウザやアプリを狙う攻撃コードを返し、そうでなければ何も返しません（出典4）。CSO Online は「第三者の検証スキャナには無害なバナーが見えていた。ほとんどの閲覧者にとっては実際に無害だったからだ」という指摘を伝えています（原文英語。出典3）。
  • アルジャジーラの端末45台が標的になった。Citizen Lab は Candiru の仕業と高い確信で判断した。 2024〜2025年の事案です（出典1・4）。ただし「標的になった45台」と「感染した45台」で資料の表現が揺れており、単位も「台」と「人」で揺れています〈齟齬1・2〉。
  • 広告が届いていた先には NATO・国連・EU 機関・20数カ国の政府網がある。ただし「広告が表示されたこと」は「感染したこと」ではない。 Citizen Lab 自身がこの区別を明示しており、機微な網への広告表示が感染につながったかは分かっていません〈未確定3〉。本記録はこの留保を落とさない（本記録の方針）。

Citizen Lab の指摘を受け、Google は Discover-Tech の広告取引所への接続を打ち切り、IAB Europe は2026年10月初めに登録簿から外しました（出典1・4）。Beeswax は買い付けプラットフォームから排除、Vungle（Liftoff）は審査のため接続停止、Eskimi はアカウントとドメインを遮断しました（出典1）。

攻撃の経過

公表された範囲の事実のみ。公表されていない段階は補完せず明示しています。

**広告の入札データから標的を個人単位で特定し、落札した広告枠に 小さなコードを載せて端末へ届ける**（出典1・3・4）。 **コードは広告ID と IP アドレスを Discover-Tech のサーバへ送り、 サーバが標的と判定した端末にのみ攻撃コードを返す**（出典4）。 **感染後の通信は3段階——Discover-Tech の広告サーバ → Candiru の選別 （バリデータ）サーバ → C&C サーバ——をたどる**（出典1・4）。 **利用者の操作は要らず、広告が画面に表示された（背景で読み込まれた場合も含む） 時点で始まる**（出典1・5）。

  1. 1. 偵察確認済
    **広告入札の要求に乗って流れる情報から、標的の端末を特定する**（出典3）。 **端末の識別子（広告ID・cookie ID・モバイル広告ID）、 精密な位置情報、IP アドレスが広告取引所を介して共有される**（出典3）。 **Controlium は顧客に対し、広告ID・ブラウザID・IP アドレスによる 個人単位の指定を可能にしている**（出典1）。 **Citizen Lab は「広告が数百万台の端末に Candiru のサーバへ ひそかに接触させており、大規模な追跡と偵察のためと見られる」と 述べている**（原文英語。出典2）。
    根拠: 「オークションの仕組みは、単一の個人を標的にできるように設計されている」 （原文英語。出典3）
  2. 2. 初期侵入確認済
    **落札した広告が端末で描画されると、広告内のコードが 端末の広告ID と IP アドレスを Discover-Tech のサーバへ送る**（出典4）。 **サーバは標的かどうかを判定し、標的であればブラウザまたはアプリを狙う 攻撃コードを返し、そうでなければ何も返さない**（出典4）。 **利用者の操作は要らない。広告が画面外（背景）で読み込まれた場合も含む** （出典5）。 **Candiru はアルジャジーラの Windows ソフトウェアを狙った**（出典3）。 **最初の実行コードそのものは研究者が確保できていない**〈未確定1〉。
    根拠: 「広告が描画された瞬間に、端末の匿名性を解除し、指紋を取り、 自動的に感染させる——ゼロクリック攻撃の一形態」（原文英語。出典1・2）
  3. 3. C2通信確認済
    **感染した端末の通信は3段階をたどる**（出典4）。 **①Discover-Tech の広告サーバ → ②Candiru の選別（バリデータ）サーバ → ③C&C サーバ**（出典1・4）。 **Citizen Lab はバリデータの指紋（V1）が305ドメインに一致し、 C&C の指紋（C1）が回収した標本の C&C サーバと一致したとしている**（出典1）。
    根拠: 「感染した端末の通信は三段階を経る。Discover-Tech の広告サーバから Candiru の選別サーバへ、さらに命令制御サーバへと続く流れである」 （出典4。原文韓国語）
  4. 4. 収集推定
    **Controlium は、スパイウェア業者に通話の録音、マイクの起動、 メッセージとメールの吸い出しを可能にするとされる**（出典2）。 **政府職員に加え、記者・反体制派・大使館職員の端末の感染にも 使われたとされる**（出典2）。 **アルジャジーラの事案で何が持ち出されたかは公表されていない** （本記録の確認）。
    根拠: 「Controlium のソフトウェアは、スパイウェア企業に通話を録音し、 マイクを起動し、メッセージとメールを吸い出すことを可能にする」 （原文英語。出典2）

被害組織の対応

所要日数は経過（タイムライン）の各時点から算出しています。
**2024〜2025年の事案が2026年10月15日に公表された。 最短でも約10か月、最長で約2年の開きがある**（出典1。算出は本記録）。
**検知から公表までではなく「事案の発生から第三者による公表まで」である** （本記録の明示）。 **Citizen Lab が調査をいつ開始し、いつ各社へ開示したかは 報告に示されていない**（本記録の確認）。 **アルジャジーラがいつ気づいたかも公表されていない**（本記録の確認）。
この事案で下された判断
  • トレードオフ: **留保を置けば、見出しの訴求力は落ちる**（本記録の整理）。 **一方、留保なしに出せば「NATO が感染した」と読まれ、 後から訂正が要る**（本記録の整理）。
  • トレードオフ: **先に各社へ渡せば、公表時点で経路は断たれている**（本記録の整理）。 **一方、各社が対処しないまま公表を遅らせれば露出が続く**（本記録の整理）。

広告そのものには攻撃コードが無い——だから6年間、広告審査をすり抜けた原因・手口

この事案の中心は、攻撃コードの精巧さではなく「どこに置かなかったか」です（本記録の整理）。

広告が端末で表示されると、広告内の小さなコードが端末の広告ID とIP アドレスを Discover-Tech のサーバへ送ります。サーバはその端末が標的かを判定し、標的であればブラウザやアプリを狙う攻撃コードを返し、そうでなければ何も返しません（出典4）。

CSO Online は、この作りの帰結を次のように伝えています（原文英語。出典3）。

広告は清潔だった。そこが恐ろしい点だ。誰も何も押していない。 （中略）ほとんどの場合、サーバは何も返さなかった。選ばれた標的だけが悪性のコードを受け取った。 第三者の検証スキャナには無害なバナーが見えていた。ほとんどの閲覧者にとっては、実際に無害だったからだ。これがタグが検証をすり抜けた仕組みそのものである。

Citizen Lab 自身も、Discover-Tech が「悪意あるコードそのものも、悪意あるコードへの指し先さえも、広告を配信・表示する企業と直接には共有していない」と述べています（原文英語。出典2）。

ここから読める性質は2つあります（本記録の評価）。

第一に、スキャンによる事前検証はこの手法に対して原理的に無効です。 検証する側が見るものと、標的が受け取るものが違います（本記録の整理）。外部スクリプトの安全性を「スキャンで確認している」と説明している組織は、その説明が本件に対して成り立たないことを前提として記録に残す必要があります（本記録の提案）。

第二に、審査の仕組みも6年間これを通し続けました。 Discover-Tech は2020年から2026年まで、Google と IAB Europe の承認ベンダー一覧に載っていました（出典1・4）。CSO Online は、報告が「審査はしばしば自己申告、フォームにチェックを入れるだけに留まっていた」と記していることと、「認定は、その背後にある審査の分だけの価値しかない」という指摘を伝えています（原文英語。出典3）。

なお、Discover-Tech のプラットフォーム側にも不備がありました。 Controlium の認証に不備があり、研究者は認証不要のログ端点に到達でき、そこに利用者名120件が露出していました（出典1）。研究者はトークンの不備が悪用可能かどうかは試していません（出典1）。スパイウェアを売る側のプラットフォームが、自身の顧客の名を漏らしていたことになります（本記録の整理）。

判断評価評価の根拠と留保
機能した**本記録の評価**——**この留保がなければ、報告は別の方向へ読まれていた。** **実際、留保があっても報道は「45台を感染させた」と書いており**〈齟齬1〉、 **本文の表現を保たない転載が起きている**（本記録の指摘）。 **留保を本文に明示したことで、読み手が原典に戻れば正しい範囲が分かる** （本記録の評価）。

CISO・経営層への示唆
  • **広告識別子は「どうでもいい識別子」ではない——身元管理の外にある 永続的な識別子を、匿名のオークションに毎日渡している**
    **CSO Online は「多くの組織が利用者の身元管理に多額を投じながら、 社用携帯が永続的な識別子を、1日に数千億回走る匿名のオークションへ 渡し続けている」という指摘を伝えている**（原文英語。出典3）。 **Citizen Lab の報告は「広告識別子の遮断だけでこの攻撃手法は 止められたはずだ」としている**（出典3）。
    取るべき行動 **①社用端末（iOS / Android）の広告識別子が MDM で無効化されているかを確認する。 ②無効化していない場合、無効化による業務影響（広告効果測定を使う部門の有無）を 洗い出して判断する。 ③BYOD で業務データを扱っている端末について、 同じ識別子が渡っている事実を前提に方針を決める。**
  • **「認定ベンダー」の価値は、その背後にある審査の中身で決まる**
    **Discover-Tech は2020年から2026年まで、Google と IAB Europe の 承認ベンダー一覧に載り続けた**（出典1・4）。 **CSO Online は「審査はしばしば自己申告、 フォームにチェックを入れるだけに留まっていた」という報告の記述と、 「認定は、その背後にある審査の分だけの価値しかない」という指摘を 伝えている**（原文英語。出典3）。
    取るべき行動 **①自組織が依拠している「認定」「承認ベンダー一覧」「業界団体の登録簿」を列挙する。 ②それぞれについて、審査が自己申告か実査かを確認する。 ③自己申告に依拠しているものについて、 自前の確認（契約上の監査権・再委託先の開示義務）を追加するかを判断する。**
  • **到達範囲と被害範囲を混ぜない。ここを混ぜると対応の規模を誤る**
    **Citizen Lab は「広告のインプレッションは感染を意味しない」と 明示している**（原文英語。出典1・3）。 **それでも報道の段階で「45台を感染させた」「NATO に広告が届いた」が 同じ強さで並び、読者が過大に受け取る形になっている**〈齟齬1〉。
    取るべき行動 **①本件に関する社内報告では「広告が表示された可能性」と 「感染が確認された範囲」を別の行に分けて書く。 ②自組織の調査は「IoC との照合」から始め、 照合できるログが無い場合はその欠落を課題として記録する。 ③経営への報告で、感染の有無が未確定であることを明示する。**
  • **「広告の無効化」は、利便を削る代わりに確実に効く数少ない対策である**
    **本件の攻撃は、広告が表示されることと広告ID が渡ることの 2つを前提にしている**（出典1・3・4。整理は本記録）。 **最初の侵害コードが分かっていないため、 脆弱性修正を当てにする対策は組めない**〈未確定1〉。
    取るべき行動 **①機微なデータを扱う端末群を特定し、その範囲で 広告遮断（DNS / SWG 層での遮断、広告識別子の無効化）を適用する。 ②高リスクの利用者（経営層・機微な地域への出張者・調査報道に関わる職員）に Apple の Lockdown Mode などの強化設定を適用する。 ③全社一律ではなく、範囲を区切って適用する前提で費用と影響を見積もる。**
セキュリティ技術者への示唆
  • **アプリ内広告は、ブラウザ拡張の広告遮断では止まらない**
    **CSO Online は「Discover-Tech の入札の多くはモバイルアプリ内の広告枠を 対象としており、ブラウザ拡張では通常見落とされる」と伝えている** （原文英語。出典3）。 **広告が表示されたのはアプリ約7.5万件・サイト約12万件である**（出典1・3）。
    取るべき行動 **①広告遮断を DNS またはセキュア Web ゲートウェイの層に置き、 管理下のスマートフォンのアプリ内広告にも届く構成にする。 ②ブラウザ拡張による遮断は補助として扱い、それだけで足りると考えない。 ③遮断一覧の更新経路（誰が・どの頻度で）を決めておく。**
  • **IoC の照合先を先に確認する——2024〜2025年のログが残っていなければ何も出ない**
    **公表されたのはドメイン13件と SHA-256 1件、 およびバリデータ指紋に一致した305ドメインである**（出典1）。 **一方、事案の期間は2024〜2025年である**（出典1）。 **boannews は「記録から3段階の接続の流れを探すべきだ」と助言している** （出典4）。
    取るべき行動 **①DNS・プロキシ・EDR のうち、通信先を照合できるログがどれかを確認する。 ②そのログの保持期間が2024〜2025年まで遡れるかを確認する。 ③遡れない場合は「照合不能」を結論として記録し、 保持期間の見直しを別件として起票する。 ④IoC は原典（出典1）から取る。本記録は悪性を検証していない。**
  • **広告枠は「他人のコードが自分の端末で走る場所」である—— その前提で監視点を置く**
    **CSO Online は「すべての広告は、誰か他人のコードが あなたの端末で走っているものだ」という指摘を伝えている**（原文英語。出典3）。 **広告枠に入るコードが実行の経路になっている**（出典3）。
    取るべき行動 **①広告のインプレッションに続く不審な発信（見慣れないドメインへの要求、 短時間での連続した接続）を見る経路があるかを確認する。 ②無い場合、どのログで代替できるかを決める（プロキシのリファラ、DNS の時系列）。 ③機微な端末群では、広告ドメインを監視対象から除外していないかを確認する。**
  • **「広告そのものは無害」という作りを、検証の仕組みの限界として記録する**
    **悪性コードは標的と判定された端末にのみ返され、 それ以外には何も返らない**（出典3・4）。 **CSO Online は「第三者の検証スキャナには無害なバナーが見えていた。 ほとんどの閲覧者にとっては実際に無害だったからだ。 これがタグが検証をすり抜けた仕組みそのものだ」という指摘を伝えている** （原文英語。出典3）。
    取るべき行動 **①自組織が広告・外部スクリプトの安全性を「スキャンで確認している」場合、 選択的配送に対して無効であることを前提として記録する。 ②スキャンに代えて、実行時の挙動（発信先・リダイレクト）を見る方向に寄せる。 ③外部スクリプトを許可する判断を、ベンダーの認定ではなく 自組織で観測できるかどうかで決める。**
