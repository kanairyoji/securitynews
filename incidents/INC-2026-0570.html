INC-2026-0570OK貯蓄銀行が3日で2度目の侵害

韓国の OK저축은행（OK貯蓄銀行）が2026年10月16日、最初の侵害からわずか3日後の10月15日未明に モバイル受信（預金）サービス関連のホームページが攻撃を受け、顧客268名の氏名・口座番号・商品名・残高・利率・ 最終取引日が追加で流出したと明らかにした——攻撃は10月15日午前3時32分から約4時間続き、 使われた IP は金融保安院が事前に共有していた不審 IP とは別のものだった。 10月12日に公表済みの融資申込ページの侵害（顧客250名）と合わせ、公表された被害者は計518名になる（重複の有無は未確認）

不正アクセス・侵害続報が続いている有名事象として記録（日本と直接の関係は薄い）公表されていない／不明
初報: 2026年10月16日 最終更新: 2026年10月17日

韓国の貯蓄銀行 OK저축은행（OK貯蓄銀行）は2026年10月16日、モバイル受信（預金）サービス関連のホームページが攻撃を受け、顧客268名の情報が追加で流出したことを確認したと明らかにした。

攻撃が行われたのは 10月15日午前3時32分から約4時間（報道の一部は午前7時34分までと記す）。流出したのは氏名・口座番号・金融商品名・残高・利率・最終取引日である。同行は10月12日に、融資申込ウェブページの侵害で顧客250名の氏名・生年月日・住所・年収・融資額などが流出したと公表したばかりで、3日後に2度目の攻撃を受けたことになる。

注目すべき点が2つある。第一に、今回の攻撃に使われた IP は、金融保安院（금융보안원）が事前に共有していたハッキング疑い IP とは別のものだった。第二に、追加の流出は、最初の侵害を受けて10月15日まで実施していたシステム全数点検の過程で見つかった——つまり、点検中に新たな攻撃を受けていた。

同行は金融監督院（금융감독원）へ報告し、対象顧客へショートメッセージとメールで個別に通知した。対策として「疑わしい IP と接続経路の遮断、口座照会の防御ロジックのパッチ、異常行為検知・遮断ソリューションの緊急適用」を完了し、「現在、新規の異常接近は無い状態」としている。

公表された被害者は計518名になるが、2つの事案の対象が重複するかどうかは確認されておらず、単純合算での被害規模の算定は難しいと伝える報道もある。

「緊急対応を完了した」と「別系統は無防備だった」は両立する評価・解釈出典 [1] [2] [3]

ここからは本記録の作成者の評価である。

第一に、この事案の要点は件数ではなく、3日という間隔である。流出したのは268名で、規模としては大きくない。しかし、最初の侵害を公表し、緊急対応を完了したと述べた3日後に、別系統のサービスが4時間にわたって攻撃を受け、成功している。しかもそれに気づいたのは攻撃の最中ではなく、全数点検という別の作業の中だった。

第二に、「疑い IP の共有」を前提にした防御の限界が、そのまま現れている。金融保安院は業界に対しハッキング疑い IP を事前共有しており、同行はそれを遮断していた。ところが今回使われたのは共有リストに無い IP だった。指標ベースの遮断は、攻撃者が送信元を変えるだけで回避される。同行が事後に投入したのが「異常行為検知・遮断ソリューション」だったことは、この順序を物語っている——指標（誰が来たか）から振る舞い（何をしたか）への切り替えが、侵害を2回受けてから行われた。

第三に、「最初の対応の範囲」が問われる。最初の侵害は融資申込ページ、2度目はモバイル受信サービスで、系統が異なる。最初の緊急対応が当該ページの周辺に閉じていたとすれば、他系統は手つかずのまま残る。侵害の初動で「同じ作りの他のページはどこにあるか」を先に列挙するかどうかで、この3日間の結果は変わりえた（本記録の評価。同行はそう説明していない）。

第四に、流出項目の性格が最初の事案と違う。最初は申込情報（年収・融資額）、今回は口座番号・残高・利率・最終取引日である。後者は、本人しか知らないはずの取引情報を含む。「お客様の残高は◯◯円、最終取引は◯月◯日ですね」と言える相手は、金融機関を名乗る詐欺電話にとって決定的な説得材料になる（本記録の評価）。
