INC-2026-0593H2O ID 約126万件が漏えい

阪急阪神百貨店の予約サイト経由で顧客管理システムが不正アクセスを受け、 グループ共通ID「H2O ID」の個人情報 約126万件が漏えい（通販2サイトは調査中）

不正アクセス・侵害初報のみ日本の組織が当事者公表されていない／不明
初報: 2026年10月19日 最終更新: 2026年10月20日

エイチ・ツー・オー リテイリングは2026年10月19日、子会社の阪急阪神百貨店が運営する 「阪急百貨店・阪神百貨店予約サイト」を経由して顧客管理システムが第三者の不正アクセスを受け、 グループ共通会員ID「H2O ID」の個人情報 約126万件の一部が漏えいしたと公表した。 同社は「ほぼ全ての H2O ID 会員」が対象だとしている。漏えい項目は H2O ID・氏名・性別・ メールアドレス・郵便番号・住所・電話番号・年齢・生年月日・利用サービス項目に及ぶ。 10月16日に予約サイト経由の侵害を確認して同日サイト全体を停止、17日には通販サイト 「HANKYU HANSHIN E-STORES」と「Remo Order」でも不正アクセスを確認して両サイトを停止、 19日に漏えいが判明した。通販2サイトからの漏えいの有無は調査中で、 同サイトはクレジットカードの種別・下4桁・名義・有効期限などを保持している （番号全桁とセキュリティコードは非保持）。ログインパスワードの漏えいは確認されていない。

予約サイトを経由して顧客管理システムが侵害され、ほぼ全会員の共通ID情報が漏えいした概観出典 [1] [2]

エイチ・ツー・オー リテイリングと阪急阪神百貨店の連名公表（2026年10月19日）によれば、分かっているのは次の点である。

  • 2026年10月16日（金）、「阪急百貨店・阪神百貨店予約サイト」を経由し、顧客管理システムに対する第三者による不正アクセスを確認した。
  • 同日、外部からの不正な通信を遮断するなどの緊急措置を講じ、被害拡大防止のため予約サイトのシステム全体を停止した。
  • 10月17日（土）、「HANKYU HANSHIN E-STORES」および「Remo Order」でも不正アクセスが確認されたため、同日に両サイトのシステム全体を停止した。
  • 10月19日（月）、顧客管理システムで管理する「H2O ID」のうち約126万件の個人情報の一部が漏えいしたと判明した。
  • 漏えいの対象項目は H2O ID、氏名（姓名・漢字カナ）、性別、メールアドレス、郵便番号、住所、携帯電話番号、電話番号、年齢、生年月日、H2O ID でのご利用サービス項目。
  • ログインパスワードの漏えいは確認されていない。
  • 現時点で、本件に起因すると考えられる不正利用や二次被害は確認されていない。

侵害されたのは個々のサイトのデータではなく、グループ共通IDの顧客管理システムである。予約サイトという1つの入口から、グループ横断の会員基盤に到達されたという構図が、本件の中心にある。

通販2サイトは「保持している情報」だけが示され、漏えいの有無は調査中である被害規模・影響範囲出典 [1]

公表文は、HANKYU HANSHIN E-STORES と Remo Order について「漏えいの可能性については現在調査中」とした上で、同サービスが保持している情報を列挙している。

  • 商品注文履歴
  • クレジットカード情報の一部（カード種別、カード番号の下4桁、名義、有効期限）
  • ポイントカード情報の一部（ポイントカード種別、カード番号の下4桁）
  • アドレス帳の情報

カード情報については「当社では決済情報の非保持化に対応しており、クレジットカード番号全桁およびセキュリティコードは一切保持しておりません」として、不正利用のおそれはないとしている。ポイントについても下4桁のみの保持であるため不正利用のおそれはないとしている。

以下は本記録の評価である。 列挙されたのは「持っているもの」であって「出たもの」ではない。読者がこの段階で判断できるのは、最悪の場合に何が出るかの上限だけである。決済情報の非保持化が効いていること（番号全桁とセキュリティコードが存在しない）は事実として確認できるが、カード種別・下4桁・名義・有効期限の組み合わせは、フィッシングで残りの桁を聞き出す材料になる。漏えい済みの H2O ID 情報（氏名・住所・電話番号・メールアドレス）と突き合わせれば、「あなたの○○カード（下4桁××××）の更新手続き」という騙り方が成立する。

件数が固まった日に公表しており、確認から3日で出している組織の対応出典 [1]

事実として確認できる時間軸は次の通りである。

日付 出来事
10月16日（金） 予約サイト経由の不正アクセスを確認。同日、通信遮断と予約サイト全体の停止
10月17日（土） E-STORES・Remo Order でも不正アクセスを確認。同日、両サイト停止
10月19日（月） 約126万件の漏えいが判明。同日、公表

検知から封じ込め（遮断・停止）までは同日。検知から公表までは3日である。

以下は本記録の評価である。 金曜に検知し、土曜に対象を広げて停止し、月曜に件数を添えて公表するという順番は、週末を挟んだ事案の処理として速い。特に、漏えいの判明（19日）と公表（19日）が同日である点は、「件数が固まるまで黙る」という失敗を避けている。一方で、件数は約126万件という概数のままで、通販2サイトは調査中である。つまり同社は「確定を待たずに、確定した部分だけを出す」判断を取っている。この判断は、会員が自衛（不審なメール・SMS への警戒）を始める時期を早める点で妥当である。

会員への注意喚起が「送信元メールアドレス」まで指定している点は、模倣のしやすさを意識した対応である対策・注意喚起出典 [1]

公表文は会員への依頼として、登録済みのメールアドレスや電話番号宛に同社を装った不審なメール・SMS・電話が行われる可能性を挙げ、自社からの案内の送信元メールアドレスを noreply@h2o-retailing.co.jp と明示している。

以下は本記録の評価である。 漏えいした項目には、メールアドレス・携帯電話番号・氏名・住所がすべて含まれている。これは百貨店を騙るフィッシングに必要な材料が一式そろった状態であり、しかも同社は同時期に会員へ正規のお詫びメールを順次送っている。「お詫びメールが届くことを会員が知っている」状況は、偽のお詫びメールが最も通りやすい状況でもある。 送信元アドレスを先に宣言しておくのは、この重なりに対する実務的な手当てである。

ただし、送信元の表示名やアドレスは偽装できる。送信ドメイン認証（SPF / DKIM / DMARC）の設定状況や、DMARC のポリシー（reject か none か）は公表されていない。

侵入経路・滞留期間・検知の端緒がいずれも公表されていない未確定事項出典 [1]

本記録が重要と判断した未確定事項は次の通りである。

  • 侵入経路・手口：「予約サイトを経由し顧客管理システムに」とあるのみ。悪用された機能も、脆弱性の有無も特定されていない（調査中）。
  • 侵入期間：確認日は示されているが、いつから侵入されていたかの記述が無い。侵入から検知までの時間を測れない。
  • 検知の端緒：自社の監視で気づいたのか、外部からの指摘か、業務の異常からかが書かれていない。
  • 通販2サイトの漏えい有無：調査中。
  • H2O ID 会員の総数：「ほぼ全会員」の母数が示されていないため、約126万件の位置づけを検算できない。

本記録はこれらを推測で埋めない。 続報が出た時点で追記する。

  • グループ共通IDは「会員基盤」であると同時に「全グループの単一障害点」である。 つながっているフロントの数だけ侵入口がある

  • 「カード番号を持たない」投資は、事故が起きたときに説明できる数少ない事実になる
    本件の公表文は、決済情報の非保持化によりカード番号全桁とセキュリティコードを 一切保持していないことを示し、カード不正利用のおそれが無いと説明できている。 ポイントカードも下4桁のみの保持であるため同様に説明できている。 **漏えいは起きたが、最悪の部分は構造的に起きえなかった**という説明が成立している
