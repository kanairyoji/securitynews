INC-2026-0617アツミ電氣DVRに非公開機能2件

アツミ電氣製の EX-SDI デジタルビデオレコーダ ADX シリーズに、 ネットワーク経由で到達できるメンテナンス用の非公開機能が2種類実装されていた—— 管理者権限でログインできる利用者が任意の OS コマンドを実行でき（CVE-2026-97627・CVSS v4.0 8.6）、 不正なファームウェアへ書き換えもできる（CVE-2026-100737・同 6.9）。 販売終了から年数が経過した ADX1004/ADX1008/ADX2016 は全バージョンが対象で対策ファームウェアの提供が無い

脆弱性初報のみ日本の組織が当事者設計・実装上の不備
初報: 2026年10月20日 最終更新: 2026年10月20日

販売終了した機器に「対策ファームウェアを出さない」と明記された脆弱性公表です。

2026年10月20日、JPCERT/CC は JVN#88864366「アツミ電氣製 DVR に利用可能な非公開機能を悪用される問題」を公表しました（出典1）。同社の EX-SDI デジタルビデオレコーダ ADX シリーズには、ネットワーク経由で外部から接続できるメンテナンス用のサービスが2種類実装されており、管理者権限でログインできる利用者が任意の OS コマンドを実行でき（CVE-2026-97627・CVSS v4.0 基本値 8.6）、不正なファームウェアへ書き換えることもできます（CVE-2026-100737・同 6.9）（出典1・2・3・4）。

本記録が要点と見たのは、次の3点です。

  • 対策が出ない機種がある。 ADX1004 / ADX1008 / ADX2016 は全バージョンが対象で、JVN は「販売終了から年数が経過しているため、対策ファームウェアの提供はありません」と明記しています（出典1）。開発者が示す対応はネットワークに接続しない運用か、後続製品（ADX5000シリーズ）への置き換えの2択です（出典1・2）。
  • 修正版の適用が、パスワード運用の見直しを伴う。 開発者は、対策ファームウェア Ver.10.8.237 へアップグレードすると「初期値や弱いパスワードが使用できなくなる」と案内しています（出典2）。脆弱性の成立前提が「管理者権限でログイン可能なユーザー」である以上、初期パスワードのまま運用されている機器が現実に存在することを織り込んだ対策である（本記録の評価）。
  • 成立前提は管理者ログインだが、CVSS は到達性を Network として評価している。 CVE-2026-97627 のベクタは CVSS:4.0/AV:N/AC:L/AT:N/PR:H/UI:N/VC:H/VI:H/VA:H/SC:N/SI:N/SA:N で、PR:H（高い権限が必要）でありながら AV:N（ネットワーク経由）・AC:L（容易）です（出典1・3）。インターネットに露出した DVR で初期パスワードが使われていれば、PR:H は実質的な障壁にならない（本記録の評価）。

悪用の観測については、JVN・開発者の案内のいずれも言及していません〈未確定1〉。国内に設置されている台数、インターネットに露出している台数も公表されていません〈未確定2〉。

問題は設定不備ではなく、製品に実装されていたメンテナンス用のサービス2種類である原因・手口出典 [1] [2] [3]

JVN と開発者の案内から、起きていることは次のとおりである（出典1・2）。

  • JVN は双方の脆弱性を CWE-912（Hidden functionality／非公開機能） として分類している
  • 開発者の案内によれば、ネットワーク経由で外部から接続できるメンテナンス用のサービスが2種類実装されていた
  • 任意の OS コマンドを実行できるサービス
  • ファームウェアのアップグレードを実行できるサービス
  • 成立前提は「当該製品に管理者権限でログイン可能なユーザー」である

これは設定を誤った結果ではなく、製品が備えていた機能そのものが問題として扱われている（本記録の整理）。保守のために用意された機能が、利用者に公開されないまま外部から到達できる状態にあった、という構図である。

ベクタの読み方に注意が要る。CVE-2026-97627 はCVSS:4.0/AV:N/AC:L/AT:N/PR:H/UI:N/VC:H/VI:H/VA:H/SC:N/SI:N/SA:N で、AV:N（ネットワーク経由）・AC:L（容易）・AT:N（攻撃前提条件なし） でありながらPR:H（高い権限が必要） である（出典1・3）。つまり「管理者としてログインできれば、あとは容易にネットワーク越しに実行できる」という評価である。

PR:H は一見高い障壁に見えるが、管理者パスワードが初期値または弱い値のまま運用されていれば実質的な障壁にならない（本記録の評価）。この点は開発者の案内が裏づけている。対策ファームウェアの注意点として「アップグレード後は、初期値や弱いパスワードが使用できなくなります。該当する場合は新しいパスワードを設定してください」と書かれており（出典2）、初期値や弱いパスワードで運用されている機器が現実に存在することを前提にした記述である。

対策ファームウェアが提供されない3機種について、JVN と開発者が示す対応は次の2つである（出典1・2）。

  • ワークアラウンド 開発者は「ネットワーク接続が無い状態での運用」を推奨している。案内ページでは、遠隔接続が不要な場合は DVR 本体から LAN ケーブルを外すよう示されている
  • 後続製品への乗り換え ネットワークを介した遠隔接続が必要な場合は、対策済みの ADX5000 シリーズへの置き換えを検討する

DVR は防犯カメラの録画装置であり、遠隔からの映像確認のためにネットワークへ接続されていることが多い（本記録の整理）。そのため「LAN ケーブルを外す」というワークアラウンドは、遠隔確認という用途そのものの放棄を意味する。対策ファームウェアが出ない機種では、運用を落とすか機器を入れ替えるかの二択になっている（本記録の評価）。

対策ファームウェアを適用できる機種についても、適用がパスワード運用の見直しを伴う。開発者は「アップグレード後は、初期値や弱いパスワードが使用できなくなります」と注記しており（出典2）、適用作業の前に新しいパスワードの決定と、設置先での周知が必要になる。

  • 国内の設置台数とインターネットへの露出台数。 影響を受ける機種がどれだけ稼働しているか、そのうちどれだけが外部から到達できる状態にあるかは示されていない〈未確定2〉
  • 非公開機能の技術的な詳細。 サービスが待ち受けるポート、認証の仕組み、コマンド実行の経路はいずれも公開されていない〈未確定3〉。悪用を助けないための非公開とみられるが、理由の説明は無い（本記録の推定）

対応の評価

評価材料がない判断は「評価材料なし」としています。結果論で断じないための区分です。
判断評価評価の根拠と留保
JVN は非公開機能の存在・CWE 分類・CVSS・影響を受ける機種とバージョン・想定される影響・対策を公表し、 技術的詳細（ポート・認証の仕組み・呼び出しの形）は公開しなかった。 開発者は案内ページで実装の性質（メンテナンス用のサービス2種類）と想定被害、 および対策ファームウェア適用後にパスワード要件が変わることを示した機能した本記録の評価である。対策が提供されない機種について 「提供はありません」と明記し、代替手段（ネットワーク非接続運用・後続製品への置き換え）まで 示している点を評価した。対策の有無を曖昧にしないことが、利用者の意思決定を可能にしている
販売終了から年数が経過した ADX1004 / ADX1008 / ADX2016 については対策ファームウェアを提供せず、 ネットワーク接続が無い状態での運用、または後続製品への乗り換えを推奨した部分的に機能本記録の評価である。方針を明示したこと自体は利用者の判断に資する。 ただし「全バージョンが対象で対策なし」という結論に至る機器が3機種あり、 これらを使い続ける組織には運用の縮小か買い替えしか残らない
CISO・経営層への示唆
  • 防犯カメラの録画装置は、資産台帳に載っていなければ脆弱性公表に反応できない
    DVR は情報システム部門ではなく施設管理・総務が導入していることが多く、 機種とファームウェア版数が IT 資産として管理されていない場合がある。 本件は機種単位で対象・対象外（ADX5016）が分かれるため、機種が分からないと判断そのものができない
    取るべき行動 防犯カメラ・録画装置・入退館装置などの物理セキュリティ機器を IT 資産台帳の管理対象に加える。 機種・ファームウェア版数・設置場所・ネットワーク接続の有無・保守委託先を記載し、 脆弱性情報の照合対象に含める
  • 「対策ファームウェアを提供しない」という結論を、調達時点のリスクとして見積もる
    ADX1004 / ADX1008 / ADX2016 は全バージョンが対象で、 販売終了から年数が経過しているため対策が提供されない。 残された選択肢は、遠隔確認の放棄か機器の買い替えである
    取るべき行動 ネットワークに接続する機器の調達時に、サポート終了後の脆弱性対応の扱いを確認し、 終了予定時期を資産台帳に記録する。 サポート終了済み機器の一覧を定期的に経営へ報告し、計画的な更新予算を確保する
  • 組込機器の脆弱性は「権限が必要」でも緊急度を下げられない
    CVE-2026-97627 は PR:H（高い権限が必要）だが、 開発者自身が対策ファームウェア適用後に「初期値や弱いパスワードが使用できなくなる」と注記している。 初期値運用が現実に存在することを前提とした記述である
    取るべき行動 脆弱性の緊急度判定の様式に「認証が前提条件の場合、その認証が実際に強固か」を確認する欄を設ける。 組込機器については初期パスワード変更の実施状況を棚卸しし、未変更の機器を優先対応に回す
  • 録画データの改ざん・破壊は、必要になった時点で初めて判明する
    開発者は OS コマンド実行による想定被害としてデータの改ざん・破壊・漏洩を挙げている。 録画は普段参照しないため、改ざんや破壊に気づく契機はインシデント調査や訴訟の場面になる
    取るべき行動 録画データを証跡として使う場面（事故・不正・労務）を想定し、 保全の手順と保存先の冗長化を決める。 録画装置の正常性（録画の継続・保存期間）を定期点検の項目に入れる
セキュリティ技術者への示唆
  • 自組織の ADX シリーズ DVR の機種と版数を確認し、Ver.10.8.237 へ上げる
    対象は ADX5004 / ADX5008 / ADX404 / ADX3004 / ADX3008 / ADX3016 / ADX204 の Ver.10.8.237 より前と、ADX1004 / ADX1008 / ADX2016 の全バージョンである。 ADX5016 は対象外と明記されている
    取るべき行動 設置されている DVR の機種名と現在のファームウェア版数を記録し、 対象機種は開発者が提供する手順書に従って Ver.10.8.237 へアップグレードする。 アップグレード後は初期値や弱いパスワードが使えなくなるため、新しいパスワードを事前に決めておく
  • 対策が提供されない機種は、ネットワークから切り離すか置き換える
    ADX1004 / ADX1008 / ADX2016 には対策ファームウェアが提供されない。 開発者は遠隔接続が不要なら LAN ケーブルを外し、必要なら ADX5000 シリーズへの置き換えを検討するよう示している
    取るべき行動 該当機種について遠隔接続の必要性を確認する。不要なら LAN ケーブルを外して運用を続け、 必要なら置き換えの見積もりを取る。 切り離す場合は、時刻同期や通知など他にネットワークを使っていた機能の代替を併せて検討する
  • DVR をインターネットに直接公開していないかを外部から確認する
    CVSS ベクタは AV:N（ネットワーク経由）であり、到達できることが成立の前提になる。 遠隔確認のためにポート転送で公開されている DVR は珍しくない（本記録の評価）
    取るべき行動 外向きのルータ・ファイアウォールの設定を確認し、DVR 向けのポート転送・UPnP による穴あけが 残っていないかを点検する。 遠隔確認が必要な場合は VPN 経由に切り替え、機器を直接公開しない構成にする
  • DVR を置くネットワーク区画から、業務系への通信を遮断する
    開発者は OS コマンド実行による想定被害として マルウェア感染と他システムへの攻撃の踏み台化を挙げている。 DVR が侵害された場合、被害は録画装置の中では止まらない
    取るべき行動 防犯カメラ・DVR を業務系と別の VLAN に分け、DVR から業務系への通信を既定で遮断する。 DVR の外向き通信も必要な宛先のみ許可し、想定外の通信を検知対象にする
  • ファームウェア版数の定期確認を点検項目に入れる
    CVE-2026-100737 は不正なファームウェアへの書き換えを許すものである。 書き換えが行われても、版数を見ていなければ気づく契機が無い
    取るべき行動 DVR のファームウェア版数を定期点検の記録項目に加え、想定外の変化を検出できるようにする。 併せて、機器が正常に動作しなくなった場合の切り分け手順（書き換えの可能性を含む）を用意する
