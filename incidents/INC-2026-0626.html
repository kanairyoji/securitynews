INC-2026-0626ウクライナのHikvision機器に集中攻撃

GreyNoise は2026年9月21日から10月1日にかけて、ウクライナ国内の Hikvision 製監視カメラ・ 録画装置（DVR）に対する CVE-2021-36260（2021年公開の認証不要コマンドインジェクション）の 悪用試行が急増したことを観測した——試行のほぼ全てが4つの IP に集中し、うち3つは リトアニアの商用VPN（PureVPN）の出口、1つはウクライナ国内の回線だった。 使われたのは Nuclei の既成テンプレートで、記録された要求はすべて同一のテストコマンドのみ、 追加プログラムの導入指示は見られず、侵害の確認も無い。活動期間はロシア軍の空襲激化と重なるが、 GreyNoise は「両者が関連しているかは言えない」としている

初報: 2026年10月8日 最終更新: 2026年10月20日

セキュリティ企業 GreyNoise は2026年10月8日、2026年9月21日から10月1日にかけてウクライナ国内の Hikvision 製監視カメラ・録画装置（DVR）を狙った脆弱性の悪用試行が急増したことを公表した。

狙われたのは CVE-2021-36260——2021年に公開された、Hikvision の一部ネットワークカメラおよび録画機器の脆弱性である。機器が外部から届いたデータの内容を適切に検査していないため、ログインしなくてもネットワーク経由で機器へコマンドを送れる。同年のうちに修正ファームウェアが提供されている。

観測の経過は次のとおりである。9月21日、4つの IP のうち1つがウクライナ国内のサービスポートへ接続を試した（この時点では悪用を試みていない）。9月22日の時点では、ウクライナに対する同種の試行は7月初めからほとんど無く、この4つの IP からのものも無かった。9月23日、試行がほぼゼロから急増し、そのほぼ全てがこの4つの IP から送られた。10月1日が4つの IP からの最後の試行で、10月7日時点でそれ以降の試行は観測されていない。

4つの IP の素性は部分的に分かっている。 うち3つ（195.238.124.178・195.238.124.181・195.238.124.188、AS56630）はリトアニアに置かれた商用VPN サービス PureVPN の出口で、GreyNoise はこの3つの活動を同一の主体によるものと評価している。残る1つはウクライナ国内の回線で、関連の可能性はあるが確度は低い（low confidence）とされた。商用VPN は複数の利用者に共有されるため、サーバーの所在地から攻撃者の身元を推定することはできない。

手口は単純である。 使われたのはオープンソースのスキャンツール Nuclei の既成テンプレート（"Hikvision IP camera/NVR - Remote Command Execution"）で、特製の要求を機器に送り、コマンドを実行できるかを確認する。記録された要求はすべて同一のテストコマンドで、機器に別のプログラムをダウンロード・インストールさせる指示は見つかっていない。 侵害の成立も、後続のペイロードも観測されていない。

この期間、ロシア軍はウクライナへの空襲を続けていた。ウクライナ空軍は9月24日にロシア軍がミサイルおよび282機の各種無人機等で攻撃したと報告している。GreyNoise は活動が「国内各地でのロシアの攻撃の激化と時期が重なる」（原文英語）と記しつつ、「両者が関連しているかは言えない」（原文英語）と明示的に留保した。動機の可能性としては、侵害した DVR を使って空襲の前・最中・後に地域を監視すること（戦場認識）が挙げられている。

そのうえで動機の可能性として1つを挙げている—— 侵害した DVR を使って、空襲の前・最中・後に地域を監視すること（戦場認識）。
