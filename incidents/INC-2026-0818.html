INC-2026-0818VOLTAが被害者の値付けをLLMに委任

Cisco Talos、窃取したあとの被害者の「値付け」を外部の大規模言語モデルに委ねる Windows インフォスティーラー VOLTA-AUTODOXER を公開—— 盗んだ Gmail・UberEats・DoorDash・Discord のセッションで自宅住所や資産を裏取りし、 OpenRouter 経由で anthropic/claude-opus-4.6 に「WHAT THEY'RE WORTH」を書かせる。 拒否を検出すると moonshotai/kimi-k2 → google/gemini-2.5-flash へ落ちる3段構成で、 観測されたエンドポイントはすべて第三者のもので攻撃者所有のインフラは1つも無い

脅威・攻撃キャンペーン初報のみ有名事象として記録（日本と直接の関係は薄い）設計・実装上の不備認証情報の悪用（使い回し・推測可能・窃取）
初報: 2026年10月31日（Cisco Talos のブログ） 最終更新: 2026年11月1日

Cisco Talos は2026年10月31日、VOLTA-AUTODOXER と自称する Windows のインフォスティーラーの解析を公開した（出典1）。窃取する対象そのものは、この種のマルウェアとして珍しいものではない ——Chromium 系ブラウザの資格情報・Cookie・保存されたカード情報、Firefox・Thunderbird・Outlook のプロファイル、Slack のワークスペース、Steam・Battle.net・Discord・Telegram・Roblox のセッション、SSH とクラウド事業者（gcloud・OpenVPN・Hide.me）の設定、暗号資産ウォレットのシードフレーズ、保存済み Wi-Fi の平文パスワード、そしてスクリーンショットである（出典1）。

新しいのは、窃取が終わったあとの段である（出典1）。VOLTA は、集めた材料から「端末の向こうにいる人」についての構造化された証拠束を組み立てる——地理情報と自宅住所、勤務先と勤務先ドメイン、推定された生年、カードの下4桁、Slack のワークスペース、文書の作成者メタデータ、iPhone のバックアップの痕跡、Roblox アカウントの時価である。 さらに、盗んだセッションを使って外に問い合わせて束を厚くする—— 被害者自身の Gmail トークンで Amazon・DoorDash・Uber Eats・Grubhub・Walmart・PayPal からの受領書を検索して自宅住所を確定させ、Uber Eats と DoorDash の注文履歴を直接引き、Discord のトークンでプロファイルを補い、Roblox の在庫を Rolimons[.]com への照会で値付けする（出典1）。

組み上がった束は JSON に直列化され、OpenRouter の /api/v1/chat/completions へ POST される（出典1）。添えられるシステムプロンプトは、モデルに「標的評価（target assessment）を作成するフォレンジック情報分析官として振る舞え」と指示する（原文英語）。求められる出力には「WHAT THEY'RE WORTH」（この人物の価値）という節があり、換金価値で順位づけされた資産が低・中・高の区分とともに並ぶ。もう1つの節「THEIR OPSEC」には、被害者のセキュリティ態勢とパスワードの衛生についての評価が入る（出典1）。Talos の表現では、モデルは運用者のトリアージ担当の分析官であり、生の資格情報ログを、出典つきで順位づけされた被害者のドシエに変える。

拒否されることが設計に織り込まれている（出典1）。既定のモデルは anthropic/claude-opus-4.6 で、応答に "I can't" や "I'm not able" といった語句が含まれるかを検査し、含まれていれば moonshotai/kimi-k2 → google/gemini-2.5-flash へと最大3モデルの連鎖で落ちていく。temperature は 0.2 に固定され、SDK を使わない手組みの JSON で、User-Agent は Mozilla/5.0 である。 鍵が無ければ LLM の段そのものを飛ばして動く。

防御側にとっていちばん重いのは、通信先の性質である（出典1）。推論の往復は被害者自身の回線・被害者自身の端末の上で完結し、観測されたエンドポイントはすべて第三者（正規サービス）が管理するもので、攻撃者が所有するインフラは1つも無い。 Talos は、設定を6つの差し替え可能なスロットとしてビルド時に埋める作りから、これが作者が売り、顧客が自分の値を入れて1件ずつビルドさせる「ビルダー型」の商品だとみている—— もしそうなら、順位づけされた標的評価を受け取る能力は、どの水準の攻撃者にも開かれている。

本記録は、この事案を「AI が新しい窃取能力を与えた」話としては読まない（本記録の評価）——与えられたのは能力ではなく、運用者がやっていた分析の手間の肩代わりである。 Talos 自身も、改善の軸は速さや規模ではなく「手間の置き換え（effort displacement）」だとし、同じ論理が別の段に現れるのは時間の問題だと書いている（出典1）。
