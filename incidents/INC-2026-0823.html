INC-2026-0823シバタが Qilin のリークサイトに掲載

ランサムウェア群 Qilin が2026年11月1日、自群のリークサイトに 日本の「Shibata Co., Ltd.」（ドメイン www.shibata.co.jp ＝株式会社シバタ。 電線・電線加工品の専門商社で、ろ過装置やビール醸造設備も手がける）を 掲載したことが Ransomware.live の索引で確認された—— ただし掲載には攻撃者の主張文（description）もデータ量（data_size）も 身代金額も記載が無く、同社サイトにも2026年11月3日時点で 不正アクセス・システム障害に関する公表が無い。 本記録は、掲載という外形だけが確認できている段階として記録する

ランサムウェア被害（暗号化・リークサイト恐喝が中心）初報のみ日本の組織が当事者公表されていない／不明
初報: 2026年11月1日（Qilin のリークサイト掲載の索引） 最終更新: 2026年11月3日（本記録の作成。Ransomware.live の API と同社サイトを直接確認）

掲載は確認できます。被害は、まだ何も確認できていません。

2026年11月1日12時25分（UTC。日本時間同日21時25分）、ランサムウェア群 Qilin のリークサイトに「Shibata Co., Ltd.」という組織名が載り、集計サイト Ransomware.live がこれを索引しました（出典1）。レコードに記録されたドメインは www.shibata.co.jp、国は JP、業種区分は Manufacturing です（出典1）。

このドメインの運営者は株式会社シバタです（出典2）。電線および電線加工品の専門商社で、あわせて水処理・環境事業部がろ過事業、ビール醸造設備、平角線などを手がけています（出典2）。東京本社は東京都新宿区歌舞伎町2-2-15 ヒルコート東新宿ビル2F です（出典2）。

しかし、掲載に中身がありません（出典1）。Ransomware.live の API が返すレコードでは、攻撃者の主張文（description）は "N/A"、持ち出したとするデータ量（data_size）は null、身代金額（ransom）も null、報道への言及（press）も null です。 攻撃者が「何を、どれだけ取ったか」を一言も書いていない段階の掲載です（本記録の整理）。

そして当事者の公表がありません。 本記録は2026年11月3日に同社サイトのお知らせ一覧を直接確認しましたが、最新は2026年10月30日の「第11回 Drink Japan 出展のお知らせ」で、不正アクセス・ランサムウェア・システム障害・サーバー停止に関する記載は1件もありませんでした（出典2。本記録の確認）〈齟齬1〉。報道も確認できていません〈齟齬2〉。

したがって本記録に書けることは限られます。 暗号化が起きたのか、データが出たのか、業務が止まったのか、身代金が要求されたのか——いずれも分かりません〈未確定1〜5〉。掲載は攻撃者側の主張であり、被害の確定ではありません（本記録の明示）。

それでも記録する理由は2つあります（本記録の判断）。①Qilin による日本の組織の掲載は、Ransomware.live の索引で累計45件に達しており、日本で現に稼働している群であること（出典1。2026年11月3日時点）。②同群の掲載の最多業種は Manufacturing（累計2,555件中524件）で、本件もその区分に入ること（出典1）。読者が自組織を当てはめる材料は、被害の詳細が出る前の時点にもある——「自社の名前が載ったことに、自社はいつ気づくのか」という問いです（本記録の評価）。
