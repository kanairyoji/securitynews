INC-2026-0881APT29 が解析サービス経由でモバイル狙う

APT29 が、ウクライナのウェブ解析サービス Plerdy の配信スクリプトを1週間だけ書き換え、 数千サイトの訪問者のモバイル端末へ利用者の操作なしに修正済み脆弱性の連鎖を撃ち込んでいた—— Sekoia が2026年11月4日に公表。iOS 16.7／iOS 18.5／Android Chrome 139〜145 向けの 3つの連鎖はすべて n-day で、最新の端末は影響を受けない。 1つは商用監視ベンダー製とみられる iOS 連鎖 DarkSword である

Sekoia の Threat Detection & Research（TDR）チームは2026年11月4日、「Poisoned Source: APT29 Watering Holes Targets Mobile Devices」を公表した（出典1）。2026年10月中旬に見つけた大規模な水飲み場攻撃で、米国・ウクライナ・チェコ・ブルガリアの著名なウェブサイトが改ざんまたは複製されていた（出典1）〈重要〉。

配送経路は3つある（出典1）。①正規サイトへの JavaScript の直接注入②本物のサイトを中継しながら HTML に注入する偽ドメイン（AiTM 型）③ウクライナのウェブ解析サービス Plerdy の配信スクリプトの改ざん。 ③は2026年8月27日から9月3日までの1週間で、Plerdy のトラッカー（a.plerdy[.]com）を読み込む数千サイト（大半がウクライナ）のうち数百サイトとその訪問者をエクスプロイトキットに晒した（出典1）。

いずれの経路でも配られるのは同じ JavaScript で、訪問者のブラウザと端末を調べたうえで、端末に合わせた連鎖を利用者の操作なしに送り込む（出典1・3・4）〈重要〉。連鎖は3つある（出典1）—— A: iOS 16.7（CVE-2025-43529・CVE-2024-27834）で Safari の Cookie を取る。B: iOS 18.5（CVE-2025-43529・CVE-2026-20700・CVE-2025-14174・CVE-2025-43510・CVE-2025-43520）で端末のデータを丸ごと取る。C: Android の Chrome 139〜145（143 を除く。CVE-2026-3910・CVE-2025-27038）でChrome の Cookie・ログイン情報・閲覧履歴・保存済み Wi-Fi 資格情報を取る。

B は DarkSword である（出典1）—— 商用監視ベンダー（CSV）が開発したとみられる iOS 連鎖で、2026年9月に VirusTotal へ上がっていた（出典1）。本記録は、流出した DarkSword が犯罪に転用された事例を別に記録している〈INC-2026-0466〉。

本記録が本件を重く見る理由は3つある（本記録の判断）。第一に、8件の CVE はすべて修正済みである〈重要〉—— Sekoia は「最新の OS を使っている利用者は安全である」と明言した（出典1）。国家の情報機関が、ゼロデイではなく「更新していない端末」を母数にしている。 第二に、永続化しない（出典1・4）—— 端末を再起動すれば活動は止まるが、再起動までに Cookie とメッセージの控えは出ていく（本記録の整理）。第三に、入口が「自分が契約していない部品」である（本記録の評価）—— サイト運営者は Plerdy のタグを1行貼っただけであり、訪問者はそのタグの存在を知らない。

帰属について、Sekoia は中〜高い確度で APT29（Midnight Blizzard／Cozy Bear／The Dukes。ロシア対外情報庁 SVR に広く帰属される）と評価している（出典1・3・4）〈重要〉—— 断定ではない。 また Sekoia は、連鎖を APT29 が第三者から入手したとみている（出典1）。日本の組織が標的になったという記載は無い（本記録の確認）〈未確定5〉。

    394項目の指紋を集めながら、配送の判定に使っていたのは3つのフィールドだけだった評価・解釈

    配られる JavaScript は、攻撃者が UltimateFingerprinter と名付けたものである（出典1）。61 の収集器から 394 のフィールドを集め、JSON にして端点へ POST する（出典1）〈数値3〉。端点は、条件に合えば実行すべきエクスプロイトコードを応答として返す（出典1）。

    集める項目は細かい（出典1）—— canvas・audio・webgl・フォント・CSS・画面情報といった定番、webrtc・mediaDevices・battery・sensors・network・performance のタイミングを使ったサンドボックス判定、iosFeatures・macFeatures・safariExtensions・touchGestures といった Apple 固有、USB・NFC・Bluetooth・IDLE 検知・compute pressure・形状検知・支払いといった新しい Web API。

    ところが Sekoia の観察はこうである（出典1）〈重要〉—— 「これだけのフィールドを集めているにもかかわらず、指紋はエクスプロイトの配送にほとんど影響しない。」 配送を止めるのは3つのフィールドだけである—— 画面の幅と高さ（99999 のような電話機としてあり得ない値）、および navigator.maxTouchPoints が 0（タッチでない端末）。 これらに当たると、配送ホストは 200 OK と空の応答を返して何も渡さない。

    Sekoia は「この広範な指紋を集める目的は不明のままである」としている（出典1）—— 本記録はこれを2通りに読む（本記録の読み）。①将来の選別のための素材集め — いまは使っていないが、どの端末がどこにいるかの地図を作っている。 ②解析者のふるい分け — サンドボックス判定の項目が多いことは、研究者の環境に当たったときに何も返さないための仕掛けとして説明がつく。 いずれも推測であり、本記録は断定しない。

    もう1つ、本記録が記録に残したい仕掛けがある（出典1）〈重要〉—— このスクリプトは 2.3 MB あり、その約98%は到達しない最小化済みの AngularJS ライブラリである。 Sekoia は意図として2つを挙げる—— 「大規模言語モデル（LLM）の文脈長を超えさせることで自動解析を妨げる」および「よく知られた JavaScript ライブラリに埋め込むことで正規に見せる」。 攻撃側が、防御側が LLM で解析することを前提に回避を設計している（本記録の評価）—— これは本件で最も新しい点の1つである。

    永続化しないことは、利用者には朗報で、調査する側には難題である対策・注意喚起

    Sekoia と報道が一致して述べているのは、永続化が無いことである（出典1・4）。「APT29 がこれらの攻撃で使ったペイロードはいずれも永続化を確立せず、端末を再起動すれば、侵害されたサイトを再訪するまで悪性の活動は止まる」（出典4・原文英語）〈重要〉。

    利用者にとっては朗報である（本記録の整理）—— 端末に居座られない。

    しかし調査する側には難題である（本記録の評価）〈重要〉—— 再起動した後の端末から「侵害されたか」を判定する手掛かりが残らない。 判定に使えるのは、当該期間の通信記録（配送ドメイン・持ち出し先への通信）だけである（本記録の判断）。Sekoia は IoC を公表している（出典1）—— static.flux-telemetry[.]com（109.104.106[.]107）、edge-ord.clouds-stacks[.]com（95.133.231[.]28）、ad.starx-net[.]com（195.58.140[.]105）、adsprism-stat[.]com、および振り分け先の ads-it-assets[.]com・cdn.adv-static[.]com・wpvortex-mod[.]com・assets-int[.]com。

    そして、もっと重要なことがある（本記録の判断）〈重要〉—— 端末に残らないが、持ち出されたものは残る。 連鎖 A と C が狙ったのは Cookie であり、Cookie はパスワードを知らなくても多要素認証を済ませた後の状態を再現できる（本記録の評価）。連鎖 B は Wi-Fi の事前共有鍵とキーチェーンまで取る（出典1）—— 端末1台の侵害が、その端末が接続する無線網の資格情報の流出になる。

    したがって本記録の示唆は、「再起動で止まる」を復旧と読まないことである（本記録の判断）—— 疑わしい期間にアクセスしたサービスのセッションの一括無効化、保存済み資格情報の更新、無線網の鍵の更新までが復旧の範囲になる。
