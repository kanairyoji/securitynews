INC-2026-0907Anubisが米組織でBYOVD大量投入

Anubis ランサムウェアの攻撃者が2026年10月、米国の組織に新しい独自後門 Backdoor.Lindnor を置き、 約1時間のうちにセキュリティ製品を止めるための実行ファイルを少なくとも13個、 公開済みの脆弱な署名付きドライバを5個投下した（BYOVD）—— AnyDesk をセーフモードでも動くようレジストリ登録して第2の遠隔経路も用意していたが、 暗号化ペイロード iservice.exe の実行はブロックされ、暗号化された証跡は無い。 Symantec は開発元を Hawkmoth（Sphinx のリブランド）として追跡している

不正アクセス・侵害ランサムウェア被害（暗号化・リークサイト恐喝が中心）初報のみ有名事象として記録（日本と直接の関係は薄い）既知の脆弱性の悪用
初報: 2026年11月5日 11:00 UTC（Symantec の公表） 最終更新: 2026年11月6日（本記録の作成。Symantec のレポートを取得して確認した時点）

Symantec は2026年11月5日、Anubis ランサムウェアの攻撃者が2026年10月に米国の組織へ侵入した事案を公表しました（出典1）。これまで文書化されていなかった独自の後門と、異例に多いセキュリティ製品の無効化ツールが使われた点が特徴です（出典1）。

後門は Backdoor.Lindnor と名付けられました（出典1）〈重要〉。1台では Chrome のコンポーネント展開ディレクトリに似せたフォルダにhealthcontroller64.exe として、もう1台では VMware のフォルダにsvchelper.exe として置かれ、いずれもサービスとして動いていたとみられます（出典1）。見つかったのは2台で、どちらも影響を受けた端末のうち唯一のMicrosoft SQL Server でした（出典1）。後門はプロセス ID・OS バージョン・自身のファイルパス・コンピュータ名・ユーザー名・ドメイン・ログオンサーバを C&C サーバへ送ります（出典1）—— 主系と待機系の2つの C&C を持ち、いずれも 443 番ポートで接続します（出典1）。

無効化ツールの量が異例です（出典1）〈重要〉。攻撃者は約1時間のうちに、セキュリティのサービスを終了させるための実行ファイルを少なくとも13個、立て続けに投下しました（出典1）。うち11個はこれまで公開されていなかったものです（出典1）。そして署名付きだが脆弱なドライバ5個（havoc.sys・monprocessex.sys・xhunter1.sys・bdapiutil64.sys・fly.sys）を持ち込み、これを悪用してカーネル権限を得ようとしています（BYOVD）（出典1）。2つの実行ファイル（gbbsym.exe・symgooq.exe）は Symantec のソフトウェアを装っており、読み込んだ脆弱ドライバ経由でカーネルコールバックを一覧する -l と、一覧して削除する -d のスイッチを受け付けます——観測されたコマンド行では -d が使われていました（出典1）。

13個のうちブロックされなかったのは huntreagent.exe と s1.exe の2つだけです（出典1）。この2つは解析用に入手できず、正確な用途は不明とされています（出典1）〈未確定2〉—— ファイルサイズが同じでハッシュが異なるため、同じツールの2つのビルドの可能性があるとしています（出典1）。

遠隔経路も二重に用意されていました（出典1）〈重要〉。正規の遠隔操作ツール AnyDesk を導入し、新しいローカルユーザーを作ってローカルグループに追加したうえで、safemode.exe を使ってAnyDesk が Windows のセーフモードでも動くように構成しています（出典1）。レジストリ登録のコマンドは"CSIDL_SYSTEM\reg.exe" add HKLM\SYSTEM\CurrentControlSet\Control\SafeBoot\Network\AnyDesk /ve /t REG_SZ /d Service /f です（出典1）。セキュリティ製品は通常セーフモードで完全には動作しないため、その間に脆弱ドライバを使って防御を切る余地が生まれます（出典1）。

それでも最後の段で止まっています（出典1）〈重要〉。Anubis の暗号化ペイロードは iservice.exe という名前で、成功すれば拡張子 .anubis を付け、restore files.txt とrestore files.html の身代金要求文を置きます（出典1）。この攻撃ではペイロードの実行がブロックされ、被害組織のネットワーク全体での暗号化段階に進めませんでした（出典1）。

Symantec は Anubis の開発元を Hawkmoth として追跡しています（出典1）。Hawkmoth は2024年12月に Sphinx ランサムウェアのリブランドとして現れたRaaS 運用体で、ペイロードは Sphinx 版からほぼ変わらず名称だけが更新されているとされます（出典1）。直近12か月の被害主張は約96件、うち52%が米国です（出典1）。

    手順: **ローカルユーザーの新規作成とローカルグループへの追加を警報にする** （出典1。本記録の整理）〈重要〉—— **本件では AnyDesk の導入とあわせて新しいローカルユーザーが作られている**（出典1）。　副作用: **端末の初期設定・保守でも同じ操作が起きるため、 作業申請と突き合わせる運用が要る**（本記録の評価）。
    手順: **常時稼働のデータベースサーバ上で、 Chrome や VMware のフォルダに実行ファイルが置かれサービス登録されることを 異常として扱う**（出典1。本記録の整理）〈重要〉—— **本件の後門は、その2つのフォルダに偽装して置かれていた**（出典1）。　副作用: **正規の更新処理でも類似のパスに実行ファイルが置かれるため、 署名と発行元の確認を併せる必要がある**（本記録の評価）。
