INC-2026-0941Kilo Code で許可外ファイルがモデル側へ

AI コーディング支援クライアント Kilo Code 7.4.20 で、 「price.py と check.py の2ファイルだけ転送を許可する」とモデルへの依頼文に書いた実験で、 プロジェクトの12ファイル全部がモデルサーバー側に渡り、 バイト単位・SHA-256 一致で復元された—— 依頼文の禁止はクライアントの技術的な制限にならず、 ツール（read / bash）の結果が会話履歴に積まれてモデルへの要求本文に乗る構造が原因である

脆弱性意図せぬ露出（設定不備等で外部から到達可能だった）初報のみ有名事象として記録（日本と直接の関係は薄い）設計・実装上の不備権限管理の不備
初報: 2026年11月7日04時04分 UTC（Habr の記事公開時刻） 最終更新: 2026年11月8日

ロシアの技術共有サイト Habr（情報セキュリティ・人工知能ハブ）に2026年11月7日、ユーザー名 momentics による実証記事が掲載された（出典1）。問いは「AI コーディング支援の作業を受け入れてよいのは、どの時点か」である（出典1。本記録の整理）—— 著者は「ディスク上に助手が残したものだけでなく、モデルのサーバーが受け取った（そして手元に残した）ものも見たかった」と書いている（出典1。本記録の訳。原文ロシア語）。

実験の作りは小さい。 12個のファイルからなる人工のプロジェクトを置き、price.py の price + count を price * count に直してcheck.py を走らせるだけの依頼を出す（出典1）。モデルへの依頼文には「転送を許可するのは price.py と check.py のみ」と明記してある（出典1。本記録の訳。原文ロシア語）。一方、クライアント側の設定（permission）は*: deny / read: allow / bash: allow である（出典1。本記録が公開コードから確認）—— 依頼文の禁止と、クライアントの技術的な権限が食い違っている状態を意図して作っている（本記録の整理）。

モデル提供者の側は、著者が立てた 127.0.0.1 の HTTP サーバーが演じる（出典1）。このサーバーは OpenAI 互換の Chat Completions API を話し、ツール呼び出しの指示として「12ファイル全部の読み取り」→「修正の実行」→「テスト実行」を順に返す（出典1）。著者は「本物のモデルは実験に居ない。命令を選ぶのはテストサーバーである」と明記しており、商用モデルがこう振る舞う傾向はこの方法では測れないと述べている（出典1。本記録の訳。原文ロシア語）〈齟齬2〉。検証対象はクライアント（Visual Studio Code 拡張 Kilo Code 7.4.20 のbin/kilo.exe、CLI の run コマンド）である（出典1）。

結果は著者が表にしている（出典1）。指定した12ファイルのうち12ファイルが、バイト単位の一致と SHA-256 の一致をもって復元された（出典1）。ディスク上で変わったのは price.py の1ファイルだけ、テストは通り、Kilo の終了コードは0、14回のツール呼び出しはすべて completed 状態である（出典1）—— つまり、クライアントの記録を見るかぎり作業は「きれいに」見える（出典1。本記録の整理）〈重要〉。

仕組みは地味である（出典1）。アーカイブも curl も、データ回収用の第2のサーバーも要らない（出典1）。Kilo が read の結果を会話履歴に積み、その履歴を次のモデルへの要求にまるごと含めるため、サーバーは role: tool のメッセージを呼び出しIDごとに保存するだけで原本を組み直せる（出典1）。この版の Kilo は読み取り結果に行番号を付けるので、著者のスクリプトは番号を外してから連結し、recovered/ に書き出している（出典1）。元のコードは11,103バイトだが、モデルへの要求本文の合計は458,779バイトに達した（出典1）—— 履歴の再送のぶんが積み上がるためで、「プロジェクト全部を1回で送る巨大な要求」は発生していない（出典1）。

本記録は、著者の主張の土台になる権限モデルをKilo Code の公式文書で裏付けた（出典2。本記録の確認）。公式文書は read / bash / edit を別々の許可として説明し、.env の読み取りだけは既定で承認を求めると書いている（出典2。原文英語）。自動承認についての警告は「自動承認の設定は確認の問いを飛ばし、Kilo Code にあなたのシステムへの直接のアクセスを与える」という水準にとどまり、読み取った内容がモデル提供者のサーバーへ送られることへの言及は無い（出典2。本記録の訳。原文英語。本記録が確認した）〈重要〉。
