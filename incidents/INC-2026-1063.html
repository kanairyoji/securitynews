INC-2026-1063CSC の GitHub 環境に不正アクセス

サイバーセキュリティクラウドが2026年11月12日、ソフトウェア開発に用いる GitHub の 自社環境が不正アクセスを受けたと公表した——発端は**外部組織からの情報提供**で、 従業員の認証情報1件の流出が判明。ログ調査で11月5日に第三者による不正アクセスの 履歴を確認したが、**参照できるログの期間と記録内容が限られ侵害期間は特定できていない**。 一部顧客の組織名・氏名・メールアドレス等が流出した可能性がある

初報: 2026年11月12日（サイバーセキュリティクラウドのお知らせ・第一報） 最終更新: 2026年11月14日

2026年11月12日、サイバーセキュリティクラウド（CSC）が、ソフトウェアの開発などに利用している GitHub の自社環境が第三者による不正アクセスを受けたことを公表した（出典1・2）。公表文の題名は「当社開発環境における情報漏えいのおそれに関するお知らせとお詫び（第一報）」である（出典1）。

発端は外部からの情報提供である（出典1・2）〈重要〉—— 自社の検知ではない。 同社従業員が業務で使用していた GitHub の認証情報1件が外部に流出していたことが、外部組織からの情報提供で判明した。 これを受けてアクセスログを調査したところ、第三者が流出した認証情報を使用したと見られる不正アクセスの履歴を2026年11月5日に確認した（出典1・2）。

侵害されていた期間は特定できていない（出典1・2）〈重要〉。同社は理由を明示している—— 「参照できるログの期間や記録内容が限られて」おり、認証情報が有効だった全期間にわたるアクセスの有無を確認できていない。 これは原因の調査が進んでいないという話ではなく、調査の材料そのものが残っていないという話である（本記録の読み）。

流出した可能性がある情報は2種類である（出典1・2）。一部顧客に関する組織名・氏名・メールアドレスなど、および同社サービスの利用にともなう通信関連情報。 対象の人数・件数は公表されていない〈未確定4〉—— 範囲と対象者は調査中で、判明した顧客から順次連絡するとしている。

二次被害は確認されていない（出典1）。同社は、本件に関連する不正アクセス・不正操作・二次被害は確認されておらず、サービスおよびセキュリティ機能は影響を受けずに通常どおり稼働しているとしている（出典1）。

本件の読みどころは、同社の事業である（本記録の評価）〈重要〉。サイバーセキュリティクラウドは WAF（攻撃遮断くん・WafCharm）等を提供する事業者であり、顧客の個人情報を委託に基づいて取り扱っている（出典1。本記録の整理）—— 公表文は、委託元企業と協議のうえ共同で当局報告を行うことを検討しており、必要に応じて本人への通知も行うとしている。 つまり本件は、1社の開発環境の侵害が、委託元を介して複数組織の個人情報に及ぶ形である。

当局への報告は済んでいる（出典1）—— 個人情報保護委員会等へ報告済みとしている。 調査は自社のセキュリティエンジニアに加えて外部専門会社によるフォレンジック調査を実施中である（出典1）。
