  • 公表 —— 2026年11月6日、Apache Software Foundation（出典1）

Apache Axis は Java の Web サービスを作るための SOAP の実装である（出典1）。Confluence Data Center の XML-RPC・SOAP の API がこれを使っている（出典2）。
