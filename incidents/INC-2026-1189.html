INC-2026-1189FBIがGootloaderでFLASH通報

FBIが2026年11月16日に Gootloader の FLASH 通報（CC-111626-MW・TLP: CLEAR）を公表—— SEO汚染と侵害された正規サイトで初期侵入を得てランサムウェアの前段として使われる JavaScript ローダーの枠組みで、2026年10月時点で感染したWordPressサイト1,000超と 運用者が支配するドメイン216を特定し、2,800万ドル超の身代金支払いにつながった。 標的は米国の弁護士・社内法務・法律事務所のパートナーなど法務専門職に絞られ、 管轄固有の契約条項のような検索されにくい語句で誘導していた。 4日前の11月12日には司法省と Europol 等が Operation Endgame の枠組みで 100台超のサーバーから Gootloader を除去したと発表している

米連邦捜査局（FBI）は2026年11月16日、Gootloader に関する FLASH 通報（FLASH Number CC-111626-MW・TLP: CLEAR） を公表しました（出典1）。Gootloader は、JavaScript のマルウェアローダー・侵害された正規サイト・検索エンジン最適化（SEO）の手法を組み合わせて組織に感染する「初期侵入の枠組み」であり、攻撃者はこれをランサムウェアの前段（ransomware precursor）として、幅広い業種の被害者への攻撃に用いたとされています（出典1。原文英語）。

2026年10月時点の数字は3つです（出典1）。①感染した WordPress サイト 1,000超。 ②Gootloader の運用者（the Gootloader administrator）が支配するドメイン 216。 ③これらが 2,800万ドル超のランサムウェア身代金支払いにつながった。

標的は米国の法務専門職に絞られています（出典1）。SEO の検索語は、実務弁護士・社内法務（in-house counsel）・法律事務所のパートナー・訴訟および privacy のチーム・リーガルオペレーション担当・ゼネラルカウンセル・法律事務所や法務部門の中のリーガルテック導入の意思決定者を狙うものだったとされます。誘導に使われたのは検索の競合が少ない語句で、一次公表は例として管轄固有の契約条項（a jurisdiction-specific contract clause）を挙げています。

手口の中核は「侵害された正規の WordPress サイト」です（出典1）。運用者は WordPress サイトを走査して xlmrpc.php（原文表記。正しくは xmlrpc.php と読める）を探し、侵害された認証情報を使ってシステムに侵入しました。侵害されたサイトは誘い込みページ・リダイレクタ・トラフィックの選別・中継インフラとして機能し、隠しキーワードリンクと仕込んだ被リンクで誘い込みページの露出を上げていました。トラフィック分配システム（TDS）により、国・リファラ・Cookie・IPアドレスで表示内容を振り分けていたとされます。

なお、この FLASH の4日前にあたる2026年11月12日、米司法省は Europol らと連携してGootloader の作戦を停止させたと発表しています（出典2。プレスリリース番号 26-1351）。2018年以降少なくとも25,000台のシステムが感染し、少なくとも44の米国拠点の被害者がランサムウェア攻撃を受け、損害は約2,880万ドル、100台超のサーバーから Gootloader を除去したとされています。FBI の FLASH はこの作戦停止に言及していません〈齟齬1〉—— したがって読者は「停止したから終わった」と読むべきではありません（本記録の評価）。

侵害された正規サイト1,000超を検索結果に押し上げ、法務専門職だけに見せていた原因・手口

Gootloader の中核は、マルウェアではなく「検索結果の支配」である（本記録の整理。出典1）。

FLASH は Gootloader を「JavaScript のマルウェアローダー・侵害された正規サイト・検索エンジン最適化（SEO）の手法を使って組織に感染する初期侵入の枠組み」と定義している（出典1。原文英語）。

検索語の選び方に特徴がある（出典1）。狙われたのは競合が少ない検索語（selected search phrases with low-ranking competition）で、一次公表は例として管轄固有の契約条項（a jurisdiction-specific contract clause）を挙げている。FLASH には実際の検索語の一覧が載っており、「Zoning Government Definition」「Who Pays for legal Fees Election」「When Was Divorce Legalized in Korea」のような、誤字を含む法律系の長いフレーズが並ぶ（出典1）。これらは検索量が少ないので、SEO で1位を取るのが容易である（本記録の読み）—— 大量のアクセスを集める必要がない。必要なのは「特定の職種の人が1人来ること」である。

侵害された WordPress サイトの役割は4つに分かれている（出典1）。誘い込みページ（lure pages）・リダイレクタ・トラフィックの選別（traffic filters）・中継インフラ（relay infrastructure）。 隠しキーワードリンクと仕込んだ被リンクで誘い込みページの露出を上げ、トラフィック分配システム（TDS）で国・リファラ・Cookie・IPアドレスにより表示内容を振り分けていた。

この振り分けが、防御側にとって重要である（本記録の評価）—— 調査者が同じURLを開いても、悪性のページは出てこない。 「アクセスしてみたら普通のサイトだった」は、安全の証拠にならない。

標的は米国の法務専門職で、職種名まで具体的に挙げられている被害規模・影響範囲

FLASH は標的の職種を列挙している（出典1）。

  • 実務弁護士（practicing attorneys）
  • 社内法務（in-house counsel）
  • 法律事務所のパートナー（law firm partners）
  • 訴訟および privacy のチーム（litigation and privacy teams）
  • リーガルオペレーション担当（legal operations professionals）
  • ゼネラルカウンセル（general counsel）
  • 法律事務所・法務部門の中のリーガルテック導入の意思決定者（legal technology decision makers）

ここまで職種を絞った注意喚起は珍しい（本記録の評価）。一方で、FLASH は Gootloader 全体については「幅広い業種の被害者（victims across a wide variety of sectors）」としている（出典1）—— 業種の広さと職種の狭さは矛盾しない。 2025年から2026年の段階で主眼が米国の法務専門職に移った、という時期の話である（出典1の3段階の記述。本記録の読み）。

日本の読者にとっての含意は、業種ではなく職務である（本記録の評価）。法務・コンプライアンス・知財の担当者は、業務上「契約条項の文例」「判例」「規程のひな形」を検索して文書をダウンロードする—— この行動そのものが誘導の対象になっている。 同じ構造は人事（就業規則のひな形）・経理（税務の様式）にも当てはまる（本記録の評価）。

手口は入れ替わらず積み上がり、第3段階でWordPressのコメント経路に広がった背景・過去事例

FLASH は Gootloader の変遷を3段階で整理している（出典1）。

2020年〜2021年（第1段階）: SEO で汚染した文書検索、模したフォーラムのページ、ZIP で配送される JavaScript、Windows Script Host による実行。

2022年〜2024年（第2段階）: トロイの木馬化した JavaScript ライブラリ、AppData への配置、PowerShell・スケジュールされたタスク・レジストリに常駐するペイロード。SEO 汚染した検索の使用は継続。

2025年〜2026年（第3段階）: WordPress のコメント経路の悪用、地理的な絞り込み（geofencing）とトラフィック分配サービス、主眼は米国の法務専門職とリーガルテックの意思決定者。

読み方として重要なのは「継続」の記述である（本記録の評価）。第2段階にも「continued use of SEO-poisoned searches」と書かれている（出典1）—— 手口は置き換わるのではなく積み上がる。 したがって第1段階の対策（Windows Script Host の無効化、ユーザー書き込み可能な場所でのスクリプト実行の禁止）は、いま現在も有効である（FLASH の推奨事項と整合。本記録の読み）。

FLASH は WordPress を悪用する別系統の攻撃者も表で併記している（出典1）—— SocGholish（TA569）・TA2726・Parrot TDS、StopAndProtect、「DoubleDonut」、偽 Cloudflare の誘い、ClearFake、DollyWay。これらは Gootloader ではない（本記録の明示）〈齟齬4〉—— 表に出てくる Evil Corp・LockBit・RansomHub・SilentEncryptor といった名前もこれら別系統の帰結として書かれている。

作戦停止の4日後にFLASHが出ており、どちらも「終わった」と言っていない刑事対応

時系列の順序に注意が要る（本記録の整理）。

2026年11月12日、米司法省が Gootloader の作戦停止を発表した（出典2。プレスリリース番号 26-1351）。Operation Endgame の枠組みで、100台超のサーバーから Gootloader を除去し、米国のドメイン名を押収した。2018年以降、世界で少なくとも25,000台のシステムが感染し、少なくとも44の米国拠点の被害者がランサムウェア攻撃を受け、損害は約2,880万ドルとされた。連携したのは Europol・ドイツ連邦刑事局（BKA）・オランダ国家警察のハイテク犯罪対策部門・カナダ王立騎馬警察およびオタワ警察・デンマーク警察・パリのサイバー犯罪対策部隊・英国国家犯罪対策庁（NCA）・オーストラリア連邦警察で、技術支援に ICHIP The Hague・Fraunhofer FKIE・RoLR・OpenAI・Sharktech, Inc. が入り、Shadowserver Foundation が感染システムの特定と被害者への通知を支援した。逮捕・起訴の詳細は示されていない。

その4日後の11月16日に、FBI の FLASH が出ている（出典1）。なお、この作戦停止そのものは本データベースの INC-2026-1061 に別の記録として収めてある（本記録の整理）—— そちらは Europol と9か国による Gootloader・CastleRAT・StealC の3種同時の基盤停止（サーバー235台・ドメイン257件の押収）として記録しており、司法省が示した「100台超のサーバーから Gootloader を除去」とは数え方の単位が違う（本記録の明示）。本記録（INC-2026-1189）が扱うのは、作戦停止ではなくFBI が公表した Gootloader の手口と対策である。

FLASH は作戦停止に一言も触れていない〈齟齬1〉（本記録の作成者が全文を確認した）。FLASH の内容は TTPs の周知と対策であり、「Gootloader は止まった」とは書いていない—— むしろ「侵害された組織は FBI に連絡してほしい」と求めている（出典1）。

本記録はこの2件を「終了の宣言」として読まない（本記録の判断）。理由は3つある。 ①運用者の特定・逮捕が発表されていない〈未確定4〉。②FLASH が併記した SocGholish 系統の例では、106台のサーバー停止と14,971サイトの浄化を経ても、2026年4月から7月に1,509サイトがなお稼働していた（出典1）—— インフラの除去は再構築されうる。 ③FLASH 自体が、停止後に出された注意喚起である。

推奨される対策はWindows側とWordPress側の2系統に分かれている対策・注意喚起

FLASH の推奨事項は、守る対象で2系統に分かれている（出典1）。これは読者の立場で読み分ける必要がある（本記録の整理）。

① Windows 側（ランサムウェアを受ける側の対策）

予防の優先順位として示されたのは（出典1）: 業務アプリが必要としないなら Windows Script Host を無効化する（または WDAC・AppLocker でスクリプトの実行を制御する）、ユーザーが書き込める場所からの未承認のスクリプト・実行ファイルをブロックする、Microsoft Defender・SmartScreen・クラウド保護・AMSI・改ざん防止を有効に保つ、標準ユーザー権限での運用・ブラウザのダウンロード制御・添付ファイルの検査・DNS フィルタリング・認証付きの Web プロキシのログ、PowerShell・Security・Sysmon または EDR・DNS・プロキシ・ファイアウォールのテレメトリを集約し、遅れて現れる後続の活動を調査できる保持期間を確保する。

検知・対応として特に具体的なのは「怪しい ZIP をダウンロードしたが開いていない」場合の手順である（出典1）：中身を展開・プレビューしない、ダウンロード元のURL・検索クエリ・ブラウザ履歴の時刻・ファイル名を記録する、証跡の保全が完了したと確認されるまでファイルを削除しない、JavaScript ファイルを開いてしまった場合はネットワーク接続を切断する（対応手順が求める場合を除き電源は落とさない）、認証情報の変更は疑いのある端末からではなく、別のクリーンな端末から行う、後続のマルウェア・認証情報の窃取・永続化が確認されたら端末を再イメージする—— 「ダウンロードしたファイルを消すだけでは信頼は回復しない」と明記されている。

② WordPress 側（踏み台にされる側の対策）

FLASH は10項目の技術的保護を表で示している（出典1）: コアと信頼できるプラグイン・テーマの自動更新（緊急時は仮想パッチ）、使っていないプラグイン・テーマ・アカウント・ステージングサイト・既定の構成要素の削除（ソフトウェアの目録を維持する）、管理者とホスティングへのフィッシング耐性のある多要素認証、xmlrpc.php を使っていないなら無効化（必要なら流量制限と必要なメソッドのみ許可）、PHP を非特権アカウントで実行し、コアファイルを可能な範囲で読み取り専用にし、wp-content/uploads 配下での PHP 実行を拒否する、最小権限（ホスティングアカウントとサイトを分離し、1サイトが他サイトのファイルを書き換えられないようにする）、WAF（マネージドルール・ボット保護・ログインの絞り込み・ファイルアップロードの制御と、新しい REST エンドポイントや異常な admin-ajax の動作へのアラート）、完全性の監視（コアファイルを公式のチェックサムと比較し、プラグイン・テーマ・mu-plugin・JavaScript・.htaccess・index ファイルの予期しない変更をアラートにする）、検索の悪用の監視（Search Console や webmaster ツールで、自社と無関係な法律・ビジネス系のクエリ、突然増えたインデックス済みページ、手動による対策、セキュリティ警告を確認する）、証跡の外部集約（Web アクセス・WAF・認証・コントロールパネル・SFTP/SSH・データベース・DNS・外向き接続のログを Web サーバの外に保持する）。

本記録が強調したいのは「検索の悪用の監視」である（本記録の評価）—— 自社サイトが踏み台にされていることは、サーバーの中を見るより「自社と無関係な検索語で自社が表示されている」ことで先に分かる。 この監視項目は、WordPress の運用担当だけでなく広報・マーケティングの持ち物でもある。

認証情報の入手経路・プラグイン名・配備されたランサムウェアは公表されていない未確定事項

  • 感染した WordPress サイトの所在国・業種〈未確定3〉—— 日本のサイトが含まれるかは不明
  • 運用者の実体・帰属・逮捕の有無〈未確定4〉—— FLASH は「the Gootloader administrator」と単数で呼ぶが、個人か集団かも示していない
  • Gootloader の後続で配備されたランサムウェアの名称〈未確定5〉—— 表に出てくる Evil Corp・LockBit・RansomHub・SilentEncryptor は別系統の帰結である〈齟齬4〉

また、FLASH 本文には IoC（ドメイン・ハッシュ・IPアドレス）の一覧が含まれていない（本記録の作成者が全文を確認した）。載っているのは隠しキーワードリンクの文字列の実例、検索語の一覧、ログ源（PowerShell 4103/4104、Windows Security 4624/4648/4688/4697/4769/5140/5145、System 7045、WMI Activity 5857〜5861、WinRM、Sysmon 1/3/7/8/10/11/13/22）、MITRE ATT&CK のマッピングである（出典1）。したがって本 FLASH は「IoC で照合する」資料ではなく「挙動で検知する」資料である（本記録の評価）。

CISO・経営層への示唆
  • 標的が「業種」ではなく「職種」で絞られる前提で、教育と監視の単位を変える
    FBI は標的を実務弁護士・社内法務・法律事務所のパートナー・訴訟および privacy のチーム・ リーガルオペレーション担当・ゼネラルカウンセル・リーガルテック導入の意思決定者と 職種で列挙している（出典1）
    取るべき行動 「業務上、ひな形・文例・判例・様式を検索してダウンロードする職務」を洗い出す （法務・コンプライアンス・知財・人事・経理）。 その職務の端末に対して、ブラウザのダウンロード制御・スクリプト実行の制限を 他より厳しく適用し、職務別の注意喚起と報告先を配る。 **全社一律の教育では、この標的の絞り方に対応できない**
  • 自社サイトが「踏み台」になっていないかを、検索結果の側から監視する担当を決める
    2026年10月時点で1,000超の WordPress サイトが感染し、誘い込みページ・リダイレクタ・ トラフィックの選別・中継インフラとして使われていた。 FBI は Search Console 等で自社と無関係なクエリやインデックス済みページの急増を 監視することを推奨している（出典1）
    取るべき行動 自社の全ドメイン・サブドメインについて Search Console の所有者を一覧化し、 「自社と無関係な検索語での表示」「インデックス済みページの急増」「手動による対策」 「セキュリティ警告」の確認を月次の作業として割り当てる。 **この画面は広報・マーケティングが持っていることが多いため、 気づいたときの報告先をセキュリティ側に明記する**
  • 「作戦停止の発表」を終了の宣言として受け取らない
    司法省は2026年11月12日に100台超のサーバーからの Gootloader の除去を発表したが、 逮捕・起訴の詳細は示されていない（出典2）。 FBI の FLASH はその4日後に出ており、作戦停止に触れず対策と報告を求めている（出典1）。 FLASH が併記した別系統の例では、106台のサーバー停止と14,971サイトの浄化を経ても 2026年4月から7月に1,509サイトがなお稼働していた（出典1）
    取るべき行動 脅威情報の取り扱い規程に「テイクダウンの発表を受けても、 対応する検知ルールと緩和策は少なくとも6か月は維持する」という方針を書く。 併せて、テイクダウン発表の際に「運用者の特定・逮捕が含まれているか」を 確認項目にする（含まれていなければ再構築を前提に扱う）
  • 身代金の支払額と被害者の損害額を別の指標として管理する
    FBI は「2,800万ドル超のランサムウェア身代金支払い」を示し（出典1）、 司法省は「少なくとも44の米国拠点の被害者と約2,880万ドルの損害」を示している（出典2）。 数字は近いが測っているものが違う
    取るべき行動 社内のリスク資料で「身代金の支払額」「被害者の損害額」「復旧費用」を 別の行として持つ。外部の統計を引用するときは、どちらの指標かを必ず併記する。 **近い数字を同一視すると、投資判断の根拠になる被害規模を取り違える**
セキュリティ技術者への示唆
  • xmlrpc.php を使っていないなら無効化する（走査の対象がここである）
    FBI は「運用者は WordPress サイトを走査して xlmrpc.php を探し、 その後、侵害された認証情報を使ってシステムに侵入した」としている（出典1）。 xmlrpc.php は攻撃者が認証の総当たりに頻繁に狙う標準の WordPress API エンドポイントだと注記されている
    取るべき行動 自社の WordPress で XML-RPC の利用の有無を確認し、使っていなければ `xmlrpc.php` へのアクセスを Web サーバ側で拒否する。 必要な場合は流量制限と、必要なメソッド・信頼できる連携元のみの許可にして、 認証の失敗と POST の量を監視する
  • wp-content/uploads 配下での PHP 実行を拒否し、PHP を非特権で動かす
    FBI の WordPress 技術的保護の表は「PHP を非特権アカウントで実行し、 コアファイルを可能な範囲で読み取り専用にし、 wp-content/uploads 配下での PHP 実行を拒否する」ことを挙げている（出典1）
    取るべき行動 Web サーバ設定で uploads 配下の PHP ハンドラを無効化し、 PHP の実行ユーザーを Web サーバのファイル所有者と分ける。 コアファイルを読み取り専用にし、ホスティングアカウントとサイトを分離して 1サイトが他サイトのファイルを書き換えられないようにする
  • コアファイルと mu-plugins・.htaccess・index ファイルの完全性を監視する
    攻撃者は窃取した認証情報で脆弱なプラグインやテーマにアクセスし、 投稿の挿入・XML-RPC・REST ルート・JavaScript の改変を行った（出典1）。 FLASH が併記した別系統では wp-content/mu-plugins に隠された must-use プラグインが使われている
    取るべき行動 コアファイルを公式のチェックサムと比較する仕組みを入れ、 プラグイン・テーマ・mu-plugin・JavaScript・.htaccess・index ファイルの 予期しない変更をアラートにする。 **新しい REST エンドポイントの出現と、異常な admin-ajax のアクションも監視対象にする**
