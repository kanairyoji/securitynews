INC-2026-1194大崎電気工業にランサム攻撃、生産停止

大崎電気工業株式会社は2026年11月18日、ランサムウェアによるサイバー攻撃を受けたと公表した—— 2026年11月17日10時35分ごろにサーバ内のデータが暗号化されていることを確認し、 同日正午ごろから外部ネットワークとの接続を遮断、埼玉事業所および生産関連子会社 （岩手大崎電気・大崎プラテック）の生産関連システムを停止した。 スマートメーターなどの生産・出荷ができない状態で、再開時期は未定。 データの外部流出の可能性も含めて外部専門機関とともに調査中で、警察・関係当局へも報告済み。 公表の同日、ランサムウェア「Qilin」のリークサイトに同社が掲載されたことが 第三者の監視サイトで確認されているが、大崎電気工業は攻撃者について何も述べていない。 【続報・2026年11月25日】第二報（11月20日）で侵入の時期と経路が判明した—— 不正アクセスは2026年11月15日午前1時30分ごろ、社外から社内ネットワークへ接続するために 設置していたVPN機器の認証が突破されたもので、多要素認証が未適用のアカウントが 一部残存しており、パスワードを試行されて認証を突破された可能性が高いと同社は推察している。 外部から社内への入口はこのVPN機器1か所のみで、他経路からの侵入と11月15日より前の 不正アクセスは現時点で確認されていない。11月19日には「攻撃者によるものとみられるサイト」への 技術情報の掲載を認知した。第三報（11月25日）では、不正アクセスにより社内システムから 外部のクラウド型ストレージサービスへデータが送信された事実を確認したと公表し （内容と範囲は調査中）、当該サービス事業者へデータの保全・隔離・削除を求める手続きを 進めているとした。攻撃者の要求には応じない方針を明記している。業務再開は 生産が11月27日以降、受注済み製品の出荷が12月1日以降、新規受注が12月7日以降で段階的。 グループ会社の大崎電気システムズも同一のVPN機器を経由した不正アクセスを 受けていたことが判明した（同一ネットワーク上のグループ会社への影響は調査中。 株式会社エネゲート・EDMI LIMITED など別ネットワーク上のグループ会社では被害未確認）。 生産設備は業務系ネットワークと基本的に分離しており、生産設備への影響はなかったと確認された

初報: 2026年11月18日 最終更新: 2026年11月25日

大崎電気工業株式会社（計測制御機器メーカー。電力用スマートメーターの大手）は2026年11月18日、「ランサムウェアによるサイバー攻撃に伴う生産停止に関するお知らせ（第一報）」を公表しました（出典1。本記録の作成者が取得して内容を確認した）。

時刻まで公表されている点が、本件の第一報の特徴です。 同社は2026年11月17日10時35分ごろにサーバ内のデータがランサムウェアにより暗号化されていることを確認し、同日正午ごろから外部ネットワークとの接続を遮断したとしています（出典1）。被害の拡大を防ぐため、埼玉事業所および生産関連の子会社（岩手大崎電気株式会社・大崎プラテック株式会社）の生産関連システムを停止しました（出典1）。

影響は生産と出荷です。 スマートメーターなどの生産・出荷ができない状態となり、再開の時期は未定です（出典1・2）。顧客に対しては生産・出荷停止について個別に説明しているとしています（出典1・2）。

データの外部流出については、可能性も含めて調査中です（出典1）。同社は社長執行役員COOを長とする緊急対策本部を設置し、外部専門機関の支援を受けて調査・復旧を進め、警察および関係当局へ相談・報告しています（出典1）。業績への影響は、見込みを含めて現時点で不明としています（出典1）。同社を装う不審なメール・電話への注意もあわせて呼びかけています（出典1）。

構造として押さえるべき点は、攻撃者側の主張が同じ日に表に出ていることです。第三者の監視サイト ransomware.live は、2026年11月18日にランサムウェア「Qilin」のリークサイトに同社（victim 名「Osaki」・ドメイン www.osaki.co.jp）が掲載されたことを確認しています（出典3。本記録の作成者が API で確認した）。これは攻撃者側の主張であり、大崎電気工業は攻撃者について何も述べていません〈齟齬1〉。評価・示唆は本記録の判断として分けて書きます。

【続報・2026年11月20日】侵入の時期と経路が公表されました。同社は第二報で、不正アクセスは2026年11月15日（日）午前1時30分ごろに行われたものと推定し、社外から社内ネットワークへ接続するために設置しているVPN機器の認証が突破されて社内ネットワークに侵入されたことが判明したとしています（出典4）。多要素認証が未適用のアカウントが一部残存しており、パスワードを試行されて認証を突破された可能性が高いと推察しています（出典4）。当該アカウントが作成された経緯と、パスワードが事前に漏えいしていたかどうかは調査中です（出典4）。外部から社内ネットワークへ直接接続できる入口はこのVPN機器の1か所のみだったため、他の経路からの侵入の可能性は低いと同社は考えており、11月15日より前の不正アクセスも現時点では確認されていないとしています（出典4）。

【続報・2026年11月25日】データが外部へ送信された事実が確認されました。第三報で同社は、11月19日に認知した「当社のシステムに保存されている情報と思われる技術情報」の掲載について調査した結果、不正アクセスにより社内システムから外部のクラウド型ストレージサービスにデータが送信された事実を確認したとしています（出典5）。送信された情報の内容および範囲は、ログの確認に時間を要しており引き続き調査中です（出典5）。同社は当該サービスの提供事業者に対しデータの保全・隔離・削除等を求める手続きを進め、警察等の関係当局へ報告・相談を続けており、「攻撃者の要求には応じない方針」を明記しました（出典5）。個人情報が含まれるかは調査中で、含まれていた場合は個人情報保護委員会への報告と本人への通知を行うとしています（出典5）。

業務再開の見通しも示されました。 生産（埼玉事業所・岩手大崎電気・大崎プラテック）は11月27日（金）以降に段階的に再開、受注済み製品の出荷は12月1日（火）以降、新規受注（受発注・顧客側システムとの連携）は12月7日（月）以降です（出典5）。侵入を受けたVPN機器と中継に使われた可能性のあるサーバ等は停止したままで、外部からの接続は接続方式および認証対策の安全性を確認したうえで再開するとしています（出典5）。生産設備のネットワークは業務系ネットワークと基本的に分離しており、今回の攻撃による生産設備への影響はなかったことを確認済みです（出典5）。

波及はグループ会社にも及んでいました。 第三報は、大崎電気システムズ株式会社が同一のVPN機器を経由した不正アクセスを受けていたことを確認したとし、同一のネットワーク上にあるグループ会社への影響は調査中としています（出典5）。同一ネットワーク上にない株式会社エネゲート・EDMI LIMITED などでは現時点で被害は確認されていません（出典5）。

2026年11月26日 続報反映更新履歴へ
**続報を反映。** 2026年11月25日の収集記事（ScanNetSecurity・出典6）を起点に、 **大崎電気工業のサイトから第二報（11月20日）と第三報（11月25日）を自分で取得して 全文を確認した**（出典4・5）。 **最大の追記は原因である**——**第二報が侵入の時期（2026年11月15日午前1時30分ごろと推定）と 経路（社外から社内ネットワークへ接続するVPN機器の認証突破）を公表し、 「多要素認証が未適用のアカウントが一部残存しており、パスワードを試行されて 認証を突破された可能性が高い」と推察している。** **これを受けて root_causes を unknown から credential-abuse と misconfiguration に変え、 attack.chain に initial-access の段階を足した。** **侵入の推定時刻から暗号化の確認までは約57時間（日曜深夜から火曜午前）で、 figures に算出値を置いた。** **外部から社内への入口はVPN機器1か所のみで、他経路からの侵入と 11月15日より前の不正アクセスは現時点で未確認である。** **2つめの追記は持ち出しの確定である**——**第三報が「不正アクセスにより、 社内システムから外部のクラウド型ストレージサービスにデータが送信された事実を 確認いたしました」とした。** **exfiltration の段階を presumed から disclosed に変え、 detail.misuse と log_availability を書き換えた。** **送信された内容と範囲は、ログの確認に時間を要しており調査中である**〈未確定8〉。 **同社は当該サービス提供事業者へデータの保全・隔離・削除等を求め、 「攻撃者の要求には応じない方針」を明記した**——**response.decisions に ransom_payment と credential_reset の2件を足した。** **気づいたのは外部のサイトへの掲載を認知してからであり、 持ち出しそのものは検知していない点を detection_opportunity に記録した。** **3つめの追記は再開の見通しとグループ会社への波及である**—— **生産11月27日以降・受注済み出荷12月1日以降・新規受注12月7日以降と日付が示され、 生産設備は業務系ネットワークと基本的に分離しており影響が無かったことが確認された。** **大崎電気システムズ株式会社が同一のVPN機器を経由した不正アクセスを 受けていたことが判明した**〈未確定9〉——**orgs に3組織 （大崎電気システムズ／エネゲート・EDMI LIMITED／クラウドストレージ事業者）を足した。** **齟齬を2件足した**——**①同社が11月19日に認知した掲載サイトを 「攻撃者によるものとみられるサイト」と記すのみで、 Qilin のリークサイト（出典3）との関係に触れていない**〈齟齬3〉**。 本記録は両者を結びつけない。** **②第三報が「当社がサイバー攻撃を受けた同日（11月15日）」と書いており、 第一報・第二報の「11月17日に攻撃を確認」との使い分けが読み手に分かりにくい**〈齟齬4〉。 **未確定事項は削除せず、解消した部分だけを項目名から外して書き換えた**—— **侵入経路は公表されたので、残る問いを「多要素認証が未適用のアカウントが残った経緯・ パスワードの事前漏えいの有無・侵入後の活動」に絞り、 新たに2件（送信されたデータの内容と範囲・送信先の名称／ 大崎電気システムズへの不正アクセスの内容）を立てた。** **status は updating を維持する**——**送信されたデータの内容と範囲、 個人情報の有無、グループ会社への影響がいずれも調査中であり、 業務再開（11月27日以降）も予定の段階である。**
