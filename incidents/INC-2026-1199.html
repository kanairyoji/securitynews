INC-2026-1199Gentlemen が NVIDIA を掲載

ランサムウェア集団 Gentlemen（Microsoft の追跡名 Storm-2697）が2026年11月18日、 リークサイトに NVIDIA を掲載した——**掲載はロゴと会社説明だけで、 盗んだ情報の欄は「DATA INFO - SOON」のまま**。NVIDIA は 「第三者パートナーに影響した可能性がある事案を調査しているが、 NVIDIA のシステムやネットワークが影響を受けた兆候は見つかっていない」と答え、 **パートナー名も事案の性質も明かしていない**

ランサムウェア被害（暗号化・リークサイト恐喝が中心）不正アクセス・侵害続報が続いている有名事象として記録（日本と直接の関係は薄い）公表されていない／不明委託先・供給元起因
初報: 2026年11月18日 9時22分（UTC。リークサイト掲載の発見時刻。本記録が確認） 最終更新: 2026年11月25日（続報反映。ransomware.live の API で掲載内容を再確認した時点）

ランサムウェア集団 Gentlemen が、自らのリークサイトに NVIDIA を掲載した（出典1）。本記録の作成者は ransomware.live の API で掲載を直接確認した（出典3）〈重要〉—— 掲載の発見時刻は2026年11月18日9時22分（UTC）、攻撃日として登録されているのは同日、国は US、分野は Technology、対象ドメインは nvidia.com。 掲載本文には売上高（3,030億ドル）・株式記号（NVDA）・会社説明が並び、盗んだ情報の欄は「DATA INFO - SOON」、身代金額は未登録である（出典3）。

NVIDIA の回答（出典1）〈重要〉—— 「NVIDIA は、第三者パートナーに影響した可能性がある事案を調査している。NVIDIA のシステムやネットワークが影響を受けた兆候は見つかっていない。状況を監視し続ける」（NVIDIA 広報の SecurityWeek への声明。原文英語。本記録が訳した）。この声明は、パートナーを特定せず、事案の性質も述べず、NVIDIA 関連の情報が露出した可能性があるかにも触れていない（出典1）。

したがって本件で確認できているのは2つだけである（本記録の整理）〈重要〉—— ①Gentlemen が NVIDIA を掲載した（本記録が直接確認）、②NVIDIA が「第三者パートナーに影響した可能性がある事案」を調査中であり、自社システムへの影響の兆候は見つかっていないと述べた。 掲載は、NVIDIA が侵害されたことも、同社のデータが盗まれたことも示していない（出典1）。

Gentlemen について公表されている背景（出典1）—— 2025年半ばごろに出現し、当初は閉じた集団として活動した後、同年後半にアフィリエイトプログラムを始めた。Microsoft は運営者を Storm-2697 として追跡している。二重恐喝型で、リークサイトの掲載は1,100件を超える。Sophos によれば、アフィリエイトは侵害された資格情報と正規の管理ツールを使い、ある調査事案では侵害後の最初の活動から24時間未満でランサムウェアが展開された。
