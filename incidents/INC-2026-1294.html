INC-2026-1294イラン系新グループが IPFS を C2 に

Check Point Research が2026年11月24日、**イランの情報・安全保障省（MOIS）に 結びつく未記録の脅威グループ「Volant Manticore」**を公表した—— **キプロスを主要な諜報対象に定めたイラン系グループは同社の把握では初めてで、 通信事業者・航空会社・重要インフラを狙う**。**新しいバックドア KuboShell は C2 に IPFS（分散ファイルシステム）を使い、商用ピン留めサービス Pinata の 公開ゲートウェイ越しに命令を取りに来る**——**被害端末の識別子は最初の ネットワークアダプタの MAC アドレスで、60秒ごとに `<MAC>.txt` を見に行き、 中身を非表示の PowerShell に渡す**。**同社は、MuddyWater の引退した枠組みを 使い続けていることなどから「MuddyWater から分かれた元構成員である可能性が高い」と 中程度の確度で評価している。被害組織数は公表されていない**

Check Point Research が2026年11月24日、これまで記録の無かったイラン系の脅威グループを「Volant Manticore」として公表した（出典1）〈重要〉。同社は、このグループがイラン系であることを高い確度で評価し、少なくとも歴史的にはイランの情報・安全保障省（MOIS）に結びついていることを中程度の確度で評価している（出典1）〈重要〉—— 現在は別のイランの機関の下で動いている可能性も排除していない（出典1）。

キプロスが活動の中心である（出典1）〈重要〉—— 同社は、キプロスを主要な諜報対象に定めたイラン系グループは自社の把握では初めてだと述べ、対象として通信事業者・航空会社・重要インフラを挙げている（出典1）。背景として、キプロスがイスラエルとギリシャとの防衛・エネルギー面の結びつきを深めており、この地域における西側の軍事活動の拠点である点を挙げている（出典1）。

始まりは1通の偽の履歴書である（出典1）〈重要〉—— 調査の端緒は VirusTotal 上で見つかった「Athena Marinou」というAI で生成されたキプロス在住の旅行・観光業の専門家の履歴書で、「完全版をダウンロード」のリンクは正規の求人サイトを示しながら、実際には Catbox 上の書庫を指しており、そこから KuboShell が届く（出典1）。Check Point は、この攻撃がキプロス・イスラエル間の路線を事業の中心とするキプロスの航空会社に向けられたものと評価している（出典1）。

2026年9月、標的がサウジアラビアに移った（出典1）〈重要〉—— サウジアラビアとイランが支援するフーシ派の対立が激化した時期に重なり、対象は医療機関である（出典1）。AI_Healthcare_Seminar.zip で KuboShell を届け、関連する Ai_Healthcare_Seminar_Online.zip には KuboShell ではなくN-able の RMM 実行可能ファイルが入っていた（出典1）。この標本に関連するメールアカウントはサウジアラビアの私立病院のもので、漏えい資格情報を使って侵害されたとみられると評価されている（出典1）〈重要〉。

KuboShell の C2 は IPFS である（出典1）〈重要〉—— IPFS は、ファイルを置き場所ではなく内容のハッシュで識別するP2P のファイル共有網である（出典1）。ファイルは誰かのノードが保持（ピン留め）している間だけ参照できるため、KuboShell は商用のピン留めサービス Pinata を使う（出典1）。被害端末の識別子は最初のネットワークアダプタの MAC アドレスで、hi と書いたファイルを <MAC>.log として上げて登録し、以後60秒ごとに <MAC>.txt の有無を見に行き、あればその中身を非表示の PowerShell に渡す（出典1）〈重要〉。

KuboShell は最終目的ではなく「関門」である（出典1）〈重要〉—— 運用者が送った命令の履歴（2026年5月〜10月）から、quser・whoami・ipconfig といった基礎的な偵察を行ってから、多段の PowerShell と JavaScript の連鎖でより高機能なバックドアを落として実行していることが分かる（出典1）。Check Point はこの後段の枠組みを「Homa Framework」と呼ぶ（出典1）。

MuddyWater との関係について、同社は「分かれた元構成員」説を採る（出典1）〈重要〉—— Homa の第3段が MuddyWater の MuddyC2Go クライアントの JavaScript 再実装であること、運用者が別のコンソール向けの命令（list・persist・payload）を誤って KuboShell に送っていたこと、これらが MuddyWater の C2 枠組み（PhonyC2 など）の既知の命令であること、一方でキプロスへの集中・ホスティングと登録業者の違い・足跡の小ささがあることを根拠に、「MuddyWater から分岐した元構成員で構成される可能性が高い」と中程度の確度で評価している（出典1）。被害組織の数は公表されていない**（出典1）〈未確定1〉。

KuboShell は内容ハッシュでファイルを参照する IPFS を C2 にしており、通信先は正規のピン留めサービスになる原因・手口出典 [1]

KuboShell は64ビットの Windows バックドアで、C2 に IPFS（InterPlanetary File System）を使う（出典1）〈重要〉。IPFS は、ファイルを置き場所ではなく内容のハッシュで識別するP2P のファイル共有網である（出典1）。ファイルは誰かのノードが保持（ピン留め）している間だけ参照できるため、KuboShell は商用のピン留めサービス Pinata の API を使う（出典1）。バックドアの PDB パスには、IPFS の原実装である Kubo が現れる（出典1）—— 名前の由来である（本記録の整理）。

動作は単純である（出典1）〈重要〉—— ①起動時に管理者権限かを確認し、無ければ昇格して再起動を試みる（利用者アカウント制御の確認画面が出る）、 ②最初のネットワークアダプタの MAC アドレスを被害端末の識別子にする、 ③hi と書いたファイルを C:\Users\Public\<MAC>.log に保存し、ハードコードされた Pinata のアクセストークンで上げて登録する、 ④Pinata に <MAC>.txt があるかを確認し、あればその IPFS 識別子を引いてPinata の公開ゲートウェイ経由で中身を取得する、 ⑤取得した文字列を非表示の窓で PowerShell に渡す、 ⑥実行後、C:\Users\Public\<MAC>re.txt を上げようとする、 ⑦以後60秒ごとに新しい命令を確認する。

KuboShell 自身は出力を取り込まない（出典1）〈重要〉—— 命令が <MAC>re.txt に結果を書かない限り、運用者には何も返らない。 この素朴さが、後述の「別のコンソールの命令を誤って送っていた」所見とつながっている（本記録の整理）。

本記録は、この C2 の設計を防御側から3点で読む（本記録の評価）〈重要〉—— ①宛先での遮断が効かない（通信先は Pinata という正規のサービス）、②一方で、60秒という規則的な間隔は通信の形として見える、③C:\Users\Public\ 配下に MAC アドレスを名前に持つファイルが作られるという端末側の痕跡は明確である。IPFS を業務で使う理由がない端末からの通信を遮断できるなら、それが最も単純な手当てである（本記録の判断）。

KuboShell は最終目的ではなく「関門」で、環境を見てから Homa Framework の3段を落とす原因・手口出典 [1]

Check Point は、Pinata に残された運用者の命令履歴と出力を2026年5月から10月まで解析した（出典1）〈重要〉—— これには、最初に観測されたフィッシングの試みの2か月前に行われた運用者自身の試験も含まれる（出典1）〈重要〉—— 道具は実戦投入の前に運用者の手元で試されていた（本記録の整理）。

履歴から見えるのは、KuboShell が関門だということである（出典1）〈重要〉—— quser・whoami・ipconfig という基礎的な確認を行ってから、多段の PowerShell と JavaScript の連鎖でより高機能なバックドアを落として実行している（出典1）。Check Point は、これが「環境を評価してから最終ペイロードを配備する」関門として機能しており、フィッシング起点の初期侵入と整合すると述べている（出典1）。

後段の枠組みを同社は Homa Framework と呼ぶ（出典1）—— 第1段はハードコードされた IP（185.205.187[.]109:8000）のクライアントごとの URI からペイロードを取得してメモリ上で実行するPowerShell のステージャ、第2段は埋め込み文字列を XOR で復号し JScript としてコンパイルして繰り返し実行する PowerShell のローダ、第3段は10秒ごとに確認し、接頭辞で PowerShell・cmd.exe 経由の SSH・cmd /c を切り替えて実行し出力を POST で返す JavaScript バックドアである（出典1）。

回避の工夫が記録されている（出典1）〈重要〉—— 運用者は、システムパスや PowerShell の既定の設定変数（SpecialFolders['AllUsersStartUp']・$PSSessionConfigurationName）から文字を切り出して iex を組み立てる手法を試していた。 文字列一致による検知が当てにならないことを示す（本記録の評価）。

第3段が読み込む追加の module は回収できていない（出典1）〈未確定7〉—— したがって最終的に何が収集・持ち出されたかは分かっていない（本記録の整理）。

帰属の根拠は「引退した枠組みを使い続けていること」と「別のコンソールの命令を誤って送っていたこと」である帰属出典 [1]

Check Point は、MuddyWater との複数の結びつきを示しながら、同一グループではなく「分かれた元構成員」説を採る（出典1）〈重要〉。

結びつきの根拠（出典1）—— ①Homa の第3段が、MuddyWater の古い MuddyC2Go クライアントのJavaScript 再実装であること（URI の形、POST の書式、最初の要求が hi であること、命名と構造の類似を保っている）、 ②運用者が list・persist・payload という、PowerShell としては無効な命令を KuboShell に送っていたこと〈重要〉—— Check Point はこれを「別のコンソール向けの枠組みの命令を誤った窓に入力した」と読み、これらが MuddyWater の C2 枠組み（PhonyC2 など）の既知の命令であることを指摘している。 運用者の手癖が帰属の手がかりになった例である（本記録の整理）。③悪性文書と RMM を組み合わせる手口、侵害したメールアカウントで RMM 事業者に登録する手口の共通、 ④両グループに結びつくサーバー上で、ポート 4444 のPython SimpleHTTPServer の公開ディレクトリが現れたこと。

分岐の時期は確定していない（出典1）〈重要〉—— 「分裂は2023年ごろに起きた可能性があるが、観測の空白があるため確認されていない」（出典1。原文英語。本記録が訳した）。

同社の主張は運用上の示唆を伴う（出典1）〈重要〉—— このグループを MuddyWater の一部として扱うことが、とくにサウジアラビアとキプロスの組織に対する盲点を生みうる、としている。 本記録はこの主張を採否しない（本記録の明示）—— 帰属の粒度は、追跡する側の体制によって妥当性が変わる。

読みどころは新グループの登場ではなく、「正規のサービスに C2 を預ける」設計が宛先による防御を無効にしていることである評価・解釈出典 [1]

本記録は、この事案の要点を3つに整理する（本記録の評価）〈重要〉。

第一に、C2 の置き場所が「正規のサービス」になっている。 KuboShell の通信先は Pinata の API と公開ゲートウェイであり、命令の実体は IPFS 上の、内容ハッシュで識別されるファイルである（出典1）〈重要〉—— 攻撃者が用意するサーバーが無いため、「悪性ドメインを遮断する」「新規登録ドメインを警戒する」という防御の前提が成り立たない（本記録の評価）。残るのは、①その種のサービスを使う必要がない端末から遮断すること、②通信の周期という形で見ること、③端末側の痕跡（C:\Users\Public\ の MAC アドレス名のファイル）で見ることである（本記録の判断）。

第二に、独自マルウェアと正規 RMM が並行して使われている。 同じ標的に、KuboShell を入れた ZIP と N-able の RMM を入れた ZIP の両方が送られている（出典1）〈重要〉。マルウェア対策で片方を止めても、もう片方は「正規のソフトウェア」である（本記録の評価）—— RMM を端末側で実行制御の対象にしていなければ、検知の網にかからない。

第三に、この解析を可能にしたのは攻撃側の失敗である。 Check Point が運用者の命令履歴を5か月分読めたのは、Pinata 上に履歴が残っていたためであり、運用環境（VirtualBox と VMware のゲスト、Active Directory の試験に使われた Azure 関連のクラスタ、ウイルス対策製品に対する事前試験の痕跡）が見えたのは、サウジアラビアを拠点とする VPS が公開ディレクトリとして露出していたためである（出典1）〈重要〉。本記録はここから一般化しない（本記録の明示）—— 運用保全の失敗がなければ、同じ道具は見えないままだった（本記録の評価）〈重要〉—— 「IPFS を C2 にする実装は、他にも見つかっていないものがある」と考えるのが妥当である。
