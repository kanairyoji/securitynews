1. ロシアSVR系Storm-2945、ホテルWi-Fiを乗っ取り出張者を標的に（CaptiveCrunch）

出典: The Hacker News（2026-08-01） / Security Affairs（2026-08-01）

MicrosoftとReliaQuestが、2026年5月上旬から続く「CaptiveCrunch」キャンペーンを公表した。

  • アクター: Storm-2945。MicrosoftはAPT29（Midnight Blizzard／Cozy Bear）の作戦サブクラスターと評価。米英政府はAPT29をロシアSVRに帰属させている
  • 手口: 複数国のホスピタリティ関連ネットワークで、キャプティブポータルのゲートウェイ（DNSリゾルバを兼務）を掌握し、DNS応答を偽装。接続確認通信を偽のブラウザ/OSアップデートページへリダイレクト
  • 配布物: Go製RAT「CornFlake」（Webカメラ・マイク・キーストローク・スクリーンショット取得、Chrome App-Bound Encryption保護下のCookie窃取、多重永続化＋復元ウォッチドッグ）。ClickFix型の手動実行誘導も併用
  • 認証窃取: 7月16日以降、一部ページはMicrosoftの正規デバイスコード認証フローへ誘導し、MFA充足済みセッションを攻撃者が取得。インメモリ型PowerShellスティーラー「ChocoShell」はToken Brokerキャッシュ（.tbresファイル）からM365/Azure ADトークンを収集
  • 含意: 被害ネットワークに共通の機器・管理システムが確認されており、ポータル事業者側の共有サービス侵害の可能性。狙いは企業出張者のアカウントとみられる

ReliaQuestは手口がGRU系APT28（Forest Blizzard）のルーターハイジャック「FrostArmada」に類似すると指摘しつつ、TTPの重複のみを根拠とするため帰属は保留している。国家系アクターの中間者型作戦が「家庭用ルーター→ホテルWi-Fi」へと拡大した形である。

  • 優先順位付けの4要素: ①資産の公開露出、②KEV（悪用が確認された脆弱性カタログ）掲載状況、③エクスプロイトの自動化可能性、④技術的影響（部分的支配か完全支配か）
  • 修正期限: 最高リスク区分（公開露出＋KEV＋自動化可能＋完全支配）は最短3暦日での修正とフォレンジックトリアージを要求
  • 実装3フェーズ: 脆弱性管理ポリシーの見直し → KEVのプロセス組み込み → リスク表に基づく修正の実施

AIによる攻撃の高速化でエクスプロイトまでの猶予が縮む中、政府調達市場では継続的エクスポージャー管理・KEV連携・悪用予測を統合した製品への需要が高まっており、連邦政府の方針転換が民間のベストプラクティス形成を先導する構図となっている。

出典: Security Affairs（2026-08-01）

Microsoft・ReliaQuestの報告から、出張帰りの端末調査で確認すべき痕跡が具体化した。

  • 永続化: %APPDATA%\svchost32\svchost32.exe、サービス名 svchost32（表示名 "Cloud Sync Service"）、Registry Runキー、スケジュールタスク。削除してもウォッチドッグが再作成するため、隔離後に全機構を同時除去する必要がある
  • 認証情報: Token Brokerキャッシュの .tbres ファイルからM365/Azure ADアクセストークン・リフレッシュトークン・WAMトークンを収集。ブラウザCookieなしのSSOセッション再生が可能になるため、感染疑い端末のユーザーはトークン失効・再認証が必須
