総評

1. ミネソタ州水道30施設へのOT攻撃、CyberAv3ngers（イラン系）と一致するパターン

出典: Security Affairs（2026-08-02）

2026年7月26〜27日、ミネソタ州の30を超える地域水道事業体のOTシステムに協調攻撃があり、Minnesota IT Services（MNIT）が州のインシデント対応体制を発動、今週時点でも継続中である。

  • 公表した自治体: Braham、Maple Plain、Plymouth、South St. Paul の4市。人口約1,700人のBrahamは井戸・浄水制御のコンピュータ制御を無効化され、浄水場が完全停止した
  • 帰属: 連邦・州とも公式な帰属は未実施。Tenableは「作戦パターンがCyberAv3ngers（米政府がイランIRGCサイバー電子軍に正式帰属済み）の脅威エコシステムと一致する」と評価
  • 時系列: 攻撃はCISAが「イラン系アクターによる米重要インフラのPLC標的化」アドバイザリを更新した4日後に発生
  • 標的選定: CyberAv3ngersは小規模な水道・自治体施設を狙うことで知られる。専任のセキュリティ要員を持たない小規模・地方施設が米重要インフラの「最も低い枝」と見られている

技術的洗練度は低い。インターネットに露出した機器へリモートアクセスし、IPアドレスとパスワードを変更しただけで、監視・制御機能の喪失に至っている。FBIは少なくとも7州の事業者からPLC関連インシデントの報告を受けたと確認した。

2. オープンソースAIが中国・ロシア・北朝鮮の新たな標的に（AWSの警告）

出典: Defense One（2026-08-02）

大手テック各社がオープンウェイトモデルへ舵を切る中、その基盤となるOSSライブラリが国家系アクターの標的になっているとAWSが警告した。

  • AWS最高セキュリティ責任者Stephen Schmidt氏は、中国とロシアが「実環境の標的で実験しても処罰を受けない立場にある」ため、この種の攻撃を実行しやすいと述べ「本当に懸念している」と表明

カテゴリ: カテゴリ2「国家サイバー戦略・法制度」
対象日: 2026年08月02日
生成日時: 2026-08-03

総評

米国では、CISAが2026年6月10日に発出した拘束的運用指令 BOD 26-04 の実装フェーズが本格化している。BOD 19-02・22-01を置き換えるこの指令は、連邦機関の脆弱性管理を静的なCVSSベースから「公開露出・KEV収載・悪用の自動化可能性・技術的影響」の4要素による動的リスクモデルへ転換するもので、最も高リスクの脆弱性には3暦日という極端に短い是正期限を課す。同時にCISAは水道・下水セクターに対し、インターネット露出PLCの即時撤去という運用命令に近い強い勧告を出しており、規範の作り方が「文書での要求」から「攻撃実態に即した即応指示」へ寄っている。国内では、行政機関の廃止ドメイン管理という地味だが構造的な論点が制度化に向かい始めた。名古屋市は2027年4月1日以降に閉鎖するサイトのドメインを閉鎖後3年間管理することを義務付け、原則として自治体等に利用が限定されるドメインの使用を義務化した。日本の府省庁・自治体にとって、「サイトを畳んだ後の3年間」を制度として持つかどうかは今後の指標になる。

1. CISA BOD 26-04、連邦の脆弱性管理をリスクベースへ転換（最短3日の是正期限）

出典: CrowdStrike Blog（2026-08-02）

2026年6月10日発出のBOD 26-04は、BOD 19-02およびBOD 22-01を置き換える。

論点 内容
優先順位付けの4要素 ①資産の公開露出 ②KEVカタログ収載の有無 ③悪用の自動化可能性 ④技術的影響（部分的支配か完全支配か）
最短期限 「公開露出＋KEV収載＋自動化可能＋完全支配」に該当する最高リスク群は3暦日以内の是正＋フォレンジックトリアージ
3フェーズ構成 ①脆弱性管理ポリシー・手順の見直しと更新 ②KEVを脆弱性管理プロセスに組み込む ③リスク表に基づく是正の実装

CVEの発生量が爆発する一方で悪用までの猶予が縮んでいるという認識が背景にある。フロンティアAIが脅威側の速度を上げているという判断が明示的に組み込まれている点で、規制文書としても新しい世代に属する。日本の政府機関・重要インフラ規制を考えるうえで、「CVSS基準の一律期限」から「露出と悪用実態による動的期限」への移行は参照価値が高い。

2. CISA、水道セクターへインターネット露出PLCの即時撤去を要請

出典: Security Affairs（2026-08-02）

ミネソタ州の水道攻撃を受け、CISAは水道・下水（WWS）セクターのPLCを狙う脅威活動の顕著な増加を観測しているとして、公開露出しているPLCおよびその他OTを「可能な限り速やかに」インターネットから切り離すよう求めた。

勧告された緩和策は、①PLCのインターネット切断（運用目的のリモートアクセスはVPN／ゲートウェイ経由に限定し、PLC直結を禁止）、②パスワード保護の有効化と既定パスワードの変更、③既知のエンジニアリング端末等からのみアクセスを許すIPアロウリスト、④切断後にロックアウトに備えたPLCイメージのクリーンバックアップ確保、の4点である。

3. 国内自治体、廃止ドメインの管理を制度として義務化へ

出典: piyolog（2026-08-02）

過去に自治体事業で使用していたドメインが第三者に取得された事例の公表が相次いだことを受け、再発防止策が制度化されつつある。

  • 名古屋市: 2027年4月1日以降に閉鎖するサイトについて、閉鎖後3年間のドメイン管理を義務付け。原則として自治体等の機関に利用が限定されるドメインを用いるよう義務化し、庁内へドメイン管理の注意点を改めて周知
  • 宮崎県: 所管サイトから旧ドメインへのリンクを削除。原則として取得が地方公共団体に限定される「lg.jp」を含むドメインの利用と、運用停止した旧ドメインの一定期間保持を庁内に周知
  • 愛知県: 公表ページで再発防止策には触れず、旧サイト閲覧目的のリンクを張っている場合は設定解除を依頼するにとどまる

IPAも政府機関・地方自治体で同様の事例が多数報告されているとして注意を呼びかけている。

  • 伝播: 窃取したnpmトークンで whoami を呼び侵害アイデンティティを特定、当該アカウントで公開された全パッケージを列挙してStage 0ローダーのシムを注入する

出典: BleepingComputer（2026-08-02）

BleepingComputerがChromium Gerritの一連の作業中変更から確認したもので、承認され次第Googleは既定で有効化する計画である。

問題の構造

Chromeは組織がエンタープライズポリシーで拡張機能を強制インストールし、ブラウザ設定を制御することを許している。ドメイン参加やMDM管理下の業務端末では妥当だが、マルウェアが同じ仕組みを一般消費者PCで悪用してきた。悪性プログラムがローカルのChromeポリシーキーを勝手に追加し、新しいタブページを置き換え・検索エンジンを変更・検索を不審サイトへリダイレクトする拡張を強制インストールする。Chromeは管理者がインストールしたものと認識するため、利用者は削除も無効化もできず、実際には組織が所有していないPCで「組織によって管理されています」という紛らわしい表示が出る。
