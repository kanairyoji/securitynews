1. イラン系アクターの米水道インフラ攻撃、ニュージャージー・アラバマに拡大し12州に

出典: Security Affairs（2026-08-11）

1. NIST、AI 時代に向けた NVD（国家脆弱性データベース）の全面刷新へ意見募集

出典: CyberScoop（2026-08-11）

2. CVE プログラム、AI「vulnpocalypse」に自動化と国際化で対応へ

出典: OODA Loop（2026-08-11）

CVE プログラムの幹部は、AI 生成の脆弱性報告の急増に対し、現行制度は「耐えられる」としつつ、採番・検証の自動化と CNA（採番機関）の国際的拡大を進める方針を示した。NVD 刷新（上記）と併せ、脆弱性情報の生成側・登録側の両方で AI 前提の制度再設計が始まっている。

4. 「ホワイトハウスは AI で正しい。次は防御側に使わせよ」— 国家安全保障メモランダムを巡る議論

出典: War on the Rocks（2026-08-11）

1. 【悪用確認】SharePoint CVE-2026-45659、ランサムウェア攻撃での悪用を CISA が確認

出典: BleepingComputer（2026-08-11）

CISA は、7月1日に KEV へ収載済みの SharePoint RCE（CVE-2026-45659、信頼できないデータのデシリアライゼーション）について、ランサムウェアグループによる悪用を確認したと KEV を更新した。低権限・低複雑性で悪用可能。Shadowserver の観測ではインターネット露出した SharePoint サーバー8,500台超のうち200台超が未パッチのまま。Microsoft 自身はまだ advisory に悪用フラグを付けておらず、KEV 側が先行している。対策はパッチ適用に加え、AMSI 統合の有効化と侵害痕跡の確認（悪用は7月上旬から続いているため「今からパッチ」では不十分な可能性がある）。

2. Rapid7、SharePoint の新規 RCE チェーン（CVE-2026-63520）と JWT 認証バイパスの詳細解析を公開

出典: Rapid7 Blog（2026-08-11） / Rapid7 Blog（2026-08-11）

Rapid7 Labs は SharePoint に対するゼロデイ研究で、2つの新規脆弱性を連鎖させた未認証 RCE（CVE-2026-63520、修正済み）を発見・公開した。併せて7月に公表済みの JWT トークン認証バイパス（CVE-2026-55040）の技術解析も公開。SharePoint は上記 CVE-2026-45659 の悪用と合わせ、オンプレミス版が集中攻撃を受けている。オンプレ SharePoint を持つ組織は8月パッチの即時適用と、外部公開の必要性自体の再検討を推奨する。

3. Adobe、ColdFusion と Campaign Classic に priority 1 の緊急パッチ — CVSS 10.0 含む

出典: SecurityWeek（2026-08-11）

Adobe は50件超の脆弱性を修正した。ColdFusion は15件（OS コマンドインジェクション CVE-2026-48362＝CVSS 10.0、eval インジェクション CVE-2026-48273＝9.9、認可不備 CVE-2026-71384＝9.6）、Campaign Classic は RCE につながる critical 3件（CVE-2026-71398・CVE-2026-27302＝10.0、SQLi CVE-2026-48381＝9.0）。両製品とも priority 1（悪用リスク高・即時適用）。Commerce も権限昇格（CVE-2026-71362＝9.1）等7件を修正（priority 2）。ColdFusion は過去に KEV 入りの常連であり、露出インスタンスは即日対応が妥当。

4. SAP パッチデー：critical 4件を含む28件を修正

出典: SecurityWeek（2026-08-11）

5. Zoom、ゼロクリックのコード実行脆弱性を修正

出典: SecurityWeek（2026-08-11）

Zoom の注釈（annotation）機能に、会議参加者が他の参加者のマシン上でコードを実行できるゼロクリック脆弱性が見つかり修正された。ユーザー操作なしで会議参加だけで攻撃が成立するため、クライアントの自動更新状況を確認したい。

6. Cisco、ClamAV の7脆弱性を警告 — 2件は PoC 公開済み

対象日: 2026年08月11日
生成日時: 2026-08-12

総評

コード署名鍵とパッケージエコシステムの両面で重い事案が続いた。Mozilla は Firefox/Thunderbird の Linux 版リリース署名に使う GPG 秘密鍵の非暗号化コピーを自社のプライベートリポジトリに誤コミットし、鍵を失効・再発行した。npm では C2 アドレスを Ethereum ウォレットから読み取る6パッケージが発見され、中国メディアは1,300パッケージ規模の汚染を報じた。WordPress ではプラグインベンダー BdThemes の侵害により JSON 汚染で不正管理者を作る攻撃が発生し、「ベンダー1社の侵害が配下の全プラグイン利用者に波及する」構図が改めて示された。防御側では「GitHub のテレメトリは既に EDR に相当する」という Black Hat 発表が、既存ログの活用という現実的な対策を提示している。

1. Mozilla、Firefox/Thunderbird の署名用 GPG 鍵を失効 — 秘密鍵がリポジトリに露出

出典: The Hacker News（2026-08-11） / BleepingComputer（2026-08-11）

Mozilla は、Linux 向け Firefox/Thunderbird のリリース署名に使う GPG 鍵の非暗号化コピーが誤って自社プライベートリポジトリにコミットされたため、鍵を失効し新しい鍵に切り替えた。悪用の証拠は示されていないが、コード署名鍵はサプライチェーン攻撃の最高価値資産であり、失効・再発行は妥当な対応。Linux でリポジトリ外から Firefox/Thunderbird を導入・検証している組織は新しい公開鍵への切り替えが必要。「プライベートリポジトリだから安全」ではなく、シークレットスキャンを private を含む全リポジトリに適用すべきことを示す事例でもある。

2. npm：Ethereum ウォレットから C2 アドレスを読む6パッケージ、さらに1,300件規模の汚染報道

出典: Infosecurity Magazine（2026-08-11） / 安全客（2026-08-11）

npm で、C2 サーバーのアドレスを Ethereum ウォレット（ブロックチェーン上のデータ）から動的に読み取る悪性パッケージ6件が発見された。C2 をブロックチェーンに置くことでテイクダウンと静的解析の両方を回避する。中国の安全客は別途、1,300個規模の npm パッケージ汚染を報じており、npm エコシステムへの投毒は量・質ともに悪化している。依存パッケージのインストール時スクリプト無効化（--ignore-scripts）とレジストリプロキシでの審査は標準対策にすべき段階にある。

3. WordPress プラグインベンダー BdThemes 侵害 — JSON 汚染で不正管理者を作成

出典: The Hacker News（2026-08-11）

WordPress プラグインベンダー BdThemes のインフラが侵害され、プラグインが取得する JSON データを汚染して WordPress サイトに不正な管理者アカウントを作成する攻撃が確認された。WordPress.org のプラグインチームは同社プラグインの配布を一時停止。プラグインの「更新チャネル」や「外部データ取得」がコード配布と同等の信頼を要求することを示す事例で、企業サイトの WordPress 利用ではプラグインベンダーの供給元リスクも棚卸し対象になる。

4. 「GitHub には既に EDR がある。聞く耳を持て」— 既存テレメトリで供給網攻撃を検知

出典: CSO Online（2026-08-11）

5. Cursor のセキュリティバグ：信頼確認前にリポジトリがコマンド実行可能だった

出典: Infosecurity Magazine（2026-08-11）

AI コードエディタ Cursor に、リポジトリを開いた際の信頼確認（trust verification）前にリポジトリ側の設定でコマンドが実行される脆弱性が見つかった。悪意あるリポジトリを clone して開くだけで侵害される経路であり、AI 開発ツールの普及とともに「エディタ＝コード実行環境」のリスクが拡大している。MCP サーバー経由の秘密情報窃取（カテゴリ13参照）と合わせ、開発環境のサプライチェーンは攻撃面として急拡大中。

法的責任・コンプライアンス

対象日: 2026年08月11日
生成日時: 2026-08-12

総評

CEVA Logistics 侵害を受けた Valve の対応が、委託先起点のデータ流出における GDPR 実務の生きた事例になっている。Valve は影響範囲を厳密に特定できないため「影響した可能性を合理的に想定できる顧客全員」に通知し、複数国のデータ保護当局への届出を進めている。執行・司法面では、ランサムウェア運営者への16年・32年の長期実刑判決、スペインでのディープフェイク本人確認詐欺の逮捕など、抑止のニュースが続いた。AI ガバナンスでは「法的保護の境界を理解しないまま AI 導入が進む」という経営責任の指摘があり、EU CRA への OSS 対応も引き続き実務課題である。

1. CEVA 侵害における Valve の GDPR 対応 — 委託先起点の通知実務

出典: The Record（2026-08-11）
