地政学リスク・国家サイバーオペレーション

カテゴリ: カテゴリ1「地政学リスク・国家サイバーオペレーション」
対象日: 2026年08月29日
生成日時: 2026-08-30

総評

中国系とみられる作戦の実像が二方向から見えた日である。フィリピンでは原子力研究機関と海軍関連の造船会社が既知の脆弱性で破られ、攻撃者の作業ディレクトリがそのまま露出した。中央アジアでは AI を使って RAT を量産する China-nexus のアクターが報告され、コード類似度による帰属が崩れつつあることが示された。米国では上水道100システム超への PLC 攻撃を CISA が確認し、電力機器の外国製依存に対する大統領令14420が出ている。インド太平洋では「通常戦にならない競争」が軍側の言葉で語られ、日本の周辺で起きていることの説明枠として使える。

1. フィリピンの原子力・海軍関連が中国語話者に破られる、既知の脆弱性2本で

出典: Security Affairs（2026-08-29）

Hunt.io は8月13日、アムステルダムのホスト 31.58.209[.]241 に開放ディレクトリを発見した。ownCloud の CVE-2023-49105 を突く Python スクリプト、Sliver・Metasploit・Mettle、持ち出したデータが 86フォルダ・1,310ファイル・1.17GB 置かれていた。標的はフィリピンの原子力研究機関と、比海軍に役務を提供する船舶工学・造船会社の WordPress サイト。CSV には原子力機関から約9GB を取った記録があり、第三の被害組織を示す痕跡もある。コメントやログの簡体字から中国語話者に帰属された。

ゼロデイではなく2023年の既知欠陥と WordPress という、資金の要らない手口で軍事・原子力の情報に到達している点が重要である。Hunt.io は TLP:AMBER で CERT-PH に共有し、通知が済むまで公表を遅らせた。

日本にとっては他人事ではない。同じ海域の緊張を共有する立場であり、国内の大学・研究機関・防衛関連の下請けが同様の構図に置かれている。自社が防衛・原子力の役務提供者である場合、インターネット公開の CMS とファイル共有の棚卸しを先に済ませたい。

2. AI で RAT を量産する China-nexus アクター、帰属のクラスタリングが効かなくなる

出典: OODA Loop（2026-08-28）

Bitdefender は単一のサイバースパイ主体が作った7つの RAT ファミリを報告し、うち5つは未記録だった。同社はこの主体を SilkParasite と呼び、ウズベキスタン・トルクメニスタン・カザフスタンなど中央アジアの政府を標的とする China-nexus のアクターと中程度の確度で評価している。AI を使ってマルウェアの実装を増やしていると分析されている。

重要なのは帰属手法への影響である。従来は道具とコードの類似で活動をクラスタにまとめ、そこに主体名を貼ってきた。1つの主体が短期間に7系統の実装を吐き出せるなら、コード類似は同一主体を分断し、別主体を同一に見せる。確度の表現（中程度）を落とさずに読む必要がある。

日本の CTI 運用への含意は具体的である。ベンダーのアクター名を鵜呑みにしてブロックリストを作る運用は、この変化に耐えない。基礎情報（公開の脅威インテリジェンス）と自組織の観測を層として分けて保持し、「同じ道具＝同じ主体」という推論を報告書に書かない規律が要る。

3. CISA、7月に米上水道の100システム超が狙われたと確認、PLC が標的

出典: OODA Loop（2026-08-28）

CISA は、インターネットに露出した米国の上下水道システム100件超への攻撃を観測したと公表した。ミシガン・ミネソタほか5州以上で続く水道事業者への攻撃の規模がこれで見えた。主な標的は Rockwell・Schneider Electric、そして最近は Siemens の PLC である。CISA は以前、これらの攻撃が公開情報をもとに脆弱な Siemens PLC を狙うスクリプトを作る AI ツールに一部依存していると述べている。

高度な手口ではなく、露出した制御機器を数で叩く型である。防ぎ方も既知——インターネットからの直接到達を断ち、既定資格情報を変え、遠隔保守経路を絞る——だが、小規模事業者ほど実施できていない。AI が偵察とスクリプト作成の敷居を下げたことで、標的の裾野が広がった。

日本の水道は市町村単位の運営が中心で、体制の薄さは米国と同じ構図にある。上下水道の広域化・民間委託が進む局面でもあり、委託先を含めた露出資産の棚卸しと、制御系の遠隔監視回線の可視化が急ぐべき論点である。

4. 米、電力系統機器の外国依存に国家非常事態を宣言（大統領令14420）

出典: Security Affairs（2026-08-28）

8月26日に署名された大統領令14420は、破壊工作・不正アクセス・悪意ある遠隔操作・供給網の途絶を招きうる電力系統機器と技術を対象とする。ホワイトハウスは、データセンター・AI・先端製造・防衛生産の拡大により電力への依存が一段と深まったことを理由に挙げ、外国製機器に隠された遠隔アクセス機構という直接的なリスクと、地政学的緊張で部材供給が切れる二次的なリスクの両方を挙げた。法形式として「異常かつ重大な脅威」を認定する国家非常事態を宣言している。

規制対象の具体的な線引きは今後の実施細則に委ねられ、対象国・対象品目の指定が実務の焦点になる。既存の Bulk-Power System 関連措置の再強化という側面が強い。

日本の含意は輸出側と調達側の両方にある。日本の重電・変圧器・パワエレのメーカーは米国市場での適合要求に直面し、国内の電力・データセンター事業者は経済安全保障推進法の基幹インフラ事前審査で同種の判断を求められる。調達仕様に「遠隔アクセス機構の申告」を入れる実務が現実的な次の一手である。

5. インド太平洋の衝突は通常戦の形を取らない、と SOCPAC 司令官

出典: Defense One（2026-08-28）

ハワイで開かれたインド太平洋非正規戦シンポジウムで、米太平洋特殊作戦軍のマイケル・ローズ陸軍准将は、米国が通常戦に強くなるほど相手は通常戦を避けると述べた。競争が消えるのではなく形が変わり、相手は継ぎ目を探し、閾値の下で動き、曖昧さを利用し、代理勢力・情報・経済的威圧・サイバー能力・海上戦力といった非対称の手段を使うという説明である。

軍の公式見解として「閾値下の競争」が主戦場だと述べた点に意味がある。サイバーは単独の領域ではなく、情報操作や経済的威圧と束ねて使われる手段として位置づけられている。

日本の企業・自治体にとっては、この「閾値下」の実務的な受け皿が民間になるという含意が重い。武力攻撃と認定されない段階で被害を受けるのは重要インフラ事業者と、その供給網の中小企業である。有事の議論に入る前に、平時から続く低強度の侵害を誰が費用を負担して防ぐのかを整理しておく必要がある。

6. X が中国関連のボット20万アカウントを停止、AI 論争が標的

出典: SC Media（2026-08-28）

X は、中国由来とみられる約20万のボットアカウントからなるネットワークを停止したと明らかにした。AI をめぐる議論を標的にしていたとされる。

規模は大きいが、プラットフォーム側の自己申告であり、独立した検証や技術的な帰属根拠は示されていない。「中国関連」の内訳——国家機関か、請負業者か、営利のボット販売者か——も不明なままで、帰属の確度は低く見るべきである。停止の事実と、背後の主体の推定は分けて扱う必要がある。

日本の含意は情報環境の側にある。AI 規制や半導体政策のような、日本でも政策決定が進む論点は同種の操作の標的になりうる。政策担当者と広報部門は、SNS 上の「世論」を政策判断の入力に使う際、増幅されたアカウント群の存在を前提に置くべきである。

7. 米空軍サイバーが AI 攻撃を前提とした防勢キャンペーン計画を策定

出典: Breaking Defense（2026-08-28）

事案対応の積み上げではなく、防御を「キャンペーン」として計画する枠組みに移した点が変化である。ただし計画の中身は公表されておらず、実効性は評価できない。

日本の防衛・重要インフラ側にも同じ問いがある。能動的サイバー防御の制度整備が進むなか、攻勢側の議論に比べて防勢側を計画として組む発想は薄い。民間企業にとっても、個別のインシデント対応手順ではなく、年単位で「どの資産をどの順で堅くするか」を計画に落とす作り方は参考になる。

1. CISA「A Tale of Two SOCs」——片方は検知ゼロ、片方は2〜20分で隔離

出典: iThome Security（台湾）（2026-08-28）

CISA は8月25日、重要インフラ2機関に対する red team 評価の結果を公表した。両方の演習で red team はドメイン全体を掌握し、機微な業務システムとクラウド資源に到達した。差は防御側にある。機関 A の SOC は攻撃を検知も阻止もできなかった。機関 B の SOC は攻撃初期の段階で約2〜20分以内に侵入を見つけて手動隔離し、red team は「侵害済みを前提（Assume Breach）」の方式に切り替え、指定内部ホスト上でペイロードを実行して本来得られたはずの権限水準を模擬せざるを得なかった。CISA は3つの教訓——挙動のベースラインを作り検知ツールを調整して警報の雑音を減らすこと、部門の壁を壊して防御側に即時対処の権限を与えること——を挙げた。

事故報告でも脆弱性警告でもなく、防御側の成熟度を比較する形式の公告である点が珍しい。ツール選定ではなく監視の設計と組織手続きが差を生んだと結論づけている。

日本の SOC 運用への含意は、外部委託 SOC に「検知」までを任せて「隔離」の権限を社内に残している構成の危うさにある。機関 B が短時間で止められたのは手動隔離を実行できたからで、検知から遮断までの権限委譲を平時に決めておく必要がある。

2. TerminalFix：逆トンネルが張られた端末は「侵入口」として扱う

4. ESX のコマンド難読化——既知文字列に依存した監視は機能しない

2. 再生できない偽 MP4 が NetSupport を運ぶ、40エンドポイントの配信基盤

出典: Censys Blog（2026-08-28）

1. McKesson の 8-K が示す「重要性なし」判断の作法

出典: BleepingComputer（2026-08-28）

5. CRA・SSDF が生む SBOM の運用負荷、VEX の扱いが分かれ目

コンプライアンス上の要点は VEX である。SBOM に載る脆弱性の多くは実際には到達不能であり、VEX なしでは是正義務の範囲が過大に見積もられる。
