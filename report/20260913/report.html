1. 韓国の企業のサイバー侵害届出は6年で8,565件、81.6%が中小企業

出典: 보안뉴스 boannews（2026-09-13）

黄貞我議員（共に民主党）が KISA から得た資料によると、2021年〜2026年6月の届出は8,565件。年別は640→1,142→1,277→1,887→2,383件で、2026年は6月までに1,236件。類型はシステムハッキング5,196件、DDoS 1,704件、マルウェア1,665件で、ハッキングは283件から1,441件へ5倍超、比率は44.2%→60.5%に上がった。中小企業が6,991件（81.6%）。ハッキングを2回以上届け出た企業は608社（2回468・3回98・4回以上42）。議員は隠蔽への厳格な責任追及と保安産業の育成を訴え、科学技術情報通信部はサイバー特化の AI 基盤モデル開発の事業者を選定した。

件数増は被害の増加と届出の定着の両面を映す。同じ企業の再被害が多いことは、事後の再発防止が機能していないことを示す。

日本でも被害は中小企業に集中しており、取引先経由で大企業に波及する。経産省が準備を進めるサプライチェーン対策評価制度では、取引先の中小企業が一度被害を受けた後の再発防止まで支援の対象に含めるべきである。

2. 9/11 後の分析の5つの誤り、「脅威を誇張せず、能力は急造できない」

出典: Lawfare（日付不明）

Soufan Center の論集をもとにした論考。米政府と分析コミュニティの誤りを5つ挙げる。①9/11 を今後の大規模テロの前触れと見たが、実際は例外だった ②継続的な対テロ圧力が脅威を弱める効果を過小評価した ③9/11 前のアフガニスタンが聖域として特異だったことを見落とした ④ジハード主義勢力内の対立を過小評価し、地域的な集団まで米国を狙うとひとまとめにした ⑤社会を作り変える力を過大評価した。教訓は、脅威の誇張を避けること、専門性・情報機関同士の関係・地域社会の信頼は急に増強できないため継続的に資源を配ること、謙虚さである。

サイバーでも最悪の事態を常態とみなすと、資源配分と同盟国との協力が歪む。一方で、平時に築いた情報共有の関係が有事の効果を決める点は同じである。

日本は能動的サイバー防御の本格運用に向けて体制を整備している段階にある。人材の育成と同盟国との情報関係は有事に急造できないため、予算を単年の脅威認識で増減させず、継続的に配分する設計が要る。

1. AI が「隠すことによる防御」を終わらせ、OT の専門性の壁が崩れる

出典: The Register（2026-09-13）

9月の Patch Tuesday（974 CVE）では、Telnet クライアント、RNDIS、NFS Portmapper、LLTD など長年顧みられなかった部品が修正された（ZDI の Dustin Childs）。FBI の Brett Leatherman は、10年検証されてきた OSS ライブラリの脆弱性を最新モデルが見つけたと述べた。8月下旬には米5機関が、AI 生成の攻撃スクリプトでインターネットに露出した Siemens S7 系 PLC が侵害されたと警告している。一方、1Password が6件の CVE で6,080本のパッチを先端モデルに作らせた検証では、完全な修正は26.0%で、53.9%は未修正か新たな脆弱性を生んだ。

OT は専門知識が少数の人に偏っていたことで守られてきたが、AI がその障壁を下げた（Google GTIG の John Hultquist）。修正の自動化は追いついておらず、発見と修正の速度差が広がる。

国内の工場・水道・ビル設備でも、S7 などの PLC がインターネットに露出していないか、リモート保守回線が常時開いていないかを棚卸ししたい。独自プロトコルだからと残してきた設備を優先して見直し、AI が作ったパッチは人のレビューを前提にする。

2. 米 HHS、医療機関向けリスク評価ツール SRA Tool 3.7 を公開

出典: DataBreaches.net（2026-09-13）

米保健福祉省の公民権局（OCR）と国家医療IT調整官室（ONC）が、Security Risk Assessment Tool の3.7版を公開した。更新点の詳細は抄録からは確認できない。

HIPAA セキュリティ規則はリスク分析を義務づけており、専任者のいない中小医療機関が無料で自己評価できる道具として使われてきた。

日本の医療機関は「医療情報システムの安全管理に関するガイドライン」第6.0版とチェックリストで同様の自己評価を求められている。米国で事業を行う医療機器・ヘルスケア企業は、米側の評価項目との差を確認しておきたい。

2. HTTP→HTTPS のリダイレクトだけでは、最初の平文リクエストで Cookie が漏れる

出典: Habr（2026-09-13）

監査で社内サービスの一部が HTTP で応答すると指摘され、HTTPS への301リダイレクトを設定して指摘は解除された。しかし301を受け取るリクエストは既に経路上を平文で送られており、パス、パラメータ、Cookie ヘッダーを含む。筆者が調べると、この経路を通るクライアントは想定より多かった。

国内の監査や診断でも「リダイレクト済み」で合格とする例は多い。社内ポータルや API の Cookie に Secure 属性があるか、HSTS ヘッダーを返しているか、http:// で接続してくる機器や連携システムがないかをログで確認したい。

Gartner は9月9日、2029年までに AI への置き換えを理由に解雇された従業員の30%が再雇用を必要とし、多くは以前より高くつくと予測した。人員削減が人材の供給源を細らせ、組織に蓄積された知識を失わせるためである。2027年までに、AI による生産性向上をコスト削減として取り込む企業の75%は、成果を再投資する競合に追い抜かれるとも予測した。「Hype Cycle for the Future of Work, 2026」では、初期の AI 投資が幻滅期に入りつつあるとしている。

セキュリティ部門でも、SOC のアラート一次対応を AI に置き換える動きがある。一次対応は若手が経験を積む段階でもあり、ここを削ると判断の根拠を理解する人材が育たず、AI の誤判定を見抜く力も失われる。

国内はもともとセキュリティ人材が不足しており、一度手放すと採用し直すのは難しい。SOC・CSIRT の自動化計画を経営層に説明する際は、削減額ではなく、自動化で空いた時間を育成と脅威ハンティングに振り向ける設計として示したい。
