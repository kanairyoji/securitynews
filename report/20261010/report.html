総評

本日の材料は、サイバー作戦そのものよりも、その土台にある国家間の力関係の変化に集まった。中国系の走査基盤を解体した米国の作戦は、前日からツール名と押収ドメイン数まで明らかになり、請負企業が国家の作戦を担う構図が改めて確認できる。中東では米イランの間接協議が再開した一方、イラン系勢力による越境攻撃は続いており、「交渉と攻撃の並行」が定常状態になりつつある。ロシアは選挙後に懸念された動員ではなく増税と公共料金の引き上げで戦費を調整しており、戦争の長期化が社会の負担へ転嫁されている。トルコのリビア政策のように、域外国が「どちらかの支援者」から「安全保障の仲介者」へ役割を変える動きも同時に進んでいる。

1. 【前回からの差分】FBIが中国系の走査基盤を解体 — ツール名は MicroScan と FishHub、ドメイン7件

出典: OODA Loop（2026-10-09）

FBIと国際パートナーが、中国の国家支援型攻撃者が運用していた攻撃ツール「MicroScan」と「FishHub」のドメイン7件を無効化した。基盤は中国政府のサイバー作戦と国家安全プロジェクトに関わる請負企業 Integrity Technology Group が運用していたとされ、MicroScan はボットネットと併用して米国の電力を含む重要インフラの走査に使われていた。前回は「7か国での基盤無効化」「日本の空港も走査対象だった」までの情報だったが、今回ツール名・押収ドメイン数・電力への走査が明示された。

走査は侵入の前段にあたる工程で、ドメインを落としても攻撃者は別の基盤へ移る。むしろ重要なのは、国家の作戦が民間請負企業の形で運営されており、起訴や制裁の対象は特定しやすい反面、人員と道具は次の会社に引き継がれやすいという構図である。

日本の読者にとっては、電力・空港・港湾といった対外公開資産が同じ走査網の視野に入っていたという点が要になる。ドメイン停止で今後の観測が途切れる前提で、公開ポートとWeb資産に対する過去数か月の走査ログを遡り、継続的に戻ってくる発信元を洗い出す作業は今日着手できる。

2. イランは「東方を見る」政策を続けるが、中国への不信が残った

出典: Jamestown Foundation（2026-10-09）

米国・イスラエルとの戦闘を経て、イラン内部で中国との関係をめぐる論争が起きている。中国は直接の軍事支援を行わず、対応は緊張緩和と主権尊重を求める外交的発言にとどまった。テヘラン側では、中国がホルムズ海峡のエネルギー流通を守るためアラブ諸国との関係と対米対話を優先したと受け止められている。それでも安全保障機関の影響力が強まった結果、25年協定・上海協力機構・BRICSを軸とする東方重視は継続する見通しだという。

評価としては、中国がイランに対して軍事同盟型のコミットメントを与えないことが確認された意味が大きい。イランの安全保障機関は拘束的な同盟よりも作戦上の独立を好むため、サイバーや代理勢力を使った自前の手段への依存がむしろ強まる方向に働く。

日本の含意は二つある。第一に、中東の緊張が長期化してもイランが中露と一体で動くとは限らず、エネルギー調達リスクの見積もりを「陣営」単位で立てると外す。第二に、イランが独立した手段に傾けば、金融・海運・エネルギーを狙うイラン系アクターの活動は国家間交渉の進展とは無関係に続く。該当業種では交渉の見出しで警戒度を下げないことが現実的な構えになる。

3. 米イランの間接協議が再開 — ホルムズ海峡という交渉材料は目減りした

出典: War on the Rocks（2026-10-09）

9月下旬、米国とイランの交渉担当者が、6月に成立した了解覚書が破棄されて以来はじめて間接協議を行った。トランプ大統領は10月8日に「生産的な議論」が進行中だと述べた。ただし、イランが提示した「1週間以内にホルムズ海峡を再開する」という申し出の価値は下がっている。海峡の通航量はすでに回復傾向にあり、封鎖を解くことが取引材料になりにくくなったためである。

交渉の再開自体は緊張緩和の材料だが、イラン側の要求が残っている限り行き詰まりの解消には時間がかかる。注意すべきは、海峡という物理的な圧力手段の価値が下がるほど、相対的に安価で否認可能なサイバー・影響工作の比重が上がる点である。

日本は原油輸入の大半を中東に依存しており、ホルムズ海峡の通航回復は実務上の好材料である。一方で、交渉局面に入ったからといって日本の海運・石油・電力に対する探索活動が止まる根拠はない。海峡の開閉という目に見える指標とサイバー面の脅威水準を切り離して管理する必要がある。

出典: Jamestown Foundation（2026-10-09）

正式な動員は政治的な代償が大きいため回避され、地域ごとの募集枠と徴兵の厳格な運用に置き換わっている。責任の所在を地方へ分散させながら兵力を補充する方式で、戦争の継続性は高いが、負担は増税と料金という形で社会に出てくる。

5月下旬、トルコは2011年以降の内戦開始後はじめて、リビアの対立する両陣営の軍人を集めた合同訓練を実施した。国連が承認する国民統一政府（GNU）と、東部を支配するハフタル氏のリビア国民軍（LNA）の兵士が、ひとつのリビア国旗の下で参加した。トルコはミスラタ港の海軍拠点、アル・ワティーヤ空軍基地からの運用、Bayraktar TB2 の配備に加え、2019年の覚書に基づく排他的経済水域の設定でギリシャ・キプロス・エジプトと対立している。

一方の陣営を支える介入から、双方に足場を持つ仲介者への転換は、将来の政治決着と安全保障体制に対する影響力を高める狙いがある。地中海東部のエネルギーと海上輸送をめぐる権益争いが、軍事協定と海洋境界の形で固定されつつある。

日本への距離は遠いが、含意は欧州の天然ガス供給と地中海航路の安定という形で返ってくる。北アフリカが不安定化すれば欧州のエネルギー価格と海運保険料に波及し、日本の調達コストにも遅れて効く。この種の地域再編は、サプライチェーンの地政学リスク評価で「中東」とは別枠で見ておく必要がある。

6. エチオピアがエリトリアの「全面侵攻」を非難

出典: OODA Loop（2026-10-09）

1. ゼロトラストの穴は「トークン発行後」にある

出典: CrowdStrike Blog（2026-10-10）

アクセス判断の正しさは、判断の材料が変わらない前提で成り立っている。CrowdStrike は、退職やエージェントの異常動作で即時に権限を剥奪したい場合、トークン発行時の前提が有効期限内に変わった場合、権限の範囲が発行後に変わった場合の3つを挙げる。対策として考えられるのは短命トークンか毎回の再検証だが、1日に平均1,000回使うトークンを毎回検証するとIdPへの負荷が1,000倍になり現実的でない。24時間から1時間へ短縮しても負荷は24倍で、利用者体験は確実に落ちる。さらに判断材料は分散している。アカウント情報はIdPやオンプレのディレクトリ、端末の侵害情報はXDR、構成遵守はMDM、業務の変化は ServiceNow や Jira、休職は人事システム、当番表は PagerDuty にある。

評価として、これは製品の不足ではなく設計の空白である。アクセス先のサービス側でミリ秒単位に評価するには、分散した状態を集約する層が必要になる。

国内でもゼロトラストの導入は認証の強化までで止まりやすい。今日できるのは、退職・休職・端末隔離といったイベントが発生したときにセッションとトークンが実際に失効するかを机上で追い、失効しない経路を一覧にすることである。

2. Copilot が読める範囲を先に絞る — SaaS上のデータ分類とラベル付与

出典: CrowdStrike Blog（2026-10-10）

Falcon Data Security for SaaS が一般提供になった。SharePoint・OneDrive・Copilot を対象に、ファイルのアクセス・変更・共有の時点で機微データを継続的に検出・分類する。既定のパターンで個人情報（PII）・医療情報（PHI）・決済カードデータを識別し、独自パターンも追加できる。分類結果にもとづいて Microsoft の秘密度ラベルを自動付与し、暗号化・アクセス制御・共有制限・透かしに加えてAIからの参照制限を効かせる。適用前のシミュレーションも可能である。匿名リンクでの公開、外部共有、過度に広いアクセス権といった露出の文脈と合わせて優先度を付け、結果は Next-Gen SIEM へ送られる。機微データには Falcon Privileged Access と連携した期限付きアクセスを割り当てられる。
