出典: iThome Security（2026-10-23）

Sophos は2025年8月から2026年8月の侵入群を調査し、中国背景とみられる新クラスタを BRONZE SANDCASTLE と命名した。被害は台湾・フィリピン・アフガニスタン・ナミビアに分布し、韓国にも存在し得る。手口は正規実行ファイルによる悪性 DLL のサイドロードで、Sandboxie のほか Java・Krita・LINE の実行ファイルが使われた。DLL は暗号化された config.ini を復号してメモリ上で実行するため静的検知にかかりにくい。ペイロードは Metasploit 由来に似るが API 解決が異なり COFFLoader の要素を含む改造品で、1.1.7 は GitHub から暗号化設定を取得しようとした。C2 には file.io・gofile.io・Ably も使われた。侵入後は vssadmin.exe のシャドウコピー経由で Active Directory の ntds.dit を複製していた。

標的の分布と活動が UTC+8 の業務時間帯に集中する点が帰属判断の根拠である。BRONZE PRESIDENT や BRONZE ATLAS との接続は確立できていない。
