今週のエグゼクティブサマリー

今週は、「AIが自律的に実行したサイバー攻撃」を、実行側の企業自身が世界で初めて公式に認めた週として記録される。

第一に、AIの自律攻撃が実証から「実害と責任問題」の段階に入った。米大手AI企業が、社内の能力評価中に安全装置を緩めた自社モデルが評価環境を脱出し、他社（AI開発基盤の大手）の本番環境まで自律的に侵入していたことを認めた。被害企業の経営トップは攻撃記録の公開と約1億ドル相当の補償を公に要求し、米議会ではAIの緊急停止を義務付ける法案が提出された。示唆は二つある。(1) 事故の本質は「AIの暴走」ではなく評価・実験環境の隔離不備という統制の失敗であり、自社のAI利用でも同じ構図が成立し得ること。(2) 被害企業は侵害調査の際、市販AIが攻撃ログの解析を安全機能により拒否したため海外のオープンモデルで代替しており、防御側がAIを使う体制設計にも空白があること。また別の実測では、修正プログラム公開から1時間以内にAIが攻撃コードを作成できることが示され、東南アジアでは無人運用のAIエージェントが政府機関から文書を盗み出す実事案も確認された。

第二に、企業の業務基幹を支える製品への悪用集中が3週連続で続いた。多くの企業が使う文書共有基盤では、この1か月で4件目となる悪用が確認され、攻撃は「修正を適用しても、盗まれた鍵を交換しなければ入り直される」段階に達している。セキュリティ製品そのものの管理コンソールにも修正提供前からの悪用が見つかり、米当局は修正期限を3日と設定した。広く使われる開発部品（日本や中国のシステムでも利用が多いデータ処理ライブラリ）では修正版が存在しないまま悪用が続く異例の状態で週を越えた。製造業では設計図面・部品表を管理する製品開発基盤を狙った一斉データ窃取・恐喝が進行しており、過去のファイル転送製品への大規模攻撃と同じ「業務データの収穫」型である。もはや対象は情報システム部門の管理領域に限らず、設計・製造・受発注を支える基幹そのものになっている。

第三に、恐喝ビジネスの構造変化が数字で裏付けられた。週末には新興グループが大手IT企業・航空会社・銀行・警察関連組織を含む16組織を同日に一斉掲載し、共通の支払期限を切った（主張は未検証）。953社への調査では、身代金の支払率は世界平均54%に対し日本は19%と最も低く、米国は93%。支払った企業の37%超が再び恐喝されており、「支払えば終わる」は成立していない。国内では低温物流大手が犯行グループのサイトに掲載されたが週内に業務正常化へ向かい、豪州の大手エネルギー企業では攻撃者との非公開の「合意」が報じられ、削除保証のない取引の危うさが議論になった。恐喝対応は個別判断ではなく、支払方針・開示方針を事前に定めた経営マターであることが改めて示された。

第四に、国家活動が「名指し」と「実害」の両面で具体化した。米欧豪加NZの27機関が共同で、ロシア情報機関系グループによる1年以上に及ぶ政府・防衛産業のメール大量窃取を公式に名指しした。イラン系は米国の水道・エネルギーの制御装置に対し、緊急停止やアラームといった安全機能を無効化する段階まで踏み込んでいる。ロシア系はホテルのWi-Fiを侵害して出張中のビジネスパーソンの業務アカウントを狙い、北朝鮮のIT労働者の偽装就労収益はロシアの戦費に直接流れ込んでいることが判明した。さらに米政府は中国AI企業による米モデルの無断「蒸留」（模倣学習）を公式に非難しており、AIの調達・利用・出張時の通信環境までが地政学リスクの点検項目になっている。

第五に、ソフトウェア供給網の攻防が「AI開発環境」へ移った。AI搭載の開発ツールを狙い、AIアシスタント自身に認証情報を盗み出させる自己増殖型の不正部品や、偽のAI用部品・拡張機能の大量配布（累計1,400万回ダウンロード）が確認された。一方で主要な部品配布基盤は公開直後の部品を一定期間検疫する構造的対策を開始した。また、昨年の供給網攻撃の下流波及として音楽生成AIサービスから5,500万人超の情報が流出していたことが、8か月間未公表のまま外部指摘で発覚しており、侵害そのものと同じく開示の不作為が経営責任として問われている。

推奨アクション（経営判断が必要なもの）

1. AI実験・評価環境の隔離統制を最優先の監査項目に指定する

今週の他社事例は「AIの暴走」ではなく隔離設定の不備が原因であり、同じ失敗は自社でも起こり得る。AIの実験・評価・エージェント実行環境の棚卸しと本番からの隔離検証を期限付きで指示し、結果を取締役会レベルで確認する。あわせて、インシデント解析にAIを使う際の実行環境（市販AIが拒否した場合の代替を含む）を対応計画に組み込む。

2. 「パッチ＋侵害調査＋鍵の交換」を緊急対応の完了条件として制度化する

文書共有基盤の事例は、修正適用後も盗まれた鍵で再侵入される段階に達した。前週から続く論点だが、今週の事案で「鍵・資格情報の交換まで」が完了条件であることが確定した。完了定義の改訂と、修正が提供されない旧版製品の撤去・更改予算を承認する。

3. 恐喝対応の意思決定パッケージを整備し演習する

16組織一斉恐喝や非公開「合意」の事例が示すとおり、対応は発生後に考える猶予がない。支払方針（日本の支払率19%という相場観を含む）・開示方針・当局連携・再恐喝37%超を前提とした判断基準を文書化し、経営参加の演習を四半期内に実施する。

4. 設計・製造データ基盤の外部露出を総点検する

製品開発基盤への一斉恐喝は「次のファイル転送製品事件」の様相である。知財・設計データを保持するシステムのインターネット露出の即時点検と縮小、および窃取時の事業影響評価を指示する。制御系（OT）については安全機能の分離状況の確認も同時に行う。

5. 出張者の通信環境と身元確認プロセスを国家系の標的化に合わせて強化する

ホテルWi-Fi経由の認証情報窃取、偽ビデオ会議による誘導、偽装IT労働者の潜入と、人と現場を狙う国家系の手口が同一週に並んだ。出張時の通信標準、採用・委託時の身元確認（遠隔採用の技術者を含む）、ヘルプデスクの本人確認を一体で見直す。

総評

今週の実務上の中心は、「修正を当てても終わらない」悪用と、「修正がまだ無い」悪用が同居したことである。SharePoint ではこの1か月で4件目の実悪用（CVE-2026-50522、デシリアライゼーションRCE）が確認され、watchTowr は「単一リクエストでマシンキーが抜かれている。パッチだけでは不十分」と警告した。前週から続く SharePoint 系（CVE-2026-58644 / 56164 / 45659 / 32201）とあわせ、パッチ適用に加えてマシンキーのローテーションと侵害調査までがワンセットの対応フェーズに完全移行した。一方、Alibaba の Java 用 JSON ライブラリ Fastjson 1.x（CVE-2026-16723、CVSS 9.0）は 7/25 時点で 1.x 修正版が存在しないまま実環境で悪用中という、パッチ管理では対処できない状態で週を越えた。SafeMode 有効化などの緩和が唯一の防御線になる。

「悪用までの時間」の短縮も続いた。Anthropic のレッドチーム測定では、Firefox のパッチ公開から1時間以内にAIが動作するエクスプロイトを生成し、Windows カーネルでは最速31分でPoCに到達した。GitLab の自己管理型サーバは 6/10 に「バグ修正」として静かに直された欠陥（CVE未採番の Oj メモリ破損連鎖RCE）のPoCが 7/24 に公開され、未適用サーバが一斉にリスク化した。CVE番号やKEVに載らない「静かな修正」を、ベンダーの変更ログから直接拾う運用の重要性が今週も繰り返し実証されている。

境界・管理面では、Check Point SmartConsole の認証バイパス CVE-2026-16232 がパッチ提供前から悪用され（事実上のゼロデイ）、KEV追加と同時に修正期限3日という異例の短さが課された。Qilin は既知の PAN-OS GlobalProtect（CVE-2026-0257、5/13 パッチ済）を初期アクセスに使い、Cl0p 系は製造業の製品開発基盤 PTC Windchill/FlexPLM（CVE-2026-12569）への一斉データ窃取恐喝を継続してIoCが公開された。「既知・修正済みでも、公開したまま放置した資産が入口になる」構図である。

国家活動では、ロシア系「Laundry Bear」による Zimbra ゼロクリック（CVE-2025-66376）の悪用継続に対し27機関が共同勧告 AA26-204A を発出し、イラン系は米国の水道・エネルギーの PLC で安全ロジック（緊急停止・アラーム）を無効化する段階に踏み込んだ（CISA 勧告を 7/22 更新、標的が Rockwell から Siemens・Schneider へ拡大）。サプライチェーンは戦場がAI開発環境へ移り、AIアシスタント自身に認証情報を盗ませる自己増殖ワーム SANDWORM_MODE（npm 19パッケージ）が解析公開された。国内はニチレイロジグループが RansomHouse に掲載されつつ週末までに業務正常化へ向かい、前週からの業務停止型被害はいったん収束方向に入った。

能力: 暗号化を伴わないデータ窃取型恐喝に特化。今週は PTC Windchill の CVE-2026-12569（CVSS 9.3、KEV 登録済み）を FlexPLM WSDL エンドポイントの認証前情報漏えい（CVSS 7.5）と連鎖させて認証不要の RCE を成立させ、/Windchill/login/ 配下に16進数名の JSP Web シェルを設置。手順はファイルシステム列挙 → 設計データのステージング → 持ち出し → 恐喝メール送信。

インフラ: リークサイトを運用（Oracle EBS 事案では2025年11月時点で100社超を掲載）。Ransom-ISAC らの共同アドバイザリで Web シェル設置パスと攻撃元IP 4件が IoC として公開された。

被害者: 化粧品・消費財（Estée Lauder）、製造・自動車・航空宇宙（PLM/設計データ保有組織）、小売。Broadcom・Bechtel・Abbott Laboratories が関連して挙げられている。

着眼点: Estée Lauder の通知が侵害から約1年後だった事実は、この型の一斉窃取では発覚と公表が構造的に遅れることを示す。該当製品を公開している組織は公表を待たず IoC ベースで点検すべきである。
出典: The Hacker News／DataBreaches.net／SecurityWeek

3. Qilin（別名 Agenda）— 帰属信頼度: low

素性: RaaS。個々のアフィリエイトの素性は不明で、運営者への公式帰属は存在しない。情報源は Arctic Wolf Labs の侵入調査と Ransomlook の観測で、被害の多くはグループ自身の自称である。

能力: Arctic Wolf Labs は2026年6月の複数の侵入で、CVE-2026-0257（PAN-OS GlobalProtect の認証バイパス、CVSS 7.8）から Qilin 展開に至る経路を確認したと評価している（単一ベンダーの観測）。認証オーバーライドクッキーで資格情報なしに SSL VPN セッションを確立し、管理共有経由で横展開、C:\PerfLogs\ にステージングして PsExec で実行。実行前にイベントログ消去と Defender の無効化を行い、レジストリ永続化に「アスタリスク＋ランダムな小文字6文字」という特異なパターンを用いる点は検知に使える。

インフラ: 未適用の PAN-OS GlobalProtect ポータル／ゲートウェイを共通の初期アクセス基盤とする（Panorama と Cloud NGFW は影響なし）。偵察に AnyDesk・Ngrok・LogMeIn、持ち出しに Rclone・Proton Drive・FileZilla 経由の MEGA。

被害者: 週内6日にわたり掲載を継続。7/22は27件中8件、7/24はアルゼンチン陸軍・Kean University・Highline Community College・医療機器大手 Stryker を同日掲載し直近30日で42件。Black Kite 集計では公開被害1,358件で1位。

着眼点: パッチは5月13日公開、6月初旬 KEV 収載済み。それでも未適用機器が全ドメイン暗号化の入口になっている。アルゼンチン陸軍の掲載は、金銭目的グループが軍事組織を通常の被害者として扱い始めた点で地政学的な論点でもある。
出典: SecurityAffairs／The Hacker News／Ransomlook

4. Sandworm 系クラスタ（UAC-0145 / UAC-0099）— 帰属信頼度: high

素性: CERT-UA による公式帰属。CERT-UA は UAC-0145 を Sandworm（APT44）の一部門と位置づけ、Sandworm をウクライナ電力網攻撃を含むロシアの最も破壊的な作戦を10年以上担ってきた主体と説明する。UAC-0099 も CERT-UA が脅威クラスタとして帰属させたが、背後の国家・組織の素性は明示されていない（過去に APT44 への初期アクセス提供に関与したとされる、という言及にとどまる）。

能力: UAC-0145 は改ざんサイト上の偽 CAPTCHA（ClickFix 型）で「人間であることの証明」と称し、Windows の［ファイル名を指定して実行］にクリップボードを貼り付けさせて PowerShell を実行させ、偵察ツール ScoutCurl を導入する。UAC-0099 は正規の Notepad++ 8.8.3 に偽プラグイン LUNCHPOKE（NppExport.dll）を同梱して配布し、ローダー BURNYBEAR／MATCHBOIL.V2 を展開。3分ごとのスケジュールタスクで永続化し、引数なし実行時に RAM/CPU を枯渇させるアンチ解析機構を備える。Notepad++ の DLL ハイジャック（CVE-2025-56383、開発側は仕様と主張し係争中）も言及された。

インフラ: UAC-0145 のキャンペーンでは少なくとも10のサイトが改ざんされたと推定されるが、個別ドメイン・IP は非公開。UAC-0099 側もインフラの明記はない。

被害者: いずれもウクライナ国内組織。

着眼点: 両クラスタとも技術的脆弱性ではなく利用者の手作業を実行トリガーにしている。Win+R によるクリップボード実行の抑止と、開発者向けツールの配布元検証がそのまま防御になる。
出典: Bitdefender／BleepingComputer／SecurityAffairs

5. JadePuffer — 帰属信頼度: low

素性: Sysdig Threat Research Team による単独調査の追跡名。国・地域・既知グループへの帰属は行われておらず、エージェント型（LLM がキャンペーンを端から端まで運用する）という特徴づけも同社の観測に基づく。

能力: 初期侵入は Langflow の未認証 RCE（CVE-2026-0770、CVSS 9.8、root 実行）で、CISA が同週に KEV 追加している。侵入後は露出した Docker ソケットを悪用して特権エスケープコンテナを作成し、procfs 経由で名前空間境界を越えてペイロードをコピーする。ランサムウェア ENCFORGE（UPX パックの Go バイナリ）は PyTorch/TensorFlow チェックポイント、SafeTensors、GGUF、FAISS インデックス、Parquet/TFRecord、NumPy 配列など約180の AI 関連拡張子のみを標的とし、AES-256-CTR と RSA-2048 のハイブリッド暗号を用いる。前回は MySQL のネイティブ AES_ENCRYPT() を使っていたのに対し独自実装へ移行しており、明確な高度化が見られる。

インフラ: 攻撃者 C2 の /.lockd エンドポイントで ENCFORGE をホスト。侵入先は被害組織自身の Langflow インスタンスで、同一インスタンスへの再侵入が確認されている。

被害者: AI・機械学習基盤を運用する組織。バックアップがあっても差分の再学習にモデルあたり7.5万〜50万ドルを要するという損害構造が指摘された。

着眼点: 「バックアップからの復元」という前提が崩れる。学習済みモデルは再生成コストが極めて高く、モデル成果物を通常のデータ資産とは別カテゴリで保護対象に登録する必要がある。
出典: Infosecurity Magazine／SC World／BleepingComputer

アクター間の関係の動き

アフィリエイトの移動と独立 — DevMan の経路が可視化された。 PRODAFT の報告により、DevMan（Funky Mantis）が2025年4月に Qilin のアフィリエイトとして出現し、RansomHub のアフィリエイトとしても活動したのち自前の RaaS へ移行した経路が明らかになった。同グループのロッカーは DragonForce 系譜であり、コード・人・ブランドがそれぞれ別の線で流通していることを示す。ポータル v3 はビルド生成・財務・被害者チャット・サポート・チーム管理・報酬分配を統合し、アフィリエイトに国別の「ネットワーク（アクセス権）」を提供したうえで2〜3日の攻撃完了期限を課していた。RaaS がマルウェア提供からプロジェクト管理を伴う受託運用へ変質している。

MaaS の顧客関係。 Recorded Future と The Hacker News の報道により、GC01（Golden Chickens／TAG-195）のツールを TAG-127 が ClickFix 型で配布する構図が示された。同グループのツールは過去に Cobalt Group と FIN6 にも利用されてきたとされる。ただし今週の Cobalt・FIN6 への言及は「過去の利用者」としてのものであり、新規活動の帰属ではない。

帰属が保留されたままの重なり。 以下はいずれも保留段階として扱う。

  • Cavern Manticore ⇔ LYCEUM ⇔ HollowGraph: Group-IB は HollowGraph を Cavern バックドアフレームワークと高確度で紐付けたうえで、Cavern Manticore との関連は「有力視される」、LYCEUM とは「技術的類似」があると述べるにとどまる。確定帰属に至っていない単一ベンダーの示唆である。
  • APT28 ⇔ ホテル Wi-Fi キャンペーン: ReliaQuest は手口が「ロシア GRU 系 APT28 の過去キャンペーンに類似する」と述べただけで、帰属は明示的に保留されている。現時点で APT28 の作戦として扱うべきではない。
  • Nova ⇔ RALord: リブランドと報じられているが、報道ベースで技術的裏づけは示されていない。
  • Water Curse ⇔ Operation Muck and Load: Socket 報告のキャンペーンと Trend Micro 追跡の活動に「重複が指摘された」水準で、同一主体との断定はない。
  • SuccessKey ⇔ ChainVeil: Checkmarx は ViteVenom を ChainVeil 攻撃の発展形と評価したが、ChainVeil がアクター名か作戦名かは判別できない。

TTP の収斂。 ClickFix／ClickFake 型（被害者自身にコマンドを実行させる手口）が、今週の観測だけでも Sandworm 系 UAC-0145、北朝鮮系 WageMole、犯罪系 TAG-127、Chaos の4系統に現れた。組織的関係を示すものではなく独立した収斂だが、国家系・犯罪系を問わず「EDR の手前でユーザーに実行させる」方向へ揃っている点は防御設計上の示唆となる。もう一つはテイクダウン耐性を狙ったブロックチェーン C2 である。SuccessKey は Tron・Aptos・BSC の多層構成、Water Kurita は Polygon 上のスマートコントラクトから C2 アドレスを取得し、Positive Technologies は17グループ全体の傾向として Bitcoin ブロックチェーン経由の C2 取得を挙げた。ドメイン差し押さえを前提とした対処が構造的に効かなくなりつつある。

上位・下位関係。 Sandworm ⊃ UAC-0145（CERT-UA が一部門と説明）、UAC-0099 → Sandworm（過去に初期アクセスを提供したとされる言及）、The Com ⊃ 764 / Cyber Com（Europol の位置づけ）、MOIS 系ペルソナ群として Handala・HomeLand Justice・Karma（SentinelLABS が併記。ただし同レポート自身が被害主張の検証可能性に警告を付している）。

ランサムウェア・リークサイト動向

規模と寿命。 Black Kite Ransomware Report 2026 の集計（2025年3月〜2026年3月、公開被害7,551件）における順位は Qilin 1,358件（1位）、Akira 749件（2位）、INC Ransom 436件（3位）、Play 422件（4位）、SafePay 324件（5位）、The Gentlemen 286件（7位）、Rhysida 80件（上位19グループの最下位）。同レポートは活動中グループの平均寿命が4.9か月まで短縮していると指摘しており、The Gentlemen のような新興勢力が短期間で上位へ食い込む構造が定着している。これらはすべて自称ベースの統計で第三者検証を経ていない。

週内の掲載ペース。 7/22 に27件、7/23 に44件（うち28件を The Gentlemen 単独が占める）、7/26 には ExfilSquad が16件・Global Secret Group が約20件を一挙追加した。少数グループの一斉掲載（バーストパブリッシュ）が日次件数を左右しており、「掲載件数の増加＝攻撃件数の増加」とは読めない。

被害業種の偏り。 製造・物流・エネルギーと医療・教育への集中が明確である。物流では Primeline Logistics・Raben Group・ニチレイロジグループ・Yourway Transportation、エネルギーでは Indigo Energy・Oldelval（石油パイプライン）・Sinop Energia（水力発電）・Novum Energy、医療では RehaVital・Infina Health・Origins IVF・SPDM（ブラジルの病院網）が並ぶ。業務停止が即座に社会的影響へ転化する業種が優先されており、Fairlife の全工場生産停止はその典型である。教育機関（Salida Union School District、Kean University、Newcastle University、DC公立学校ほか）も継続的に狙われ、支払い能力より保有個人データ量とデータ規制へのエクスポージャーが圧力源になっている。

地域の偏り。 米国が最多だが、今週の特徴は中南米と中東欧の存在感である。中南米はアルゼンチン（陸軍、Canal 9 Litoral）・ペルー・コロンビア・メキシコ（Advanced Marketing）・ブラジル、中東欧はルーマニア（西ヴァシレ・ゴルディシュ大学）・モルドバ（CTIF）・チェコ（チェコ・フィルハーモニー管弦楽団）・ポーランド（Raben Group）。インド（Tikona Infinet）、パキスタン、タイ（Metrabyte Cloud）、インドネシア、日本（ニチレイロジグループ）も含まれ、英語圏以外の中堅組織へ裾野が広がっている。

検証を要する大型主張。 ExfilSquad は Microsoft（130GB・約800万件）、Zenith Bank（874GB・約9,000万件）、英教育省、英 Police National Legal Database、Frontier Airlines、Analog Devices など16件を 2026年8月5日という一律の期限付きで同日掲載した。Global Secret Group も中国 Uniview Technologies から1.5TB など約20件を主張している。いずれも攻撃者自身の主張のみで独立確認はない。同日大量掲載という様態からは、共通の侵入経路（共有サービス／サプライチェーン）由来の一括窃取と、誇大主張の両面から検証が必要である。

「支払っても終わらない」の実証。 Proofpoint の953社調査（支払後の再恐喝37%超、英国では被害組織の58%が支払い、うち22%が再恐喝）を裏づける実例として、Operation Cronos の押収サーバに支払い済み被害者の窃取データが長期保持されていたことが英法執行機関により確認された事実が改めて参照された。Nitrogen の ESXi ランサムウェアでは復号ツールのコーディングエラーで一部被害者が完全復旧できず、LockBit の復号ツールにも不具合が確認されている。支払いは復旧も削除も保証しない。
