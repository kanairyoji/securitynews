大項目1: 国家系の攻撃が「能力の証明」から実際の停止に変わった

何が起きたか。 8/23、イラン系とみられるアクターが英国の小規模発電所を4日間停止させたと報じられた。同時期に米12州の下水処理場で溢水と水圧低下が起きている。8/19 には米5機関が、露出した産業用制御機器へのAI生成スクリプトによる侵入を連名で警告した。現段階は設定を書き換える前の「位置取り」で、第三者の保守業者が使う遠隔メンテナンス経路が盲点だと名指しされている。目的は破壊ではなく誇示と評価される。

日本への影響。 対象の制御機器は国内の製造業・上下水道で標準的に使われる。危ないのは自社の回線ではなく、保守委託先が自分の都合で維持する遠隔接続である。

経営の問い。 自社の制御系に外部から入れる経路を、委託先分まで含めて誰が把握しているか。1週間止まったときの損失額と代替手段を事業部門と合意できているか。

→ 詳細は事例レポート「英発電所の停止」「米上下水道への露出PLC侵入」を参照。

大項目2: 製造業の設計データが恐喝の主戦場になった

何が起きたか。 恐喝集団が、公開された製品ライフサイクル管理基盤の欠陥を突き、被害主張を週初の43社から約50社へ広げた。名が挙がったのは大手石油会社（89GBの図面・点検報告）、重電、医療機器、決済、台湾の光学部品大手である。認証情報を復号する専用ツールを仕込み、全量を持ち出す作りだった。別の集団は自動車メーカーの設計アーカイブ5TB超の放出を主張する。恐喝の対象が設計情報へ移った週である。

日本への影響。 この製品は航空宇宙・防衛・自動車・重機で3万社超が使う。国内では農業用温室メーカーが8/1の感染で全システムを止めたまま受注・出荷に影響が続く。国内調査でランサムの平均業務停止は10.2日→36.0日、平均被害額は3.48億円へ上がった。

経営の問い。 図面・仕様・治具データが漏れたとき、取引先との契約上どこまで賠償と通知の義務を負うか。36日止まる前提の代替生産計画はあるか。

→ 詳細は事例レポート「Clop による PTC Windchill 悪用」「大仙の全システム遮断」を参照。

大項目3: 修正が出てから悪用されるまでが2日を切った

何が起きたか。 大手調査会社の年次報告で、公開された実証コードの88%が48時間以内に悪用され、中国系は24時間以内に動くと示された。今週の実例は、AI基盤ソフトが番号採番の数時間後、開発基盤が修正2日後、メール基盤が修正28日後に攻撃を受けている。月例パッチは415件・最重要62件と過去最大級で、AIによる欠陥発見の増加が修正側の能力を超え始め、ある大手製品は更新版の提供を延期した。米当局は是正期限を一律から資産の性質別（3日・14日・60日）へ切り替えた。

日本への影響。 「月次のパッチ会議で決める」運用は、この速度に構造的に間に合わない。修正版の適用は終結の根拠にならず、適用前に侵入されていなかったかの確認まで含めて完了条件になる。

経営の問い。 緊急パッチを業務停止付きで当てる判断を、誰が何時間以内に下せる決裁になっているか。その権限は CISO に委譲されているか、毎回事業部門の合意が要るか。

大項目4: 侵害の入口は「委託先とその先」に移った

何が起きたか。 国内大手ホスティング事業者は、顧客環境583アカウントへの不正ログインに加え、調査の過程で自社の販売管理システムへの侵入が判明し、最大136万会員の契約情報が対象になりうると公表した。同じ週に、予約・顧客管理SaaSへの不正アクセス、業務メールを6年間外部転送されていた事案、委託先の公開領域からの患者情報流出が国内で並ぶ。海外では米金融大手が「取引先のさらに先」の事故と説明し、ポーランドの医療ソフト1社の侵害が最大1,900万人・1.2万医療機関に及んだ。開発側でも累計2.45億DLの部品が乗っ取られ、ビルドしただけで開発端末とCI環境が感染した。

日本への影響。 統制の及ばない場所で起きた事故が、自社の届出義務と説明責任を発火させる構図が定着した。

経営の問い。 預けているデータの一覧と、委託先が侵害されたときの通知窓口・判断手順があるか。契約は「先方の問題」で終わる書き方になっていないか。

→ 詳細は事例レポート「さくらインターネットへの不正アクセス」「Rust クレート arrayref の汚染」を参照。

大項目5: AIエージェントは権限を持つ「主体」として統制が要る

何が起きたか。 英当局はエージェント型AIの運用に、自律度に応じた封じ込め、エージェントごとの識別子と短寿命の資格情報、名前付きの責任者、緊急停止権限を求める暫定指針を出した。大手ベンダーは実行環境を7層で隔離する設計と、外部ツール呼び出しを実行前に止める製品を出した。一方で、暗号化した命令をモデル自身に復号させて安全装置を素通りさせ、対話履歴を外部へ送出させる手法が実証され、AIエージェント製品自体にも最高評点の欠陥が並んだ。

日本への影響。 国内でも1社あたりの導入体数は平均5から13へ増えた。権限設計を後追いにすると、人間より広い権限を持ちながら監査証跡には残らない主体が増える。

経営の問い。 自社が動かしているエージェントの一覧と、責任者・緊急停止権限を持つ者が決まっているか。その操作は人間と同じ監査の対象になっているか。

→ 追跡中の特集「誰の権限でエージェントは動くのか」も参照。

総評

今週の実務上の中心は、「修正が出てから悪用されるまでの距離が、同じ週に3つの実例で測られた」ことである。Zimbra は修正28日後（CVE-2026-73570、CERT Polska が観測）、GitLab は修正2日後（CVE-2026-19478、ハニーポットで試行）、MLflow は CVE 採番から数時間後（CVE-2026-64849、クラウドメタデータ経由で IAM 認証情報が窃取）に攻撃を受けた。CrowdStrike の 2026 Threat Hunting Report が「公開 PoC の 88% が48時間以内に悪用、中国系は24時間以内」と出したのと同じ週に、その数字が実測で裏付けられた形である。いずれも自社管理のオンプレ／自前ホスティング基盤であり、修正の入手ではなく適用の速度が勝負どころになる。

悪用確認済みの本命は Cl0p × PTC Windchill/FlexPLM（CVE-2026-12569）である。8/17 の43組織掲載から週を通じて拡大し、8/22 時点で Shell（89GB の図面・点検報告）、Philips、GE、Fiserv、台湾の大立光など約50社の主張に達した。攻撃者はキーストアの認証情報を復号する専用ウェブシェルを設置しており、部分窃取ではなく全量持ち出しを前提とした作りである。PTC 製品は航空宇宙・防衛・自動車・重機で3万社超が使う。国内製造業の Windchill 利用組織はインターネット公開の有無を即時に確認すること。→ 詳細は事例レポート「Clop による PTC Windchill 悪用」を参照。

OT では、8/19 に NSA・CISA・FBI・エネルギー省・EPA の5機関が合同勧告 AA26-231A を出した。攻撃者は Censys/ZoomEye で露出した Siemens S7 シリーズ PLC を探し、AI で生成した攻撃スクリプトと、オープンソースの産業自動化ライブラリで作った「正規の OT 監視ツールに偽装したカスタムツール」で、S7comm 経由の読み書きを行っている。現段階は書き込み前の位置取りで、勧告は第三者の保守業者が使う遠隔メンテナンス経路を盲点と明示した。標的は「Siemens 製品に限らない」と書かれている。8/23 にはイラン系とみられるアクターによる英発電所の4日間停止と、米12州の下水処理場での溢水・水圧低下が報じられ、同じ系統の活動が実被害に至った例として並んだ。→ 事例レポート「英発電所の停止」「米上下水道への露出PLC侵入」。

サプライチェーンでは Rust の crates.io が破られた。 累計2億4,538万ダウンロードの arrayref ほか2クレートがメンテナ乗っ取りで汚染され、タイポスクワットした proc-macro1 への依存が1行足され、cargo build するだけで開発端末と CI 上でペイロードが実行された。攻撃者は悪性版公開の24秒後に正規の旧版5つを yank し、cargo の「取り下げ版から更新せよ」という警告を悪性版への誘導に転用した。露出86〜107分、検知から削除まで134分。Wiz は北朝鮮 Sapphire Sleet のインフラと重複すると評価している。npm 側では Shai-Hulud 第4波が keyv（週1億2,700万DL）のメンテナ乗っ取りから有効な provenance 付きで1,280パッケージに広がっており、署名基盤が正しく動いたまま攻撃が成立している。→ 事例レポート「Rust クレート arrayref の汚染」「npm ワーム ChainDrop」。

国内では、さくらインターネットの事案が週内で桁が変わった。 8/19 の「レンタルサーバ顧客環境583アカウントへの不正ログイン」から、8/20 には販売管理システム侵入により最大136万会員の契約情報が対象になりうると拡大した。ほかに EPARK「PeakManager」（約3,300万レコード）、藤倉コンポジットの Exchange Online 全受信メール外部転送（約6年間）、旭化成セラピューティクスの委託先公開領域からの流出、NEC UNIVERGE IX ルータの認証欠如（CVE-2026-16876、9.3）が並んだ。→ 事例レポート「さくらインターネットへの不正アクセス」「藤倉コンポジットの全受信メール外部転送」「EPARK PeakManager」。

未修正のまま週を越えたのは Microsoft Defender の「ShieldBreak」（CVE-2026-69414）である。6月修正の Rogue Planet（CVE-2026-50656）の迂回で、8/23 時点でパッチはない（経緯は後述）。

トレンド1: AI は攻撃の「一工程」として実装フェーズに入った

今週は、AI が攻撃に使われた事例が例外報告ではなく作業工程の記述として並んだ週である。Cisco Talos は中国語話者の犯罪集団 UAT-10147 が、エクスプロイトの反復改良・トラブルシュート・侵入後自動化・検証・手順書生成にエージェント型 AI を使い、新実装 SPECTRE（BYOVD による EDR 無効化・Linux ルートキット）の開発にも AI 支援の痕跡があると報告した。米5機関の合同勧告 AA26-231A は、露出した Siemens S7 PLC を AI 生成スクリプトで探索・侵入する活動を能動的脅威と断じ、Bitdefender は SilkParasite が AI 開発ツールで新種 RAT 5種を含む7ファミリを短期量産したと報告した。

決定的なのは価格である。犯罪向け AI サービス Kriminal は、Grok や Claude をジェイルブレイク用プロンプトで包んで月12.99ドルから再販するだけで独自モデルを持たない（ThreatDown）。犯罪向け C2 の RedC2 4.0（99.99ドル）には LLM エージェント「Red Agent」が同梱され始めた。攻撃側の AI は「フロンティアモデルへのアクセス」ではなくハーネスとワークフローであり、能力はすでにコモディティ化している。防御側の想定を「高度なアクターだけが使う」に置くと外れる。

トレンド2: 発見が修正を追い越し、パッチ運用の設計が壊れ始めた

AI による脆弱性発見の増加が、修正・配布側の処理能力を超えた兆候が今週複数出た。Theori は AI ツール Xint Code で Linux 暗号サブシステムを1時間スキャンして root 奪取バグ Copy Fail（CVE-2026-31431）を発見し、700バイト強の Python で 2017年以降の主要ディストリに効くと示した。Microsoft は AI が見つける脆弱性の対応で Exchange Server SE CU1 を無期延期し、Cisco・Microsoft はいずれも修正量の増加理由に AI 由来の発見を挙げた。8月 Patch Tuesday は 415 CVE・Critical 62件に膨らんでいる。

出口側では、CrowdStrike が公開 PoC の 88%が48時間以内に悪用され中国系は24時間以内と数値化した。入口が増え出口が速い以上、深刻度スコア順のパッチ会議は構造的に間に合わない。CISA は拘束的運用指令 BOD 26-04 で是正期限を一律15/25日から資産の性質別（3/14/60日）へ切り替え、露出・KEV 収載・自動化可能性・掌握度で優先順位を決める枠組みに移した。責任論も動いており、CSIS は「AI が欠陥を安価に見つけられる以上、ソフトウェアの as-is 免責は成り立たない」と論じている。

トレンド3: 防御の重心が「モデル」から「ハーネス」へ移った

エージェント型 AI の防御論が、今週まとまった形に収束した。英 NCSC の暫定指針は、必要な自律度の見極め → 脅威モデリング → 既定拒否のネットワークと許可リストによるサンドボックス → エージェントごとの識別子と短寿命クレデンシャル → ログ・監視 → 緊急停止、という順序を示した。CrowdStrike は自社の攻撃エージェント実行環境を 7層（ネットワーク分離・VM・コンテナ/syscall フィルタ・カーネル強制のプロセス閉じ込め・MCP 層の許可制御・人間承認・資源上限）で封じ込める設計を公開し、いずれの層もエージェントの協力に依存しないことを原則に置いた。

裏づけは攻撃側から出ている。Adversa AI の Cryptographic Context Injection は、AES-256-GCM で暗号化した命令を Web ページに置き、モデル自身のコード実行ランタイムで復号させて分類器型ガードレールを素通りさせる手法で、Grok では zero-click で氏名・所在地・契約プラン・全チャット履歴を外部送出させた。Gemini でも通用している。同社の結論は「対策はモデル層ではなくハーネス層にある」であり、検知も単一ペイロードではなく未信頼コンテンツの流入 → コード実行 → 依存グラフ外ホストへの通信という連鎖で行うべきだとする。ID 側では Ping がエージェントを OAuth 2.0 の第一級 ID として扱う設計を出し、元 CISA の Matt Hartman は「すべてのエージェントを特権アイデンティティとして扱う必要がある」と述べた。

→ この主題は特集「誰の権限でエージェントは動くのか」で継続追跡している。

トレンド4: サプライチェーンの汚染点が「ビルド時」と「正規の配布経路」に移った

crates.io で累計 2.45億ダウンロードの Rust クレート arrayref・internment・append-only-vec がメンテナのアカウント乗っ取りで汚染された。なりすまし作者のタイポスクワット proc-macro1 への依存を1行足すだけで、その build.rs が cargo build の時点で3 OS 対応の窃取型を実行する。クレートの機能を一度も呼ばずに成立し、攻撃者は悪性版公開の24秒後に正規の旧版5つを連続 yank して、cargo の「取り下げ版から更新せよ」という警告を誘導装置に変えた。露出は 86〜107分、CVE-2026-77649/77650/77651 が採番されている。npm でも、インストールフックを使わず import しただけでLinux ビーコンが起動する RedC2 配布パッケージ14本が見つかり、--ignore-scripts では防げないことが示された。

8月4日の Shai-Hulud 第4波はさらに厄介だった。週1億2,700万ダウンロードの keyv のメンテナアカウントが乗っ取られ、正規リポジトリ・正規ワークフロー経由で毒入りリリースが有効な provenance 付きで公開され、数時間で1,280パッケージに広がった。署名基盤は正しく動いたまま攻撃が成立している。Unit 42 が整理した ChainDrop ワームは GitHub Actions ランナーのメモリから OIDC トークンを読み、VS Code と Claude Code の設定にフックを残す。CrowdStrike はレジストリ脅威の 87% が npm だと総括した。共通するのは、汚染点が成果物ではなく工場（ビルド環境）と配布経路にあることで、SBOM で版を照合するだけでは捕まらない。同じ構図は TrueConf の乗っ取りサーバからのクライアント差し替えや、車載 Android ヘッドユニットの純正アップデータ経由のプロキシボット化にも表れている。

→ 詳細は事例レポート「crates.io の arrayref 汚染」「npm ワーム ChainDrop」を参照。

トレンド5: 「正規機能の悪用」が IoC 型防御を無効化しつつある

侵入の入口が脆弱性から正規機能へ移った週でもある。ロシア系クラスタは OAuth 同意・アプリパスワード・WhatsApp の端末リンクという正規の認証フローで MFA を迂回し、フィッシングキット iAuthFlow V2 は被害者の Gmail に攻撃者のパスキーを登録して、パスワードリセットという復旧手順そのものを無効化した。CrowdStrike の観測ではヴィッシングが半年で2倍、デバイスコードフィッシングが 15倍である。Zimperium が解析した ToxicPanda 2.0 はゼロデイを一切使わず、Accessibility Service・Wireless Debugging・Device Administrator API という Android の正規機能だけで端末を掌握し、16か国349の金融アプリに標的を広げた。TWINLOOT は SharePoint・Teams・OneDrive を C2 に使い切ることでドメインレピュテーションと IP ブロックを無力化する。

防御部品自体も裏返る。Check Point は Microsoft 署名の Defender 起動時駆除ドライバ BTR.sys が、暗号化トランザクションを与えるだけでエクスプロイトもメモリ破損もなしに Ring 0 の任意ファイル・レジストリ操作エンジンになり、BYOVD なしで EDR/AV を無効化できることを示した。Akamai は「Bring Your Own EDR」を提示している。ハッシュとドメインの照合は、メモリ内実行・短命ドメイン・SNS デッドドロップ（E4del・PINHOLE は FTP バナーや Pinterest から C2 設定を取得）の前ではもう決め手にならない。CrowdStrike が示した VMware ESX 上のシェルコマンド難読化 21手法は、ESX のログがパース前の文字列を記録するためキーワード検索型の検知が原理的に効かないことまで示した。痕跡は「ハッシュ」から「振る舞いとログの相関」へ移る。

中長期に効く変化（CTO 向け示唆）

第一に、脆弱性管理を「深刻度順」から「露出と悪用可能性順」へ設計し直す時期に来た。 発見が AI で増え、悪用までが48時間になった以上、月次のパッチ会議は速度の面で構造的に負ける。BOD 26-04 の3/14/60日という区分は、そのまま民間の分類軸として使える。技術判断としては、パッチ適用を完了条件にせず適用前の侵害有無の確認までを1つの手順に含めること、そして緊急適用を業務停止付きで実行する権限を事前に委譲しておくことが要点になる。

第二に、AI エージェントは「新しい種類の主体」として認可・監査の対象に加える必要がある。 人でもサービスアカウントでもない主体が、権限を持って外部と通信し、コードを実行する。今週の合意点は明確で、封じ込めはエージェントの協力に依存しない層（ネットワーク既定拒否、短寿命クレデンシャル、ツール呼び出しの事前判定、緊急停止）で作る。防御ロジックをプロンプトやモデルの安全訓練に置く設計は、暗号化コンテキストインジェクションの前で崩れる。導入前にこの設計を持てるかが、来年の事故率を分ける。

第三に、ソフトウェア供給網の検証点を成果物からビルド環境へ移す。 provenance が有効なまま毒入りリリースが流通し、ビルドしただけで開発端末と CI が同時に感染する事例が同じ週に出た以上、SBOM と署名は必要条件だが十分条件ではない。実装としては、依存の完全固定と lock ファイルの差分レビュー、ビルド時実行スクリプト（build.rs・postinstall・import 時副作用）の可視化、CI ランナーの OIDC トークンの寿命と権限の最小化、そして開発端末を CI と同じ調査対象に含めることが要る。

第四に、検知の投資先を IoC から振る舞いとログ相関へ振り替える。 ハッシュ・ドメイン照合が効かない攻撃が主流になり、正規の認証フロー・正規署名ドライバ・正規クラウドサービスを通る侵入が増えた。ID の棚卸し（MFA 未登録、想定外の国からのサインイン、OAuth 同意済みアプリ、登録済み認証手段）は、今週の材料からは最も費用対効果の高い着手点である。Halcyon の観測ではランサムの初期活動の69%が日中・91%が平日であり、夜間監視に偏った体制なら日中の管理者権限とリモートセッションを見る体制への組み替えが先に効く。

§4. アクター間の関係の動き

  • 同一事案に三つの名前。crates.io（arrayref）・npm Axios・Mastra の3事案は Wiz が同一 IP レンジ（Hostwinds）の重複を指摘しており同一実体の可能性が高いが、呼称は割れている。CrowdStrike は STARDUST CHOLLIMA、GTIG は UNC1069、Microsoft は高い確度で Sapphire Sleet。OpenCTI では Sapphire Sleet が Stardust Chollima（別名 APT38・BlueNoroff）に、Lazarus は別実体に紐づく。突合をしないと同じ攻撃を3回数えることになり、今週最大の台帳運用上の課題である。
  • ロシアの初期アクセスの分業化。GTIG は ICE RELIC（旧 APT29）が初期アクセス担当のサブクラスターを複数運用していると中程度の確度で評価した。UNC6293（アプリパスワード詐取→6月から OAuth 検証コード搾取）と UNC7005＝STORM-2945（偽会議登録・WhatsApp 端末リンク・ホテル Wi-Fi 乗っ取り）が配下、UNC5976 は手口が重なるが別機関所属の可能性がある。Lumen は Wi-Fi ゲートウェイ到達が MSP 侵害経由の可能性を指摘しており、諜報の入口が委託先へ寄っている。
  • 犯罪ブランドと命名クラスタの境界の崩れ。ShinyHunters は 8/23 の掲載文で「UNC6040・Salesforce Aura・AWS の3件の侵害」と自称し、ベンダーが付けた UNC 名を自らの実績として引用した。命名は追跡の道具であって実体の境界ではない。
  • RaaS 内部の信頼の崩壊。GuidePoint は DragonForce・Settra・Anubis の3事案で、同一ホスト名とバックドアパスワードを持つ単一のアフィリエイトが偽の復旧支援業者「Ransom Busters」として被害者に接触し、身代金を自陣営へ流し込んでいたと評価した。
  • TTP の収斂——AI と悪用速度。UAT-10147・Earth Krahang・Earth Naga・SilkParasite の AI 利用が同じ週に並び、報告元は Talos・トレンドマイクロ・Bitdefender と分かれる。悪用速度も VAULT／GENESIS PANDA が24時間以内、UMBRAL BISON が20時間余り、Medusa が「公表24時間以内」と収斂し、PoC 公開から丸1日が実質的な猶予の上限になった。

§7. 予測（実験的）

この章は§0〜§6の観測・帰属とは独立している。 角度不明の推測が事実の記述に紛れないための隔離章である。尤度（予測の確率）と確度（証拠の質）は別物として書いている。対象は中国の戦略的意図に絞る。

  • 正規クラウドを C2 に使う中国系の手口が、対日キャンペーンでも次四半期中に観測される可能性がある（50-75%）。確度: 中。根拠は今週の SilkParasite の観測と、中国系が「正規のものに紛れる」手法を DLL サイドローディングとして MirrorFace 系でも長年使ってきた歴史的パターン。ただし SilkParasite と対日アクターの直接の関係は観測されておらず、手口の伝播を仮定した推論である。

  • 中国系による日本の重要インフラへの潜伏が今四半期中に公表される可能性は低い（15-25%）。確度: 低。根拠は今週の対日 PIR に該当観測が無かったことと、Salt Typhoon の米国事案が発覚まで長期を要した歴史的パターン。これは「潜伏が無い」という意味ではない——発覚の遅れ自体が低確率の理由であり、状況証拠のみに基づくため確度は低とする。

  • 中国系の標的が「境界機器そのもの」へさらに寄る現実的な可能性がある（25-50%）。確度: 低。根拠は直近90日の UAT-7810（SOHO ルーターの踏み台化）・knaithe（NetScaler・n8n の走査）と、今週の VAULT／GENESIS PANDA の24時間悪用パターン。ただしこれらに今週の新規観測は無く、90日窓の材料を今週へ外挿した推論である。

  • 国家系水準の実装が中国語圏の犯罪系へ広がる方向は今後も続くのがほぼ確実（>95%）だが、対日での観測となると可能性がある水準（50-75%）。確度: 中。根拠は UAT-10147（金銭目的集団が BYOVD＋カーネルルートキットを持つ）と SHADOW-EARTH-067 の BYOVD ルートキットが同じ週に報じられたこと。両者に直接の関係は観測されておらず、「中国語話者」は出自の推定であって国家帰属ではない点がこの予測の弱点である。

  • 半導体・防衛への技術窃取については、今週は確度のある予測材料に乏しい。3週連続で「明確な観測なし」が続き、_intent_analysis も対日 PIR のこの項目に該当アクターを挙げていない。無理に予測は作らない。観測が無いことは活動が無い証拠ではなく、収集の届いていない範囲が広い可能性のほうが高い（これも推論で確度は低）。
