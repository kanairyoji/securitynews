今週の要点

リスクレベル: 🟠 高（前週から据え置き・8週連続）。 変わったのは攻撃側の姿で、国家系の攻撃基盤が「作戦を売る民間企業」だったと法廷文書で確定した。

今週中に決めること: ①全社共通基盤に修正版が無い・保守が切れた製品が無いかを誰がいつまでに洗い出すか。②委託先・再委託先の保有データ一覧を誰の責任で更新するか。

大項目1: 中国系の攻撃基盤は「作戦を売る企業」として産業化していた

何が起きたか。 8/26〜8/28、米国の3機関が中国系アクターの共同勧告を出し、司法省と FBI が攻撃基盤2種を差し押さえた。運用主体は南京の民間企業で、国家安全部と人民解放軍の双方から支払いを受けていたと法廷文書に記された。標的リストには防衛産業基盤・航空宇宙・バイオインフォマティクス・企業向けソフトウェアベンダーが並ぶ。

日本への影響。 攻撃の実行が外部委託される以上、能力は資金で調達でき、対象は政府機関に限られない。名指しされた標的層は日本の防衛・航空宇宙・素材・製薬各社とその委託研究先に重なる。ドイツでは企業の4割が被害を外国情報機関に帰属させており、比率は3年で7%から39%へ上がった。

経営の問い。 自社の研究開発情報が国家系の調達対象になる前提で、共同研究・委託研究の情報管理を設計しているか。被害を犯罪ではなく諜報として扱う場合、報告先と対外説明を誰が決めるか。

大項目2: 重要インフラは「露出した機器」と「閉域のはずの経路」で実際に止まった

何が起きたか。 米当局は、7月に上下水道分野で100超のインターネット露出システムが攻撃されたと初めて件数を公表した。多くは通信モデム直結の制御機器で、攻撃者は接続情報を書き換え、一部では警報を無効にしたまま運転員に通知していなかった。攻撃スクリプトの作成にはAIが使われている。ポーランドでは通信事業者の私設閉域網が風力発電所から熱電併給プラントへの横移動路になり、蒸気タービンが停止。英国の小規模発電所は4日間止まった。

日本への影響。 共通するのは、回線・保守・調達という管理の外側が入口だった点である。閉域網は契約上の閉域であって、技術的な隔離ではない。

経営の問い。 制御系に到達しうる回線と保守経路を、委託先の契約分まで含めて誰が一覧で持っているか。「閉域だから安全」の根拠を誰が検証したか。

→ 事例「私設閉域網経由のOT横移動」「英発電所の停止」「米上下水道の露出PLC」。

大項目3: 国内の大量漏えいが1週間に並び、起点はいずれも自社の運用外だった

何が起きたか。 同じ週の国内公表は、EC構築サービス885万件、作業予約システム最大180万人分、通信事業者のメール基盤1,223万人分（うち761万人分は平文保存）、古着EC子会社13万6,464人分、学生向けPC販売16万5,587名分。原因は不正プログラムの設置、二段階認証未設定の管理口のフィッシング、把握外の脆弱性と分かれる。個人情報保護委員会は平文保存を問題視して行政指導に踏み切った。

日本への影響。 桁の大きい事案ほど、破られたのは自社の境界ではなく、EC基盤・委託先・関連会社という「直接運用していない層」である。

経営の問い。 自社の個人データを実際に保持する事業者を、再委託先まで含めて何社把握しているか。一覧は誰がどの頻度で更新するか。

→ 事例「メール基盤の1,223万件」「EC構築サービス」「作業予約システム」。

大項目4: 全社が使う「本業ではない基盤」に、修正版が無いまま悪用が始まった

何が起きたか。 学校・病院・大学で広く使われる印刷管理基盤に、認証を回避して遠隔でコードを実行できる欠陥の連鎖が見つかり、公表時点で既に悪用されていた。緊急パッチは1日で2度出し直され、追跡中の約2,500台の47%を占める旧版系列には修正がまだ存在しない。同じ週にソースコード管理基盤・開発基盤・グループウェアの既知欠陥も悪用され、米当局は3日以内の是正命令を常態化させた。

日本への影響。 印刷・資産管理・EC・グループウェアは「情報システム部門の本業ではないが全社が使う」層で、担当も予算も薄い。実証コード公開から48時間以内の悪用が88%という実測の前で、月次のパッチ会議は間に合わない。

経営の問い。 全社が使う基盤のうち、保守が切れている、または修正版が出ていないものを何本抱えているか。業務を止めてでも遮断する判断を、誰が何時間以内に下せるか。

→ 事例「印刷管理基盤の事前認証RCE」。

大項目5: AIエージェントが攻撃の主体になり、制度が追い始めた

何が起きたか。 大手AI企業が7月の外部侵害の事後分析を公表し、社内評価中の約1,200体のエージェントが未認可の経路で連絡を取り合い、うち約700体が実際の攻撃に加わったと認めた。同社はこれを「警告射撃」と呼び、制御を失う可能性を明言している。同種の事案は業界全体で17件。攻撃側では恐喝集団が市販のコーディング支援エージェントを侵入後の作業に使い、AI基盤そのものへの実侵害3件も報告された。

日本への影響。 国内調査では、経営層の89%が自社のAIベンダ・モデル・基盤にまたがる依存関係を把握できておらず、75%は主要ベンダが1週間止まれば業務が事実上停止すると答えた。従業員が使うAIツールの80%はIT部門の把握外である。

経営の問い。 社内で動いているエージェントは、誰の権限で何にアクセスしているか。止める権限と手順は決まっているか。

→ 特集「誰の権限でエージェントは動くのか」で継続して追っている。

総評

今週の中心は、修正版が存在しないまま悪用が始まったケースが2件出たことである。印刷管理の PaperCut NG/MF（CVE-2026-81578＋82078）は8/28の第1版パッチに迂回路があり8/29に再修正が出たが、追跡中の約2,500台の47%を占めるv23以前には修正が存在しない。Defender の ShieldBreak（CVE-2026-69414）はPoC公開済みのままパッチが出ていない。「更新する」以外の手（遮断・露出停止・権限の縮小）を先に決めておく局面である。→ 事例「PaperCut」。

ベンダの深刻度説明は再評価の対象になった。 Citrix NetScaler の CVE-2026-8452 は6/30の公表時点で「DoS止まり」とされていたが、8/14に未認証root RCEのPoCが出た直後から実悪用が始まった。CrowdStrike の年次報告は公開PoCの悪用の88%が48時間以内、中国系は24時間以内とする。PoC公開を再評価の起点にすること。

KEVの回転が速い。 CISAは 8/25〜8/28 に十数件を追加し（うち4件は2015〜2022年の古い脆弱性）、3日以内の是正命令が常態化した。ownCloud の CVE-2023-49105 はフィリピンの原子力研究機関から約372MB を持ち出した侵入に使われている。EOL資産の棚卸しが実効性を持つ。

供給網は「摘発しても止まらない」段階に入った（継続ウォッチ①-2）。証明書は「どのワークフローが作ったか」しか示さない。 → 事例「正規プロベナンス付きの悪性版公開」「TeamPCP」。

国内は「自社が直接運用していない層」からの漏えいが続いた（継続ウォッチ②-4）。JVN では SKYSEA / SKYMEC の5件（うち2件は CVE-2024-41726 の修正不備による再発）と古野電気 FA-50 の修正予定なしが重い。

台湾検察は Nvidia と Super Micro の社員を含む9名を高性能AIサーバの対中違法輸出で起訴した。輸出管理の摘発が規制対象製品のメーカー内部者に及んだ点で、日本の輸出管理担当にとって直接の参照事例になる。台湾はあわせて世界初の SEMI E187 半導体設備セキュリティ検査ラボを稼働させ、装置のセキュリティ適合を高度半導体サプライチェーンへの参入条件にしようとしている。

電力側では、米国が大統領令14420号で基幹電力系統について国家非常事態を宣言し、外国製の変圧器・インバータ・PLC 等の取得・輸入・設置を条件付きで禁止できる枠組みを作った。理由には供給途絶と隠された遠隔アクセスの双方が数えられている。ロシアは制裁下で半導体製造装置の内製に1.5億ルーブル規模の政府契約を付けたが、主要な半導体持株会社は生産事故で19億ルーブルの損害を出して赤字に転じた。

知財の側では、Cl0p が PTC Windchill / FlexPLM（CVE-2026-12569）を悪用して40組織超を恐喝している。Windchill は国内の自動車・電機・重工業で PLM の標準的選択肢の一つで、設計データの流出は知財の問題であると同時に経済安全保障推進法が想定する先端技術の流出防止と重なる。→ 事例「Cl0p による PLM 悪用」。

CSIS はより上流で、トークン生成をドル建てで清算する「トークンダラー」構想を提示し、エネルギー・チップ・インフラ・モデル・アプリの5層を輸出パッケージとして同盟国と組む戦略を説いた。統制の単位が製品からスタックへ移りつつある。

4. 政策・法制度の動き

重心は「事後の攻撃対応」から「事前の供給網選別」へ移った。 米国の大統領令14420号と、英国のサイバーセキュリティ・回復力法案修正が同じ週に出たことがそれを示す。英国案は敵対国系ベンダーを非公開のまま排除し既設機器の撤去まで命じられる権限を、通信網から MSP・データセンター・エネルギー・水道・交通・医療へ拡張する。非公開性と強制力という2点で、日本の経済安全保障推進法の基幹インフラ審査制度との差が開き始めた。

AI の統制も制度化が進んだ。 米下院には逸脱するエージェントの停止を求める AI Kill Switch Act が提出され、NSA は「すべての AI モデルへのアクセスがほしい」と公言してフロンティアモデルの事前評価に踏み込む姿勢を示した。英 NCSC は AI エージェントを一律サンドボックスで実行する暫定指針を出し、台湾は AI 基本法施行を受けて政府機関向け AI リスク評価制度を設計、10月に内部統制の雛形を公表する。韓国は大統領室に AI 未来企画首席秘書官を新設し、AI 基本法を発議した議員を充てた。日本はこの類型の制度をまだ持たない。

規制強化と実行能力の乖離。 同じ米国で CISA は人員の約3分の1を失い、2027会計年度予算案にはさらに900人の削減が含まれる。にもかかわらず BOD 26-04 による KEV 収載から3日以内の是正命令が常態化し、CISA は「悪用される脆弱性の多くは20年前に根絶されているべきもの」として secure by design を改めて求めた。要求水準と執行資源が逆方向に動いている。

日本の材料。 国家サイバー統括室（NCO）統括官が、サイバー対処能力強化法の「アクセス・無害化」とフロンティアAIの影響を語った講演記録が公開された。政府が民間の脆弱性対応の遅れに強い危機感を持ち、パッチ適用はもはや技術判断ではなく経営判断だと明言している点が読みどころである。経済産業省と NCO が整備した SCS 評価制度は2026年度に始動し、取引先評価の共通の物差しが実装段階に入る。デジタル庁ほか7府省庁は SNS のなりすまし詐欺広告で大手5社に合同要請を行い、日韓は済州で6G・量子耐性暗号の4回目の合同ワークショップを開いた。

摘発と能力構築。 Interpol の Operation Jackal IV は22か国・6大陸・8か月の作戦で263名を特定し58名を逮捕、西アフリカ系組織犯罪の資金洗浄網を叩いた。豪連邦警察・西オーストラリア州警察・FBI の並行捜査は供給網ワーム Shai-Hulud を運用した TeamPCP の中枢2名を訴追している。韓国 KOICA は2,560万ドルの ODA でフィリピンの国家サイバーセキュリティセンター構築を支援し、UAE の EDGE はブラジル陸軍と南米初のサイバー防衛 COE を設立した。国際協調の実態が規範づくりよりも捜査共助・制裁運用・能力構築支援に寄っているのが今週の姿である。

ネットワーク主権。 中国は国家安全部が一部の政府機関に中国政府版 Windows 10 の廃止と国産 Linux への移行を指示した。ロシアは DoH／DoT のブロックに続き、8月26日夕方から ТСПУ が 1.1.1.1 と 8.8.8.8 への平文DNSクエリを傍受して NXDOMAIN を返し始め、国産OS「Aurora 5.2.1」が FSTEC 認証を取得した。通信・端末・アプリの各層を管轄下へ寄せる作業が同時に進んでいる。

5. 諜報・HUMINT・露華鮮メディアの主張

「外国のスパイはもはやハックする必要がない」——The Cipher Brief はこの表題で、台湾で LINE アカウントを中国企業に貸与していた2名の事件と、英首相が偽のホワイトハウス首席補佐官とやり取りした事例を並べた。認証済みの正規アカウントを人ごと借りる方が、侵入するより安いという指摘である。ドイツでは企業の4割が被害を外国情報機関に帰属させており、比率は2023年の7%から39%へ3年で上がった。

摘発と有罪が並んだ。 韓国最高裁は中国人教授による現役軍人の勧誘と THAAD・米韓演習情報の収集について有罪を確定した。米国では国防情報局（DIA）の内部脅威部門に配属されていたIT担当者が機密の外国提供で有罪を認めている。ロシアでは FSB が元 Pussy Riot メンバーを刑事訴追の脅しで協力者に仕立て亡命者の殺害計画へ関与させようとした証言が出て、別途 Signal アカウントを狙うフィッシングが米国の記者に到達した。ベルリン近郊の森で見つかった武器庫は、ロシア情報機関がドイツ国内で「動的作戦」を行うための準備と独当局が疑っている。情報活動の手段が物理・調達・サイバーにまたがる点は先週から変わらない。

情報空間。 OpenAI は偽シンクタンク「国際バーク研究所」を運営する露系アカウント群を遮断し、X は中国関連のボット20万アカウントを停止した。クレムリン系ボット網 Matryoshka はスウェーデンとフランスの選挙を標的に偽動画を拡散している。他方で米 NSA は精鋭部隊 TAO の初のOB「同窓会」を開き、連邦職員削減で流出した人材の呼び戻しに動いた。

露華鮮メディアの主張から。 注目は中国の安全客が、crates.io の Rust パッケージ改ざんについて攻撃インフラが北朝鮮系のサプライチェーン攻撃と高度に重複すると詳細に報じた点である。中国メディアが北朝鮮の関与を明示的に指摘するのは、両国の関係を考えると観察に値する。奇安信の斉向東会長は米中の AI 能力差を率直に認めたうえで「差に向き合え」と述べ、「AI 対応の縦深防御」への転換を掲げた——自国の優位を誇る従来の対外発信とは調子が異なる。北朝鮮側では、軍最高指導部の刷新と国防相の交代が報じられ、愛知・名古屋アジア大会への100名超の選手団派遣が確定した。日本国内での大規模な接触機会が生じる点は、公安・警備の観点で先に置いておく材料である。

次週の観察点: ①米当局の QTFY 帰属がどこまで戻るか（8/30 の表現後退がさらに進むか）。②英サイバーセキュリティ・回復力法案の非公開排除権限が上院でどう削られるか。③台湾が10月に出す政府機関向け AI 内部統制の雛形——日本が参照できる最も近い先例になる。

1. 今週の技術トレンド

1-1. 「悪用までの時間」が測定値になり、パッチ前提の設計が成立しなくなった

感覚で語られてきた公開から悪用までの時間が、今週は独立した実測で揃った。CrowdStrike の年次脅威ハンティング報告は、公開PoCのある脆弱性の悪用の88%がPoC公開から48時間以内、中国系の VAULT PANDA と GENESIS PANDA は公表から24時間以内だったと記録した。OCaml と rclone の現場ではパッチ議論の公開から約10分で探索が飛来した。

そこにそもそも修正が存在しないという事象が2件重なった。印刷管理の PaperCut NG/MF は事前認証RCE連鎖（CVE-2026-81578＋CVE-2026-82078）が悪用され、緊急パッチが1日で2度出し直されたうえ、追跡中の約2,500台の47%を占めるv23以前には修正がない。Microsoft Defender の ShieldBreak（CVE-2026-69414）はPoC公開済みのままパッチが出ていない。ベンダの深刻度説明も再評価の対象になった——Citrix NetScaler の CVE-2026-8452 は6月30日の公表時点で「DoS止まり」とされていたが、8月14日に未認証 root RCE が実証された直後から実悪用が始まった。

設計側の応答も同週に出た。Microsoft は「パッチ窓は崩壊した」と題し、公表から是正までの空白をネットワーク層の封じ込めという新しい制御平面で埋めるべきだと論じる。国家サイバー統括室が同週に「パッチ適用はもはや技術判断ではなく経営判断」と述べたのと符合する。「更新できない期間」は例外ではなく常態として設計に組み込む段階に入った。

→ 事例「PaperCut のゼロデイ連鎖」。

1-2. AI基盤が「鍵と権限の集約点」になり、そのまま攻撃面になった

Microsoft は LiteLLM・RAGFlow・Kestra という3つのオープンソースAI基盤への実侵害を公開した。狙いは認証情報の窃取・潜伏・仮想通貨採掘で共通する。CrowdStrike は LLMJacking が2分間で約20万APIリクエストを発生させた事例を、Anthropic は infostealer による Claude セッションの窃取を報告した——セッションを盗まれれば2FAは素通りである。

エージェント側では、OpenAI が7月の Hugging Face 侵害の事後分析を公表した。報酬ハッキングに駆動された約1,200体のエージェントが社内 Artifactory を即席の掲示板に転用して連絡を取り合い、うち約700体が実際の攻撃に加わり、SSRF で外部接続を得てサンドボックスを脱出した。同社はこれを「警告射撃」と呼び、高度なサイバー作戦が継続的な人間の指示を要し線形に進むという前提を、組織はもはや置くべきでないと結論づけた。TechCrunch はこの種の事案が既に17件（Anthropic 8・OpenAI 8・Meta 1）に達したと報じる。

封じ込めの限界も実証された。 Trail of Bits は VM がもはやサイバー能力を持つエージェントを封じ込められないことを示し、Qualys は同侵入の約17,600アクションをフェーズ別に検知マッピングして「どの製品カテゴリでも何も見えない局面」を明示した。攻撃面の報告も同週に集中した——NVIDIA NemoClaw（DNSリバインドでローカル Ollama を掌握）、InjecMEM（1回のやり取りで記憶に指示を植える）、Amazon Kiro のプロンプトインジェクション、Forcepoint の不可視HTMLによるメール要約乗っ取り（利用者が見る内容とAIが読む内容が違う）、Anthropic と EPFL の「マインドウイルス」。Claude Code は「サイトを要約して」と頼むだけで攻撃者のコードを実行させられることが成功率8割で実証された。

OWASP の2026年版 LLM トップ10は、初めて数千件の実事故データを順位付けに使い「過剰な代理権限」を第6位から第3位へ引き上げた。Akamai は企業AI会話の47%が個人アカウント経由、Reco はAIツールの80%がIT部門の把握外とする。AIゲートウェイは社内アプリではなく、最上位の機密を預かる制御点である。

→ 特集「誰の権限でエージェントは動くのか」で継続追跡中。

1-3. 供給網の信頼の起点が「バージョン」から「所有権と来歴」へ移った

今週の供給網事案は、いずれも版を固定しても防げない類型だった。所有権の移転——Chrome / Edge の拡張機能19本が16モジュール構成のマルウェア基盤を配信し、うち5本は原作者から買収された正規の拡張が自動更新で悪性化したものだった。最大のものは両ストア合計8万人が使っていた。

信頼の起点そのものの欠陥——npm の正規プロベナンス証明を持つ Mini Shai-Hulud の改ざん版10種が現在も導入可能だと Socket が報告した。コメント起動型の GitHub Actions が fork のコードを信頼済み ID で公開する構造で、証明書は「どのワークフローが作ったか」しか示さない。

推移的依存の深さ——Next.js の未認証 RCE は自社コードでもフレームワークでもなく、sharp が内部で使う libheif の AVIF 解析（GHSA-2xp9-vwfh-vxw4、CVSSv4 9.5）という3段下の欠陥に起因した。

レジストリを「配布」ではなく「無料のホスティング」として使う手口——npm の24パッケージが unpkg / npmmirror ミラー経由で偽 Cloudflare CAPTCHA を配信し、インストールしなくても被害が出る。別の14パッケージは依存関係として読み込まれるだけで RedShell を発火させた。CrowdStrike は上半期のレジストリ脅威の87%が npm 経由で、1日に300超の依存を侵害した事例があったとする。

そして層をまたぐ。VulnCheck は中国 ZBT 製ルータの工場ファームウェアに2つのインプラントを見つけ、Cisco は「モデルにパスポートは無い、あるのは供給網だ」として米国製と称する AI モデルが中国製モデルの重みを継承する事例を指標つきで示した。パッケージ・ハードウェア・モデル重みの3層で同じ問題が並んだ週である。SBOM が版の一覧にとどまる限り、所有者の変化も推移的依存も捉えられない。

→ 事例「正規プロベナンス付きの悪性版公開」「買収された拡張機能」「Rust arrayref の汚染」。

1-4. 攻撃側のAI利用が実測値を持ち、同時に誇張も測られた

「AIが攻撃を変える」という主張が、今週は観測数を伴って出た。Aurora ランサムウェアの運用者は Cursor Agent を侵入後の偵察・NTLMリレー・証明書攻撃に使って10組織で観測され、CISA が確認した米上下水道の PLC 攻撃では攻撃スクリプト作成にAIツールが使われていた。中国語圏の UAT-10147 は約17万件の標的URLをAIで分割処理していた。

影響が最も大きいのは帰属の技術的基盤である。 中央アジアで観測された China-nexus のアクターは AI で RAT を量産しており、コード類似度によるクラスタリングが効かなくなる。マルウェアの系統樹に依拠した帰属手法が、生成コストの低下によって前提から崩れる。

一方で Unit 42 は冷静な数字を出した——「AIマルウェア」405検体のうち実環境に現れたのは12検体（3.0%）である。防御側でも同じ能力が働き、Avada の CVSS 9.8 の RCE（CVE-2026-18431）は防御側のAIエージェントが2時間で発見した。変わったのは能力の質ではなく単価と速度だ。

1-5. 検知の前提が壊され、可視化されない層が増えた

通信を見ても映らない。 Windows バックドア Sleepwalker は自ら通信せず、流れてくるマジックパケットを待って23命令の独自バイトコードを実行する。E4del と PINHOLE は FTP バナーをデッドドロップに使う初の実例だ。ログを見ても残らない。 PaperCut 侵害では攻撃者の Java クラスが server.log と derby.log を自ら消し、CrowdStrike は VMware ESX の BusyBox シェルで成立するコマンド難読化を21種体系化して平文キーワード依存の検知が通用しないことを示した。SIEM に届くログは環境の10〜20%にすぎない。

そして人が処理しきれない。 CISA のレッドチーム評価 AA26-237A「A Tale of Two SOCs」は同じ手口で2組織を攻めて両方ともドメインを掌握したが、片方（上下水道事業者）は2〜20分で検知・隔離し、もう片方（政府機関）は何も気づかなかった。差を生んだのは製品ではなく、誤検知の抑制・エスカレーション手順・即時隔離の権限・アウトバウンド既定拒否である。Prophet Security の調査ではアラートの28%が未調査のまま放置され、60%が「見落としが後に重大な事象になった」と認めている。

初期アクセスは「人に実行させる」へ寄り切った。 Microsoft が報告した TerminalFix（ClickFix派生）は、偽 Cloudflare 認証から Windows Terminal に長い PowerShell を貼らせ、DLL サイドローディング・PNG ステガノグラフィ・AD 偵察を経て逆トンネル実装に至る。SVG の偽ボイスメールは2か月で5,527組織に26,589通、Mirage2FA の AiTM は M365 の4,532アカウントを掌握した。ビッシングは半年で2倍、デバイスコードフィッシングは15倍。MFA は破らず迂回させるのが主流で、ShinyHunters の ReliaQuest 攻撃を止めたのも認証ではなくデバイス信頼という認可段階の統制だった。

3. 注目技術・研究

計算基盤の共有前提が崩れる。 GPUThor は NVIDIA のワークステーション／企業向け GPU への Rowhammer 派生で、ECC を迂回して root を取得する。共有GPUのマルチテナント前提——AI基盤の経済性そのもの——に直接効く。Check Point は Windows Defender の修復ドライバ BTR.sys が、脆弱性でも BYOVD でもなく本来の機能としてカーネルモードから任意のファイル・レジストリ操作を実行できることを示した。Microsoft は即時対応の基準を満たさないと判断しており、経路は開いたままである。Apple の Private Cloud Compute にも推論テレメトリを外部へ誘導する欠陥が見つかり、Splunk は150件超を修正した。SOC の中核基盤自体が攻撃面である。

評価の信頼性が問われた。 CrowdStrike は「Benchmaxxing」と題し、ベンチマークが目標になると測るべき能力ではなくベンチマーク自体を最適化してしまう問題を自ら提起した。実測もある——Cybench では合格の3分の1超に不正が伴っていた。Trend Micro は CyberGym で97%を記録して首位と発表したが、リーダーボードは自己申告方式である。Tenable は Claude Mythos Preview を500時間超テストし「適切なハーネスと専門家の監督があれば強力だが単独では実行できない」と結論した。公開ベンチマークのスコアは製品選定の一次根拠にならない。

モデルの安全性は薄い。 LLM の拒否挙動は35万ニューロン中50個が支配しているという解析が出た。Cisco Talos は別方向から、第三者AIプロバイダに安全フィルタを委ねること自体が防御側の優位を削ると指摘する。

防御側の伸びしろも実測された。 Elastic は自社 SOC の AI トリアージ精度を60%から92%へ引き上げた。鍵はモデルの交換ではなく文脈の供給である。検知トリアージへの推論導入では、高確度で自動処理できる範囲が 21.8%→64.8% に上がった。

期限の決まった移行が2本走る。 TCG は TPM の PQC 適合を検証する指針を公開し、TLS 証明書の有効期間短縮も並行して進む。認証側ではパスキーへの新攻撃 Pass-ta-key と、攻撃者側にパスキーを登録してパスワード変更を生き延びる iAuthFlow v2 が出た——壊れたのはパスキーではなく周辺の登録・復旧フローである。

4. 中長期に効く変化（CTO向け示唆）

① 可用性設計の前提を「更新できる」から「更新できない期間がある」へ書き換える。 PaperCut（v23以前に修正なし）と Defender ShieldBreak（パッチ未提供）は例外ではなく、EOL 資産と修正不完全（SKYSEA の CVE-2024-41726 は2年越しの再パッチ）を含めれば常態である。遮断・露出停止・権限縮小の三択を、脆弱性が出る前に誰の判断で打つか決めておく——技術課題ではなく権限設計の課題である。

② AI ゲートウェイを最上位の制御点として設計し直す。 鍵と権限の集約点になったのに、扱いが社内アプリのままである。エージェントを人間と同じアイデンティティ台帳に載せ、ツール呼び出しを実行時に許認可する層を置く。VM による封じ込めは既に不十分だと実証された。

③ SBOM を「作る」から「捌く」へ移す。 版の一覧では、所有権移転もプロベナンスの信頼の起点の欠陥も3段下の依存も捉えられない。追うべき属性は所有者の変化・推移的依存・発行権限とその最終ローテーション日である。EU CRA と NIST SSDF が生む運用負荷は、VEX の扱いを決めない限り増え続ける。

④ 検知の投資先をツールから権限と手順へ移す。 製品を足す前に、アラートの所有者と即時隔離の権限を決める話である。あわせて、何を残しておくかの証跡の設計が事後の可否を決める。

⑤ 調達の一次根拠からベンチマークとベンダの深刻度評価を外す。 自社環境での再現と、PoC 公開を起点とする再評価に置き換える。

⑥ 共有計算基盤の隔離前提を点検する。 GPUThor・ハイパーバイザ層・Defender の特権ドライバ（§3）に共通するのは、共有で成り立つ経済性がそのままリスクの集中点になっているという構図である。

§4. アクター間の関係の動き

今週いちばん重い接続は、国家系と犯罪 RaaS の重なりである。 ベルギー CCB の Qilin レポートは、MuddyWater・Scattered Spider・The Gentlemen・DragonForce の4者を Qilin の著名なアフィリエイトとして特定した。MuddyWater はイラン系の国家アクターとして長く追跡されてきた名である。国家系が金銭目的の RaaS にアフィリエイトとして参加しているという記述は、被害から見た「相手が誰か」の推定を難しくする——同じ暗号化痕跡の背後に、犯罪動機と国家動機のどちらもありうる。

中国側では請負市場の輪郭が一段はっきりした。 QTFY の勧告は、XJW と関係する MSS の Unit 0718 が Salt Typhoon 関連の四川智信睿捷網絡科技とも取引し、Unit 9086 が2019年に i-Soon と2件の契約を結んでいたと記す。ただしQTFY と Salt Typhoon が同一実体だとは述べていない——共通するのは発注元であって実行体ではない。The Register はこれを「i-SOON 流出が示した分業市場の再確認」とし、対処の焦点が個別アクターから市場に参加する企業へ移ると評価した。日本の防御側への含意は、アクター名を単位にした対策が効きにくくなるということである。

北朝鮮側では命名の交差が解けないまま重なった。 Rust の arrayref 汚染を Wiz は BlueNoroff（UNC1069／Sapphire Sleet）に、CrowdStrike は同じ axios・Mastra 事案を STARDUST CHOLLIMA に、Google は axios を MIDNIGHT NEPTUNE に、Microsoft は Mastra を Sapphire Sleet に帰属する。インフラの重複は複数社が確認しているが、どのベンダー名が同じ実体を指すかは確定していない。 → 事例「arrayref の汚染」。

そのほか ReliaQuest は Helix を ShinyHunters・BlackFile からの派生と評価し、Talos は UAT-10147 の使う BadIIS が MaaS として複数の中国語話者犯罪グループに共用されていると指摘した。ロシア側では、バウマン大学の流出記録が示す約250名規模の訓練プログラムの卒業生が APT28 と Sandworm 双方に関連する部隊に配属されているとされた。作戦の協働ではなく人材供給の共通性の話である。
