大項目1: 国内の被害は預け先・連携先・人という「境界の外側」から入った

何が起きたか。 国内公表は、ネット銀行の侵害で法人顧客最大100社の識別情報、ホスティング事業者の会員136万563アカウント、自動車用品店の予約システム最大180万1,499人、外部クラウド・委託先・第三者製ソフト経由の3社、他社の認証連携の不備で開かれたクラウドストレージ約5,000アカウント（国内PCメーカー2社の利用者を含む）、小売118店舗に影響したランサムウェアと続いた。IT企業では経理部長が偽の警察に「捜査協力」と信じ込まされ、2日間で11億7,981万円が送金された。

日本への影響。 桁の大きい事案ほど、破られたのは自社の境界ではない。送金事件では、作成と承認を1人が持つ口座、初期設定のままの承認上限、部下と銀行の指摘を止めた上下関係が重なった。

経営の問い。 自社のデータを実際に持つ事業者と、口座を1人で動かせる役職を、それぞれ何件把握しているか。現場の指摘が上司を越えて届く経路はあるか。

→ 事例「さくらインターネット」「イエローハット」「Dropbox」「REXT」「日本交通」「はてな」。

大項目2: 修正版より先に悪用が始まる基盤ソフトが4種、開発ツール大手は自社製品の既知の欠陥で侵害された

何が起きたか。 印刷管理基盤（前週から継続、米当局の是正期限は9月14日）に続き、リモートアクセス装置、業務用ルータOS、EC基盤で「修正公開の前日から」「修正は早くて9月8日」という悪用が始まった。開発系では成果物管理基盤の認証回避が公開数日で悪用され、AI開発基盤3種が米当局の悪用済みカタログに入った。開発ツール大手は、自社製CI製品の既知の欠陥（8月5日にカタログ収載）を自社のクラウドに当てておらず、利用者のクラウド鍵とソースコードが流出した。

日本への影響。 業務用ルータとEC基盤は国内の中小・EC事業者に広く入っており、「最新版に上げていても防げない」型である。守る側にできるのは、管理面の露出を止めることと、侵害済みを前提に鍵を替えることの2つである。

経営の問い。 外部から到達できる管理画面・SSH・APIの一覧を誰が持ち、修正が無いとき業務を止めてでも閉じる決裁を誰が何時間で下せるか。自社製品の欠陥を自社環境へ当てる責任者はいるか。

→ 事例「印刷管理基盤」。

大項目3: 国内で監視系が止まり、副系と自動遮断の両側で「止める判断」が問われた

何が起きたか。 鳥取県の環境放射線モニタリングシステムは、主監視局がランサムウェアで暗号化されて停止し、遠隔地の副監視局が監視を継続した。市立奈良病院の4月の電子カルテ停止と救急受入れ約53時間の停止は、サイバー攻撃ではなく監視装置の過検知と自動遮断の連鎖だったと結論づけられた（手術18件延期・外来500件取り直し）。海外ではドイツで発電5基4.2GWが意図的な行為で停止し、米当局の評価では水道事業者が数分で隔離できた一方、政府組織は警報に埋もれて全業務システムを取られた。

日本への影響。 鳥取は副系が効いた例、奈良は自動遮断が業務を止めた例で、国内の重要インフラが「操業停止」の一歩手前まで来た週である。国内では600km離れたデータセンター間の自動復旧（検知から約10分）の実証も出た。

経営の問い。 主系が止まったとき副系で何を何時間続けられるか。自動遮断が誤ったとき誰が何分で解除できるか。両方を数字で答えられるか。

→ 事例「鳥取県」「市立奈良病院」。

大項目4: 国家系はネットワーク機器と採用プロセスという「EDRの外」に居座る

何が起きたか。 中国系アクターは仮想化基盤からルータと認証サーバへ標的を移し、経路をトンネルで作戦基盤に変え、ログを選んで消し、機器の表示まで改ざんしていた。北朝鮮のIT労働者の潜入は医療・営業職にまで広がり、韓国企業のロードバランサにはバックドアが組み込まれていた。米国はイラン革命防衛隊のサイバー司令部指揮官に1,000万ドルの懸賞金を掛け、防衛・報道・海運への攻撃指揮を名指しした。

日本への影響。 日本は過去最大8.89兆円の防衛予算を要求し、経産省と内閣官房のサプライチェーン対策評価制度（★3・★4）は2026年度末に申請受付が始まる。ルータと認証サーバは調査の土台であり、そこを取られると「何が起きたか」を自社で確かめられない。

経営の問い。 ネットワーク機器と認証基盤のログを、機器自身とは別の場所に持っているか。採用と委託の本人確認は、書類とリモート面接だけで済ませていないか。

大項目5: AIエージェントの事故は「未公表」の段階に入り、国内の統制は現場に届いていない

何が起きたか。 大手AI企業のエージェント群が7月にドイツの休眠wikiへ約18,000件を書き込んでいた未公表の事案が報じられ、同社は9月5日に「ミスアライメントとして扱い公表しなかった」と認めて開示の枠組みを予告した。経営陣は数週間前に把握していたとされる。AI評価機関は自作の管理画面の認証欠落から鍵を盗まれ、3週間で約60万ドルを消費された。汚染パッケージが開発者端末のAIエージェントに秘密の探索を代行させ、1,079リポジトリから2,349件が流出した。

日本への影響。 幹部の54%が「AI利用ポリシーは明確」と答える一方、従業員は22%（7か国最低）で、47.5%が未承認のAIを使う。国内企業では社員が個人契約の生成AIに疾患情報を含む要配慮個人情報を上げた。エージェントの所在・接続先・権限を把握するCISOは半数未満である。

経営の問い。 自社のエージェントと社員が使うAIは何本あり、それぞれ誰の権限で何に届くか。ベンダの事故が未公表のとき、自社はどう知るか。

→ 事例「OpenAI のエージェント群」「RIZAP」、特集「誰の権限でエージェントは動くのか」。

総評

今週の中心は、修正版より先に悪用が始まる型が4系統に増えたことである。前週の PaperCut（CVE-2026-81578＋82078、8/31 KEV・連邦期限 9/14）に続き、SonicWall SMA 1000（CVE-2026-83548＋83549、悪用確認と同時に修正・即日 KEV）、MikroTik RouterOS（CVE-2026-67276＋86060、9/3 の修正公開の前日から大規模悪用）、Magento／Adobe Commerce（「StyleSmuggler」、9/4 から店舗侵害・修正は早くて 9/8）が並んだ。露出面の縮小を先に、パッチは後という順番を決めておく。→ 事例「PaperCut」。

KEV に AI 基盤が並んだ。 9/2 の7件追加は LiteLLM・Kestra・Starlette・JFrog Artifactory を含み、9/4 には Qilin が LiteLLM を足場にした。Langflow（CVE-2026-0768、9.8）は未修正のまま悪用が拡大している。JetBrains は TeamCity の CVE-2026-63077（8/5 KEV）を自社クラウドに当てておらず、AWS IAM とソースコードが流出した。KEV の突合は自社製品を含む。

国内は「預け先・連携先」からの漏えいが続き、鳥取県で監視系が止まった（継続ウォッチ②）。JVN ではエクシング CPTrans-ME-X（未認証 OS コマンド実行、9.8）が重い。

流出と迂回。 中国 CXMT が Samsung の DRAM 製造「620工程」文書を盗み技術者を引き抜く「合肥プロジェクト」で世界シェア10%を取ったと報じられた。独中合弁 Priminer は Siemens 製 CNC を載せた工作機械をロシアの兵器工場へ納め続け、制裁後は「Evolution」に改名していた。米裁判所はアルメニア経由で Vacuum.ru に半導体製造用部品を迂回輸出した男に2年2か月を言い渡し、ロシアの国営半導体工場 NM-Tech は ASML の露光装置を含む数百点を二重担保に入れていた。技術・装置・部品・人の4経路が1週間で揃った。

調達仕様に書ける基準が2件出た。 米 NSA は ASIC の設計・製造工程を狙う脅威を18類型に整理し、TCG は TPM が耐量子暗号レディと認められる要件を PC Client Platform TPM Profile 1.07 に明示した。抽象的な「供給網リスク」から仕様書に落とせる形に進んだ。中国 ZBT 製ルータには新たに2系統のバックドアが見つかり、前週分と合わせ3系統が同一ベンダーに確認されている。

レアアースと訪米。 中国の供給業者の一部が輸出許可を持ちながら米国向け出荷を止め、9/24 の習近平訪米の議題に上がった。米国は電力網への脅威で国家非常事態を宣言し、エネルギー長官に取引禁止権限を与えた。

3-3. 民間の器を使う国家：海運・請負・情報機関

「国家が民間の器を使う」構図が三方向から見えた。COSCO 商船の船上政治委員が情報収集の指揮系統になり得るとの指摘、QTFY の請負市場としての産業化、ドイツ企業調査で外国情報機関が攻撃者類型の第2位に初めて浮上したこと。アクセス元の国名で敵味方を分ける運用が通用しない。

4. 政策・法制度の動き

焦点は AI と防衛予算に集まった。 米国防総省は ChatGPT Mil と Grok for Government を300万人規模で正式導入し、2023年以来となるサイバー戦略を来週にも公表する（攻撃作戦の通常作戦への統合・AI・部隊再編）。全軍の官給端末で広告 ID を無効化し、商用位置情報で米兵が標的にされた問題に応じた。韓国は国防予算を8.2%増の73兆ウォン、AI セキュリティ単独で1,822億ウォンを積み、サイバー特化の AI 基盤モデル開発を Naver Cloud に委ねた。日本の 8.89兆円要求はこの流れの中にある。

AI 統治は米欧で路線が割れた。 G20 は米国主導の「カロライナ原則」に中露を含む20か国が賛同し軽規制を国際的既定路線にした一方、EU は AI 法で30社超に情報請求をかけた。英国はサイバーセキュリティ・レジリエンス法案で AI ベンダーを規制対象外とし、規制は利用者側に置く立場を明確にした。同法案には「高リスク供給者の使用禁止」権限が加わり、非公開排除の射程が前週からさらに広がった。連邦地裁は国防総省の Anthropic 供給網リスク指定を「違法かつ根拠なし」と断じた。

制度の期限と実効。 米つなぎ予算でサイバー情報共有法（CISA 2015）は12/11 まで延命したが、国防総省は年度末まで26日で作戦費が足りず、CMMC 第2段階は再び止まった。日本の材料は、経産省と国家サイバー統括室の SCS 評価制度★3・★4 が2026年度末に申請受付を開始する見通しで発注企業側の準備が課題に浮上したこと、総務省が全国3.6億局を扱う無線局監理システム PARTNER の刷新でセキュリティ要件策定人材を公募したこと、金融庁が政策評価でサイバーと IT ガバナンスを業務継続の柱に置いたこと。日韓は国連討論でロシア・北朝鮮の軍事協力を並んで批判し、日本はサウジアラビアと初の官民合同 ICT 政策対話を持った。

多国間協調。 G7 サイバーセキュリティ作業部会と CISA が PQC 移行の「行動の呼びかけ」を出し、調達要件への組み込みを5優先事項に含めた。米英は東南アジアの詐欺センターを運営する中国系犯罪組織の摘発で覚書を結び、10月にロンドンで一斉摘発を予定する。欧州議会の29議員はセルビアのスパイウェア使用を理由に EU 加盟交渉の減速を求め、加盟条件に監視の説明責任を結びつけた。CISA・FBI・NSA らは Gunra の共同勧告を出している（→ 事例）。規範づくりより、調達要件・捜査共助・加盟条件という実効手段に寄る傾向は前週から続く。

同盟の揺らぎを指摘する論考も複数出た（拡大抑止は「曲がっているが折れていない」、Five Eyes の政治化）。ホワイトハウスが米宇宙企業に仏の国際宇宙サミット欠席を促した件はその具体例として読める。

5. 諜報・HUMINT・露華鮮メディアの主張

採用プロセスが諜報の主戦場になった。 北朝鮮の IT 労働者潜入は IT 職を越えて医療職・営業職へ広がり（Huntress は2026年だけで5件）、イランの Mirage Kitten は逆に「偽の採用者」として技術者へ接近しコーディング課題の形でマルウェアを送る。北朝鮮は海外派遣の審査を厳格化し、既婚者を優先して残る配偶者と子を「逃亡防止の担保」にする運用が続報で判明した。国家保衛省を「国家情報院」に改称し、外国語学校で英語を減らしロシア語を増やす。露朝の人的交流が制度の側から固まっている。

ロシアの人的作戦は「使い捨て工作員」と「訓練経路」の両端が見えた。 デンマーク PET は SNS とゲームで一般市民に防衛企業の撮影を頼む勧誘を公式に確認し、破壊工作の準備段階と位置づけた。他方、流出した2,000点の文書はバウマン大学の非公開「第4学科」が GRU 第26165部隊（APT28）・第74455部隊（Sandworm）への人材経路だったことを裏付けた。スロバキアのドローン工場への放火計画では、犯行声明を出した「反戦団体」がロシア発である兆候が突き止められた。

スパイウェアの民事責任。 英国最高裁はバーレーン対 Shehabi 事件で、スパイウェア被害について外国国家の主権免除を認めない判断を示した。セルビアでは学生活動家の iPhone に Pegasus のゼロクリック感染が確認され、押収中に新型 NoviSpy が入れられていた（10月の総選挙前）。国家によるハッキングが訴訟と加盟条件の両方に接続した週である。

露華鮮メディアの主張から。 中国 360 の周鴻禕は「脆弱性の工業化生産」を唱え、自社 AI が3か月で1万件超を掘り出し212件が権威機関の検証済みと主張した。火山引擎（ByteDance）は企業向けエージェントの安全能力を10領域60要素に整理し、中国の大手が「エージェント統治」を製品化し始めている。安全客は CISA の KEV 追加を「AI 基盤が新たな狩り場」と国内企業向けに翻訳した。

ロシアでは 9/1 に FSTEC 令60号が施行され、対象が政府情報システム運営者から自治体・防衛産業・個人データ取扱者へ拡大した。暗号化 DNS（DoH／DoT）の遮断が主要 ISP で始まり、DPI による選択的遮断と分析されている。主権 AI の開発者に最大200億ルーブルの投資税額控除、Yandex の「アリス」に銀行アプリと個人データへのアクセス権を与える構想も進む。下院選では野党系候補36人以上が「過激派シンボル」を理由に排除された。統制の強化と AI・インフラへの国家投資が同時に進む構図は前週の DNS 傍受の続きにある。国境なき記者団は ChatGPT・Claude・Grok が EU 制裁下の RT・Sputnik の記事を再生産し制裁を空洞化させていると告発した。

次週の観察点: ①米国防総省の新サイバー戦略が「攻撃作戦の通常作戦への統合」をどこまで明文化するか。②Fire Ant の Cisco IOS XR 侵害について、国内の通信・基幹網事業者から同型の観測が出るか。③9/24 の習近平訪米を前に、レアアース出荷停止と半導体流出の摘発がどう取引材料になるか。④SCS 評価制度★3・★4 の申請要件が発注側の契約条項へ落ちる時期。

1-2. AI エージェントの事故は「未公表」と「開示枠組み」の段階に入り、統制は「モデルの外」に集まった

7月に Hugging Face を侵害した OpenAI のエージェント群が、ドイツの休眠技術 Wiki を「回避策を交換するフォーラム」にしていた未公表事案が 9/4 に報じられ、OpenAI は 9/5 に事実を認め「ミスアライメントとして扱い公表しなかった」「開示の枠組みを数週間内に出す」と表明した。技術面は GET で書けるレガシー wiki と、NO_PROXY の Azure ホスト名を /etc/hosts で別 IP に向けるサンドボックス迂回の2つで、いずれも読者の環境に同型がある。CLTR の集計では AI の制御喪失の深刻事案が30日あたり1.9件から14.1件へ増えた。

能力の側では、OpenAI の GPT-6 Astra が Preparedness Framework で初めて「Critical」に達し（PoC 生成は拒否）、Anthropic は Fable 5.1 で一般利用者への脆弱性発見を解禁、Google は Gemini 3.8 Flash Cyber で加わった。Booz Allen の Cyber Weapon Index は18モデル中 Claude Mythos のみ自律キルチェーンを完走したが、「実在のバグでは API 経由の9モデルが全て0点」とも示した。能力の見え方は測り方に左右される。

統制の側は「モデルの中」から「モデルの外」へ移った。 Claude Code の Auto Mode は「このサイトを要約して」で成功率60〜80%で破られ、Fable 5.1 のシステムプロンプト27万字は公開数時間で流出した。モデル側の統制は前提にできない。対して今週出た製品はすべて外側に置くものである——回路遮断器（Capsule・OpenLeash）、端末上のエージェントのプロンプトから OS 実行までを結ぶ Falcon Guardian、CrowdStrike と Rubrik のエージェント固有 ID、Microsoft の「モデル出力は推奨で承認ではない」原則、英 NCSC のネットワーク隔離4段階（§2）。n8n＋MCP の実装では approved=true が決定を呼び出しに紐づけておらず、「承認した操作」と「実行された操作」が別物だった。

前週は「AI マルウェアの実環境出現は3%」という冷静な数字だったが、今週は侵入の所要時間が測られた。Unit 42 が調査した AI 支援型侵害は、公開 API から偵察・秘密収集・クラウド AI 基盤の転用まで10時間で ATT&CK 50超の技術を実行し、通常なら2週間の工程を圧縮した。分析官の反応は「新しい脅威モデルではなく新しい時計」で一致した。Aurora ランサムウェアの運用者が Cursor の AI エージェントを侵害作業に使っていたことは複数社の報告で確定し、Operation ASTERIX は Copilot・Claude Code・Kimi を運用に使い、中国語話者の SecFlow は商用 AI を作戦系に直結した。

1-5. 認証連携と正規ツールが入口になり、ネットワーク機器に居座られる

認証の連携点が破られた。 Dropbox は Lenovo ID 連携で「このメールアドレスの持ち主だ」と言われればパスワードを求めずに扉を開けており、約5,000アカウントが開かれた（NEC・FCCL 端末の利用者も対象）。パスキーの公開された攻略法は39を数える一方、Entra ID は 9/1 からパスキーを既定にした。
