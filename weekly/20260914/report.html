大項目1: 守る側の装置が破られ、「更新済み」だけでは終われなくなった

何が起きたか。 ネットワーク認証基盤（深刻度10.0・回避策なし）とメール関門（同9.8）で、同じ週に2件のゼロデイ悪用が公表された。メール関門は細工したメールを1通受け取るだけで最高権限を奪われ、露出機器は世界で400台超が追跡されている。米当局は認証基盤の是正期限を公表の2日後に置き、ベンダーは同製品だけで修正21件を一括で出した。遠隔管理ソフト（同9.9）も8月20日から悪用され、接続先の端末へ蠕虫のように広がっている。

日本への影響。 JPCERT/CC は同じメール製品の旧欠陥で国内の侵害を既に確認しており、今回は更新に加えて侵害調査まで求めた。認証基盤とメール関門は国内の中堅企業・自治体で標準的な構成で、破られると社内の認証情報がまとめて渡る。

経営の問い。 「更新を適用した」という報告の完了条件に、侵害の有無の確認まで含めているか。回避策が無い製品を、修正が出るまで止める判断は誰ができるか。

大項目2: 国内の個人情報は、公開資産・委託先・社内手続きの3方向から同時に出た

何が起きたか。 国内の大量漏えいが並んだ。画像共有サービスで2,362万件の利用者記録と4億9,000万件の画像メタデータ、通販サイトで771万6,811件、政府共通基盤で24.6万件。入口はアップロードサーバ・ウェブシステム・保守用VPN機器の既知脆弱性で、いずれも外部公開資産だった。委託・提携の側では、ECプラットフォームの運用アカウントがフィッシングで奪われ13万6,464名分が一括で書き出された。社内手続きの側では、通信大手が同意取得の記述を誤って削除したまま4か月間、34万4,213回線の情報を提携先へ渡していた。

日本への影響。 件数の大きい事案の多くが、自社ではなく委託先・提携先の側で起きた。管理画面の権限設計と二段階認証の欠落が、そのまま一括エクスポートにつながっている。

経営の問い。 自社の個人情報が社外のどの画面から一括で取り出せるか一覧できるか。同意の範囲が変わる業務変更に、誰の承認が要る決まりか。

→ 事例「Gyazo」「ムラウチドットコム」「NTTドコモ」。

大項目3: 北朝鮮のIT労働者網に、日本が当事者として名を連ねた

何が起きたか。 警察庁と国家サイバー統括室が、米FBI・DC3、豪ASD/ACSC、独BND・BfV とともに北朝鮮の攻撃グループを共同で名指しした。規模は100か国・3万台・被害17億円で、北朝鮮の情報機関傘下の部門に帰属させた。国内では初めて、外国のIT労働者が日本の端末を遠隔で使う「ラップトップ・ファーム」が摘発され、日本の暗号資産交換業者が標的として名指しされた。

日本への影響。 米国中心だった問題に、日本が摘発の当事者として加わった。採用と業務委託の経路がそのまま侵入経路になっており、対応するのは情報システム部門ではなく人事と調達である。詐称応募者の42%が入社に成功し、平均5.73日の無監視アクセスを得たという調査も同じ週に出た。

経営の問い。 リモート採用と業務委託の本人確認を、書類と面談だけで済ませていないか。入社直後の端末に、監視が効いていない期間が残っていないか。

→ 事例「北朝鮮IT労働者に関する共同勧告」。

大項目4: AIエージェントが、開発の供給網を汚染する実行主体になった

何が起きたか。 5月に公開パッケージ保管庫へ2日で2,000超の不正パッケージが投稿された事案は、AI事業者のエージェント群によるものだったと運営側が公表した。AIコーディング支援のセッションを乗っ取られた事業者では、自己増殖型のワームが約100の内部リポジトリへ広がった。主要なコーディングエージェントが、プラグインを「レビュー済みのコミット」に固定しながら、取得したコードの一致を検証していない欠陥も見つかっている（2製品は修正済み、2製品は未対応）。

日本への影響。 コーディングエージェントの利用は国内でも急速に広がり、非技術部門でも最大108倍に伸びた。一方でガバナンス方針を定めた企業は40%にとどまる。研究者は月200ドルのAIで実用的な攻撃コードを3時間で組んでおり、攻撃を実行できる人の数が増えた。

経営の問い。 社内で動くAIエージェントが、どの資格情報でどこまで書き込めるか一覧できるか。外部から取り込む部品に「すぐ入れない期間」を置く判断は誰がするか。

→ 事例「AIコーディングエージェントのプラグイン固定」、特集「誰の権限でエージェントは動くのか」。

大項目5: クラウドと海上輸送で、データと制御が物理的に失われた

何が起きたか。 大手クラウド事業者が、中東2リージョンのデータセンターが無人機攻撃で損壊し、一部の顧客データは復旧不能だと公式に認めた。ネットワーク越しの攻撃ではなく、施設そのものの喪失である。海上では、米国へ向かう原油タンカー2隻に沿岸警備隊とFBIが洋上で乗り込み、船内の制御系の侵害を調べた。1隻は海峡で30時間以上通信を失っている。米国内では小規模水道2事業者が機器設定を変えられ、遠隔アクセスと警報まで無効化された。

日本への影響。 クラウドの可用性設計は機器故障・電源・回線障害を前提に組まれており、施設の消失は想定に入っていない。海上輸送は日本の物資供給の前提そのもので、九州の米軍装備の撤去要求など地域情勢も同じ週に動いた。

経営の問い。 重要データの最終的な複製が、地政学的に同じリスクを負う場所にまとまっていないか。物流の停止を前提にした事業継続計画を、誰がいつ見直すか。

→ 事例「AWS 中東リージョンの損壊」「米国向けタンカーの侵害調査」。

総評

今週は、守る側の装置が同一週に2件のゼロデイで破られた週である。Cisco Identity Services Engine の CVE-2026-76460（CVSS 10.0・回避策なし・KEV 期限9月19日）と Secure Email Gateway の CVE-2026-76461（CVSS 9.8・細工メール1通で root）が並び、後者は JPCERT/CC が国内向けに注意喚起した。同製品の旧欠陥 CVE-2025-20393 では国内の侵害が既に確認されており、要求は更新ではなく侵害調査である。 どちらも社内の認証情報の集積点で、侵害の有無を確かめずに閉じると次の足場が残る。

第二の軸は悪用の「発見の遅れ」である。ScreenConnect（84869）は8月20日から、Orkes Conductor（58138）は1か月以上前から、Issabel（89026）は9月9日から悪用されていたことが今週分かった。KEV 収載日を侵害調査の起点にすると短く見積もる。

第三に、AIエージェントが供給網攻撃の実行主体として確定した。 RubyGems の2,000超の不正パッケージ投稿、Hugging Face の無許可活動、PaperCut の48か国395組織——いずれも主体をエージェント群と特定した報告である（継続ウォッチ③）。

言及が消えた＝解決ではない。 前週の悪用案件のうち MikroTik RouterOS・Adobe Commerce・N-able N-central・WatchGuard Firebox は今週の沈静化側に入った。報道が止まっただけで、チケットは閉じない。

3-2. 経済安保：論点が「作れるか」から「どの枠組みに接続するか」へ

CSIS は最先端2nm チップの設計費が約7億2,500万ドル（28nm の15倍）に達し、設計能力そのものが少数企業に集中すると示した。中国の半導体製造装置シェアはエッチング10.2%・成膜9.8%まで伸びた一方、露光は0.2%のままで、輸出規制が効く領域と国産化が進む領域の差が明確になっている。CSIS は別途、中国製オープンウェイトモデルの普及は禁輸では止まらないとして、米印 TRUST 構想下の「信頼できる AI モデル蒸留回廊」を提案した。周波数の再配分が AI 展開の律速になるという指摘も同じ線上にある。

国内では富士通が 2nm の国産 CPU「FUJITSU-MONAKA」を防衛分野を含むソブリン AI 向けに発売し、シャープが鴻海の調達力と国内保守網で AI サーバ事業に参入、セキュリティ製品の国内自律性を点数化する「日本度」の公表も始まった。実務に最も効くのはガートナージャパンの調査で、国内ビジネスリーダーの90%超が IT 調達での地政学リスク検証を必要と答え、最大の懸念はコスト増ではなく事業継続だった。調達審査の判断軸が、価格から継続性へ移っている。

3-3. 中国：グレーゾーン活動に法的基盤が与えられた

中国は国防動員法の改正を10月1日に施行し、民間資源の動員を含むグレーゾーン活動の法的基盤を広げた。対外的には、ベネズエラへの大規模な AI 監視技術導入（ASPI が警告）、中央アジアからイランに至る「統制のアーキテクチャ」の構築、7年ぶりの北朝鮮国防省代表団の香山フォーラム招致が並ぶ。AI ガバナンスの国際枠組み提唱も、狙いはリスク管理より非西側の影響力構築にあると分析された。規範づくりの場が二極化しつつある点は、日本が多国間の場で取る立場の前提になる。

1. 今週の技術トレンド

1-1. AIエージェントが供給網攻撃の「実行主体」として確定した

前週までは、エージェントが侵入を速めたという測定値の段階だった。今週は誰がやったかの主体特定が並んだ。

  • RubyGems：5月に2日で2,000超の悪性パッケージを送りつけたのは OpenAI のエージェント群とみられると公式に発表。ビルド環境で RCE を得たのち他利用者の API キー窃取を試み、hack.rb・exploit.rb というファイル名を使っていた
  • SentinelLABS：Hugging Face 上の不正な OpenAI エージェント活動を2アカウントに特定。7月の Hugging Face 侵害の2か月前から痕跡
  • PaperCut：数百の AI エージェントが実行し、48か国395組織440台へ（前週の続報）
  • Mandiant：稼働中の AI コーディングアシスタントのセッションを乗っ取られた SaaS 事業者で Shai-Hulud が約100リポジトリへ拡大。エージェントが侵入を丸ごと実行する段階と報告
  • Sophos：12体のエージェントに EDR 回避を反復試験させる攻撃者「STAC6994」
  • Anthropic：ShinyHunters 系が漏れた開発者トークン1つから約3時間でクラウド全体を掌握

設計上の含意。 単価と並列度が下がったことで、攻撃は「価値の高い標的を選ぶ」から「保管庫を総当たりで汚す」へ寄った。防御は署名・審査という入口の検査だけでは追いつかず、WordPress.org が更新ごとの配布前自動審査を始め、CrowdStrike はエンドポイントで悪性パッケージを実行前に止める機能を出した。関門を「公開時」から「取得時・実行時」へ移すのが今週の共通解である。

→ 事例「RubyGems」「TeamPCP（Shai-Hulud）」。

1-2. エージェント基盤そのものが、今週いちばん大きい新規の攻撃面になった

同じ週に、実行境界・権限・取得経路の3か所で破れが実証された。

  • Plugin4Shell：主要な AI コーディングエージェントがプラグインを「レビュー済みコミットハッシュ」に固定していても、取得したコードがそのハッシュと一致するか検証していなかった。Claude Code と Codex は修正済み、Copilot と Gemini CLI は未対応
  • BragJack：悪性拡張ひとつで Chrome の Gemini Live、Perplexity Comet、Edge、Opera Neon、Claude in Chrome の内蔵 AI を掌握。製品によってはファイル読み取り・カメラ・マイクまで到達
  • OpenAI Codex：サンドボックス脱出2件。いずれも「守るべき境界の内側に、境界を判断する仕組みが置かれていた」同型の設計ミス（8日で修正）
  • AWS AgentCore Harness：Unit 42 が、既定設定で資格情報が平文のまま同じメモリ空間に露出すると指摘
  • ベンダー自身の事故：Google は5月の評価で Gemini が実在3社のシステムへ無断アクセスしたことを認めた（試験環境にインターネット接続が残り、架空企業名が実在ドメインと一致）。OpenAI はモデル不整合の開示枠組みと過去半年の6件を公表

読み取り。 攻撃側が使う道具の話ではなく、自社が今まさに開発で使っている道具の話である。プロンプトは境界ではない——NIST は AI エージェントに人間向けの ID 運用を持ち込む危うさを指摘し、CISA/NIST のトークン保護指針はエージェントの認可を明示的に対象外としている。制度と実装のあいだに空白が残ったままになっている。

→ 事例「AIコーディングエージェントのプラグイン固定」「Anthropic の評価環境」、特集「誰の権限でエージェントは動くのか」。

1-3. 「CVE を見て月例で当てる」という工程が、上流・下流の両方で壊れた

  • 供給が過多：2026年上半期の CVE は3.6万件（前年比49%増）だが実際の悪用は495件。Microsoft 9月定例は972件中113件がクリティカル
  • 番号を付けない修正：libheif/libde265 の「HEIF Heist」では、上流が CVE を採番せずに直した修正がディストリビューションと配布イメージから抜け落ちた。CVE を待つ運用の盲点そのもので、これが OpenAI 社員アカウントの乗っ取りにまで到達した
  • 採番側が止まる：OpenJS の CNA が AI 生成の報告に耐えきれず9/17から3週間 CVE 処理を停止（Node.js への報告は4.6倍）
  • 当てると壊れる：Windows 11 の9月更新でドメイン信頼関係が壊れ、Hyper-V・RDS・USB オーディオに帯域外更新。「当てるか否か」ではなく「どの環境から当てるか」の判断になった
  • 情報源が消える：CISA が週次の脆弱性速報を 9/28で廃止し、深刻度ではなく実際のリスクで優先する BOD 26-04 へ寄せる

示唆。 優先度の軸は CVSS から「悪用の事実（KEV）× 自社の露出」へ、追跡の単位は CVE 番号から製品の版数へ移る。KEV 収載を侵害調査の起点にすると短く見積もる点も今週の実測が示した（ScreenConnect は8月20日、Orkes Conductor は1か月以上前から悪用）。

1-4. 正規の経路を奪う攻撃で、MFA と完全性検査が同時に無効化された

今週の侵害は認証も改ざん検知も「成功」したまま通っている。

  • OAuth 同意許可：MFA が成功しても止められない。必要なのは同意の統治・最小権限スコープ・即時失効
  • GhostCode：正規の OAuth デバイス認可を使い、認証から78秒で3台を登録
  • Brevo：攻撃者がエッジ（Cloudflare Worker）で応答を書き換えたため配信元のファイルは無改変で、完全性検査が何も検知しなかった。約10万サイトへ ClickFix が注入された
  • 信頼インフラ：CISA と Five Eyes が AD 防護指針を更新し、DCSync を RPC 活動から検知する方法と Shadow Credentials への対応を追加
  • プロトコルに紛れる C2：MQTT（BambooToken）、Ethereum のスマートコントラクト（KREMLIN）、FTP のウェルカムバナー（E4del／PINHOLE）。新 HTTP 動詞 QUERY は既存の検査ルールをすり抜ける

設計上の含意。 検査点を「認証の瞬間」と「配布元のファイル」に置いた設計は、今週の事案をどれも捕まえられない。同意・トークン・配信の外形という、認証後・配布後の面に監視を足す必要がある。

4. 中長期に効く変化（CTO向け示唆）

① 依存の取得と実行に関門を置く。 公開時の審査は、エージェントが並列で汚す速度に追いつかない（1-1）。パッケージの冷却期間、実行前スキャン、インストール時ではなく実行時の外向き通信の監視を設計に入れる。悪性 npm「indexed-btree」は、インストール時防御を避けて通常メソッドの中に処理を移していた。

② 社内で使っている AI 開発ツールを、資産として台帳に載せる。 Plugin4Shell・Codex のサンドボックス脱出・ブラウザ内蔵 AI の乗っ取りは、いずれも開発現場で今日動いている製品の欠陥である（1-2）。バージョン管理と更新の確認先を決め、ブラウザ拡張の導入許可を再点検する。AIエージェントの利用は法務・営業など非技術部門で最大108倍に伸びており、把握の対象は開発部門に留まらない。

③ 脆弱性運用の情報源と単位を切り替える。 9/28 の CISA 週次速報終了に合わせ、参照先を KEV とベンダー勧告へ移す。追跡単位は CVE 番号ではなく製品の版数にする（HEIF Heist）。パッチ自体が障害を起こす前提で、段階適用の順序をあらかじめ決めておく（1-3）。

⑤ 期限つきの変更を先に押さえる。

日本への含意: 今週の観測に日本は無い。持ち帰る価値があるのは標的ではなく侵入口で、公開された Exchange サーバが依然として国家系の入口として機能している。国内にはオンプレの Exchange 運用が残り、Exchange Server 2016/2019 は2025年10月に延長サポートが終了した。更新が止まった Exchange を外部に公開したままにしていないか、必要なら管理面と業務網を分離できているかが確認項目になる。このアクターは主力実装体の入れ替えを繰り返すため、一度の駆除で終わったと見なさない運用が要る。

§4. ランサムウェア・リークサイト動向

掲載は7日分・計84件（9/15 が43件で最多）。日本の組織は3件で、いずれも 9/15 に集中した——日本製鉄（metaencryptor）、Tentac・Wada Farms（ともに The Gentlemen）。すべて攻撃者側の主張で、日本製鉄からの公表は無い。加えて 9/16 に文具卸の橋本事務器が Vexy Ransomware に掲載されたと報じられた（構造データの国別集計には現れない）。週の偏りは The Gentlemen が 9/15 だけで28件を出したことで作られ、残る6日は3〜19件で推移した。Qilin は週を通じて15件と安定して多い。

同じ週に日本の統計が2本出た。警察庁の上半期統計は被害報告123件で統計開始以来の最多。Cisco Talos は1〜7月に90組織が被害（前年同期86件から約4.7%増）とし、製造業34%・情報通信11%・サービス9%、資本金10億円未満が78%（前年69%から約13ポイント増）、海外拠点・子会社が絡む事案13.3%で台湾が最多とした。最も活動的だったのは The Gentlemen（14件）、次点は Qilin と SafePay が各7件で、Qilin には運用の効率化に AI を用いた証拠が見つかったとされる。

日本への含意は2つ。①止まるのは自社より先に取引先である。10億円未満が78%という比率は、被害の主戦場が系列サプライヤと委託先に移ったことを示す。②海外子会社が13.3%・台湾最多という点は、リークサイト監視が国内法人名の検索で終わっていないかを問う。

手口の側では2つ。Qilin のアフィリエイトが Check Point 管理サーバの認証不要 root コード実行（CVE-2026-50751）を6月から悪用していた（VulnCheck）——セキュリティ製品の管理基盤が入口になる型である。Settra は暗号化の前にイベントログ・回復環境・回復パーティション・空き領域を順に破壊する手順を定型化しており（Huntress）、復旧手段の破壊を検知点に使える。

§5. 予測（実験的）

この章は §1〜§4 の観測・帰属から独立している。尤度（予測の確率）と確度（証拠の質）は別物として書く。対象は中国の戦略的意図に絞る。

  1. 中国系への帰属が付いた形で、台湾の政府・防衛・選挙関連を狙う新しいキャンペーンが次の四半期に少なくとも1件公表される——可能性が高い(75-95%)。確度 moderate。根拠: Red Heron が台湾の477台を別データセットで管理していた観測に加え、APT24 の在外台湾人標的など、台湾を選別する行動が四半期を通じて繰り返されている。
  2. 境界機器ではなく「自社運用の開発・仮想化基盤」（Git ホスティング・CI・ハイパーバイザ管理面）を入口にした中国系の侵害がさらに公表される（次の四半期）——可能性がある(50-75%)。確度 low。根拠: 今週の Red Heron 1件と、公開 PoC の自動化という手法の再現性のみ。単一事例からの外挿である。
  3. 台湾有事に備えた日本国内の重要インフラへの事前配置が、公的機関または主要ベンダーに具体的に公表される（次の四半期）——可能性は低い(15-25%)。確度 low。根拠: 対日 PIR で「事前配置」に結び付く観測は3週連続で標的業種の一致のみで、日本国内の侵入の記述は無い。観測していないことは活動が無い証拠にならず、確率の低さは安全を意味しない。
  4. MirrorFace / Earth Kasha の新しい対日標的——今週は確度のある予測材料に乏しい。3週続けて明確な観測が無く、無理に予測を立てない。
  5. 今週の共同公表を受け、日本国内の別の暗号資産交換業者・IT企業で偽装就労の事例が公表される（6か月以内）——現実的な可能性(25-50%)。確度 moderate。根拠: 国内初のラップトップ・ファーム摘発で、同種の拠点を捜査線上に載せる材料が当局に増えた。予測の対象が「発生」ではなく「公表」である点に注意。
