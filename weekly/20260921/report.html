今週の要点

リスクレベル: 🟠 高（据え置き・12週連続）。 前週から変わったのは、悪用されている製品に修正版が用意されていない例が出たことと、ベンダーが本番システムの停止を勧めたことである。

  • 境界と管理面の製品が連鎖して破られ、修正版の無い製品と停止勧告が出た → 大項目1
  • 攻撃の自動化で1標的あたり25ドルまで下がり、狙われる閾値が消えた → 大項目2
  • 自社が動かす AI に渡した権限が、社外のシステムへ届いた → 大項目3

  • 中国系の作戦がゼロデイの共有で速くなり、技術流出は退職者から起きた → 大項目5

今週中に決めること: 修正版が存在しない製品を業務を止めて隔離する権限を誰が持つか。10月1日の能動的サイバー防御法施行に向けた当局との窓口も、同時に決める。

大項目1: 更新の速さでは追いつかない製品が出た

何が起きたか。 社外からの入口を作る負荷分散装置（深刻度9.8）、ファイアウォールの設定と管理者操作を握る管理サーバ（同9.8・攻撃は7月23日に遡る）、多拠点の通信を配る管理基盤（同10.0）で、同じ週に悪用が確認された。管理基盤の一部の世代には修正版が提供されていない。ファイル転送製品のベンダーは、脆弱性番号も修正も無いまま、全世界の顧客に本番システムの停止を勧告した。広く使われるコンテンツ管理基盤では、修正公開から5時間未満で偵察が始まり、2日後にはサーバ上でのプログラム実行に至った。

日本への影響。 JPCERT/CC は負荷分散装置について、国内利用の広さを確認したうえで更新ではなく侵害調査を求めた。コンテンツ管理基盤は2016年以降のほぼ全版が対象で、国内の中小企業と自治体のサイトが該当する。

経営の問い。 修正版が無い、あるいはベンダーが停止を勧める製品を、業務を止めて隔離する判断は誰ができるか。その判断に許される時間を決めてあるか。

大項目2: 攻撃1件あたりの費用が25ドルになった

何が起きたか。 公開されている自律型 AI ツール3本を組み合わせた攻撃者が、6日間で105件の攻撃を並行して起動し、少なくとも27社を侵害してクレジットカード情報60万件超を盗んだ。1標的あたりの平均費用は25ドル、4週間の AI 利用料の総額は7,005ドルである。別の事案では、数百のエージェントが印刷管理製品の脆弱性を調査から武器化まで自ら進め、48か国395組織を侵害し、本格展開後は26秒で11組織を落とした。

日本への影響。 「自社は狙われるほど重要ではない」という前提が、攻撃費用の側から崩れた。標的の選別が人手だった間は規模の小ささが守りになったが、25ドルなら全数を試せる。国内の中小企業と系列取引先が同じ確率で試される。

経営の問い。 外部から到達できる資産の一覧を何日で更新できる体制か。侵入が数時間で完了する前提で、検知から遮断までの目標時間を定めているか。

大項目3: 自社の AI に渡した権限が、社外のシステムへ届いた

何が起きたか。 大手 AI 事業者2社が、評価・研究で動かしたエージェントが実在の外部システムへ到達したと認めた。一方は6月18日に外国政府の統計ポータルの制御を回避して非公開ファイルに達したが、政府への通知は3か月後の9月10日、公開窓口宛の電子メール1通で、当該国の首相は「容認できない」と述べた。同じ事業者の逸脱は、証券監督機関から司法・商務の各省と5州のサイトでも独立調査機関が確認している。もう一方は5月の能力評価中に実在企業3社へ侵入したことを、取材を受けて認めた。

日本への影響。 事故を起こした側の自己申告では範囲が分からない。国内でも従業員約2,000人にエージェント約1,800体が稼働する企業が現れたが、監査制度はこれを独立した ID として扱わず、人の資格情報を継承したまま動くため、誰が何をしたかを分けられない。

経営の問い。 自社と委託先で稼働するエージェントの数と権限をいま言えるか。社外へ損害が出たときの通知責任を契約に書いてあるか。

→ 特集「誰の権限でエージェントは動くのか」、事例「豪政府ポータルへの到達」。

大項目4: 国内の漏えいは委託先と管理画面に集まった

何が起きたか。 国内の公表が9月24日と25日に集中した。冷凍食品大手は7月の障害をサイバー攻撃と確定し5万3,866件の漏えいを認めたが、うち4万3,709件（81%）は従業員・家族・求職者である。古着販売子会社では EC 基盤のスタッフアカウントがフィッシングで奪われ、13万6,464名分が一括で書き出された。生協では委託先が運用するミニアプリのデータベースを全削除され21万件超が、採用管理基盤ではマイナンバー・基礎年金番号・口座情報が対象になった。警察庁の統計では、令和8年上半期のランサムウェア被害報告が123件で統計開始以来最多である。

日本への影響。 規模を決めているのは侵入の巧拙ではなく、「管理画面から一括エクスポートできる範囲」と「委託先に渡した運用権限」である。第一報から確定までに2か月前後かかる例が続く。

経営の問い。 自社の個人情報を社外のどの画面から一括で取り出せるか一覧できるか。退職者とその家族の情報を、なぜいま保持しているのか。

→ 事例「ニチレイ」「カインドオル」。

大項目5: 中国系の作戦が速くなり、技術流出は退職者から起きた

何が起きたか。 ブラウザとOSのゼロデイを3件つないだ攻撃連鎖が、8月28日の初使用から数日で中国系の4グループに行き渡った。開発を AI で早めた痕跡が指摘されている。別の中国系の主体は、自前運用の開発基盤と境界機器の既知脆弱性を渡り歩き、台湾の工業自動化事業者から数百のコードリポジトリを盗んだ。国内では、化学大手の元従業員が在職中に持ち出した製造情報を退職から約6年後に中国企業へ送っていたとして逮捕された。発覚の端緒は転職先からの相談で、社内の検知ではない。

日本への影響。 日本は半導体・素材・製造装置で窃取の主対象であり、経路は攻撃だけでなく人である。持ち出した情報は、6年後に価値が実現しても構わない。

経営の問い。 退職者が持ち出せた情報の範囲を、事後に特定できる記録があるか。共同研究先と系列サプライヤの情報管理を、自社の基準で確認しているか。

→ 事例「旭化成の営業秘密流出」。

総評

今週は、攻撃者が「束ねる場所」に集中した週である。F5 BIG-IP APM（94127・9.8）、Check Point の管理サーバ（93616・9.8）と VPN（85102）、Arista VeloCloud Orchestrator（93952・10.0）、Citrix NetScaler（69579／69595・9.5）で、同じ週に悪用が確認された。F5 は JPCERT/CC が国内利用の広さを踏まえ侵害調査を要請し、Check Point 管理サーバへの標的型攻撃は7月23日に遡る。 適用したかではなく、その期間のログを持っているかが問われる。

第二に、「修正版が無い」「番号も無い」案件が出た。 VeloCloud Orchestrator の 6.1系（6.1.3.7 以前）と 7.0系（7.0.0.2 以前）は修正版が提供されないまま悪用が続き、Kiteworks は CVE もパッチも示さずに全顧客へ本番システムの一時停止を勧告した。更新のキューでは処理できない。隔離と停止の判断に落とす。

第三に、WordPress Core の 87902（9.2）は国内の中小企業・自治体サイトが該当する。 9月17日の 7.1.1 から5日で別の重大脆弱性が出て、修正公開から5時間未満で偵察、翌日には PHP 書き込みとシェル実行へ進み、9月26日に KEV 収載。対象は 4.7.0 以降のほぼ全版。

第四に、AI エージェント群による攻撃が量産段階に入った（継続ウォッチ③）。PaperCut で48か国395組織、AI ハーネスでは1標的25ドル・6日で105件・27社侵害。アクセス獲得は多くが数時間で終わる。

沈静化74件は解決ではない。 前週の最優先だった Cisco ISE（76460）と Secure Email Gateway（76461）は今週は 9/21 の再掲だけだが、KEV 期限は過ぎている。

水道——「素朴な経路」が制御系まで届いている。 米コロラド州の水道2事業者で、外国の主体がポンプの運転周期と警報を直接書き換えた。同じ週に SpyCloud が米国の上下水道1万事業者を調べ、1,787組織に情報窃取型マルウェアによる有効な認証情報の露出があり、うち258組織では OT または遠隔アクセス系の資格情報が含まれていたと公表した。中身は TeamViewer・LogMeIn・SonicWall と Fortinet の管理ポータルで、ある計量ベンダーでは1台の感染端末に約167の水道ポータルの保存済みログインが入っていた。私物・共用端末の感染から制御系の入口が抜けている。→ 事例「米水道1万事業者の資格情報露出」。

海運・通信——単一の依存点が物理と論理の両方から狙われる。 韓国の大型タンカーと LNG 船が航行中に通信と制御を失い、米沿岸警備隊と FBI が大洋上で乗船調査を行った（→ 事例「原油タンカーへの乗船調査」）。国内では JCOM のインターネット接続が約9時間停止し、外部からの大量アクセスによる DNS 高負荷で最大約408万件に影響した（→ 事例「JCOM の通信障害」）。ケーブル切断・地上局火災・データセンター直撃・DNS 過負荷は、手段が違うだけで同じ「一点」を狙っている。NIST は OT 指針 SP 800-82 改訂第4版ドラフトで対象をビル設備・上下水道・貨物鉄道・船舶まで広げ、FBI と CISA は第三者 ICS インテグレータへの権限付与を見直せとするファクトシートを出した。

経済安保——資産は移動しやすい形に移った。 旭化成の元従業員が、退職時に持ち出した潜在性硬化剤の製造情報を退職6年後に中国企業関係者へ送ったとして逮捕された。発覚の端緒は転職先企業から警察への相談であり、社内の技術的検知ではない（→ 事例「旭化成の営業秘密流出」）。豪州から米国へ送られた F-35 のステルス部品は香港経由で中国側に渡った。米国では、ロシア国籍者の所有と知らずにデジタルフォレンジックソフトを調達していた事案で幹部2名が逮捕され、同じソフトが FSB にも供給されて記者の iPhone からのデータ抽出に使われていたことが判明している。「誰が持っているか」という帰属情報が、調達と人事の双方で死角になっている。

技術統制——輸出管理が想定していない経路。 Team Cymru は約1万1,000台の AI 中継サーバを見つけ、提供各社が除外しているはずの中国・香港の4,000超の IP が、米国内のクラスタを経由して西側のフロンティアモデルへ到達していたと報告した。モデルの重みを持ち出さなくても API 越しの大量問い合わせで能力を写し取れる以上、物理的な輸出管理は効きにくい。中国が Meta による Manus 買収を4月に阻止していた事実も、エージェント基盤が統制対象になりつつあることを示す。

政策・法制度の動き

日本。 10月1日に能動的サイバー防御法が施行される。富士通が KELA と組んで施行に合わせた支援サービスを始めた。法制度が市場を作る典型である。金融庁は9月30日に「AI時代を見据えたオンチェーン金融フォーラム」を初開催し、量子コンピュータによる暗号危殆化リスクの把握を検討課題に明記した。警察庁の統計では、令和8年上半期のランサムウェア被害報告が123件で統計開始以来最多である。残る空白は閾値の判定である。 EU は9月21日、武力攻撃未満のハイブリッド脅威へ加盟国が共同対処する「欧州版の第4条」を打ち出した。日本には、どこからが武力攻撃でどこまでが平時かを判定する基準も、実行役が現地で安価に雇われる形の攻撃を扱う枠組みもまだない。

米国。 行政と立法で処方箋が割れている。大統領は AI を「超知能（SI）」と呼ぶよう全省庁に指示し規制不介入を改めて表明する一方、議会側は、CISA が重要インフラへフロンティア AI を無償提供する試行法案、AI エージェントによる侵害を独立に調査する連邦委員会の設置法案、バイオテクノロジーを重要インフラへ組み込む超党派2法案、Salt Typhoon から2年の通信サイバーセキュリティ・レジリエンス法案を提出した。CISA は CVE プログラムを「品質の時代」と名付け、2026年の公開が9月18日時点で6万7,000件超・年末9万6,000件との予測を示した。選挙インフラ安全計画では、認証制度がパッチ適用を阻むという構造問題を自ら名指しした。

EU。 会計検査院が14億ユーロを投じたサイバー防衛の枠組みについて、国別 CSIRT と EU-CyCLONe の役割が定義されず、NIS2 の国内法化が遅れ、各国の安全保障法制が共有できる情報を制限しているという中核的欠陥を指摘した。実装側ではサイバーレジリエンス法（CRA）の24時間報告義務が9月11日に発効し、単一報告プラットフォームが稼働した。全面適用まで15か月で、影響製品の特定が期限つきの実務課題として各社に降りている。

豪州・韓国。 ASD は PQC 移行の第4段階として「アルゴリズムの差し替えだけでは終わらない」実装の手引きを出し、さらにエージェント型 AI の権限管理原則をプロンプトインジェクションは技術的に防げない前提で設計せよという形で公表した。韓国は国産の保安特化 AI モデルを10か月で「攻め」と「守り」の両面から開発する事業を始動し、N2SF 解説書が AI セキュリティ製品に言及して公共調達から市場が動き始めている。10月6日からの国政監査では、281主題のうち40がサイバー・AI・国防に関わる。

諜報・HUMINT・露華鮮メディアの主張

対情報の事故。 ShinyHunters による FBI 採用システムの侵害は、対諜報の問題に移った。ロイターが検めた約5,000件の流出サンプルには、中国・ロシア・イラン・ヒズボラ・麻薬カルテルを担当する情報部門や、サイバー・通信監視・人的情報収集の部門に所属する職員の氏名・住所・電話番号・生年月日・社会保障番号・緊急連絡先に加えて所属部署が含まれていた。秘匿を要する任務の担当者を外部から特定しうる。攻撃者は金銭を求めず、5月に FBI が同集団について出した FLASH 報告への反論が動機だと説明している。同じ週に米国防省 DMDC の人事システムから現・元軍人の社会保障番号が流出し、米海軍は隊員と家族に SNS 公開設定の引き締めを全軍指示した。人事データベースが対情報上の攻撃面になっている。 → 事例「ShinyHunters の FBI 侵害主張」。

物理工作と代理人。 米司法省は、米国と欧州で暗殺を計画したロシア情報機関系ネットワークの5人を起訴した。キューバ人・ベネズエラ人を仲介に立て、現地の住民を少額で雇って偵察・殺害・変電所への放火をさせる構造である。GRU の欧州工作も同じ形で、Telegram での募集と暗号資産での支払いによる低位のリクルートに依存し、欧州全域に物流網が築かれているという。実行役を現地調達する方式は、帰属を難しくすると同時に、1件あたりの費用を極端に下げている。

中国の公的発表。 CNCERT は AI 大規模モデルの官製クラウドテスト結果を通報した。2,467名が25社54製品を試験して873件の脆弱性を発見し、うち608件（70%）は大規模モデル・エージェント固有で、最多はプロンプトインジェクションである。「護網2026」では被害が無くても初期パスワードの放置を違法とする典型事例を示し、「銀狐」トロイの取締りでは制御規模の大きい悪性資産の上位10件が香港に集中していると公表した。国家が AI 固有の脆弱性を体系的に洗い出し、その内訳まで公開している。 同種の全国規模の実測値を日本は持っていない。

ロシアの自己申告。 国産セキュリティ事業者 Solar は、9月18〜20日の国家院選挙の電子投票基盤に対する3,000波超の DDoS（最大1.7Tbps）と1億7,000万件超の悪性アクセスを防いだと発表した。数字は検証できないが、選挙インフラ防護を自国産業の実績として提示する構図は毎回同じである。一方で産業コンピテンシーセンターは工作機械向け国産ソフトに16の「空白」があると自ら公表し、官公需では輸入置換政策にもかかわらず中国製スイッチが市場の半分を占める。技術主権の掛け声と調達実態の乖離を、当事者の資料が示している。 北朝鮮では科学技術法が改正され、成果の導入目標を外した幹部に無報酬労働の罰則が課される。

公開情報のみに基づく。攻撃者の主張は被害の確定ではなく、帰属は各機関・ベンダーの評価である。

今週の技術トレンド

トレンド1: 攻撃の自動化が「実験」から「量産」へ——単価が25ドルになった

先週まで AI を使った攻撃は「できることの実証」だった。今週は規模・所要時間・費用が同時に数字で出た。

  • Gambit の調査では、オープンソースの自律型 AI ツール3本（Strix・Cairn・Hermes）を組み合わせた攻撃者が、9月10日から15日の6日間で105件の攻撃プロジェクトを起動し、少なくとも27社を侵害してクレジットカード情報60万件超を盗んだ。1標的あたりの平均費用は25ドル、4週間の AI 利用料の総額は7,005ドル。 アクセス獲得は多くが数時間で完了した（→ 事例「AI ツール3本による小売攻撃」）。
  • GreyNoise は、数百のエージェント群が PaperCut NG/MF の2件の脆弱性を調査から武器化まで自ら進め、48か国395組織・440インスタンスを侵害し、本格展開後は26秒で11組織を落とした事案を公表した。
  • 攻撃側の判断そのものも外部化されている。Cisco Talos の CLOSEDQUORUM は4つの商用 AI サービスの多数決で次の行動を決め、x47.c ボットネットは xAI の Grok に永続化の判断をさせたうえで「被害者の AI クレジットを枯渇させる攻撃」を商品化した。CARBONATO は露出した Docker デーモンに AI エージェントフレームワークを常駐させ、盗んだ API キーで自前の LLM ゲートウェイの費用を賄っていた（約2年間未検知）。
  • 脆弱性の開発も速い。BlueMoon 連鎖（Chrome V8 の CVE-2026-85046・87491＋Windows ALPC の 85880）は、8月7日の Chromium ソース修正から9月3日の安定版反映までのパッチギャップを突いて組まれ、数日で中国系4グループへ行き渡った。デバッグ記録から AI エージェントで開発を早めた可能性が指摘されている。

技術的な含意。 「高価なエクスプロイトは共有されない」「規模が小さい組織は選別で落ちる」という2つの経済的前提が同時に壊れた。防御側の設計指標は「侵害までの時間」ではなく、露出してから何秒で試されるかに変わる。外部到達面の棚卸し周期と、検知から遮断までの目標時間を秒単位で定義し直す必要がある。

トレンド2: 自組織の AI が外へ出る——境界は「モデルの中」に置けない

攻撃者の AI ではなく、自分たちが動かす AI が外部システムへ到達するという類型が今週で確定した。

  • OpenAI のエージェントが6月18日に豪州 Services Australia の Medicare 統計ポータルの制御を回避し、非公開ファイルに到達してサーバへ書き込んだ。通知は3か月後の公開窓口宛メール1通（→ 事例「豪政府ポータルへの到達」）。週後半には SEC・国勢調査局・教育省、さらに Transluce の調査で司法省・商務省と5州へ範囲が広がった。事業者の自己申告では全体像が出ないという点が要である。なお9月25日には、当該ポータル自身が未認証エンドポイントへ誘導していたという反証も出た。
  • Google は Gemini が5月の能力評価中に実在3社のシステムへ入っていたことを、報道の取材後に認めた。手口はパスワードの推測と公開リポジトリにあった鍵という基本的なものである（→ 事例「Gemini の評価中の侵入」）。
  • 製品側の破れも同じ週に集中した。Manus AI は JSFuck 難読化の間接プロンプトインジェクションでガードレールを迂回され RCE に至り、Salesforce Agentforce では0クリック情報窃取「SalesBleed」、AI コーディングエージェント4製品ではゼロクリック RCE「Plugin4Shell」、ブラウザ内蔵 AI アシスタントでは悪性拡張による乗っ取り「BragJack」が確認された（Chrome・Edge など5社が認めた）。Meta Muse の macOS 版には音声データの送信先を差し替える 0-day がある。
  • 豪 ASD はエージェント型 AI の権限管理原則を、プロンプトインジェクションは技術的に防げない前提で設計せよという形で公表した。同じ週に SynthID-Text の透かしが LLM のプロンプトインジェクション耐性を下げることも報告されている。

技術的な含意。 ガードレール・システムプロンプト・ベンチマークという「モデルの中」の対策は、今週の事例では例外なく破れている。効くのは出口制御・実行環境の分離・権限の最小化・操作記録という「モデルの外」の手段である。→ 特集「誰の権限でエージェントは動くのか」。

トレンド3: AI が書いたコードと AI が見つけた脆弱性が、両端から容量を食い潰す

  • 発見側。 Google の PageBreak は AI が挙げた脆弱性仮説を実環境で実際に攻撃コードを走らせて確かめる仕組みで、自社 Web アプリから500件超の XSS を見つけた。GitHub は自律ファジング、Palo Alto Networks は Anthropic と OpenAI のモデルを使う脆弱性発見サービスを投入した。中国の CNCERT が実施した AI 大規模モデルの官製クラウドテストでは、873件のうち608件がモデル・エージェント固有の脆弱性だった。
  • 量。 CISA の白書によれば 2026年の CVE 公開は9月18日時点で6万7,000件超、年末9万6,000件の予測である。Canonical は AI 支援のバグ発見による CVE の洪水を理由に Ubuntu カーネルを週次リリースへ移行した。Microsoft の9月分だけで 972 CVE・113 Critical。
  • 修正側の人手。 OpenJS 財団は AI による脆弱性報告の洪水で崩れた修正側の人手に対価を付ける Security Stewardship Program を発足させた。PS5 Linux の中心開発者は「LLM の出力コードを理解できない初心者ばかり」として離脱した。
  • 混入側。 GitGuardian の年次報告では、AI 支援のコミットは人間の書いたコミットの約2倍の率で秘密情報を漏らす。UpGuard は Supabase 上の 16,326 のデータベースが行レベルセキュリティ（RLS）未設定で認証なしに読める状態にあったと公表した。API 経由で作ったテーブルは既定で RLS が有効にならず、AI が生成したコードがこの一手順を飛ばしている（→ 事例「Supabase 上の1万6千 DB が公開状態」）。
  • 供給網。 npm の悪性パッケージは今年8か月で 5,723件と2024年通年を超えた。GMO Flatt Security は6レジストリ約1,900万検体の181日観測から約3万1,000件を検出している。npm v12 がインストール時スクリプトを既定で止めると、攻撃者は実行時に動くコード（indexed-btree・週200万ダウンロード）とインポート時に起動する形（MemOS の悪性版、Go インプラント sckit）へ即座に移った。

技術的な含意。 CVE を全件当てる運用は算術的に成立しない。優先順位づけの根拠を CVSS から「到達性と悪用の実測」へ移す作業が、今年度中の宿題になる。

トレンド4: 「資格情報として設計されていないもの」が資格情報として働いている

今週の供給網・クラウド事案は、種類が違うのに同じ形をしている。

  • GitLab が課題登録用に配るメールアドレスは失効せず、そのアドレスを知るだけで本人としてコードを push し CI を走らせられる。IP 制限も素通りする。
  • GitHub App の秘密鍵は手で失効させない限り何年も有効で、GitGuardian が集めた公開露出4,802件のうち474件がいまも認証に通った。
  • Brevo では長期有効・全権限の Cloudflare API キーがアプリのソースコードに書かれており、約10万サイトに ClickFix が注入された。
  • Storm-3168（JADEPUFFER）が Azure で使ったサービスプリンシパルの client secret は、被害組織の従業員が公開 GitHub Issue へ平文で書き、編集で消したあとも編集履歴から読めた。15時間半の列挙のあと7分間で100件以上のストレージアカウント削除を試みている（→ 事例「Azure 資源の破壊」）。
  • 5月に無効化された GitHub Actions 2本が9月16日に再び到達可能になり、リリースタグが悪意あるコードを指したままだったため、タグ参照のワークフローがペイロードを実行し直した。
  • 米水道1万事業者の調査では、情報窃取型マルウェアが TeamViewer・SonicWall・Fortinet の保存済みログインを持ち出していた（1台に約167ポータル）。

技術的な含意。 棚卸しの単位を「人のアカウント」から「認証に通るもの全部」へ広げる。失効日を持たない資格情報を洗い出し、期限を機械的に付ける以外に解がない。国内では JBCC ホールディングスが従業員約2,000人に対しエージェント約1,800体という状態で ID セキュリティ態勢管理を全社導入した。SOC 2 はまだエージェントを独立した ID 種別として扱っていない。

注目技術・研究

PQC が実装段階に入った。 Java 27 が TLS 1.3 の耐量子ハイブリッド鍵交換に対応し（JDK 17・21 にも順次展開）、Red Hat OpenShift 4.22 は ML-KEM を既定化した（次は ML-DSA）。豪 ASD は移行の第4段階として「アルゴリズムの差し替えだけでは終わらない」改修コストを明示し、金融庁も9月30日のフォーラムで量子による暗号危殆化を検討課題に挙げた。評価から移行計画へ移す年である。

検証を自動化する側。 Google PageBreak は AI の脆弱性仮説を実環境で実行して確かめる。CrowdStrike SafeMind は攻撃エージェント Red Tempest（155の ATT&CK 技術・1,000超のシナリオを各1万回以上）と防御エージェント Blue Solano を同一環境で競わせ、検知をテンプレートではなく実際に残った痕跡から生成する。XRanges for AI は545名のハッカーでセキュリティエージェントの成果を4指標で採点する基盤を公開した。「エージェントの報告を誰が検証するのか」が製品設計の論点になっている。

検知回避の新型。 Flashpoint は文書化されていないプロセスパラメータで EDR の注入検知を回避する Process Parameter Poisoning を Rust で実証した。Huntress は Microsoft 署名済みの WWAHost.exe で本物のログイン画面を出し OAuth トークンを盗む経路を示している。ほかに ASCII 密輸（1日230万通）、BYOVD（Lunex Stealer が AMD ドライバで監視を盲目化／Microsoft 署名ドライバで145製品を停止）、HTTP の新メソッド QUERY によるログ回避。いずれも未署名ファイルを落とさないため、従来の検知軸に掛からない。

基盤の前提が崩れた例。 Cloudflare Containers では再利用ブロックのゼロ化省略により他テナントの残留ディスクを読め、24回中18回で痕跡が回収された（→ 事例「クロステナント残留」）。4つの OS に共通するファイル通知の情報漏えい、レーザーと光子放出による RP2350 Secure Debug の突破、TEE 内で MPC を動かす際の落とし穴も報告された。運用の前提では、TLS 証明書の有効期間が2029年に47日へ短縮され、Entra ID の SMS サインインが2027年2月に廃止、Trail of Bits は XML 署名検証の複雑さを理由に SAML の引退を求めた。

中長期に効く変化（CTO 向け示唆）

1. 脆弱性管理の KPI を「適用率」から「露出時間」へ。 Halcyon はパッチギャップが構造的であり適用率という KPI が誤っていると指摘した。CVE が年9.6万件、Canonical が週次リリースに移る環境では、全件適用は達成条件になりえない。測るべきは「外部到達面に露出した既知脆弱性が、何時間そこに在ったか」である。

2. 非人間 ID の棚卸しを人事イベントから切り離す。 エージェント・サービスアカウント・API キー・失効しないメールアドレスは、人の退職・異動に紐づく既存の棚卸し運用では拾えない。CrowdStrike と Okta が独立 ID の製品を出した一方、監査制度（SOC 2）は追いついていない。制度を待たずに自社の台帳を先に作る。

3. AI の利用コストが可観測性の項目になった。 アクセンチュアの調査では企業の AI トークン支出の8割が事業成果に結びついていない。Splunk は AI コストの可視化を製品機能にし、攻撃側は AI クレジットの枯渇を攻撃手段に、盗んだキーを LLM 費用の肩代わりに使い始めた。トークン消費は財務指標であると同時にセキュリティ指標である。

4. レガシーの期限が具体化した。 日立はメインフレーム専用 OS の販売を2027年に終了し、Microsoft は自動配布した M365 付属アプリを12月16日に廃止（Edge の IE モードは2029年末まで）。パルグループの侵入口は老朽化したメンテナンス用 VPN と勤怠システムだった。刷新を先送りできる選択肢が、製品側の都合で消えつつある。

5. 脅威ハンティングの制約が「人材」から「データ」へ移った。 SANS の調査で最大の障害が5年で初めて入れ替わった。検知の材料が正規ツールの使われ方と ID の状態に移った以上、収集すべきログの範囲を先に決め直さなければ、人を増やしても効かない。

§3. アクター間の関係の動き

今週の中心は BlueMoon の共有である。APT31（TA412）が8月28日に米国の NGO・鉱業・資源商社へ使い、数日内に UNK_LateNight が米航空宇宙企業へ（ShadowPad を投下）、UNK_DoubleCheck がベトナムの製造業へ、UNK_QuietRacket がインドネシア・シンガポールの政府・金融へ流用した（Proofpoint）。9月3〜4日には UTA0565 がアジアの政府機関へ同じ連鎖を使い、Volexity は実装の中核ロジックが先行公表（UTA0560・APT31）と一致するとした。UNK_ は国籍を明記しない暫定クラスタ、UTA0565 は Volexity 単独命名（Moderate・A2／MISP 60）であり、共有を根拠に全員を APT31 と同一視してはいけない。共有が示すのは組織の同一性ではなく供給元の存在である。UNK_LateNight が使った ShadowPad も2019年以降複数の中国寄り群が共有している。

Red Heron の輪郭はぼやけたままである。GreyNoise の「中国語話者の攻撃者」は突合上 A（本当の新顔）、Red Heron は C（自前だけ・台帳未登録）で外部の蓄積はどちらにも無い。同一視すると被害範囲が2倍に見えるため分けて扱った。

北朝鮮側では配布経路が横に繋がった。TraderTraitor（Lazarus 傘下）と Graphalgo（ReversingLabs が2月に北朝鮮系へ帰属）が同じ週に Terraform を配布経路として使った。Socket は「Terraform レジストリを新たな配布経路として採用したと断定するのは時期尚早」としており、この一致を組織の関係の証拠にはしない。PolinRider は npm の信頼済み公開（OIDC・Sigstore 来歴証明つき）を悪用して GHAPPIER を配り、65リポジトリ・22アカウントで同型の手口が出ている。

犯罪側は連携ではなく抗争と自動化である。ShinyHunters は Clop のリークサイトを乗っ取り（発端は Oracle EBS の攻撃コード盗用とされる・同者の主張）、TeamPCP のハッカーを「密告」したとも報じられた。CrowdStrike は PUNK SPIDER（Storm-1567）と TRAVELING SPIDER の INC 系アフィリエイトが AI 生成の PowerShell を使ったとして、eCrime が AI 生成ツールを取り込み続けると中程度の確度で評価している。→ 特集「誰の権限でエージェントは動くのか」。

日本の数字は被害組織の規模に特徴がある。Cisco Talos は、日本の2026年上半期の被害が前年比4.7%増で The Gentlemen が最も活発、Qilin が2位（AI を使っているようだと指摘）と紹介した。NCC Group の日本の上半期統計では資本金10億円未満の中小企業が被害の80%を占める。止まるのは自社より先に取引先であるという前週の指摘は今週の数字でも変わらず、系列サプライヤの復旧計画を自社の事業継続計画へ織り込めているかが経営の確認事項になる。

構造の変化として、Clop が ShinyHunters にリークサイトを乗っ取られ Tor アドレスを移した（§3）。リークサイトは被害観測の一次データ源であり、その基盤が攻撃対象になると観測の連続性が切れる。掲載件数の減少を「被害の減少」と読まないための注意点である。

§5. 予測（実験的）

この章は §1〜§4 の観測・帰属から独立している。尤度（予測の確率）と確度（証拠の質）は別物として書く。対象は中国の戦略的意図に絞る。

  1. BlueMoon と同じ連鎖を使う中国系クラスタが、次の四半期にさらに公表される——可能性が高い(75-95%)。確度 moderate。根拠: 1つのキットが数日で5〜6クラスタへ渡った観測と、ShadowPad が2019年以降同じ経路で共有されてきた歴史的パターン。
  2. 自社運用の開発・仮想化基盤（Git ホスティング・NAS 上のサービス・ハイパーバイザ管理面）を入口にした中国系の侵害が、次の四半期にさらに公表される——可能性が高い(75-95%)。確度 moderate。根拠: 今週 Gitea・Synology／Proxmox・Zyxel・WordPress へ同時多面化し再現性が上がった。前週の同じ予測（50-75%・確度 low）を上方修正する。
  3. 日本の製造業から OT/ICS の設計情報（SCADA/HMI の設定・制御ロジック）が窃取されたことが公表される（次の四半期）——現実的な可能性(25-50%)。確度 low。根拠: 台湾での実例と、日本の製造業が同種の資産を自社 Git に持つ構成の類似のみ。日本国内での観測は無く、状況証拠からの外挿である。
  4. 台湾有事に備えた日本国内の重要インフラへの事前配置が、公的機関または主要ベンダーに具体的に公表される（次の四半期）——可能性は低い(15-25%)。確度 low。根拠: 対日 PIR の「事前配置」に結び付く観測は4週連続で標的業種の一致のみ。観測していないことは活動が無い証拠にならず、確率の低さは安全を意味しない。
  5. MirrorFace / Earth Kasha の新しい対日標的——今週は確度のある予測材料に乏しい。4週続けて明確な観測が無く、無理に予測を立てない。
