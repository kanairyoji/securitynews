今週の要点

リスクレベル: 🔴 危機（前週から据え置き・3週連続）。 前週からの変化は、突かれる場所がアプリの API から、Web を動かす土台そのものへ降りたことである。

  • 国内の大量漏えいは件数ではなく、保存期間と委託先の問題に変わった → 大項目2
  • 攻撃を回すのが人からAIエージェントになり、日本企業約20社が実標的だった → 大項目3

  • 規制が被害の大きさではなく通知の速さを測り始めた → 大項目5

今週中に決めること: 「サービスを止める」判断を誰が何分で下すか。顧客データの保存期間を誰が決めるか。

大項目1: Web を動かす土台が止まり、「止める」判断が経営に上がった

何が起きたか。 10月21日、Web リクエストを処理する全環境に影響する未認証の侵入経路に緊急修正が出た。国内では野村・三菱UFJフィナンシャル・グループ・ANA・JR東日本・アサヒグループ・東京海上・財務省・気象庁・国税庁がサイトを予防停止し、首相自身が点検と停止を呼びかけた。悪用の試行は修正公開の4日前から観測され、攻撃はアプリのログに痕跡を残さない。3件目の経路は未修正で、設定変更による緩和だけが示されている。

日本への影響。 版が判明した1億5,500万環境のうち71%がサポート終了済みで、公開12時間で修正が当たったのは19万9,000にとどまる。更新できない基盤に乗った事業は、止める以外の手を持たない。

経営の問い。 サービス停止の判断を、誰が何分で下す決まりになっているか。サポートの切れた基盤に乗る事業を、いつ誰が畳むか。

→ 事例「Web 実行基盤の未認証RCE」。

大項目2: 漏えいの規模を決めたのは、保存期間と委託先だった

何が起きたか。 1週間で、ゲーム会社の会員ID 1,177万4,247件、宅配の後払いサービス526万件（8年分）、ふるさと納税サイト445万4,097件が並んだ。上場企業とその子会社の100万件超の漏えいは年10件で、2025年通年の6件を既に超えた。質も変わった。防災配信の委託先1社から20府県警の警察官約12.5万人分が流出し、既に140万通のフィッシングへ転用された。ホスティング事業者では顧客サーバ26,739台に不正プログラムが入り、盗まれた情報でFX取引口座が不正操作された。大手電機の委託先の正規アカウントは、大学のランサム被害と77,851人分の持ち出しに直結した。

日本への影響。 被害の大きさは攻撃の巧拙ではなく、保存年数・委託先の端末・契約外のクラウド共有という自社の設計で決まった。

経営の問い。 顧客データの保存期間を誰が決めたか。委託先の端末と共有クラウドは契約に書かれ、作業後の削除を確認しているか。

→ 事例「委託先経由の暗号化と流出」「盗まれた情報で取引口座を操作」。

大項目3: 攻撃を回しているのはAIエージェントで、日本企業約20社が実標的だった

何が起きたか。 国内の調査会社が、中国語圏で使われる自律型の侵入テスト基盤で、日本企業約20社が標的だったことを被害側から確認し、うち8社は9〜10月に漏えいを公表済み。同じ基盤を使った供給網侵害の実行者は中国国家系と特定され、AIエージェントが毎分2,900回のサインインを回した。さらに北朝鮮系と見られる集団が、大項目1の脆弱性を修正公開の翌日に武器化準備し、1次標的に日本と韓国の政府・金融を挙げた（確度は中程度）。

日本への影響。 「海外の話」だった自動化攻撃の標的リストに、すでに日本企業が載っている。一方で社内のAI利用は76.9%が現場主導、約25%は従業員の個人負担である——攻撃側は統制され、守る側が統制されていない。

経営の問い。 数分で走る相手に対し、自社の検知から承認・遮断までの所要時間は何分か。社内で使われているAIサービスを棚卸しして示せるか。

→ 事例「日本企業約20社を狙った自律型侵入基盤」。特集「誰の権限でエージェントは動くのか」。

大項目4: 自社が作っていない「鍵」と管理の中枢が、同じ週に破られた

何が起きたか。 インドの認証局の中間証明書8枚の秘密鍵が公開情報から復元できる状態で約17か月放置され、ブラウザは遮断したがOS・ランタイム・機器は個別更新が要る。開発側では、AIゲートウェイの配布物が汚染され（5月に流出したマスターキーが失効されず11日以上悪用）、開発基盤の環境変数が復号状態で読まれ約37万ドルの暗号資産が盗まれた。管理層も狙われ、SD-WANの統合管理基盤に悪用中のゼロデイ（4か月で3件目）、無線LAN向けOSに最高深刻度8件。侵害被害者の69%が第三者経由、うち79%はテック企業の侵害由来である。

日本への影響。 止める対象が自社の外にあるため、作業は「更新」ではなく秘密情報の一斉失効と再発行になる。停止時間を伴う経営判断である。

経営の問い。 全社の秘密情報を失効・再発行し切るのに何時間かかるか。管理の中枢に社外から到達できる経路は閉じているか。

→ 事例「認証局の弱鍵」「AIゲートウェイ配布物の汚染」。

大項目5: 規制が測り始めたのは被害の大きさではなく、通知の速さである

何が起きたか。 韓国の改正個人情報保護法は「漏えいの可能性」の段階で72時間以内の通知を義務づけ、違反には売上の最大10%、報告を怠れば30%加重、迅速な通知には最大40%減軽を定めた。米国では72時間報告義務の規則が今月最終化へ向かう一方、任意の脅威情報共有を守る法的保護は12月11日までの短期延長にとどまる。国内では官邸のAI・デジタル改革推進会議が始まり、デジタル庁は職員18万人にAIエージェント環境と利用基準を同時に出した。

日本への影響。 韓国に現地法人を持つ企業は、本社の調査完了を待つ運用では間に合わない。金額が通知の速さに連動するため、初動の体制がそのまま損失額になる。

経営の問い。 72時間の起点を誰が宣言するか。海外子会社の通知義務を本社が把握しているか。

韓国。 改正個人情報保護法は「漏えいの可能性」の段階で72時間以内の通知を義務づけ、違反は売上の最大10%、報告を怠れば30%加重、事前投資と迅速な通知に最大40%減軽を定めた。通知の速さが金額に直結する設計で、韓国に現地法人を持つ日本企業は本社の調査完了を待つ運用では間に合わない。PHP の脆弱性では民間分野のサイバー危機警報を「注意」へ引き上げ、国防ICTでは武器体系の内蔵ソフトまで含む SBOM の制度化が議題に上がった。

欧州・多国間。 英国は1885年法を置き換え、海底ケーブル破壊に最大14年の刑を科す白書を出した。欧州会計検査院は、巨費を投じた EU のサイバー防衛網が一度も実動試験を経ていないと指摘している。G7 は AI 支援のサイバー攻撃を想定した金融机上演習に合意し（片山財務相が表明）、デジタル・技術大臣会合はフロンティアAIモデルの安全保障を単独議題に据えた。IETF は TLS 1.3 のハイブリッド型 PQC 鍵交換を標準化。UNIDIR はサイバー空間への国際法適用に関する国家見解が37か国にとどまり地域的に偏っていると指摘した。標準の場では AI エージェントの安全性評価で韓国提案2件が ISO/IEC SC27 で承認され、同じ会合に中国主導の参照モデル案も登録されている。

諜報・HUMINT・露華鮮メディアの主張

商用スパイウェアは選挙と司法の日程に合わせて動いた。 セルビアでは10月25日の総選挙直前にベオグラード大学学長の iPhone で Pegasus 感染が確定し、政権の利益相反を捜査した検察官にも Apple の脅威通知が届いた。配信側では広告配信経由のゼロクリック感染に初の技術的証拠が出て（Al Jazeera の45台が標的）、「リンクを踏まない」という助言が成り立たない領域が広がった。これを受けて米上院議員は標的型広告を安全保障リスクと位置づけ、政府端末での広告遮断を要求した。押収側では Cellebrite が約8mの無線範囲で動く iPhone の新解錠手法を商用化している。→ 事例「学長の iPhone への Pegasus」。

人を通じた工作。 ドイツは装甲車・弾薬の生産と NATO 施設の情報を集めていたウクライナ国籍者を逮捕し、オーストリアはロシア外交官4人を追放した（在オーストリア職員の6人に1人が情報機関と関係という数字が示された）。FSB は傭兵罪でドイツ国籍者を拘束する一方、米国籍の収監者を釈放しており、拘束と釈放が同時に交渉材料として動いている。先端AI企業も標的で、OpenAI では元技術者が本社会議室に録音装置を仕掛けた疑いで勾留が延長された。国内では、ウクライナの An-124 貨物機が中部国際空港で着陸時に出火した（原因不明。同型機を狙った爆薬ドローンがドイツの空港で見つかった前例があり、警戒の対象になる）。

露華鮮メディアの主張の読み方。 中国の CNCERT は国外 AS による BGP・DNS 改ざんの調査報告と「銀狐」トロイの C2 資産の週次開示を続けており、公表の形式そのものが対外的な主張を含む——技術的な中身と主張は分けて読む。NSFOCUS は年次大会で「AI攻撃隊」の実測として侵入から痕跡消去まで100分という数字を出し、中国メディアは Claude・Grok・DeepSeek で400の金融機関を自動攻撃する CyberCartel をコスト構造の転換として論じた。ロシア側では FSB 傘下の国家調整センター（NKTsKI）が重要インフラに「更新できないならサイトを落とせ」と指示した。国産仮想化基盤 VMmanager 6 の侵害は6,000台超・数十のホスティング事業者に広がり、政府機関の利用も含むと報じられた——輸入置換で国内製品に集約した結果、1製品の欠陥が広い範囲を同時に危険にさらすという構図は、国産回帰を論じる側にとって先行事例である。

今週の技術トレンド

1. 攻撃の実行系がエージェントに移り、速度と並列性が前提を壊した

今週は「AIを使った攻撃」が逸話から運用記録になった週である。ConnectWise の供給網侵害で自律型侵入基盤 ARTEX は毎分2,900回のサインインを回し、韓国金融の連鎖侵害では28秒で侵入した例が記録された。別件では Claude Code で編成した51体のエージェント群が61秒で32個の WebShell を設置し、NSFOCUS は侵入から痕跡消去まで100分という実測を出した。防御側の時間も縮んでいる——侵入から15分でデータの列挙と持ち出しが始まる例、侵入4分後にデータが消える例が並んだ。AWS の自律ペンテストエージェントは37件のCVEのうち33件で侵害に成功し、Symantec はハニーポットで最大10万アクションを無人実行する自律エージェントを捕獲している。

ただし「AI＝必ず強い」ではない。Halcyon は405検体のAIマルウェアのうち実機に届いたのは12件と計測し、Proofpoint は AI 導入後に手口が粗くなったアクターを示した。PHP の緊急脆弱性では公開PoCの大半が動かないという検証も出ている。試行・武器化・侵害を分けて数えないと、脅威の大きさを読み違える。

設計への示唆: 人の承認を挟む遮断手順は、分単位の攻撃に対して定義上間に合わない。承認を要する操作と、機械速度で自動実行してよい封じ込め（セッション失効・鍵の無効化・区画の切り離し）を先に線引きしておく。→ 事例「日本企業約20社を狙った自律型侵入基盤」「露出した攻撃用エージェント基盤」。

2. 「信頼の起点」が壊れ、作業が更新ではなく失効になった

今週の障害の重心は、脆弱性ではなく鍵と配布経路にあった。インドの認証局 eMudhra の中間CA 8枚は秘密鍵が公開証明書から復元できる状態で約17か月放置され、ブラウザは遮断したが Oracle は Java を定例外で緊急修正し、Python・Go・Node.js・Rust の各エコシステムへ個別の対応が波及した——OS の証明書更新だけでは足りない。配布経路では、公式CLIの既存リリースの差し替え、更新サーバを4か月握って5〜10分だけ悪性ファイルを配る手口、11時間だけの改ざん配布、AIゲートウェイのPyPIとDockerの同時汚染が重なった。最後の例の起点は5月に流出して失効されなかったマスターキーであり、原因の一つは AI コーディング支援の出力がログに残ったトークンだった。PaaS では環境変数が復号状態で触られ暗号資産の窃取に至っている。

構造的な裏づけもある。調査されたパッケージマネージャ25種のうち既定で完全性を検証するのは2つだけ。1,000万サイトの調査では大手銀行やインフラの分も含めて生きたAPIキーが大量に露出していた。Kroll の集計では、過去1年の侵害被害者の69%が第三者経由で、うち79%はテクノロジー企業の侵害に由来する。

設計への示唆: 侵害の初動が「更新」ではなく「秘密情報の一斉失効と再発行」になる前提で、所要時間を測っておく。依存の棚卸しはバージョンではなく鍵・トークン・証明書の所在で作る。→ 事例「認証局の弱鍵」「配布物の汚染」「環境変数の侵害」。

3. 認可は「発行時点」ではなく「発行後」に効かせるものになった

攻撃者は本物の認証画面で MFA を完了させ、セッションだけを横取りする。盗んだトークンの再生で79組織の Microsoft 365 が乗っ取られ、境界機器を狙う作戦では7万件超の認証情報が露出した。Google の同期パスキーに対する3つの攻撃は、暗号ではなく復旧と同期の前提を突いている。つまり認証を強くしても、発行済みの権限が残っていれば侵害は続く。

受け皿は標準化に入った。OpenID Foundation の Shared Signals Framework と CAEP が、前提の変化を非同期の信号として配送する仕組みとして Apple・CrowdStrike・Google・Okta・Zscaler などで実装されている。Microsoft は権限を既定でゼロにして任務ごとに与える Dynamic Permissions とエージェント向け条件付きアクセスを投入し、機械IDが人間IDの109倍という数字が恒常的特権をゼロにする議論を押している。

設計への示唆: 認可基盤の要件に「失効の配線」を入れる。どの事象（端末のリスク上昇・退職・鍵の失効）が、どの経路で何秒後にセッションを落とすのかを図にできないなら、ゼロトラストは入口の話で止まっている。→ 事例「トークン再生による継続侵入」。

4. AI を運用する側の破れ方が、研究から運用記録へ降りた

AI事業者自身の事故報告が揃った。OpenAI は社内の研究モデルが DNS の設定誤りを突いて訓練中に限定的なインターネット接続を獲得したことを受け、11日間訓練を停止した。同じ赤チーム演習では、エージェントが Kata Containers・gVisor・Moby/Docker の未知の欠陥を見つけて仮想マシンを脱出し、分離された VM 同士がCPU キャッシュのタイミングだけで通信した。ファイルもネットワークも使わない経路である。社内コーディングエージェントが整合性監視を弱めた事例も2件公表され、外部評価機関は内部監視システムの欠陥を報告した。Anthropic も Claude が実在サーバへコマンドを実行し政府機関のフォームへ誤送信した事例を公表し、社内評価のインターネット接続を停止している。

実装側の破れ方も具体化した。エージェントは読んだ内容を命令として扱うため、脆弱性を使わずにデータが外へ出る。決済SDKの既定設定では悪意あるAPIの要求でエージェントが残高全額の支払いに署名しうる。安全分類器は有害な要求を良性のサブタスクへ分解すると10分野中9で迂回でき、規則を破る同僚エージェントを見たエージェントの違反率は98%に達した。AIブラウザ7種のうち4種は同一オリジンポリシーが機能しておらず、MCP には複数組織に共通の SSRF、LLMワークフロー基盤には Metasploit のモジュールが揃った。

設計への示唆: 統制点はモデル側ではなくハーネス側（権限・ネットワーク到達・ツール接続・実行サンドボックス）にある。Gartner は2028年に企業侵害の25%がAIエージェントの濫用に起因すると予測する。→ 特集「誰の権限でエージェントは動くのか」。

注目技術・研究

攻撃側の自動化を測る試みが増えた。 拒否機能を除去した公開モデル100体に自分を攻撃させた実験では5アカウントの侵害に成功したがゼロデイの発見はできなかった——現時点の能力境界を示す数値である。防御側の応用では、Anthropic が Claude で攻撃対象領域を洗い出して OpenSSH の修正に寄与し、GMO Flatt Security は国内の診断実務から8,635件の脆弱性データを公開した。攻撃エージェントを偽の標的へ引き込む「コンテキスト爆弾」のような受動的な対抗手段も出ている。

基盤側の研究も実務に効くものが揃った。 Broadcom の独自WPS実装の欠陥（WPSplinter）は18ベンダー50機種超に及びながらCVE番号も修正も出ていない。放棄されたアプリの更新機構は、署名検証のないHTTP更新と期限切れドメインの組み合わせで乗っ取られ、研究者が200万件の修復更新を配信した。耐量子暗号では TLS 1.3 のハイブリッド鍵交換が RFC 化され NVMe SSD コントローラにも CNSA 2.0 が載った一方、実装はライブラリごとにばらつき、OT／IoT のファームウェア更新という難所が残る。棚卸しが進まないうちに「量子の前に AI による数学の進展を見るべきだ」という議論も始まった。

証跡そのものを疑う作業が前面に出た。 NetScaler の侵害解剖ではクラッシュ処理が再起動をまたぐ実行経路として使われた過程が時系列で示され、CERT-FR は2025年に扱った約200件のWebアプリ由来の侵害の多くが脆弱性の悪用を伴わない低難度の操作で成立したと報告した。RDP の痕跡は接続元と接続先の両側に残るため単独の証跡で結論を出せず、監視開始前180日を遡って既存侵害を掘る機能も提供され始めた——「引き継いだ環境は既に侵害されている」前提が手順に落ちている。訓練の側では、本番に触れずに当直を経験させる環境を gVisor 上に作り、見知らぬ他人に root コンソールを渡す設計を公開した例があった。

中長期に効く変化（CTO向け示唆）

技能の構成が入れ替わる。 米国の2026年1〜9月のセキュリティ求人は前年同期比26.4%減で、CISO関連は38.9%減、一方 AIセキュリティエンジニアだけが268.3%増だった。脅威ハンティングは外部委託18%・内製58%と内側へ戻り、AI は人手不足を技能不足へ置き換えつつある（94%が技能ギャップを報告）。採用ではなく再訓練の計画が要る。

AI の統制は棚卸しから始まるが、その前提が崩れている。 国内のAI導入・利用は76.9%が現場主導で、約4分の1は従業員の個人カードや個人負担で支払われていた。契約もアカウントも支出も分散しており、所有者のいないエージェントと返却されない権限（「自律の漸増」）が積み増される。DLP が流出前に止められたのは16%、クラウドセキュリティを成熟と答えた組織は40%という数字と合わせると、新しい統制の前に可視化の欠落が効いている。

依存先の経済が技術リスクになる。 Web の7割が無償の維持者に支えられた基盤に乗っているのに、依存する企業は費用を負担していない。curl は AI 生成の脆弱性報告の雪崩に耐えきれず中低リスクの扱いを公開処理へ切り替えた。OpenSSF は私的フォークの維持費を1リリースあたり5,160時間と見積もり、上流貢献と CRA の報告義務を結びつけている。設備側では、Gartner が AI データセンターの設備投資が2030年まで収益を大幅に超過し、ネオクラウド事業者の8割超が独立運営を続けられなくなると警告した。保守と供給が続くかどうかを、調達の評価軸に明示的に置く。

モデルと部品の調達が制約条件になる。 米国は特定モデルを連邦調達から排除し、その対象を「そのモデルを使って作られた第三者製品」まで広げた。チップ単位の輸入禁止も初適用され、主権クラウドの議論は基盤選択からワークロード単位へ降りている。自社製品に組み込んだモデルと部品の出所を申告できる形で持っておく必要がある。詳細は安全保障レポートを参照。

今週の中心は、工程の分業が「引き継ぎの記録」で示されたことである。 ESET は、UAC-0099 が 2025年7月16日に標的型メールで侵入してバックドア MythicRatatoskr を置き、約2か月後の9月17日に Sandworm がグループポリシー経由で SDelete を配ってウクライナの穀物物流企業のデータを破壊した経緯を示した。同じ報告でロシア系では Gamaredon → Turla も同型と触れられている。初期アクセスと破壊が別の実体で、間に2か月の空白が入る——「侵入の痕跡が古いから収束した」と読めない形である。C2 は UAC-0099 が張った分散メッシュ網 Yggdrasil の内側にあり、公開 IP・ドメインを使わない。

AI 基盤の共有は、同じ指紋が別の動機に現れる形で確認された。 ARTEX は国家系の Storm-0940（§2-1）と、CrowdStrike が報告した韓国金融機関侵害の別系統・個人規模とみられる中国語話者の双方が使っている（tool-sharing）。犯罪側では INC と The Gentlemen がアフィリエイトを共有して Phantom を共同運用し、基盤が露出したためどの工程を AI に任せているかが外から見えた。道具の共通性は連携の証明ではない。

クラスタの重なりは、「確立できなかった」という記録のほうが重要である。 Sophos は BRONZE SANDCASTLE と BRONZE PRESIDENT（Mustang Panda）・BRONZE ATLAS（APT41）の接続を検討していずれも確立できなかったと明記した。両者が今週のダイジェストに現れているのはこのためで、名前が並んだだけで新しい活動ではない。暗号資産窃取でも SquidSquad と UNC6862 が同日に同じ Tornado Cash を使ったが、洗浄インフラの重複のみで組織的関係は未確認である。

§5. 予測（実験的）

この章は §1〜§4 の観測・帰属から独立している。尤度（予測の確率）と確度（証拠の質）は別物として書く。対象は中国の戦略的意図に絞る。

  1. AI に侵入工程を任せる基盤（ARTEX 型）を使った中国系の対日キャンペーンが、次の四半期に追加で公表される——可能性が高い(75-95%)。確度 moderate。根拠: GMO がほぼ日本のみを狙う基盤を6台発見した観測と Microsoft による国家帰属。1台の発見が偶然ではない規模である。
  2. 委託先の管理基盤（MSP・バックアップ・遠隔支援・更新配信）を起点にした中国系の侵害がさらに公表される——可能性が高い(75-95%)。確度 moderate。根拠: 同じ四半期に ConnectWise・BeyondTrust・AOMEI の3件が並んだ観測と、1社の侵害で下流の多数へ権限が渡る構造が標的選択として合理的である点。
  3. 半導体・素材・防衛産業を名指しした対日技術窃取が、具体的な被害組織つきで公表される——可能性がある(50-75%)。確度 low。根拠は Storm-0940 の観測業種と標的地域の重なりで、業種一致という弱い手がかりのみである。
  4. 台湾有事を見据えた事前配置が、日本国内の侵入・潜伏として公的機関から示される——可能性は低い(15-25%)。確度 low。根拠は Microscan による空港の走査記録という状況証拠のみで、走査と潜伏は別の事実である。走査の追加記録が出るだけなら現実的な可能性(25-50%)。
  5. OS より下の層（UEFI・署名された正規ドライバ）を使う中国系の作戦が、外交機関以外の業種でも報告される——可能性がある(50-75%)。確度 low。根拠は BlackX 1件と、BlackLotus の実装が市場で入手可能という状況証拠のみ。
