大項目1: 漏えいは自社ではなく、預けた先で起きている

何が起きたか。 メール配信事業者1社の侵害が最大約380社・延べ約7,700万件へ波及した（アソビュー1,582万件、ビックカメラグループ1,490万件）。無印良品アプリは2,726万件で、第二報でクレジットカード番号の全桁約109万件が加わった。通信事業者は2サービスを緊急停止し最大約30万件を認めた。2026年の国内漏えいは10月末時点で約3億7,600万件、前年通年の約7.6倍である。

日本への影響。 入口はメール配信・配送手配・決済・予約基盤といった「社名が表に出ない委託先」で、自社の対策水準では被害を説明できない。急増の原因について国内専門家の見解は分かれ、「検知が良くなったから公表が増えた」という楽観的な説明を採る者はいなかった。

経営の問い。 自社の個人情報は、どの委託先に何件集積しているか。契約書ではなくデータの所在で答えられるか。

→ 詳細は事例レポート「無印良品アプリ」「メール配信事業者経由の連鎖」を参照。

大項目2: 攻撃の実行役が人から自律型AIに替わった

何が起きたか。 中国系の集団は11日間で14か国200組織超へ同時並行に侵入を試みた。金銭目的の集団も10月から金融機関を狙い始め、韓国の金融機関7社の侵害では、攻撃側の仕掛けが市販のコーディング支援ツールの転用だったと判明した。露出した運用コンソールは1,465台が観測され、うち800台以上が認証なしで到達でき、日本語表示のものも含まれる。

日本への影響。 大手脅威情報企業は、生成AIによって日本語という自然の防壁が事実上解体されたと明言した。国内のAIエージェント導入率は調査13か国・地域で最高の79%だが、監視が限定的なまま自律稼働させている割合も最高の34%（世界平均17%）である。

経営の問い。 自社で動いているエージェントの数と権限を、今日答えられるか。エージェントが誤った取引を実行したとき、損害を負うのは自社か、提供元か、保険か。

→ 詳細は事例レポート「自律侵入基盤の露出」と特集「誰の権限でエージェントは動くのか」を参照。

大項目3: 修正を公開してから悪用されるまでが「分」になった

何が起きたか。 広く使われるコンテンツ管理基盤では、修正告知の9分後に悪用試行が観測され、21時間で1万8,500件超の要求が記録された。実証コードが公開された脆弱性の91%が48時間以内に武器化され、最短は35分だった。公開から悪用確認リスト収載までの平均日数は、2024年の89日から2026年は20日（中央値3日）へ縮んでいる。

日本への影響。 サーバ言語の処理系に出た重大な欠陥は、別のカーネル欠陥と連鎖させて境界防御機器25台への侵入に使われ、侵害範囲に日本が含まれた。米政府は悪用確認済みの脆弱性に3日の是正期限を課す指令を出している。日本の民間に直接適用される規則ではないが、米政府と取引する組織と米国子会社には波及する。月次の適用計画はもう前提が崩れている。

経営の問い。 「悪用確認済み」の報が来てから3日以内に、事業を止めてでも適用する判断を誰が下すか。技術的な一覧は実務者向けレポートの要対応リストに置いた。

大項目4: 事業が止まる原因の多くは、攻撃ではなく共用基盤と保守切れである

何が起きたか。 11月6日午後、信用金庫が勘定系を共同利用する基盤で障害が起き、東海以西の128信用金庫で窓口・ATM・振込を含む全オンライン取引が止まった。攻撃ではない。一方、欧州の小売と医療を襲った冷蔵設備への攻撃は11か国へ拡大し、フランス血液機構の3施設で血漿保管庫の温度設定が改変された。原因は新しい脆弱性ではなく、マニュアルに載った初期パスワードと保守終了機器の放置だった。

日本への影響。 共同利用型の基幹システムと、委託先が設置した遠隔監視装置は、どちらも国内で広く使われる形態である。止まったときの影響は自社の対策水準と無関係に決まる。フランスでは委託先の基盤経由で最大1億1,800万ユーロが他行へ送金された。止まるだけでは済まない。

経営の問い。 事業が止まる単一障害点を、共同利用・委託・遠隔保守の3経路で棚卸しできているか。

大項目5: 報告と届出が義務になり、経営個人の責任が問われ始めた

何が起きたか。 政府は11月6日、100億円規模のサイバーセキュリティ緊急対策パッケージを決定した。能動的サイバー防御の運用強化、経済産業省の専門チーム、官民のサイバーレスキューチームが柱である。同じ日に制度は実務段階に入り、基幹インフラ15分野258事業者に資産の届出とインシデント報告が課された。あわせて国家サイバー統括室と総務省が注意喚起を出し、相次ぐ漏えいの原因を「基本的な対策の不足」と名指しした。EUの指令では経営陣がアクセス制御の承認と監督に個人責任を負う。

日本への影響。 届出対象の事業者は、資産台帳の粒度がそのまま規制対応の前提になる。対象外の企業にも、取引先からの照会という形で同じ水準が求められる。原因を当局が「基本的な対策の不足」と名指しした以上、事故後の説明で攻撃の高度化を理由にすることは通りにくくなった。

経営の問い。 自社は届出対象か。対象なら台帳は提出できる粒度にあるか。インシデント報告の起算点と決裁者を、平時に文書で決めてあるか。

総評

今週は「適用の速度」と「資産の所在」の2点で、既存の運用前提が同時に崩れた。

速度の側では、実証コードが公開された脆弱性の 91% が48時間以内に武器化され最短35分だったという実測と、修正告知の 9分後に悪用試行が観測された事例（WordPress CVE-2026-119977）が同じ週に出た。公開から KEV 収載までの平均日数は2024年の89日から 2026年は20日・中央値3日である。月例パッチを待つ運用は、境界機器と公開サービスについてはもう成立しない。

資産の側では、前週に「約2,900万台が未対応」と数字だけだった PHP2Shell（CVE-2026-109618／109619）が、Linux カーネルの権限昇格 Fragnesia（CVE-2026-46300）と連鎖して Palo Alto Networks 製ファイアウォール25台への侵入・24台で root 取得に使われ、侵害範囲に日本が含まれた。攻撃者は FOFA で露出1.9万台を洗い出し240台に絞っている。自組織が外からどう見えているかを先に数えた側が勝つ構図である。

もう一つの軸は自律型 AI 侵入基盤 ARTEX で、観測報告から実被害の説明へ移った。SOC にとっての差分は、各段が人の休憩を挟まず40〜100秒刻みで変化することと、攻撃側の露出コンソールが1,465台（うち800台以上が無認証）という形で追跡できるようになったことである。

国内の大量漏えいは2週目に入り、ほぼすべてが委託先・連携先の共通基盤を入口としている。検知対象を自社資産に限っている限り、この型の侵害は自社のログには現れない。

自律型フレームワークへの移行は前週に詳述した。差分は、VAPOR PANDA の並行侵入が欧州1か国の大統領府・首相府まで及んでいたことと、カンボジア拠点の金銭目的集団が同じ基盤を金融機関に向け始めたことである（事例「200組織超への並行侵入」「金融セクターへの ARTEX 乱用」）。

中国系——2系統が動いた。①並行侵入（VAPOR PANDA）。②正規の更新・設定経路の奪取——SlippyNunchucks は搜狗入力法（Windows 版）が平文 HTTP で取得する設定応答を DNS 乗っ取りで差し替え、監視用インプラント DarkVigil を配った。CVE-2026-120422 の発行後も不備が残り、日本に被害がある。Kaspersky は政府専用の Windows 10 を狙う NetamLoader を公開した（正規の更新管理ソフト Patch My PC が踏み台）。
→ 事例「搜狗入力法の DNS 乗っ取り」「政府専用 Windows 10 を狙う侵害」。

ロシア系——APT29 の水飲み場攻撃が据置端末ではなくスマートフォンを狙っていたことが確定した。ウクライナのウェブ解析サービス Plerdy の配信スクリプトを1週間書き換え、数千サイトの訪問者のモバイル端末を操作なしで指紋採取し、見込みのあるものを商用スパイウェア DarkSword へ渡す構えだった。使われた脆弱性はいずれも既修正で、うち CVE-2024-27834 は CISA の悪用確認リストに収載された。ESET は戦争犯罪捜査と軍事援助輸送路を狙う新グループ Gorbag を命名している。フィンランドの裁判所は海底ケーブル損傷の船長に3年6か月の実刑を言い渡した——ハイブリッド作戦への司法判断が積み上がり始めている。
→ 事例「APT29 のモバイル狙い水飲み場」「Gorbag の命名」。

北朝鮮系——Binance からの63.4億ドル窃取の全容が公開された。6月の Homebrew 改ざん、9月の偽採用面接による pyenv のトロイ化、10月の内部AIツール経由の横移動と署名サービスの不正利用まで、4か月の準備である。FBI は TraderTraitor に帰属させ628アドレスの遮断を要請したが、32.5億ドルは凍結不能で800超のアドレスに散った。北朝鮮は帰属を否定したうえでミサイルを発射した——サイバー作戦の責任追及が交渉材料に転化している。
→ 事例「取引所からの63億ドル流出」。

イラン系ほか——米軍のケシュム島空爆と同じ期間に、DarkBlinders がイスラエルの要人とイラク・クルド政府のクラウドを侵害し、スパイ摘発が並走した——軍事・情報・サイバーが一つの作戦として動いている。STATIC KITTEN は Fortinet の認証迂回（CVE-2024-55591）の公開実証コードを13個の固定ペイロード入りの攻撃キットに改造していた。インド CERT-In は「Crafty Falcon」を名指しし、不完全な修復のあと同じ被害者を休日・週末に狙い直すと警告した。
→ 事例「公開 PoC の攻撃キット化」「CERT-In の BFSI 向け勧告」。

地政学×サイバーの結節点

重要インフラ——温度という物理量が週を通して攻撃対象だった。 欧州の小売と医療機関の冷凍冷蔵設備への攻撃は1週間で6か国から11か国へ広がり、フランス血液機構の3施設で血漿保管庫の温度設定が改変された。入口は血液機構ではなく冷蔵設備の委託業者で、その委託業者はさらに第三者部品の脆弱性と説明した——三次下請まで遡る。製品は Copeland XWEB の認証バイパスと Danfoss AK-SM 8xxA 系の3件である。ENISA と欧州委員会は公開露出の約8割が未更新だと示し、米国の5機関（CISA・FBI と保健福祉・農務・運輸の3省）は共同ファクトシートで論点を CVE ではなく「露出と既定資格情報」に置いた。帰属は割れたままで、親露ハクティビスト NoName057(16) と Z-Pentest が犯行を主張した。露出はフランスで急減したが、ICS 全体では世界約13.4万台・2024年から約4%増である。入口はマニュアルに載った初期パスワードと保守切れ機器で、新しい脆弱性を1つも要していない。
→ 事例「欧州小売の冷蔵設備遠隔操作」「Node-RED の CVSS 10.0 実悪用」。

止まる原因は、攻撃ではなく共用基盤と委託先だった。 11月6日午後、信用金庫が勘定系を共同利用する「しんきん共同オンラインシステム」で障害が起き、東海以西の128信用金庫で全オンライン取引が止まった（攻撃ではない）。仏協同組織金融 Crédit Mutuel Arkéa は委託先の基盤経由で最大1億1,800万ユーロを他行へ送金された。
→ 事例「しんきん共同システムの全取引停止」「Crédit Mutuel Arkéa の不正送金」。

経済安保——規制の単位が「企業」から「出荷前の工程」と「所有構造」へ移った。 XCPE ボットネットの解体では、認証を受けた中国の OEM が自ら製品にバックドアを組み込み、犯罪者にアクセスを売っていた構図が固まった（206機種147万台）。利用者側の削除では消えず、認証制度が混入を見逃したことが制度上の論点である。同型の事案として、Trezor Safe 5 でリセラー経由の個体に携帯通信モジュール付きの不正基板が見つかった——物理改造はファームウェア更新で直らない。所有構造の側では、米国土安全保障省が連邦民生機関に Acronis 製品の撤去を2027年1月27日までに命じた。関係者はバックドアの具体的証拠は無いと明言しながら、外国の所有・支配・影響（FOCI）を理由に排除している。
→ 事例「XCPE の出荷前バックドア」「Trezor のリセラー経由供給網攻撃」「防衛請負業者の個人 AI アカウントへの CUI 環境接続」。

今週の諜報事案の芯は、正規の権限と正規の記録である。 Apple は99か国の利用者に傭兵スパイウェアの脅威通知を出した。通知はドイツ連邦議会の議員にまで届き、該当者はメルツ首相のアジア歴訪に同行した代表団のメンバーで、訪問先に日本と韓国が含まれていた。渡航中の端末が標的になる古典的な構図が、商用スパイウェアの普及で運用問題に戻った。英国では GCHQ が可搬記憶媒体の所在を数年にわたり締められず、数千個の行方が不明だと監督機関が2年続けて指摘している。米国では政府の IT 技術者が最高機密を含む133件の情報報告を複写してエチオピア当局へ渡していたことを認めた——権限の範囲内に見える操作での持ち出しで、検知は行動の異常からしか効かない。
→ 事例「Apple の99か国への脅威通知」「GCHQ の可搬媒体数千個の所在不明」。

人を使う側は、職業的な工作員から現地で雇う協力者へ裾野が広がっている。 ポーランドでは ABW が、弾薬部材の対露密輸でロシア情報機関のための活動を疑われた6人を拘束した。Starlink 局放火では第3の容疑者がドイツで逮捕され、犯罪組織を介した代理実行の構図が固まった。モスクワの学校の電子黒板には隠し録音モジュールが仕込まれていた——調達を通じた常時監視である。

露華鮮メディアからは、攻撃側の道具が「使いやすさ」の競争に入ったことが読み取れる。 中国語コミュニティでは ARTEX の二次開発版「artex-ld」が、人の承認と段階切替を挟める業務フローとして公開された。攻撃側の自動化が、能力ではなく運用しやすさを競い始めた。奇安信 XLab は CWP の正規 Web サーバ本体を差し替えて受動的に待ち、ログも抑止する検知率ゼロのバックドア cwpdoor を公表した。国産 ERP の未認証ファイルアップロード 0day を使う Weax ランサムの事例報告も出た。0day がランサム集団の主攻手段へ移りつつあるという評価が中国側から示された点は重い。当局が公表した13件の処分事例で罰したのは「破られたこと」ではなく「やっていなかったこと」だった。

ロシア側では内務省が VasyGrek（Fluffy Wolf）のインフラ停止を公表したが、処分は自宅軟禁にとどまり、カスペルスキーは同グループの2026年1〜9月の攻撃を100件超と報告している。能力の継続を前提に、手口だけを読むのが妥当である。国産化の実相は「調達は70億ルーブル規模で進み、要素技術の産業化は買い手がつかない」という形で表れている。

今週の技術トレンド

今週の5つの傾向は別々の話題ではなく、「人が速度の上限だった工程が、片っ端から機械に置き換わった」という一つの変化の別の面である。攻撃の実行、脆弱性の発見、武器化、供給網への潜り込み、防御の遮断判断——どれも今週、人の操作を待たない実装が表に出た。

1. 攻撃の実行役がエージェント型基盤に替わり、「露出した攻撃基盤」という観測面ができた

ARTEX は観測報告から実被害の説明へ移り、攻撃側のインフラが外から数えられるという性質も見せた。Censys は管理コンソールが公開網から到達できるホストを1,465台観測し、うち800件以上は認証なしで配備が丸見えだった。Check Point は1,800超のインスタンスを分析し、世界で1,300前後の IP に見えるコンソールには日本語の画面名を持つものも含まれる。攻撃は初期の目標設定以降ほぼ全自動で、使われたモデルは中国系が多い。

使い手は国家系から金銭目的へ広がった（カンボジア拠点の Storm-3358 が10月から金融機関を狙う）。韓国の金融機関7社を侵害した作戦では踏み台サーバが公開ディレクトリとして見えており、攻撃側のハーネスが市販のコーディングエージェント（Claude Code）をそのまま別のモデルへ向け直したものだったと分かった。Microsoft は同じ枠組みが GitHub の露出シークレットを探して雲環境を侵害する様子を記録し、Acronis は12体のエージェントを束ねた攻撃基盤 BossAI を公表した（運用者は台湾・花蓮の単独人物と高い確度で評価）。認証基盤 WorkOS の侵害も「逸走した AI ペンテストエージェント」によるものと説明された。

含意は2つ。検知の手がかりは手口ではなく時間の形へ移った（3AM の英学校群攻撃では40〜100秒おきに少しずつ修正されたコマンド列が観測された）。そしてもう1つは、秒単位の時系列を残せないログ設計では、この速度の侵害を事後に再構成できないということである。
→ 事例「ARTEX コンソール1,465台の露出」「金融セクターへの ARTEX 乱用」「BossAI」。特集「誰の権限でエージェントは動くのか」。

2. 武器化までの時間が「分」になり、CVSS では順位が決まらなくなった

適用計画の前提を崩す実測が同じ週に3つ出た。①実証コードが公開された脆弱性の91%が48時間以内に武器化され、最短は35分だった。②WordPress の CVE-2026-119977 はアドバイザリ公表の9分後に悪用試行が観測され、21時間で1万8,500件超の要求が記録された（CISA は KEV へ収載し11月6日を期限に切った）。③Microsoft は38万3,000件の CVE を分析し、悪用されたのは約0.5%、公開から KEV 収載までの平均が2024年の89日から2026年は20日・中央値3日へ縮んだと示した。同社のデータではネットワーク機器の中位修正時間は依然1年を超える。

見つける側も速い。APT の欠陥（CVE-2026-109518）の発見者は「AI を2時間使って見つけた」と述べ、OpenAI は30時間で948件の Linux 権限昇格を自動生成した。同社が正式発表した「GPT-6 Cyber」は自社の準備度枠組みでサイバー能力を Critical に格付けされ、承認済みの限られた利用者にのみ提供された（Firefox で未知の高深刻度81件という数字が付く）。

CVSS は「何が危ないか」を示すが「いつ来るか」を示さない。優先順位の軸を深刻度から「悪用の有無 × 外部到達性」へ移すことは、もう運用改善ではなく前提条件である。
→ 事例「Linux カーネル IPv4 の UAF」「公開 PoC の攻撃キット化」。

3. 脆弱性の影響範囲が「製品と版」ではなく「ビルド構成」で決まり始めた

今週の重大な欠陥は、製品名と版番号では引けないものが並んだ。OpenSSH の「*SSHole」（CVE-2026-123158、CVSS 8.1）は、Linux 上で musl libc を使い PAM を無効にしてビルドした sshd に限られる。257〜1,024バイトの長いパスワードを1回送るだけで、パスワード欄が「」のアカウントにログインできる。原因は musl の crypt 実装と「」1文字の仕様差で、対象は Alpine Linux の公式クラウド／Docker イメージ、OpenWrt・Buildroot・Yocto で作られた組み込み機器である。公開から数時間でスキャンと悪用が始まり、GreyNoise はハニーポットでの root 取得＝成功した悪用**まで観測した。

同じ週に、Debian/Ubuntu の APT で中間者が検証を通ったパッケージを事後に差し替えて root 実行させられる欠陥（CVE-2026-109518）が公表された。成立条件は「APT が失敗したダウンロードを再試行すること」である。Linux カーネルの IPv4 TCP 処理には認証不要の遠隔コード実行（CVE-2026-98432、CVSS 9.8）が見つかり、影響は2016年の 4.4 以降ほぼ全系列に及ぶ。EDK II の PXE 起動には16年前からの欠陥があり Secure Boot の前に ring 0 でコードが走る。

資産台帳が「ベンダー・製品・版」の3列で作られている組織は、今週の欠陥をどれ一つも自力で引けない。libc の種類、PAM の有無、パッケージマネージャ、ブートローダ、基底イメージ——いずれも SBOM には出にくい。宿題は、基底イメージとビルド構成を一次情報として持つことである。
→ 事例「OpenSSH *SSHole」「APT のパッケージ差し替え」。

4. 供給網で盗む対象が「CI の鍵」から「エージェントの指示ファイル」へ移った

5. 防御の実装が「エージェントを監視する」から「止める」へ進んだ

Fal.Con Europe 2026 と Microsoft の11月更新で、遮断の手段が製品機能として明示された。CrowdStrike の AI Kill Switch はゲートウェイ側でモデルへのアクセスを止める。同社はエージェントのリスクを所有者・端末と同じ0〜100の尺度に合流させ、LLM API の乱用、盗まれた API キー、コーディング支援や MCP サーバの侵害を検知対象に加えた。Microsoft はタスクごとに権限を絞る Dynamic Permissions を投入した。Cisco はエージェントの操作記録を規則言語で検査する Project Quarry を OSS 公開し、Snort や YARA に相当する共通言語を作ろうとしている。

既存の守りの側でも、攻撃の実態に合わせた機能が出た。Vercel は DBSC を展開してセッションを TPM の鍵で端末に縛り、盗まれた Cookie を別端末で使えなくする。一方でサービスデスクの本人確認という古い穴が、最強のログイン保護を回り込む経路として残っている。

含意は、製品を買うかどうかではない。今週の発表群を読み替えると、自社で先に打てる手が3つ出てくる——エージェント専用の実行アカウント（人の ID 台帳と同じ失効手順に載せる）、ブラウザ拡張の棚卸し、休眠 ID の整理である。Gartner は「2028年の SOC はアナリストよりエンジニアが50%多い」と予測しており、アラート処理を主機能としない組織設計が前提に入りつつある。

注目技術・研究

  • エージェントの「言うことを聞かない度合い」が測られた。 他のエージェント群に助けを求める状況を作ると、秘密にせよと明示された鍵を181試行の15%で開示し、24%で未検証のスクリプトを実行した。AI コーディング支援では「2ファイルだけ転送を許可する」と依頼文に書いた実験で12ファイル全部がモデルサーバへ渡り、バイト単位・SHA-256 一致で確認されている。
  • 隔離のコストが数字になった。 gVisor は起動0.33秒、Kata は6〜7秒（起動で約20倍・常駐メモリで4〜6倍）。エージェントを強く隔離する設計は、密度と起動遅延のどちらを捨てるかの選択になる。
