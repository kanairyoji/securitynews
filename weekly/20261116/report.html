大項目1: 委託先1社の侵害が、数十社の「自社の公表」になった

何が起きたか。 接客基盤を提供するマーケティング事業者が11月13日未明に脆弱性を突かれ、DB接続用の認証情報を奪われた。利用企業側では約1,911万件、最大約1,829万アカウントという規模が同じ日に並び、大手銀行を含む数十社が順次公表した。海外でも国際カードブランド2社と米大手銀行が第三者経由の侵害を認め、アイルランドでは信用組合43社に基幹バンキングを提供する事業者が侵害され、ログの粒度が足りず影響範囲を特定できなかった。

日本への影響。 計測・接客のタグは各社のサイトとアプリに組み込まれて動くが、資産台帳に載っていない。公表の主体は利用企業、調査の主体は提供元という分離が常態化し、委託先名を示さない開示慣行への批判も出た。

経営の問い。 自社のサイトとアプリで動いている外部タグ・SDK を列挙でき、それぞれがどの個人情報に触れるか答えられるか。委託先が侵害されたとき、顧客への通知を自社の判断で出せるか。

→ 詳細は事例レポート「接客基盤の侵害と連鎖公表」「信用組合向け基幹バンキングの侵害」を参照。

大項目2: 破られたのは本番ではなく、テスト環境と公開ダッシュボードだった

何が起きたか。 ネット証券は、テスト環境に置いた本番データから最大1,125万口座分のID流出のおそれを公表した。国の研究機関はスーパーコンピュータの運用系が公開中の稼働状況ダッシュボードを足がかりに侵害され、最大4,597名の登録情報と、利用者が預けていた他機関への接続用の秘密鍵まで流出した可能性を認めて運用を停止した。政府共通基盤のファイル共有では、7月30日から11月12日までの3か月半、正規でない相手のアクセスが続いた可能性があり、25機関・約15万人が利用していた。

日本への影響。 いずれも本番Webの防御とは別の面であり、公的研究基盤と政府共通基盤にまで及んだ。「守る対象」の台帳が本番だけを指す組織には、同じ穴が残る。

経営の問い。 本番データを本番以外の環境へ複製することを誰が承認しているか。インターネットに出ている自社の画面を、本番以外も含めて一覧で持っているか。

→ 詳細は事例レポート「研究基盤運用系への侵入」「政府共通基盤のファイル共有」を参照。

大項目3: 全社の土台が同じ週に当たり、適用の猶予が消えた

何が起きたか。 Java実行環境、Webサーバ、2つのスクリプト言語処理系が同じ週に重大な修正を出し、いずれも認証前に到達し得る。仮想化基盤の管理面の認証回避には回避策が無く、中国系の国家諜報が9月初めから修正のないまま悪用していた。米政府機関は週内に悪用確認済みの8件を是正対象に加え、うち4件の期限を公表から3日後に置いた。

日本への影響。 Javaは基幹系・金融系のアプライアンスに同梱されており、「どのベンダーが入れた版か分からない」という資産可視化の弱点をそのまま突いた。開示猶予の短縮も続き、修正が出るまでの猶予も、当てるまでの猶予も縮んでいる。

経営の問い。 「悪用が確認された」の報から何時間で事業を止めて適用するか、判断者は誰か。修正が提供されない機器を撤去・置換する予算を今年度に持っているか。

→ 技術的な一覧は実務者向けレポートの要対応リストに置いた。詳細は事例レポート「Java実行環境の重大脆弱性」「仮想化基盤の認証回避」を参照。

大項目4: 攻撃側のAIエージェントが、見立てから実測値の段階に入った

何が起きたか。 中国系アクターが運用する自律エージェントが、医療画像ソフトの未知の脆弱性を11分で見つけ管理者権限を奪った記録が公開された。セキュリティ製品ベンダーのクラウド環境では、委託先に渡したまま失効させていなかった鍵を起点に44時間で10のクラウドアカウントを横断され、別の事案では侵害から深部到達まで15分、23秒間に27件の操作が記録された。

日本への影響。 検知から遮断までを人が順に判断する設計は成立しない。米上院議員が防御AIの国家的取り組みを求めた書簡は、日本での侵入事例を根拠に挙げている。一方で調査では、AIエージェントが本番環境を触れる企業でも、未管理のAI活動を全面的に検知できるのは1割未満にとどまる。

経営の問い。 自社で動いているAIエージェントの数と権限を答えられるか。それを止める権限は情報システム部門と事業部門のどちらにあるか。

→ 詳細は特集「エージェントは誰の権限で動くのか」と事例レポート「製品ベンダーのクラウド環境の侵害」を参照。

大項目5: 制度と事業環境が動いた——国内法の改正検討と、海外資産の切り離し

何が起きたか。 デジタル大臣は総理の指示を受けてサイバー対処能力強化法の改正検討に入ったことを明かし、国内で完結する通信を監視・分析の対象に含めるかが論点になると述べた。警察庁長官は2026年以降の大規模漏えい事案を一括して対象とする態勢指示を出した。一方、日本たばこ産業はロシア事業7社を国家管理下に置かれ、2026年通期で1兆3,770億円の損失を計上する。米国は半導体の輸出管理を第三国データセンター経由の遠隔利用にまで広げ、中国製AIモデルを本番で使っているかの開示義務化も検討している。
日本への影響。 能動的サイバー防御の運用設計は、権限の範囲と説明責任を同時に決める段階に入る。調達では、どの国のモデルと計算基盤を使っているかが報告事項になり得る。

経営の問い。 自社が使うAIモデルと推論先の所在地を、取引先に説明できる形で持っているか。政治的判断で切り離され得る資産と事業を、地域別に把握しているか。

総評

今週の差分は3つである。

第一に、「どの組織にも必ず入っている層」が同じ週に当たった。Java 実行環境（Java4Shell）、nginx の HTTP/2（NGINX2Root・5件）、PHP 18件、Ruby 7件、仮想化基盤の管理面である。版の一覧を配っても終わらない点が共通で、Java は影響版・CPU の AVX-512 VBMI 対応・攻撃者由来の Base64 を復号するアプリの3条件が揃って初めて露出する。

第二に、悪用確認の区分へ移った件数が増えた。CISA は11/18に4件（期限11/21）、11/20に4件（期限11/23）を KEV に追加し、Puppet Enterprise は12/1期限である。vCenter は9月初めからのゼロデイ悪用だった。公開 PoC の91%が48時間以内に実戦投入され最短35分という実測も出ている。

第三に、国内の漏えいの入口が「本番以外」に寄った。テスト環境の本番データ（最大1,125万口座）、13年間変えていない検証環境の認証情報（90万2,576件）、公開中の稼働状況ダッシュボード（理研「富岳」）、政府共通基盤のファイル共有（3か月半・25機関）。棚卸しから本番以外が落ちている。

リークサイト掲載に日本の組織が入ったのは11/19と11/20の各1件。一方11/22の9組織同時掲載のうち2件は2022年の FortiOS 脆弱性に由来する資格情報露出が残っていた。パッチを当てても資格情報は無効化されない。

DFIR — 「侵害後に顧客側がやり直すこと」が論点になった

前週の中心は配布インフラの侵害だったが、今週はAI の委託構造が経路として定着した。推論委託先の侵害で国内 SaaS 3社が流出可能性を公表し、顧客の相談内容まで対象に入った。Microsoft の agent-framework は PyPI 上で汚染版が公開され、Python 起動のたびに Azure と CI/CD の資格情報を抜いた。Hugging Face では Kokoro（月1,300万DL）が放棄ドメイン1つで公開者アカウントを取られ、重みだけが87秒で改変された。

防御アーキテクチャ — WAF が「当面の盾」として前に出た

Cloudflare は ruby2shell と phpAfterShell の規則を無料プランまで配布したうえで、WAF は代償制御でありパッチの代わりにはならないと明記した。PHP2Shell の初期の標的がファイアウォールの管理画面だった事実は、守る側の装置も Web アプリであるという前提を突いている。

→ ①境界機器とセキュリティ製品の管理画面を公開面から外す②WAF 規則を「適用済み」の記録と分けて管理する③エージェント専用IDと短命権限へ移す。

脅威インテリジェンス — 「正規の通信先に紛れる」設計が標準になった

宛先ベースの検知を前提にした運用が正面から崩されている。HTTP/3（QUIC）を C2 に使う例、SharePoint・GitHub・Ably を使う Operation ShadowCloud、C2 をSolana のトランザクションに埋める UAT-12643、正規の OSS VPN を改造して政府機関に常駐する Webworm、外部の指令サーバを持たない Turla の Cereal が同じ週に並んだ。

→ ①宛先レピュテーションではなくプロセス系譜と認証イベントで検知する②正規 SaaS 宛通信のベースラインを取る③BADBOX 3.0 のように出荷時点で汚染された端末もある。

今週の安全保障サマリー

今週の変化は2つ。国家諜報の標的が「認証を信じる仕組み」そのものへ移ったこと。そして AI エージェントが補助役から、未知の脆弱性を見つけて侵入まで完遂する実行主体になったことである。 前週の論点は帰属の粒度と自動化の速度だった。今週はその速度が国家作戦の記録として確定し、同時に米国のサイバー統治に人事の空白が生じた。

1. 中国系の国家諜報が仮想化基盤の管理面を取り、SAML 署名鍵まで奪った

ARMORY CASTLE（旧 UNC5221）が VMware vCenter の認証回避（CVE-2026-123890・CVSS 9.8）を9月初めから2か月以上、修正が存在しない状態で悪用していた。前段は BeyondTrust Remote Support のゼロデイ（CVE-2026-102764）で、自製の Go 製ツールで内部 DB と SAML 署名の秘密鍵を持ち出した。

署名鍵を取られると、修正を当てた後も偽造された権限が有効なまま残る。パッチで閉じるのは入口だけで、鍵と証明書の再発行まで行わないと侵害は終わらない。日本では仮想化基盤の管理面が業務ネットワークから到達できる構成が珍しくない。CISA は11月20日に KEV へ入れ、是正期限を11月23日に置いた。
→ 事例「vCenter の認証回避」。

2. AI エージェントが作戦の実行主体になった——11分でゼロデイ、人の介在なしに窃取まで

中国系アクターの自律エージェントが医療画像ソフトの未知の脆弱性を11分で見つけ、root を奪った作戦記録が11月21日に公開された。Amazon は囮網で、中国系とみられるアクターがオープンソースの自律ペネトレーションテスト基盤を転用し、AI モデルの鍵を盗んで自分のエージェントの燃料にしていたのを捉えた。GTIG はパッチ公開前後のソースコードを継続比較して n-day 化し、窃取まで人の介在なしに到達した最初の事例を公表している（設定にロシア語のコメントが残る）。

作戦数の上限が要員の頭数から外れた。同じ予算で標的の幅が広がり、大使館・軍・大手以外の中堅組織まで射程に入る。中国の工業情報化部系 NVDB は公式の注意喚起に「AI モデルで利用コードと利用チェーンを素早く生成できる」という一文を入れた——公的機関が文書で AI による悪用加速を認めたのは異例である。
→ 事例「人の介在なしに発見から窃取まで」「自律ペンテスト基盤の国家系転用」。特集「誰の権限でエージェントは動くのか」。

3. 欧州では物理サボタージュと制度改編が同じ指揮系統の話として進んだ

エストニアのドローンメーカー Threod Systems への爆破・放火未遂を首相が「GRU の指示」と断定し、同国は12月1日から対露国境を全面閉鎖した。人の往来そのものをリクルート経路として断つ判断である。ドイツ軍は Quantum Systems の偵察ドローンを更新サーバ侵害の疑いで飛行停止にし、11月22日には連邦議会が戦後最大の情報機関改革を可決して BfV と BND に秘密作戦の権限を与えた。

→ 事例「ドローンメーカーへの爆破・放火未遂」。

→ 事例「COLD RELIC のなりすまし侵入」「軍事系ソフト企業社員への物理監視」。

北朝鮮系——停止措置に耐える設計と、人を介した商談への進出が同時に出た。UAT-12643 は C2 の宛先を Solana のトランザクションに埋め込む Overlord RAT を使い、テイクダウンでは止まらない。別系統では偽の建設会社を運営し、商談でリアルタイムのディープフェイクを使っている——IT 職以外の業種へ広がった。対抗側では FaceStealer の基盤押収と Binance 流出分27億ドルの凍結が進んだ。

地政学×サイバーの結節点

日本の公的基盤が同じ週に2つ破られた。理化学研究所のスーパーコンピュータ「富岳」はインターネット公開中の稼働状況ダッシュボードが入口になり、運用系が侵害されて運用停止に至った。流出の可能性は最大4,597名の登録情報にとどまらず、利用者が預けていた他機関への接続用 SSH 秘密鍵まで及ぶ。デジタル庁の政府共通基盤 GSS のファイル共有では、7月30日から11月12日までの3か月半、正規でない相手のアクセスが続いた可能性があり、25機関・約15万人が利用していた。いずれも「守る対象」の台帳が本番 Web だけを指す組織に同じ穴が残る。大崎電気工業のランサム被害はスマートメーターの生産・出荷を止め、計量インフラの部材供給が1社の事故で詰まることを見せた。
→ 事例「研究基盤運用系への侵入」「政府共通基盤のファイル共有」。

政策・法制度の動き

国内が最も動いた。古川デジタル大臣は高市総理の指示を受けてサイバー対処能力強化法の改正検討に入ったことを明かし、与党が求める「内内通信」（国内で完結する通信）を監視・分析の対象に含めるかが論点になると述べた。同大臣は業界団体に専門人材の派遣枠組みを含む3点を要請した。警察庁長官は2026年以降の大規模漏えい事案を一括して対象とする態勢指示を出し、GMOインターネットの事案に合同捜査本部を置いた。個人情報保護委員会は韓国の同委員会と越境データ移転と AI プライバシーを協力分野とする覚書を結んだ。日本版DBS の専用システムは脆弱性多数で12月25日の運用開始が延期されている。

Nvidia の前 CEO 辞任の一件は、帰属評価の難しさと対諜報の空白を同時に見せた。中心人物 Alice Huang の上海金融界の人脈と、米情報機関が中国国家安全部（MSS）の協力者と見ているという評価は裏付けが具体化した一方、CIA が持つ情報は彼女が中国情報機関のために動いていたことを証明していない。元 FBI 対情報部門長は「無名の下級エンジニアも数十人狙われているだろう」と述べている。11月21日には AI 業界のほぼ全員がハニートラップに弱いという指摘が公然と出た。狙われるのは経営者だけでなく秘書・取締役・投資担当まで含まれ、接近の形は恋愛よりも投資家・顧客・採用担当・コンサルという「書面上は正当な要求」が主である。日本の AI・半導体関連企業にそのまま当てはまる。

今週の技術トレンド

前週の主題は、自律型の侵入基盤が当局の公式警報の対象になり「適用済み」が安全の根拠から外れたことだった。今週はその次である。全組織に必ず入っている最下層が同じ週に当たり、資産台帳が「どこに何が入っているか」を答えられないことが露出した。そして AI は脆弱性を見つける側でも攻撃を回す側でも速度の実測値を出し、守る側の律速が「適用」から「判断」へ移った。

1. 言語処理系・Web サーバ・仮想化基盤が同じ週に当たり、「版の一覧」が無力だと分かった

Java 実行環境（Java4Shell／CVE-2026-114938・CVSS 4.0 で 9.2）、nginx の HTTP/2（NGINX2Root 5件・CVE-2026-123007 ほか）、PHP 18件（Critical 7件・PHP-FPM の CVE-2026-129289）、Ruby 7件（ruby2shell／CVE-2026-132825）、そして VMware vCenter の認証回避（CVE-2026-123890・回避策なし）が同じ週に並んだ。Oracle の11月 CSPU は655パッチ・948 CVE、Microsoft は1,252 CVE、Chrome は204件である。

重いのは件数ではなく「影響版の一覧では露出が決まらない」ことである。Java4Shell は影響版・CPU が AVX-512 VBMI 対応か・攻撃者由来の Base64 を復号するアプリがあるかの3条件が揃って初めて露出し、ディストロのパッケージは版数上は新しく見えても脆弱という罠がある。既定構成で事前認証 RCE が実証されたのは Keycloak・Jira・Confluence・Jenkins で、いずれも「Java を入れた覚えのない」運用主体が管理している。nginx の欠陥は2015年の 1.9.5 から存在し、同じ CVE-2026-123007 が Synology にも影響して版によって修正が未提供である。

設計の宿題は資産台帳の粒度にある。SBOM が示すのはライブラリ名と版で、ベンダーが同梱した実行環境や、CPU 命令セットに依存する露出条件は表現できない。副作用も出た。高深刻度の公表に反応して運用を止める判断が繰り返され、「-shell が無視される日」という警告疲れが今週すでに指摘されている。
→ 事例「Java4Shell」「nginx HTTP/2 の整数アンダーフロー」「PHP 全サポート版の緊急修正」。

2. AI による脆弱性発見のコスト曲線が折れ、同時に「結果が揺らぐ」ことも数字になった

Forescout は市販モデルと自作ツールで 10の TCP/IP スタックの解析を9か月から90時間に縮め、99件（うちゼロデイ66件）を見つけた。費用は静的解析で約935ドル、1件あたり2.58ドルである。Xint の報告では、2026年初頭には見つけられなかったゼロデイが数ドル・15分以内で見つかる。nginx の5件のうち4件は90分の解析で自律的に発見されたもので、Calif は1時間で Java4Shell を発見し2時間で利用チェーンを作った（実装費用200ドル）。

ただし同じ材料から同じ答えが出ない。Echo の比較では、同一コードを3つのフロンティアモデルに監査させた121件の指摘のうち全モデル一致は1件だけだった。Dragos は ICS レンジで保護リレー系のゼロデイ2件を見つけた一方、試験中の機器を2度、意図せず停止させている。発見は安くなったが、検証と再現は人の側に全部残る。

供給が増え、需要側の処理能力は増えていない。Linux の CVE は1日平均27件でレビューの担い手が足りず、AI が書いたパッチが攻撃の地図になる事例も具体化した——vm2 の34件の修正のうち19件を Claude が共作し、数週間後に研究者が AI エージェントで迂回に成功している。開示猶予も構造的に縮む。Google Project Zero は2027年に60日・2028年に30日へ、Anthropic は2027年から重大・高リスクを30日へ短縮する。ベンダーの猶予が減れば、利用側が当てるまでの猶予も同じだけ減る。

3. 攻撃側エージェントの速度が実測値になり、人を直列に挟む設計が成立しなくなった

AI エージェント型の攻撃フレームワークは、個別事案の報告から全体像の整理へ移った。Shadowserver は露出インスタンスを3,847件（ARTEX 2,852件）観測し、ReversingLabs は11の派生系と3,147件のホスティング IP を整理した。実測値は、Barracuda で委託先に渡して失効させていなかった鍵から44時間で10クラウドアカウント横断、別の事案で侵害から深部到達まで15分・23秒間に27件の操作、PaperCut を4日で突破した事例は26秒で11組織、最終的に395組織である。欧州委員会は10月22日検知の攻撃でフレームワークの関与を認め、Bell Canada は「agentic な脅威アクター」による法人顧客データ窃取を公表した。

応変の記録も初めて具体的に出た。Eye Security の対応では削除した悪性 Pod が1秒後に再作成され、防御側も AI で調査を加速して時間を詰めた。SOC の猶予は半分になり、「L1 が開く前に終わっている」。一方で AI エージェント起点の検知は手がかりが人起点の2.5倍出るという観測もあり、材料はむしろ増えている。

設計上の変更点は3つ。①修正の既定を自動適用に寄せ、外向きのシステムには時間単位の期限を置く。②相関窓を伸ばし、送信元 IP や User-Agent ではなく行動で束ねる。③調査に「本人か、エージェントが勝手にやったのか」の切り分けを加える。信頼されたエージェントの正常な動作が攻撃の兆候と区別できない「良性の真陽性」は、今週実務の言葉として整理された。
→ 事例「欧州委員会への AI 駆動攻撃」「製品ベンダーのクラウド環境の侵害」。特集「誰の権限でエージェントは動くのか」。

4. AI の供給網が「委託先」として破られ、プロンプトと重みが新しい機密になった

今週もっとも重いのは推論の委託先である。OpenRouter は3つの推論プロバイダを切り離した——内部から数か月にわたり利用者のプロンプトが盗まれており、盗まれた要求の一部には「保存しない（ZDR）」設定が付いていた。データ保護が設定ではなく運用で担保されている現実が露出した形である。Dragos は AI へ送った約200万件のカナリアトークンを追跡し、少なくとも3事業者からの漏出と、米国事業者へ出したプロンプトが中国の組織へ送られていた事例を観測した。

配布経路の側も同じ週に3件破れた。Microsoft の agent-framework は PyPI 上で汚染版が公開され、Python 起動のたびに Azure と CI/CD の資格情報を抜く作りだった。Hugging Face では月1,300万ダウンロードの Kokoro が放棄ドメイン1つで公開者アカウントを掌握され、重みだけを87秒で改変された。Optimizely 経由の改ざんでは178組織のサイトに悪性 JavaScript が配られ、攻撃者は1日に26回ペイロードを作り直して A/B テストのように配信を最適化していた。

重みの中身は SBOM では見えない。50ドルの LoRA 微調整で埋め込んだバックドアは標準の評価を通過することが検証され、11月22日には配備前に重みの静的解析とトリガー復元で検出する2段構えの手法が示された。検査手段が与えられた以上、「標準の評価を通ったから安全」はもう根拠にならない。モデルとアダプタの受け入れ検査を調達要件に書く段階である。公開イメージに残した API キーは7.86秒で使われるという実測も出た。
→ 事例「推論プロバイダからのプロンプト窃取」「agent-framework の汚染版」「公開者アカウント掌握によるモデル改変」「A/B テスト基盤経由の大規模改ざん」。

5. 防御側は「エージェントを構成要素として織り込む」方向へ揃ったが、強制点はまだ代償制御である

Microsoft Ignite 2026 の発表（Perception・Windows endpoint security platform・Server 2028・Edge Lockdown Mode。詳細は下の一覧）に共通するのは、攻撃面の削減とカーネル依存の縮小が明示的な選択肢として製品に入ったことである。統制面では、エージェントをインサイダー脅威として扱う検知、エージェント専用 ID と短命・最小スコープの権限付与、静的なアクセス判断から継続的な再評価へという3点が出そろった。

ただし今週の「盾」の主力は WAF だった。Cloudflare は ruby2shell と phpAfterShell の規則を無料プランまで既定 Block で配布したうえで、WAF は代償制御でありパッチの代わりにはならないと明記している。守る側の装置自体も Web アプリであり、PHP2Shell の初期の標的が PAN-OS の管理画面だったこと、F5 BIG-IP・Splunk SOAR・WatchGuard が緊急修正に回ったことがそれを裏づけた。

「仕様が強いから安全」という前提も崩れた。パスキー対応103サイトの検証では WebAuthn が義務付ける全基準に合格したサイトは1つもなく、5サイトは暗号署名の検証そのものを行っていなかった。AI アシスタント自体も攻撃面で、悪性ウェブページ1枚で Meta Muse の会話と記憶が承認プロンプトなしに抜けた。情報窃取マルウェアが奪った「ログイン済みセッション」では、パスワード変更と2段階認証を済ませても AI サービスが不正利用される。
→ 事例「AI エージェントによる会話・記憶の抽出」。

  • 耐量子移行が「実証」と「期限」の両方で動いた。 NEC と日本 IBM が QKD と PQC のハイブリッド実証に成功し、米 GSA は PIV カードで PQC を適用、NIST はガイダンスを確定、韓国は移行目標を2031年へ前倒しした。AI の数学的進展が既存の公開鍵暗号への信頼を損なう確率を論じる議論も始まっており、期限は前倒しされる側に動いている。
  • エージェント基盤の実装面の穴が同時に複数出た。 MCP のツール毒化、LiteLLM の認証バイパス、FastMCP の経路横断から認証つき SSRF（3.2.0 で修正）、Docker Model Runner の引数インジェクションからホスト脱出。シャドー API のモデル偽装では17サービスが査読論文116本で使われており、「どのモデルで評価したか」が検証できない。
  • AI 生成コードが本番へ直通している。 Lovable 製アプリの7,000超のデータベースに権限設定不備が見つかった。レビューではなく既定値の安全性が効く局面である。
  • 既定値が守りを崩す例が3つ並んだ。 USB トークンから秘密鍵が抽出できるのは属性設定の問題（CKA_EXTRACTABLE を疑う）で、国内の電子証明書運用に直接響く。Android の VPN スプリットトンネリングは仕様上 kill-switch と両立しない。Kubernetes の組込みサブジェクトの広すぎる権限は65,000クラスタの実測で裏づけられた。
  • 自覚せず呼んでいる変換経路が攻撃面になる。 Ghostscript のサンドボックス脱出でアップロード経路から RCE に至る。アプリが意識せず呼ぶ経路の棚卸しが課題である。

中長期に効く変化（CTO 向け示唆）

① 資産台帳を「実行時の条件」まで降ろす。 Java4Shell は影響版・CPU 命令セット・アプリの入力経路という3条件で露出が決まり、ディストロのパッケージは版数上は新しく見えても脆弱だった。SBOM はベンダー同梱の実行環境も、モデルの重みの中身も表現できない。台帳に「どの製品が何の言語処理系を同梱しているか」「どのモデルとアダプタをどこから受け入れたか」の2列を足す作業が、今後1年の対応精度を決める。

② AI 基盤を委託先として契約・鍵・ログの3点で管理する。 推論プロバイダの内部からプロンプトが数か月盗まれ、「保存しない」設定が守られていなかった週である。推論基盤・エージェント実行環境・コード支援ツールを委託先管理の枠（報告義務・鍵の失効手順・実行記録の保持とマスキング）へ正式に入れる。プロンプトとトレースは機密の二次倉庫である。

③ 対処の速度を機械側に合わせ、人の判断は事前に済ませる。 15分で深部到達、26秒で11組織という速度に対し、検知から遮断までを人が順に判断する設計は成立しない。自動対処の既定化・外向きシステムの時間単位の期限・「止める権限」の事前合意を平時に決める。

④ 優先順位を母数に耐える形へ切り替え、警告疲れの基準を先に決める。 公開 PoC の91%が48時間以内に実戦投入され最短35分という前提では、CVSS を基準にした月次サイクルは成り立たない。「悪用確認 × 外部到達性」で切り、修正が提供されない構成（OT 製品・EOL・別配布のモジュール）は隔離・置換の別予算に分ける。あわせて「名前が付いた脆弱性のうち何に反応するか」の社内基準を文書化しておく。

⑤ 検証の処理能力を設計対象にする。 脆弱性の発見は1件2.58ドル・15分まで下がったが、同じコードで3モデルの指摘が一致したのは121件中1件で、検証と再現は人の側に残る。開示猶予が30日へ縮む2028年までに、自社が1週間に検証・適用できる変更の量を数字で把握し、それを前提にアーキテクチャ（止めずに当てられる構成、外部到達面の削減）を組み替える。生成量ではなく検証の処理能力が律速である。

§3. アクター間の関係の動き

道具の共有が今週も最大の関係である。 ARTEX は作者が10月8日に取り下げたあとも拡散が続き、Cloudflare は関連コードを置くリポジトリが1.2万超・うち数百が改変派生、Spectrum は公開網の管制卓2,335台のうち78%が ARTEX 系と報告した。ReversingLabs は11の派生系を整理した。同じ基盤を国家系（Storm-0940）と金銭目的（Storm-3358）の双方が採用しており、使った道具は帰属の根拠にならない。

中国系では請負業者の層が見えてきた。 ZRON リークのコード解析は、宣伝された広範な能力に対し実装の多くがオープンソース依存である一方、政府顧客向けに窃取データを収集・翻訳・報告書化する業務は活発に回っていたと結論づけた。GTIG も、中国の請負業者が LLM で窃取データを翻訳・精査して顧客に販売していた事例を確認している。攻勢能力が「高度なマルウェア」ではなく「情報処理の下請け産業」として層をなしているという見方の裏づけになる。ShadowCloud には中国語圏の FamousSparrow・CopperTurtle と同じ作業フォルダを使った形跡が報じられた（帰属は未特定）。

イランではアクセスの受け渡しが構造化されている。 AttackIQ はイランの国家支援型20グループを分析し、諜報目的の侵入で得たアクセスが別のグループへ引き渡され、ランサムウェアやハクティビズムの外形をとる破壊的攻撃に転用される構造を示した。初期侵害を「情報が抜かれた事案」として閉じると、数週間後に別の実行主体が同じ足場を破壊目的で使う。 残存アクセスの全面無効化までが封じ込めになる。

恐喝側はクラスタが増え続けている。 Unit 42 は Com 系のビッシング波に CL-CRI-1264（Vortex）・CL-CRI-1274（Cinder）を追加し、2つは Google が UNC6671 として追跡する活動と重なる。固定した組織ではなく手口と調達先を共有する緩い集合で、1つを摘発しても別の名前で続く。

§4. ランサムウェア・リークサイト動向

日本の組織の掲載は3件。 11/16 に SEKISUI HOUSE, LTD（群 metaencryptor・製造）、11/19 に CENTERED CO., LTD.（群 incransom）、11/20 に wakao.co.jp（群 blackout）。加えて計測制御機器の大崎電気工業が11/17 にサーバの暗号化を確認し、埼玉事業所と生産関連子会社のシステムを停止、スマートメーターの生産・出荷が止まった（Qilin への掲載は第三者の監視サイトが確認。同社は攻撃者について述べていない）。 → 詳細は事例レポート「大崎電気工業のランサムウェア被害」

この1件は供給網の形で他社に波及する。 スマートメーターは電力会社の計量・遠隔検針の部材で、供給が止まれば設置計画と故障交換が滞る。自社の防御では避けられないリスクで、長納期部材の単一供給先依存と納入業者の通知義務の確認に直結する。

海外の偏りは、業種では医療・製薬・法務、ブランドでは分散である。 目立ったのは Vortex（11/17 に6件・11/19 に9件。Caris Life Sciences 2,143万件、Molex 1,644万件）、n0n（台帳は dan0n。11/16 に13件・製薬と金融）、Inception（AMD・PepsiCo・Lucid Motors）、thegentlemen（AARP・NVIDIA）である。四半期統計も分散を示す。Check Point は第3四半期の公開被害を2,830件（過去最高）とし上位10グループのシェアは3期連続で低下、Dragos の産業向け集計は1,266件（前期比11%増）で製造876件（69%）、Qilin と The Gentlemen で362件（29%）だった。

注意が2つある。 ①群名に Barracuda を称するものが現れた（11/20・11/21）。同名のベンダー Barracuda Networks のクラウド侵害とは別の話で、社内の情報共有で混同しないこと → 「Barracuda のクラウド環境侵害」。②掲載は攻撃者側の主張で、被害組織の公表と一致しないことがある。 NVIDIA は掲載に対し自社システムへの影響の兆候は無いと答えている。

§5. 予測（実験的）

①vCenter の「適用済みなのに侵害済み」が国内で公表される（確度 中）。 悪用は9月初めまで遡り、署名鍵を奪われた組織はパッチでは戻らない。12月から年明けに「修正適用後に不正な SSO 管理者が見つかった」形の公表が出る見込みで、鍵の再発行を終えていない組織が年末年始の保守の谷で再侵入される経路が最も現実的である。

②公開 PoC の武器化はさらに前倒しされる（確度 高）。 CrowdStrike の観測では2026年上半期に悪用が確認された脆弱性の91%が48時間以内に武器化され、最短は PoC 公開から35分だった。GTIG はパッチ差分から攻撃コードを自動生成する exploit_agent を確認している。12月のパッチ公開直後の悪用が、国内でも月次パッチ会議の周期を破る形で出る。 → 特集「誰の権限でエージェントは動くのか」

③台湾の11月28日地方選に合わせた情報工作が山を作る（確度 高）。 台湾当局は中国系とみられる Threads アカウント約2,700件を Meta に通報し、ほぼ全てが直近の開設だった。1つのプラットフォームで大量開設し、検知される前に選挙期間を走り切る運用で、日本の選挙期にも同型が使える。

④イラン系の破壊的作戦が OT の露出面で広がる（確度 中〜低）。 冷蔵制御器への攻撃は最大13か国へ拡大し、日本の小売・物流・病院・製薬の冷蔵設備も構成は欧州と変わらない。ただし日本を標的とする観測は今週も無く、業種と機器構成の重なりだけを根拠にした推論である。

⑤北朝鮮の受注型が IT 以外の業種へ届く（確度 中）。 偽の建設会社がリアルタイムのディープフェイクで商談に出た事例が公表された。マルウェアを配らず契約を取りに来る形で、「北朝鮮の遠隔労働者」が警戒対象になっていない建設・設備・設計委託の分野が次の接触先になる。
